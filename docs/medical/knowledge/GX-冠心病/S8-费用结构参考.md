## S8 费用结构参考
用途：供费用解释段、费用基线参考引用；不写任何具体金额与自付比例阈值，异常判定基准来自理赔数据集；不生成"多收费/费用异常"结论。

- **ID**：GX-S8-01
- **适用范围**：PCI住院病例
- **内容**：PCI住院费用构成大类：手术操作费（造影+介入手术）、耗材费（支架/球囊/导引导管/导丝/造影剂等，通常占比最高）、药费（双抗、他汀、围手术期抗凝与辅助用药）、检查检验费（心电图、肌钙蛋白、心脏彩超、化验）、床位护理监护费（含CCU监护天数）。耗材条目与手术记录一一对应，可逐项解释。
- **锚定**：费用清单科目、手术记录（支架/球囊数量与型号）
- **用途**：费用解释段 / 费用基线参考
- **来源**：《中国经皮冠状动脉介入治疗指南》（诊疗项目构成口径）；理赔费用清单常见结构
- **状态**：draft-待医学审核

- **ID**：GX-S8-02
- **适用范围**：跨年份费用解读情境
- **内容**：支架集采与年份口径敏感：冠脉支架纳入国家组织集中带量采购，2020年11月开标、2021年1月起落地，支架均价从约1.3万元降至700元左右（降幅约93%），2022年完成接续采购【年份口径待医学审核确认】；住院费用结构从"耗材主导"部分转向操作、药品与监护，集采前后（以2021年为界）费用不可直接比较。不同年份、地区、医院等级的费用口径差异很大，跨年份或跨院比较费用必须标注时间口径，避免得出"费用下降=治疗缩水"或"费用高=多收费"的误读。
- **锚定**：费用发生年份（入院日期）、医院级别/地区信息
- **用途**：费用解释段 / 费用基线参考
- **来源**：国家组织冠脉支架集中带量采购政策（公开政策信息）
- **状态**：draft-待医学审核

- **ID**：GX-S8-03
- **适用范围**：手术耗材条目解读情境
- **内容**：药物涂层球囊与新器械提示：部分病例以药物涂层球囊（DCB）替代支架，或使用腔内影像学（IVUS/OCT）、功能学评估（FFR）等新技术，耗材条目名称与常规PCI不同、单个条目价格结构也不同；这些条目的出现属正常技术选择，报告可向患者解释"为什么这笔账单里没有支架、却有球囊/评估项目"。
- **锚定**：手术记录中的耗材名称与数量、费用清单耗材明细
- **用途**：费用解释段 / 检查疑点标签
- **来源**：《中国经皮冠状动脉介入治疗指南》（器械选择口径）
- **状态**：draft-待医学审核

- **ID**：GX-S8-04
- **适用范围**：急诊与择期费用分层情境
- **内容**：急诊PCI与择期PCI费用差异：急诊PCI（STEMI/高危NSTE-ACS）通常费用更高——急诊手术时段、CCU监护天数更长、围手术期抗栓与辅助用药更多、重症时可能使用IABP等辅助装置。费用高与病情复杂度匹配时属合理现象，解读必须先分层（急诊 vs 择期）再比较，不得以择期基线评价急诊账单。
- **锚定**：入院方式（急诊/门诊）、诊断分型（STEMI/NSTE-ACS/稳定性）、是否CCU/ICU、辅助装置记录
- **用途**：费用解释段 / 费用基线参考
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》（再灌注策略口径）
- **状态**：draft-待医学审核

- **ID**：GX-S8-05
- **适用范围**：仅造影未植入支架病例
- **内容**：造影未植入支架病例的费用结构：仅行冠脉造影（药物路径或CTA后确诊）的住院，耗材占比低、总费用明显低于植入支架的病例；费用解读前应先从手术记录确认是否植入支架/球囊，防止把"没放支架"误读为"治疗不彻底"，也防止用PCI病例基线评价造影费用。
- **锚定**：手术记录（有无支架植入）、费用清单耗材明细
- **用途**：费用解释段 / 费用基线参考
- **来源**：《中国稳定性冠心病诊断与治疗指南》（治疗路径口径）
- **状态**：draft-待医学审核

- **ID**：GX-S8-06
- **适用范围**：结算口径说明情境
- **内容**：口径说明：费用清单常见"总费用=医保统筹/基金支付+个人支付"；个人支付内部又分"自付"（医保目录内个人承担部分，含起付线与共付段自付比例）与"自费"（目录外项目）。费用解读必须区分"总费用"与"个人实际支出（自付+自费）"，防止用户把总费用误认为自己的负担。
- **锚定**：费用清单结算字段（总费用、统筹支付、个人自付、自费）
- **用途**：费用解释段
- **来源**：理赔费用清单常见结算口径（行业通行结构）
- **状态**：draft-待医学审核

- **ID**：GX-S8-07
- **适用范围**：自付异常提示情境
- **内容**：自付比例异常的判定基准来自理赔数据集的分层统计（病种、路径、地区、年份口径），本知识包不提供金额或比例阈值；本包仅提供"该类病例费用构成应包含什么、如何按急诊/择期与造影/PCI分层理解"的结构参考，供异常提示触发时解释成因，不判定异常。
- **锚定**：费用清单、入院方式与手术类型、理赔数据集基线（外部数据，非本包）
- **用途**：费用基线参考
- **来源**：理赔数据集口径（由数据侧提供，本包不定义）
- **状态**：draft-待医学审核

- **ID**：GX-S8-08
- **适用范围**：出院后长期费用情境
- **内容**：长期药费提示：出院后的持续性支出主要是长期药物（双抗＋他汀＋降压/降糖药等）与复查检验；报告可提示"长期规律服药与复查是二级预防的基础，如有费用压力可与医生沟通选择目录内替代方案，但不得自行减停"，不评价任何金额高低。
- **锚定**：出院带药清单（长期药品种数）、随访购药记录（如有）
- **用途**：费用解释段 / 长期随访加分项
- **来源**：《中国经皮冠状动脉介入治疗指南》（二级预防用药框架）
- **状态**：draft-待医学审核
