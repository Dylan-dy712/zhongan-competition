## S11 手术与检查通俗解释
用途：为治疗回顾段提供过程级通俗解释。总边界同各包 S11：只解释目的与过程；不评价该患者手术/检查是否必要、成功与否；过程为"一般情形"，与病例事实冲突时不引用。

- **ID**：GX-S11-01｜心电图（含动态心电图）
- **适用范围**：胸痛评估、随访通用
- **内容**：是什么：在胸口手脚贴电极片，记录心脏的"电流活动"，几分钟完成无痛。能看什么：心律、心率、有无心肌缺血或梗死痕迹。动态心电图（Holter）是随身佩戴24小时以上连续记录，用于捕捉间歇发作的心律失常。为什么做：胸痛/心悸的第一步检查。
- **锚定**：检查医嘱/报告
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：GX-S11-02｜肌钙蛋白检测
- **适用范围**：疑诊急性冠脉事件
- **内容**：是什么：抽血查心肌受损时释放到血里的"标志物"，是判断有无心肌损伤最敏感的指标。怎么做：静脉抽血，常需间隔数小时复查2次看变化趋势。为什么做：区分心绞痛与心肌梗死的关键依据之一。注意：数值升高也可见于其他心肌损伤情形，由医生结合心电图解读。
- **锚定**：检验报告（数值与时间）
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南（2019）》
- **状态**：draft-待医学审核

- **ID**：GX-S11-03｜冠脉造影（CAG）
- **适用范围**：疑诊或确诊冠心病的"金标准"检查
- **内容**：是什么：从手腕（桡动脉）或大腿根（股动脉）穿刺送入细导管，向冠脉注射造影剂并在X光下"给心脏血管拍电影"，直接看血管哪里窄了。怎么做：局部麻醉、穿刺点仅一个小口，全程清醒，约15-40分钟；术后穿刺点加压包扎。患者会经历：注射造影剂时可能有一过性全身发热感（正常现象）。
- **锚定**：手术/操作记录（入路、结果）
- **用途**：治疗回顾段 / S1诊断解释段
- **来源**：《中国经皮冠状动脉介入治疗指南（2025）》
- **状态**：draft-待医学审核

- **ID**：GX-S11-04｜PCI（球囊扩张+支架植入）
- **适用范围**：冠脉严重狭窄的开通治疗
- **内容**：是什么：在造影基础上，把细导丝送过狭窄段，用球囊撑开血管，再植入金属支架把血管"撑住不回缩"，多与造影一次完成。患者会经历：与造影相似，术中偶有胸闷；术后需按医嘱长期抗血小板治疗（衔接 GX-S4-03 双抗疗程）。边界：解释过程不等于承诺疗效。
- **锚定**：手术记录（支架数量、部位、入路）
- **用途**：治疗回顾段 / S1诊断解释段
- **来源**：《中国经皮冠状动脉介入治疗指南（2025）》
- **状态**：draft-待医学审核

- **ID**：GX-S11-05｜冠脉CTA
- **适用范围**：中低危疑诊者的无创评估
- **内容**：是什么：CT血管成像——注射对比剂后做CT，重建出冠脉三维图像，看有无钙化斑块与狭窄。怎么做：静脉留置针注射对比剂后扫描，约10-20分钟；需评估肾功能与过敏史。为什么做：无创排查；阴性预测价值高，必要时仍需造影进一步确认。
- **锚定**：检查医嘱/报告
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《中国慢性冠脉综合征患者诊断及管理指南（2024）》
- **状态**：draft-待医学审核

- **ID**：GX-S11-06｜心脏彩超（超声心动图）
- **适用范围**：评估心脏结构与泵血功能
- **内容**：是什么：用超声波给心脏"拍动态影像"，看心脏腔室大小、瓣膜开合和泵血能力（射血分数LVEF）。怎么做：胸口涂耦合剂用探头扫查，10-20分钟，无痛无辐射。
- **锚定**：检查报告（LVEF值）
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：GX-S11-07｜运动负荷试验
- **适用范围**：心脏康复评估/缺血排查
- **内容**：是什么：在平板跑步机或踏车上按方案逐级加量运动，同时记录心电图与血压，看心脏"加负荷后"的表现，是心脏康复前评估运动安全的常用手段。怎么做：约10-20分钟，全程有医护人员监护，出现胸痛头晕等不适即停止。注意：是否适合做由医生评估。
- **锚定**：康复评估医嘱
- **用途**：治疗回顾段 / 康复计划段
- **来源**：《中国心脏康复与二级预防指南（2018年版）》
- **状态**：draft-待医学审核
