## S2 术语通俗对照
用途：术语解释动作——理赔材料中出现下列术语时查表生成通俗解释；部分条目同时供诊断解释段、检查/用药疑点标签引用。

说明：本节按槽位定义采用表格形式。每行是一个条目，逐条字段（ID、术语/常见写法、通俗解释、患者为何困惑、用途）在表中列明；统一字段以表后"公共字段声明"为准，与全文统一列表字段等效。

| ID | 术语/常见写法 | 通俗解释 | 患者为何困惑 | 用途 |
|---|---|---|---|---|
| GX-S2-01 | 冠心病/冠状动脉粥样硬化性心脏病/缺血性心脏病 | 供应心脏自身血液的冠状动脉内壁长出斑块，血管变窄变硬、心肌供血不足所引起的疾病 | 名称长且相似词多，患者常把"冠心病"与"心衰""心律失常"混为一谈，也不理解没有症状怎么也算冠心病 | 术语解释动作 / S1诊断解释段 |
| GX-S2-02 | 心绞痛（稳定型/劳力性心绞痛） | 心肌暂时缺血缺氧引起的胸痛胸闷压迫感，典型在活动、饱餐、受凉、情绪激动时出现，休息或含服硝酸甘油后几分钟内缓解 | 很多人的"心绞痛"并不表现为痛，而是闷、紧缩、烧灼或只是气短，患者以为"不痛就不算"；女性和老年人还常见牙床、上腹、咽部等不典型部位 | 术语解释动作 / S1诊断解释段 |
| GX-S2-03 | 不稳定型心绞痛（UA/恶化型/静息心绞痛） | 心绞痛变得"不稳定"：静息或轻活动就发作、发作更频繁、程度更重、持续更久，提示斑块不稳定、可能进展为心肌梗死，需尽快就医评估 | 患者容易当成"还是老毛病"，意识不到发作规律的改变本身就是危险信号 | 术语解释动作 / S9相关（就诊提示） |
| GX-S2-04 | 急性心肌梗死（AMI/心梗/梗死面积） | 供应某块心肌的冠状动脉被血栓突然完全堵住，心肌持续缺血发生坏死；坏死的心肌不能再生，时间越久坏死范围越大，所以抢救强调"时间就是心肌" | 分不清"心绞痛"（一过性缺血）与"心梗"（心肌坏死）的本质区别，不理解为什么强调打通血管的黄金时间 | 术语解释动作 / S1诊断解释段 |
| GX-S2-05 | STEMI/ST段抬高型心肌梗死 | 心电图上ST段抬高提示一支冠脉被完全堵死、心肌全层缺血坏死，是最严重的一类心梗，需要最紧急的再灌注治疗（急诊支架手术或溶栓） | 看不懂心电图术语，不理解"ST段抬高"几个字为什么意味着要马上手术 | 术语解释动作 / 检查疑点标签 |
| GX-S2-06 | NSTEMI/非ST段抬高型心肌梗死 | 心肌已有坏死（肌钙蛋白升高）但心电图没有ST段抬高，通常是血管没有完全堵死或有侧支供血；危险性仍然高，医生按危险分层决定尽快或择期造影 | 患者常以为"没有ST抬高就不严重"，不了解这类心梗同样需要及时评估处理 | 术语解释动作 / 检查疑点标签 |
| GX-S2-07 | 急性冠脉综合征（ACS） | 不稳定斑块破裂引起急性缺血的一组疾病的统称，包括不稳定型心绞痛、NSTEMI和STEMI，代表"可能随时发生更严重心脏事件"的状态 | 容易当成单一病名，不理解它是三种情况的统称、三者处理节奏不同 | 术语解释动作 / S1诊断解释段 |
| GX-S2-08 | 慢性冠脉综合征/稳定性冠心病（CCS） | 病情相对平稳的冠心病阶段：症状可预测、可控，治疗以长期药物加危险因素管理为主，必要时择期评估是否介入 | 是较新的叫法（旧称"稳定性冠心病"），患者不理解它与"急性冠脉综合征"的对应关系 | 术语解释动作 |
| GX-S2-09 | 动脉粥样硬化/粥样斑块（软斑块/钙化斑块） | 血液中的脂质等成分沉积在动脉内壁形成"斑块"，使血管变窄、弹性变差；脂质多的软斑块容易破裂，钙化斑块相对稳定但也使血管变硬 | 患者常问"斑块能不能化掉"，也不理解"钙化"既提示老化又可能意味着斑块相对稳定 | 术语解释动作 |
| GX-S2-10 | 不稳定斑块/易损斑块/斑块破裂/斑块糜烂 | 纤维帽薄、脂质核心大的斑块，容易在某些诱因下破裂；破裂后血液成分接触斑块内容物、迅速形成血栓——这是多数急性心梗的直接起点 | 患者常以为"血管堵到最严重才危险"，实际上未必最窄的斑块最危险：不稳定斑块即使只造成轻中度狭窄也可能突发心梗 | 术语解释动作 / S1诊断解释段 |
| GX-S2-11 | 血栓形成/冠脉内血栓/血栓抽吸 | 血液在血管内凝固形成的"血块"。冠脉内血栓多在斑块破裂处形成，可在瞬间阻断血流；急诊手术中可用抽吸导管尝试把血栓吸出 | 患者不理解为什么既要长期"抗血小板防血栓"，又要同时警惕"出血"——这正是抗栓治疗的两面 | 术语解释动作 / 用药疑点标签 |
| GX-S2-12 | 冠状动脉造影（CAG/冠脉造影/冠造） | 判断冠脉狭窄部位与程度的"金标准"：从手腕（桡动脉）或大腿根（股动脉）的动脉送入细导管到冠脉开口，注入造影剂在X线下显影；必要时可同期衔接球囊扩张和支架植入 | 常见担忧是"造影会把斑块捅掉""造影剂伤肾"；它是有创检查，但也是介入治疗的第一步，多数患者检查与治疗一次完成 | 术语解释动作 / 检查疑点标签 / 费用解释段 |
| GX-S2-13 | 冠脉CTA/冠状动脉CT血管成像 | 无创的冠脉成像：静脉注射造影剂后用CT重建冠状动脉图像，适合中低危人群的排查与随访；提示显著狭窄时通常仍需造影进一步确认和处理 | 患者常混淆CTA（无创筛查）与造影（有创诊断+治疗），以为做过CTA就不必造影，或反过来觉得CTA"白做" | 术语解释动作 / 检查疑点标签 |
| GX-S2-14 | PCI/经皮冠状动脉介入治疗/支架植入术/冠脉支架术 | 通过手腕或大腿根的动脉把球囊和支架送到狭窄处，先充气球囊撑开血管，再植入金属支架维持通畅；局部麻醉，手术通常一小时内左右完成【数值待医学审核】 | 最常见的疑问是"支架能用几年""放了支架是不是就痊愈了"；支架解决的是这一处狭窄，全身的动脉粥样硬化仍要靠长期药物和生活方式管理 | 术语解释动作 / S1诊断解释段 / 费用解释段 |
| GX-S2-15 | 药物洗脱支架（DES）/金属裸支架（BMS）/生物可吸收支架 | 目前主流的支架表面涂有缓慢释放的防增生药物，可降低再狭窄；裸支架无药物涂层；可吸收支架可在体内逐步降解。支架类型直接影响术后双抗疗程长短 | 患者多数不知道自己放的是哪种支架，也就不明白"为什么别人的双抗吃短些、我的吃久些" | 术语解释动作 / 用药疑点标签 |
| GX-S2-16 | 球囊扩张/PTCA/预扩张、后扩张 | 用可充气的球囊在狭窄处把血管撑开，可作为支架植入前的准备（预扩）、植入后的整理（后扩），也可单独完成而不放支架 | 手术记录里大量英文缩写和反复出现的"扩张"字样，让患者误以为自己被做了多次手术 | 术语解释动作 / 治疗回顾段 |
| GX-S2-17 | 药物涂层球囊（DCB） | 表面涂药的球囊，撑开血管的同时把药物留在血管壁上，随后球囊撤出、体内不留置支架；部分病例用它替代支架（如小血管、分叉病变、支架内再狭窄等情境） | 患者听说"做了手术却没放支架"会困惑，甚至误解为"手术没做成功"；这是正常的技术选择 | 术语解释动作 / 费用解释段 |
| GX-S2-18 | 桡动脉入路/股动脉入路/经皮穿刺 | 手术器械进入血管的通路：手腕桡动脉（术后压迫止血数小时即可较早下床）或大腿根股动脉（术后需卧床、下肢制动一段时间）。入路不同，术后注意事项和不适感不同 | 患者不明白为什么别人术后当天能走、自己却要卧床；也不知道手腕或大腿根的淤青、肿胀哪些属于常见现象 | 术语解释动作 / 治疗回顾段 |
| GX-S2-19 | 双联抗血小板治疗（DAPT/双抗/双联抗栓） | 同时使用两种抗血小板药（通常是阿司匹林＋氯吡格雷或替格瑞洛），协同防止血小板在支架和斑块处聚集形成血栓；是支架术后的核心用药，通常持续一段时间后由医生减为单药 | 最容易混淆"抗血小板""抗凝""溶栓"三个概念；也不知道双抗期间绝不能自行停药——擅自停药可能诱发支架内血栓，后果严重 | 术语解释动作 / 用药疑点标签 |
| GX-S2-20 | P2Y12受体抑制剂（氯吡格雷/替格瑞洛/替罗非班） | 双抗中的"第二种药"，通过阻断血小板表面的P2Y12受体发挥作用；替格瑞洛起效快、作用强但部分人有气短等不适，氯吡格雷相对温和；替罗非班是静脉制剂，多在围手术期使用 | 患者不理解为什么出院药里有两个"抗血小板"药，也不清楚其中一个何时能停——这必须由医生评估决定 | 术语解释动作 / 用药疑点标签 |
| GX-S2-21 | 肌钙蛋白（cTnI/cTnT/高敏肌钙蛋白） | 心肌细胞受损后释放入血的蛋白，是判断有无心肌损伤（坏死）最敏感、最特异的抽血指标；需要间隔一段时间（常为1–3小时或按高敏试剂方案【数值待医学审核】）抽2–3次观察变化 | 化验单上"轻度升高"或"就高一点点"让患者困惑；是否诊断心梗要结合心电图和动态变化，由医生判断，单看一次数值没有意义 | 术语解释动作 / 检查疑点标签 |
| GX-S2-22 | 心肌酶谱/肌酸激酶同工酶（CK-MB） | 另一组反映心肌（及骨骼肌）损伤的抽血指标；CK-MB相对特异，现在多与肌钙蛋白配合，用于估计梗死时间、判断再梗死 | 化验单上多个"酶"一起升高，患者常误以为是肝脏出了问题 | 术语解释动作 |
| GX-S2-23 | 低密度脂蛋白胆固醇（LDL-C/低密度脂蛋白/"坏胆固醇"） | 把胆固醇运往血管壁的"坏"脂蛋白，是动脉粥样斑块形成的主要"原料"；冠心病患者的控制目标比健康人严格得多，且需要长期维持达标 | 患者常看"总胆固醇正常"就放心，或以为"血脂正常了就能停他汀"；实际上不同危险人群目标不同、停药后血脂会回升 | 术语解释动作 / 用药疑点标签 |
| GX-S2-24 | ST段抬高 | 心电图上相邻导联ST段弓背样抬高，提示心肌全层严重缺血，是STEMI的关键表现，也是最需要抢时间的心电图改变 | 体检报告偶见"ST段抬高"（部分为正常人变异，如早复极），患者容易过度紧张——是否危险需医生结合胸痛症状判断 | 术语解释动作 / 检查疑点标签 |
| GX-S2-25 | ST段压低/ST-T改变 | ST段压低或"ST-T改变"可见于心肌缺血，也可见于其他心脏情况甚至正常人；在胸痛发作当时出现的动态压低提示缺血，意义更大 | "ST-T改变"是报告上的高频词，很多患者据此以为"心脏坏了"；它特异性有限，需结合症状解读 | 术语解释动作 / 检查疑点标签 |
| GX-S2-26 | T波改变（T波倒置/低平/高尖） | 心电图T波形态改变，可见于心肌缺血、梗死后演变，也常见于紧张、电解质异常等情况；动态变化比单次结果更有意义 | 与ST-T改变类似，患者容易把这类非特异描述当成严重诊断 | 术语解释动作 |
| GX-S2-27 | 病理性Q波/异常Q波 | 心电图上异常加宽加深的Q波，多提示心肌曾发生透壁性坏死，是心肌梗死（包括陈旧性心梗）留下的"痕迹"之一 | 患者不理解为什么"从没感觉"也有Q波——部分心梗（尤其无痛性心梗，糖尿病者多见）可以没有典型胸痛史 | 术语解释动作 / S1诊断解释段 |
| GX-S2-28 | 射血分数（EF/LVEF/EF值） | 左心室每次收缩泵出血液的比例，反映心脏泵血功能，通常50%以上为大致正常【数值待医学审核】；心肌梗死后EF下降提示心功能受损，是重要的预后指标，也影响部分药物的选择 | 患者看到"EF 55%"不知道算好还是坏，也不理解EF值与出院带药（如ACEI、β受体阻滞剂）选择的关系 | 术语解释动作 / 用药疑点标签 |
| GX-S2-29 | 室性心律失常（室性早搏/室性心动过速/心室颤动） | 心室起源的心跳异常。室性早搏常见、多数良性；室性心动过速尤其心室颤动是心梗急性期最凶险的并发症，可致猝死——这正是急性期要住监护室持续监测的原因 | 报告里"室性早搏"让患者恐慌；而真正危险的室速/室颤多发生在监护中被及时处理，患者自己看不见，反而难理解监护的意义 | 术语解释动作 / 治疗回顾段 |
| GX-S2-30 | 房室传导阻滞（一度/二度/三度AVB） | 心房的电信号传导到心室受阻，按程度分一至三度；下壁心梗（多为右冠相关）容易合并传导阻滞，轻者观察、重者需临时起搏治疗 | 患者不理解"传导阻滞"与"心跳慢"的关系，也不明白为什么医生有时只观察不处理 | 术语解释动作 |
| GX-S2-31 | 心房颤动（房颤/AF） | 心房快速而不规则的颤动，心肌缺血或心包炎症时可出现；房颤本身增加卒中风险，可能需要抗凝治疗——与双抗联用时出血风险上升，需要医生权衡 | 患者不理解为什么"心梗"之外又多出"房颤"诊断，也不明白抗凝药与抗血小板药为什么不能随意叠加 | 术语解释动作 / 用药疑点标签 |
| GX-S2-32 | 支架内再狭窄/支架内血栓 | 支架内再狭窄是支架处血管内膜过度增生导致再次狭窄，多表现为术后数月症状复发，进展相对缓慢；支架内血栓是支架处急性形成血栓阻断血流，罕见但极其凶险，多与擅自停用抗血小板药相关 | 患者分不清两者，也常把"放完支架又胸痛"笼统理解成"支架没用"，或误以为取掉支架就行 | 术语解释动作 / 复诊建议段 |

**S2公共字段声明（等效于逐条字段）：**
- **适用范围**：成人冠心病（稳定性与ACS/PCI两条路径）理赔材料解读
- **锚定**：理赔材料原文出现该术语（入院记录、出院小结、心电图/影像/化验报告、手术记录、医嘱单、费用清单）
