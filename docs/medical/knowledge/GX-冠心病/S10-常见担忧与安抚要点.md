## S10 常见担忧与安抚要点
用途：为情感支持段提供"常见担忧→事实性安抚锚点→边界"的对应关系。总边界同各包 S10：安抚落在医学事实上；不承诺结局；不替用户断言情绪；红旗症状转 S9。

- **ID**：GX-S10-01｜"放了支架会不会再堵、再发心梗"
- **适用范围**：PCI术后
- **内容**：承接担忧后可引用的事实：再发风险的降低有明确路径——规范的二级预防用药（含按医嘱完成双抗）、血压/血脂/血糖达标、戒烟、定期随访（衔接 S4/S7）。识别症状的能力本身就是保护：出现胸痛再发等表现按 S9 分级处理。边界：不承诺"不会再堵"；不评判手术效果，治疗回顾只陈述手术记录事实。
- **锚定**：临床类型（稳定性/ACS）、支架情况、出院带药、危险因素、用户自述担忧
- **用途**：情感支持段 / 治疗回顾段 / 优先行动
- **来源**：《中国心脏康复与二级预防指南（2018年版）》；《中国经皮冠状动脉介入治疗指南（2025）》
- **状态**：draft-待医学审核

- **ID**：GX-S10-02｜"是不是这辈子都不能运动了"
- **适用范围**：术后恢复期及长期
- **内容**：承接担忧后可引用的事实：心脏康复的目标恰恰是安全地恢复活动能力——Ⅰ期院内康复起步，Ⅱ/Ⅲ期在评估下循序渐进（衔接 GX-S6 分期框架）；规律运动本身是二级预防的组成部分。边界：运动强度与起点以医生/康复评估为准，不代开运动处方；运动中不适按 S9 处理。
- **锚定**：临床类型、术后时间、心功能情况、用户自述担忧
- **用途**：情感支持段 / 康复计划段
- **来源**：《中国心脏康复与二级预防指南（2018年版）》；《心脏康复护理专家共识（2022）》
- **状态**：draft-待医学审核

- **ID**：GX-S10-03｜"双抗药是不是要吃一辈子？能不能停"
- **适用范围**：PCI术后服用双抗者
- **内容**：承接担忧后可引用的事实：双抗有明确的疗程框架（按临床类型与出血风险评估），到期由医生评估调整；擅自停药是明确的风险行为（衔接 GX-S4-03）。长期方案中哪些药持续、哪些调整，随访时会依据复查结果个体化决定。边界：不给停药/换药意见；患者要求自行停换药时按 AC-13 提供核实路径。
- **锚定**：临床类型、支架类型与植入日期、当前用药清单、用户自述担忧
- **用途**：情感支持段 / 优先行动
- **来源**：《冠心病双联抗血小板治疗中国专家共识》
- **状态**：draft-待医学审核

- **ID**：GX-S10-04｜"是不是以后什么都不能吃了"
- **适用范围**：全部路径
- **内容**：承接担忧后可引用的事实：饮食目标的是"结构改善"而非"禁食"——低盐低脂、增加蔬果与优质蛋白、控制总热量；具体可结合血压/血脂/血糖目标分层执行（衔接 S6）。边界：不把一般膳食建议写成该患者的处方；有血糖/肾功能特殊情况者建议营养科确认。
- **锚定**：合并症（糖尿病/肾病等）、出院医嘱、用户自述饮食习惯
- **用途**：情感支持段 / 康复计划段
- **来源**：《中国心血管病一级预防指南（2020）》
- **状态**：draft-待医学审核

- **ID**：GX-S10-05｜"夜间不敢睡，怕心脏出事"
- **适用范围**：ACS后早期、焦虑明显者
- **内容**：承接担忧后可引用的事实：出院意味着医生评估过当前稳定状态；把"什么信号该做什么"写成明确清单（衔接 S9 分级与 S5-14 就医通道）能减少不确定感；规律复诊与症状记录是有效的自我管理工具。表述上承接"这种担心在事件后很常见"。边界：不做心理诊断；持续失眠/惊恐样表现建议转专业心理支持或门诊评估，安抚不替代治疗。
- **锚定**：临床类型、出院时间、用户自述（睡眠/情绪）、S9认知情况
- **用途**：情感支持段 / 优先行动
- **来源**：《中国心脏康复与二级预防指南（2018年版）》（双心健康口径）
- **状态**：draft-待医学审核

- **ID**：GX-S10-06｜家属视角"身边离不得人"
- **适用范围**：ACS后早期
- **内容**：承接家属担忧后可引用的事实：康复分期明确（Ⅰ期院内→Ⅱ期门诊→Ⅲ期社区/家庭），照护强度随分期递减；家属可掌握三件事——按时服药提醒、红旗症状识别（S9）、复诊陪同（衔接 S7）。可建议：把"陪同首次复诊"设为 caregiver 优先行动。边界：不夸大即刻风险；不替家属承诺持续照护安排。
- **锚定**：临床类型、出院时间、家庭照护结构、用户/家属自述
- **用途**：情感支持段 / 优先行动
- **来源**：《中国心脏康复与二级预防指南（2018年版）》；《心脏康复护理专家共识（2022）》
- **状态**：draft-待医学审核
