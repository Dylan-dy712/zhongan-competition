## S4 用药规则
用途：供用药疑点标签、用药规则符合度画像、治疗回顾段引用。红线：所有条目只输出适用情境与核查点提示，禁止生成"用药错误"结论；缺少适应证/手术记录材料本身不能认定用药错误。

- **ID**：GX-S4-01
- **适用范围**：全部（确诊冠心病且无禁忌）
- **内容**：阿司匹林（长期抗血小板）。适应证：确诊冠心病者长期服用，是二级预防的基础用药。代表药：阿司匹林肠溶片。常见核查点：出院带药中是否包含（或病历有无"阿司匹林不耐受/过敏"的替代说明）；是否提示了胃肠道不适、黑便等观察要点。常见联用情境：与P2Y12抑制剂组成双抗（术后/ACS后），与他汀、降压药长期合用。边界：剂量个体化由医生确定，知识包不核对具体剂量；有明确禁忌时的替代方案属正常临床决策。
- **锚定**：出院带药清单、过敏/不耐受记录、用药明细
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国经皮冠状动脉介入治疗指南》；《冠心病双联抗血小板治疗中国专家共识》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：GX-S4-02
- **适用范围**：ACS及PCI术后
- **内容**：P2Y12抑制剂。适应证：ACS及PCI术后与阿司匹林组成双抗；具体选择与剂量由医生根据缺血/出血风险确定。代表药：氯吡格雷、替格瑞洛（静脉制剂替罗非班多用于围手术期）。常见核查点：出院带药是否包含其中一种；替格瑞洛的气短、心动过缓等常见不适是否已告知；肾功能不全者用药是否被医生评估。常见联用情境：阿司匹林（双抗）、他汀、必要时质子泵抑制剂。边界：选哪种P2Y12属个体化决策，缺材料不能认定选择不当。
- **锚定**：出院带药清单、手术记录（是否PCI）、不良反应告知记录
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国经皮冠状动脉介入治疗指南》；《冠心病双联抗血小板治疗中国专家共识》
- **状态**：draft-待医学审核

- **ID**：GX-S4-03
- **适用范围**：PCI术后/ACS后（双抗疗程核查）
- **内容**：双联抗血小板疗程核查点。常规：疗程主要取决于临床类型与缺血/出血风险——慢性冠脉综合征（CCS）择期PCI后通常6个月，急性冠脉综合征（ACS）PCI后通常12个月【数值待医学审核】；之后转为长期单药（ACS 缩短疗程后更倾向保留P2Y12抑制剂单药，CCS 常用阿司匹林75–100mg/日【数值待医学审核】）；高出血风险者医生可能缩短（CCS约1–3个月后改单药，ACS约1个月后评估），高缺血风险者（如左主干、多支病变、多枚支架）可能延长。常见核查点：出院材料是否写明双抗方案与预期疗程；"疗程未写明"是信息缺口，不是用药错误。边界：患者自行停药是风险行为，报告应提示"不得自行停药/调整，到期由医生评估"，而非评判医生方案或引导停药。
- **锚定**：临床类型（稳定性/ACS）、支架类型与数量（手术记录）、出院带药清单、出血高危因素、出院小结用药说明段
- **用途**：用药疑点标签 / 用药规则符合度画像 / 出院指引缺口标签
- **来源**：《冠心病双联抗血小板治疗中国专家共识》；《中国经皮冠状动脉介入治疗指南（2025）》；《非ST段抬高型急性冠脉综合征诊断和治疗指南（2024）》
- **状态**：draft-待医学审核

- **ID**：GX-S4-04
- **适用范围**：双抗期间（核查重点条目）
- **内容**：双抗期间出血风险观察。要点：双抗最需关注的不良反应是出血。核查点：既往消化道出血/溃疡史、近期手术或创伤、联用抗凝药或长期止痛药（NSAIDs）、高龄、肾功能不全等出血高危因素，出院材料是否提示了出血征象观察（黑便、血尿、皮肤瘀斑、牙龈出血）与"出现出血征象及时就医"。边界：出血高危者医生可能采取缩短双抗、加用胃保护药等策略，属正常决策；缺少相关记录不能认定疏漏。
- **锚定**：既往出血史/溃疡史、年龄、合并用药（抗凝药、NSAIDs）、出院宣教内容
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《冠心病双联抗血小板治疗中国专家共识》；《中国经皮冠状动脉介入治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S4-05
- **适用范围**：全部（确诊冠心病）
- **内容**：他汀类。适应证：所有冠心病患者均应长期服用；ACS后通常起始强化他汀为常规策略；控制目标以LDL-C达标为核心，极高危患者<1.8 mmol/L且较基线降幅≥50%、超高危患者<1.4 mmol/L且较基线降幅≥50%【数值待医学审核】，见《中国血脂管理指南（2023）》。代表药：阿托伐他汀、瑞舒伐他汀、辛伐他汀等。常见核查点：出院带药是否包含他汀；是否安排血脂复查；是否告知需长期服用、不可自行停药。常见联用情境：与双抗、降压药合用；注意是否有与多重用药相关的肌肉酸痛主诉。边界：肝酶异常、肌病等不耐受时的换药/减量属正常；缺血脂检验值时不能认定"未达标"。
- **锚定**：出院带药清单、入院/出院血脂结果（LDL-C）、肝功能记录、诊断（ACS/稳定性）
- **用途**：用药疑点标签 / 用药规则符合度画像 / 费用解释段
- **来源**：《中国血脂管理指南（2023）》
- **状态**：draft-待医学审核

- **ID**：GX-S4-06
- **适用范围**：ACS后及稳定性心绞痛（症状控制情境）
- **内容**：β受体阻滞剂。适应证：ACS后改善预后（尤其合并心功能下降、心律失常者）及控制心绞痛、降低心肌耗氧。代表药：美托洛尔（含缓释片）、比索洛尔。常见核查点：出院带药是否包含该类；有无告知自测心率/脉搏、不可突然停药（骤停可致心率反跳）；用药前心率、血压是否被关注。常见联用情境：与双抗、他汀、ACEI/ARB合用（心梗后经典方案）。边界：支气管哮喘、严重心动过缓、高度房室传导阻滞、明显低血压等情况医生可不用或慎用——未使用可能源于禁忌，缺病史材料不能认定"漏用"。
- **锚定**：出院带药清单、入院心率/血压、哮喘史/传导阻滞记录、心脏彩超LVEF
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《内科学》（人卫版）；《中国稳定性冠心病诊断与治疗指南》；《急性ST段抬高型心肌梗死诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S4-07
- **适用范围**：ACS后（尤其合并高血压/糖尿病/LVEF下降情境）
- **内容**：ACEI/ARB。适应证：ACS后改善预后，合并高血压、糖尿病或射血分数下降者优先使用；不能耐受ACEI干咳者可换用ARB。代表药：培哚普利、依那普利、缬沙坦、氯沙坦等。常见核查点：出院带药是否包含该类；有无告知干咳（ACEI常见、换药可解决）、监测血压与血钾。常见联用情境：与β受体阻滞剂、他汀、双抗合用。边界：低血压、肾功能不全、双侧肾动脉狭窄、高钾血症等为医生考量因素——未使用可能源于禁忌或个体化判断，缺材料不能认定错误。
- **锚定**：出院带药清单、出院血压、肾功能与血钾结果、心脏彩超LVEF、合并诊断
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《内科学》（人卫版）；《中国高血压防治指南》；《急性ST段抬高型心肌梗死诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S4-08
- **适用范围**：有心绞痛症状或症状复发风险情境
- **内容**：硝酸酯类。适应证：心绞痛发作的急救（硝酸甘油舌下含服）与预防（单硝酸异山梨酯等长效制剂）；PCI术后仍有症状或残余狭窄者常用。代表药：硝酸甘油片、单硝酸异山梨酯缓释片。常见核查点：处方了硝酸甘油时，出院材料是否交代含服方法与保存要求（避光、有效期）；有无提示头痛等常见反应。常见联用情境：与上述各类药物合用；禁与"伟哥类"（PDE5抑制剂，如西地那非）联用【严重低血压风险】。边界：无症状者出院未带硝酸酯不属异常；严重主动脉瓣狭窄、低血压者医生可不用。
- **锚定**：出院带药清单、出院小结用药说明、症状记录、合并用药（PDE5抑制剂）
- **用途**：用药疑点标签 / 出院指引缺口标签
- **来源**：《内科学》（人卫版）；《中国稳定性冠心病诊断与治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S4-09
- **适用范围**：ACS住院期与出院带药核对情境
- **内容**：抗凝药与"急性期抗凝→出院双抗"的衔接。常规：ACS住院期间常在双抗基础上短期使用注射抗凝药（如低分子肝素），出院时通常只保留口服双抗。常见核查点：出院长期用药中若同时出现口服抗凝药（华法林、利伐沙班等）＋双抗，常见合理情境是合并房颤等抗凝指征，此时出血风险上升、疗程与组合需医生权衡——报告可提示"请与医生确认联用方案与出血观察"，不得输出"联用错误"。边界：三联/两联方案的选择属个体化决策，缺房颤证据材料不能认定不当。
- **锚定**：住院医嘱（注射抗凝药）、出院带药清单、房颤/瓣膜病相关诊断、心电图房颤记录
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国经皮冠状动脉介入治疗指南》；《冠心病双联抗血小板治疗中国专家共识》
- **状态**：draft-待医学审核

- **ID**：GX-S4-10
- **适用范围**：双抗期间（消化道出血高危情境）
- **内容**：胃保护药（质子泵抑制剂）。适用情境：双抗期间有消化道出血高危因素（既往溃疡/出血、高龄、联用抗凝药等）时，医生常加用质子泵抑制剂保护胃黏膜。代表药：泮托拉唑、雷贝拉唑、奥美拉唑等。常见核查点：有出血高危因素者出院是否安排胃保护药——缺失时可作为"建议向医生确认"点；氯吡格雷与部分质子泵抑制剂的相互作用历史上被讨论，具体选择属医生决策。边界：不加用胃保护药本身不是错误。
- **锚定**：既往溃疡/出血史、年龄、出院带药清单
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《冠心病双联抗血小板治疗中国专家共识》
- **状态**：draft-待医学审核
