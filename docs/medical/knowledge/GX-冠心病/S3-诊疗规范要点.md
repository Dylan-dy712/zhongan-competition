## S3 诊疗规范要点
用途：供治疗回顾段核对住院经过是否符合规范路径、生成"检查疑点标签"与"治疗规范符合度画像"、供费用基线参考（住院天数）引用；条目只做"事实与情境核对"，不做病例级医疗质量结论。

- **ID**：GX-S3-01
- **适用范围**：全部
- **内容**：诊断标准要点：ACS诊断依赖三要素结合——缺血性胸痛等临床表现＋心电图动态改变＋心肌损伤标志物（肌钙蛋白）动态变化，并据此分为STEMI、NSTEMI、不稳定型心绞痛；稳定性冠心病的诊断依赖典型症状特点＋缺血证据＋解剖学证据（冠脉造影或冠脉CTA显示有意义狭窄）。诊断名称与检查结果互相印证，是报告核对的基本盘。
- **锚定**：入院记录症状描述、心电图报告、肌钙蛋白结果序列、造影/CTA报告、出院诊断分型
- **用途**：治疗回顾段 / 检查疑点标签 / 治疗规范符合度画像
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》；《非ST段抬高型急性冠脉综合征诊断和治疗指南》；《中国稳定性冠心病诊断与治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-02
- **适用范围**：全部（疑似ACS情境）
- **内容**：心电图适用情境：胸痛首诊的第一道检查，应在到达后短时间内完成【数值待医学审核】，STEMI据此快速分型；疑似ACS者需动态复查（症状发作时、必要时连续对比），单次正常不能完全排除缺血。病历有心电图而材料缺失该报告时，属材料缺口而非"未做"。
- **锚定**：急诊/入院时间与首次心电图时间、心电图报告序列、症状记录
- **用途**：治疗回顾段 / 检查疑点标签
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》；《非ST段抬高型急性冠脉综合征诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-03
- **适用范围**：全部（疑似ACS情境）
- **内容**：肌钙蛋白动态监测适用情境：疑似ACS的必查项目，需间隔一段时间复查（常为1–3小时或按高敏试剂方案【数值待医学审核】）观察升高及其变化趋势；不稳定型心绞痛的特征是肌钙蛋白不高＋缺血证据存在。只有单次结果时，需核对是"仅做一次"还是"报告缺失"。
- **锚定**：化验申请与回报时间序列、肌钙蛋白数值变化、诊断分型（UA/NSTEMI）
- **用途**：治疗回顾段 / 检查疑点标签
- **来源**：《非ST段抬高型急性冠脉综合征诊断和治疗指南》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：GX-S3-04
- **适用范围**：全部（有创评估情境）
- **内容**：冠脉造影适用情境：拟诊冠心病需明确血管解剖、ACS拟行血运重建时的标准路径；NSTE-ACS按危险分层决定造影时机（极高危2小时内、高危24小时内等节奏【数值待医学审核】）；稳定性冠心病在症状影响生活或无创检查提示高危时进行。造影同时完成诊断与（必要时）治疗。
- **锚定**：造影手术记录、入院至造影的时间间隔、危险分层记录、造影结果描述（狭窄部位/程度）
- **用途**：治疗回顾段 / 检查疑点标签 / 治疗规范符合度画像
- **来源**：《非ST段抬高型急性冠脉综合征诊断和治疗指南》；《中国经皮冠状动脉介入治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-05
- **适用范围**：稳定性冠心病（无创评估情境）
- **内容**：冠脉CTA适用情境：无创评估，用于中低危胸痛患者的排查、造影禁忌或患者拒绝有创检查时；CTA提示显著狭窄（尤其高危解剖特征）时通常转入造影确认。CTA阴性对排除冠心病价值较高，阳性不等于必须放支架。
- **锚定**：CTA报告结论、后续是否造影、危险因素清单
- **用途**：治疗回顾段 / 检查疑点标签
- **来源**：《中国稳定性冠心病诊断与治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-06
- **适用范围**：全部
- **内容**：超声心动图适用情境：评估节段性室壁运动异常、左室射血分数（LVEF）与机械并发症；ACS患者出院前或术后早期常规评估心功能，LVEF结果直接影响用药方案与随访强度。彩超"正常"不能排除冠心病（它看的是结构与功能，不是血管管腔）。
- **锚定**：心脏彩超报告（LVEF、室壁运动）、出院前检查清单
- **用途**：治疗回顾段 / 检查疑点标签
- **来源**：《内科学》（人卫版）；《急性ST段抬高型心肌梗死诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-07
- **适用范围**：全部（治疗决策情境）
- **内容**：治疗路径分支（药物/PCI/CABG的选择逻辑层面）：单支或局限病变、解剖合适者常选PCI；左主干病变、多支复杂病变（尤其合并糖尿病）等由心脏团队评估外科搭桥（CABG）或介入；不适合血运重建或狭窄程度未达介入指征者以药物治疗为主。材料中出现"建议搭桥但患者选择药物"或反之，属于共同决策范畴，不能生成"治疗选择错误"类表述。本条只提供分支方向，不替医生下结论；病例若实际行CABG，转 exclusions。
- **锚定**：造影结果（病变支数/部位）、手术记录（PCI/无）、会诊或心脏团队记录、患者知情同意材料
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《中国经皮冠状动脉介入治疗指南》；《中国稳定性冠心病诊断与治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-08
- **适用范围**：ACS/STEMI情境
- **内容**：STEMI再灌注时间窗要点：发病12小时内的STEMI首选直接PCI；12–24小时仍可考虑造影与开通梗死相关动脉，>24小时仅限持续缺血、血流动力学不稳定或恶性心律失常等情形【数值待医学审核】。时间质控口径：首诊于PCI中心者目标为首次医疗接触（FMC）至导丝通过≤60分钟；需转运者≤90分钟【数值待医学审核】（部分体系以FMC至器械≤120分钟作为PCI与溶栓的决策阈值）。若预计不能及时完成PCI，评估静脉溶栓（发病12小时内、无禁忌），溶栓后常规转运至PCI中心进一步造影。"门球时间"（入院至球囊扩张）的快慢与心肌坏死范围直接相关，是治疗回顾段最有价值的核对点之一。
- **锚定**：发病/呼救时间、到达医院时间、心电图确诊时间、手术开始时间、是否溶栓及溶栓时间
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-09
- **适用范围**：ACS/NSTE-ACS情境
- **内容**：NSTE-ACS危险分层要点：按GRACE等评分结合心电图、肌钛蛋白动态变化评估危险分层，决定介入时机（立即/早期/择期）。本知识包不做评分复算，只核对"病历是否有危险分层评估的痕迹"（评分记录、分层表述或对应的介入节奏）。
- **锚定**：GRACE或等效评分记录、肌钙蛋白动态结果、心电图动态改变、造影时机
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《非ST段抬高型急性冠脉综合征诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-10
- **适用范围**：ACS情境（无PCI条件医院）
- **内容**：溶栓适用情境要点：预计不能及时转运行PCI的STEMI患者，发病12小时内且无禁忌时可静脉溶栓；溶栓成功的判断（胸痛缓解、ST段回落等）与溶栓后转运造影的建议均属规范内容。溶栓适应证/禁忌证核查需结合病历原文（出血史、血压、年龄等），材料不全时不下结论。
- **锚定**：发病时间、转院记录、溶栓医嘱与时间、溶栓后造影记录
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-11
- **适用范围**：全部（住院时长核对情境）
- **内容**：住院天数参考区间：择期冠脉造影/PCI（稳定性冠心病）——国际日间路径下无并发症者可当日出院（观察约4–6小时）或次日出院，国内实际住院常见2–5天【数值待医学审核】；ACS/急诊PCI——低风险且术后稳定者约48–72小时（早期出院路径可更短），伴并发症（心律失常、心功能下降、穿刺并发症等）时明显延长【数值待医学审核】。该区间仅为费用解释与合理性提示的粗参考，个体差异大且日间手术趋势在扩展；显著偏离只生成"提示核对"，不生成"异常"结论。
- **锚定**：入出院日期、住院天数、是否急诊/CCU、并发症记录
- **用途**：费用解释段 / 费用基线参考 / 检查疑点标签
- **来源**：《内科学》（人卫版）；《中国经皮冠状动脉介入治疗指南》（供参考的临床常见区间，口径待医学审核确认）
- **状态**：draft-待医学审核

- **ID**：GX-S3-12
- **适用范围**：全部（出院核对情境）
- **内容**：出院标准要点（共性）：生命体征平稳、无静息缺血发作、无需持续静脉血管活性药物、口服长期用药方案确定并完成宣教、穿刺点/伤口无活动性并发症、必要复查（心电图、心脏彩超、化验）已完成。出院方式"治愈/好转"与上述要素相互印证，供治疗回顾段核对。
- **锚定**：出院前生命体征与症状记录、出院医嘱完整度、出院前复查清单、出院方式
- **用途**：治疗回顾段 / 出院指引缺口标签 / 治疗规范符合度画像
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》；《非ST段抬高型急性冠脉综合征诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-13
- **适用范围**：PCI术后（住院期与出院早期）
- **内容**：术后穿刺并发症监测要点：桡动脉入路——压迫止血后观察手腕肿胀疼痛程度、手指颜色与温度，警惕血肿及罕见的手部血供问题；股动脉入路——卧床与下肢制动一段时间，警惕局部血肿、假性动脉瘤（局部搏动性包块）及腹膜后血肿（低血压、腹痛腰背痛）。监测记录缺失本身只作为"需确认"提示，不构成"过错"结论。
- **锚定**：穿刺入路（桡/股）、术后护理记录、穿刺点愈合描述、出院小结伤口描述
- **用途**：检查疑点标签 / 治疗回顾段
- **来源**：《中国经皮冠状动脉介入治疗指南》；《内科学》（人卫版）
- **状态**：draft-待医学审核
