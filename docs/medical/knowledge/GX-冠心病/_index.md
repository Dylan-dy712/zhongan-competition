# KP-GX 冠心病知识包 · 调取索引

# 冠心病知识包（草稿）

**使用边界（对生成器的红线约束，优先级高于任何单条知识）：**

1. 本知识包是"接地与核对依据"，不是科普文章库。报告中不得整段拼接本包内容；每条知识只能以要点形式、且被病例事实锚定后引用。
2. 用药条目（S4）一律不得生成"用药错误"类结论；只能生成"适用情境说明 + 核查点提示"，并须声明"缺少适应证/手术记录材料本身不能认定用药错误"。涉及双抗的表述一律包含"不得自行停药、调整前咨询医生"，不得生成任何鼓励停药的内容。
3. 优先级口径：主管医生书面医嘱/出院医嘱 > 本知识包一般口径。凡冲突，以医嘱为准并在报告中按医嘱表述。
4. 复诊日期生成规则：出院医嘱提供了日期则用医嘱；未提供时不得生成确定日期，仅按 S7-01 提示"可与医生确认通常节奏"。
5. 所有标注【数值待医学审核】的数值未经医学审核通过前，不得原样写入患者报告；费用条目（S8）不写具体金额、不生成"多收费/费用异常"结论。
6. 病例提示搭桥（CABG）、心衰、心肌病、瓣膜病时，先查 exclusions，不适用即转人工。

## 调取指引

1. 先读本文件：核对病例病种与 scope/exclusions；命中 exclusions 时停止调取并转医学人工，不读任何槽位文件。
2. 按本次能力需要选槽位文件（槽位→用途映射见下），不需要的槽位不加载。
3. 在槽位文件内按条目'适用范围'与'锚定'字段对照病例事实筛选，只把命中条目注入生成/规则上下文。
4. 引用条目时以条目 ID 作为 knowledge_refs 的定位依据；含'【数值待医学审核】'的条目未获准前不得注入患者可见内容。
