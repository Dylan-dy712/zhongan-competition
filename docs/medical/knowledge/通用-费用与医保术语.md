## 通用费用与医保术语通俗对照
用途：理赔费用清单与结算单中的高频术语解释，供费用解释段引用。总边界：①各地医保政策差异大，条目只解释"术语含义"，不解释"当地报销比例"；②不得据术语推断用户实际负担——最终负担缺少结算/赔付证据时不可推算（spec 6.1）；③来源为通行医保口径，地方细则需医学/合规审核确认。

- **ID**：TY-COST-01｜甲类/乙类药品（医保目录分类）
- **适用范围**：费用清单药费部分
- **内容**：甲类：疗效确切、价格低，全额纳入医保报销范围（再按比例报销）；乙类：先由个人自付一定比例，剩余部分再按比例报销。常见困惑："医保目录内为什么还要自己掏钱"——乙类先行自付+起付线+报销比例共同造成差额。
- **锚定**：费用清单"药品类别/医保属性"列
- **用途**：费用解释段 / 术语解释动作
- **来源**：基本医疗保险药品目录通行分类口径
- **状态**：draft-待医学审核

- **ID**：TY-COST-02｜自付/自费/先行自付（三个词不是一回事）
- **适用范围**：结算单
- **内容**：自费：医保目录外、医保完全不报销的部分；自付：目录内费用经医保报销后由个人承担的部分；先行自付：乙类药品/部分服务医保报销前个人先按比例承担的那一段。三者混称会造成"自费比例异常"的误判——费用偏离判定前必须统一口径（衔接 spec 6.1）。
- **锚定**：结算单"自付一/自付二/自费金额"字段
- **用途**：费用解释段 / 术语解释动作 / 费用基线参考
- **来源**：医保结算单通行字段口径
- **状态**：draft-待医学审核

- **ID**：TY-COST-03｜起付线与封顶线
- **适用范围**：结算单
- **内容**：起付线：年度/次住院费用中需先由个人承担的门槛部分，医保从起付线以上开始按比例报销；封顶线：医保基金年度最高支付限额。常见困惑："花的钱不少，报销比例却不像说的那么高"——起付线以下、封顶线以上、目录外部分都不在按比例报销范围内。
- **锚定**：结算单起付线/统筹支付字段、参保类型
- **用途**：费用解释段 / 术语解释动作
- **来源**：职工/居民医保通行待遇口径
- **状态**：draft-待医学审核

- **ID**：TY-COST-04｜统筹基金支付（医保报销部分）
- **适用范围**：结算单
- **内容**：统筹支付=医保基金按政策为本次费用支付的部分，即通常说的"医保报了多少"；与大病保险二次报销、医疗救助共同构成多层保障。展示费用构成时，"统筹支付+个人负担=总费用"是对账的基本恒等式，对不上时先查口径（衔接 COST_AMOUNT_RECONCILIATION 标签）。
- **锚定**：结算单"统筹基金支付"字段与总额
- **用途**：费用解释段 / 费用基线参考
- **来源**：医保结算通行口径
- **状态**：draft-待医学审核

- **ID**：TY-COST-05｜大病保险与商业保险赔付的位置
- **适用范围**：有大额费用或商业险用户
- **内容**：基本医保报销后个人负担仍较重时，大病保险按合规费用二次报销（由医保结算或事后申请）；商业医疗险按保单条款对剩余部分赔付。本次系统的理赔关怀发生在商业险赔付环节，但费用清单上的数字通常只反映基本医保口径——用户"最终净负担"需结合理赔结论，缺少证据时不可推算（spec 6.1）。
- **锚定**：结算单大病支付字段、理赔申请材料类型
- **用途**：费用解释段
- **来源**：多层次医疗保障体系通行结构
- **状态**：draft-待医学审核

- **ID**：TY-COST-06｜DRG/DIP 按病种付费
- **适用范围**：住院费用（多数统筹区已实施）
- **内容**：医保按"病组/病种分值"给医院定额付费，而非按项目逐项报销——同一病组内医院"花多花少"影响的是医院结算而非患者个人报销规则。常见困惑："清单上某项收费高"未必等于患者多掏钱；费用结构解读时需知医院侧付费方式与患者侧报销是两套逻辑。
- **锚定**：出院日期（判断是否处于按病种付费覆盖期）、统筹区
- **用途**：费用解释段 / 费用基线参考
- **来源**：国家医保局DRG/DIP支付方式改革公开口径（2025年按病种付费已占医保出院人次约91.8%）
- **状态**：draft-待医学审核

- **ID**：TY-COST-07｜高值耗材集采（支架/关节/脊柱等）
- **适用范围**：含植入耗材的住院费用
- **内容**：国家/联盟组织集中带量采购使冠脉支架、骨科关节与脊柱耗材价格大幅下降；同一手术的费用结构在集采落地前后不可直接比较（如冠脉支架2020年11月开标、2021年1月落地）。解读"手术为什么便宜/贵了"先看费用年份与耗材品类。
- **锚定**：费用发生年份、手术/耗材类型
- **用途**：费用解释段 / 费用基线参考
- **来源**：国家组织高值医用耗材集中带量采购公开政策
- **状态**：draft-待医学审核

- **ID**：TY-COST-08｜日间手术/日间化疗
- **适用范围**：按"日间"路径结算的住院记录
- **内容**：日间手术指"当天入院、当天或24小时内出院"的手术路径（如部分择期PCI、内镜手术），住院天数天然很短——短住院不等于治疗缩水；判断治疗充分性以诊疗规范与医嘱为准（衔接各包 S3/S7）。
- **锚定**：入出院日期差、结算类型字段
- **用途**：费用解释段 / 检查疑点标签（防止误报"住院过短"）
- **来源**：国家卫健委日间手术试点通行口径；EAPCI日间PCI共识（经氢离子平台查证）
- **状态**：draft-待医学审核

- **ID**：TY-COST-09｜异地就医结算
- **适用范围**：参保地与就诊地不一致者
- **内容**：异地就医需备案后才能直接刷卡结算；未经备案回参保地手工报销，报销比例或范围可能不同。常见困惑："同样的病在老家报得多"——统筹区政策与备案状态都会影响结果，属于政策差异而非医院乱收费。
- **锚定**：参保地/就诊地信息（如有）、结算类型
- **用途**：费用解释段
- **来源**：国家医保局异地就医直接结算通行口径
- **状态**：draft-待医学审核

- **ID**：TY-COST-10｜自费药/丙类目录与外购药
- **适用范围**：费用清单含目录外药品或外购记录
- **内容**：丙类/目录外药品完全自费；部分药物医院院内没有需"外购"（凭处方在院外药店购买），这类支出常不出现在住院结算单里，容易被遗漏在费用理解之外。费用解释时注意区分"清单内费用"与"用户实际总支出"。
- **锚定**：费用清单药品备注、外购处方记录（如有）
- **用途**：费用解释段 / 术语解释动作
- **来源**：医保目录管理通行口径
- **状态**：draft-待医学审核
