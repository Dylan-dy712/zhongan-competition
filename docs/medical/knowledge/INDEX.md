## 2. 调取流程（四步）

1. **选包**：按病例第一诊断确定病种包；只加载一个病种包，通用术语文件（KP-TY）按需附加。
2. **判适用**：读该包 `_index.md`（≤2KB）核对 scope/exclusions；命中 exclusions → 停止调取、转医学人工。
3. **选槽位**：按下方"能力→槽位速查"只读取需要的槽位文件（3-18KB/个），不需要的不加载。
4. **筛条目**：在槽位文件内按条目"适用范围"与"锚定"字段对照病例事实，只注入命中条目；条目 ID 即 `knowledge_refs` 定位依据。

## 4. 注意

- 所有 `draft-待医学审核` 条目均不得注入患者可见内容（装配器阻断）；`【数值待医学审核】` 另作为重点审核信号。
- 引用知识必须走 `professional_explanation` claim 并带 `knowledge_refs`，不整段拼接（命题红线）。
- S10 安抚条目必须绑定用户自述关注点或病例事实；空洞保证、"放心吧没事"类表述是红线（各包 S10 头部总边界）。
- 费用金额基线来自官方脱敏数据集，S8 与 KP-TY 只提供费用结构、口径与术语解释。
