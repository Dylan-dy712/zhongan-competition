## S3 诊疗规范要点
用途：供治疗回顾段、检查疑点标签、治疗规范符合度画像、费用基线参考（住院天数）引用；条目只做"事实与情境核对"，不做病例级诊断评价。

- **ID**：FY-S3-01
- **适用范围**：成人CAP住院患者
- **内容**：诊断标准要点：社区发病 + 肺炎常见临床表现（发热、咳嗽咳痰、气促、胸痛等）+ 影像学新出现浸润影（胸片或CT）+ 排除肺结核、肺部肿瘤、肺栓塞、肺水肿等其他疾病。影像学浸润影是CAP诊断的必备条件之一。
- **锚定**：入院记录症状描述、影像报告结论、鉴别诊断与排除记录
- **用途**：治疗回顾段 / 检查疑点标签 / 治疗规范符合度画像
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》
- **状态**：draft-待医学审核

- **ID**：FY-S3-02
- **适用范围**：成人CAP住院患者
- **内容**：初始治疗前病原学检查适用情境：门诊轻症一般不强制；住院患者建议在抗感染治疗前送检痰涂片与痰培养；重症患者推荐在使用抗菌药物前送检血培养，并可送检肺炎链球菌尿抗原、军团菌尿抗原等快速病原学。病历未送检病原学本身不构成"治疗不规范"结论，需结合严重度与材料完整性判断。
- **锚定**：入院时间、首次抗菌药物给药时间、病原学送检与回报记录、严重度分级
- **用途**：治疗回顾段 / 检查疑点标签 / 治疗规范符合度画像
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S3-03
- **适用范围**：成人CAP住院患者
- **内容**：严重度评估：住院CAP患者应进行严重度评估以决定治疗场所（普通病房/ICU），常用CURB-65等工具。本知识包只核对"病历是否记录了严重度评估"这一符合度事实，不在报告中复现打分过程或重算分数。
- **锚定**：CURB-65或等效评估记录、是否吸氧、是否入住ICU
- **用途**：治疗规范符合度画像 / 检查疑点标签
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S3-04
- **适用范围**：成人CAP住院患者
- **内容**：治疗路径主线：确诊后尽早启动经验性抗感染治疗（重症强调入院后尽快给首剂）；同步评估氧合并按需氧疗；治疗48–72小时评价疗效（体温、症状、氧合、炎症指标）【数值待医学审核】；有效则继续原方案并考虑降阶梯/序贯口服；无效则复查影像并查找原因（病原未覆盖、并发症、非感染性疾病等）。
- **锚定**：首次抗感染给药时间、住院期间体温记录、炎症指标复查、影像复查记录
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S3-05
- **适用范围**：成人CAP住院患者
- **内容**：经验性抗感染的类别逻辑：住院非重症CAP的经验方案通常需同时覆盖肺炎链球菌等典型细菌和非典型病原体，常见形式为β-内酰胺类联合大环内酯类，或单用呼吸喹诺酮类；有基础病、耐药风险、近期住院或抗菌药物暴露史者按指南分层调整。生成器只核对"方案类别与患者分层是否匹配"，不评价具体药物对错。
- **锚定**：病原学结果、基础病清单、近3个月内住院/抗菌药物使用史
- **用途**：治疗回顾段 / 用药规则符合度画像
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S3-06
- **适用范围**：成人CAP住院患者
- **内容**：抗感染疗程一般原则：轻中度CAP总疗程一般5–7天【数值待医学审核】；重症、初始治疗反应差或出现肺外并发症者可延长。疗程以病原体、严重度和治疗反应为准，不追求"用满固定天数"。
- **锚定**：抗感染药物起止日期、病原学结果、出院带药天数
- **用途**：治疗回顾段 / 用药规则符合度画像
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S3-07
- **适用范围**：成人CAP住院患者
- **内容**：静脉转口服（序贯）条件：血流动力学稳定、症状明显改善（体温正常、可口服进食、胃肠功能正常）、无需要静脉给药的特殊病原或深部感染依据时，可转为同类或抗菌谱相近的口服药完成疗程；口服+静脉合并计算总疗程。
- **锚定**：体温曲线、给药途径变更记录、出院带药清单
- **用途**：治疗回顾段 / 用药规则符合度画像
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S3-08
- **适用范围**：成人CAP住院患者
- **内容**：出院标准要点：体温正常并平稳（指南口径为体温正常超过24小时【数值待医学审核】）、生命体征稳定、呼吸系统症状明显改善、氧合改善（不吸氧或低流量吸氧下血氧维持稳定）、可口服药物、合并症无需住院处理。达到出院标准即可出院，不以影像完全吸收为前提。
- **锚定**：出院前体温记录、生命体征与SpO₂记录、出院方式（治愈/好转出院）
- **用途**：治疗回顾段 / 出院指引缺口标签 / 治疗规范符合度画像
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》
- **状态**：draft-待医学审核

- **ID**：FY-S3-09
- **适用范围**：成人CAP住院患者
- **内容**：住院天数参考区间：住院非ICU、无并发症者常见约5–7天，出院以临床稳定为核心标准（体温正常48–72小时、心率/呼吸/血压/氧合稳定、可口服进食），部分患者第3天左右即达稳定出院；重症、ICU或有并发症者明显延长；个体差异大，不同指南与临床路径口径存在差异【数值待医学审核】。显著短于区间需核对出院标准是否满足，明显延长需核对有无并发症或合并症处理——均只生成"提示核对"，不生成结论。
- **锚定**：入出院日期、住院天数、是否ICU、并发症记录
- **用途**：费用解释段 / 费用基线参考 / 检查疑点标签
- **来源**：国家卫生健康委社区获得性肺炎临床路径；《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》
- **状态**：draft-待医学审核

- **ID**：FY-S3-10
- **适用范围**：成人CAP住院患者
- **内容**：影像检查口径：入院时胸片或CT均为可接受的初始影像（CT分辨率更高，鉴别困难或疑并发症时更常用）；出院不以影像吸收为前提；出院后是否常规复查影像存在指南与临床实践口径差异（详见S7-03），不能据此直接生成"漏检"标签。
- **锚定**：入院影像报告、出院前是否复查影像及结论
- **用途**：检查疑点标签 / 治疗回顾段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S3-11
- **适用范围**：成人CAP住院患者
- **内容**：常见检查项目及适用情境：血常规、CRP、生化为入院常规；PCT多用于重症或抗菌药物管理（非强制全员）；痰涂片/培养、血培养按S3-02情境送检；血气分析用于低氧或重症评估；心电图与心功能指标用于鉴别和基础病评估；胸腔穿刺或闭式引流用于中大量胸腔积液或疑诊脓胸者。检查费用差异本身不提示异常。
- **锚定**：检验检查医嘱与执行记录、是否吸氧、胸腔积液影像描述
- **用途**：检查疑点标签 / 费用解释段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；国家卫生健康委社区获得性肺炎临床路径
- **状态**：draft-待医学审核

- **ID**：FY-S3-12
- **适用范围**：成人CAP住院患者
- **内容**：疗效评价节点：规范诊疗应在启动治疗后48–72小时评估病情（体温、呼吸系统症状、氧合、循环、炎症指标）【数值待医学审核】；达到临床稳定后可考虑序贯口服与出院安排。病历缺该时段评估记录可作为"治疗回顾"中的提示点，而非结论。
- **锚定**：住院中段体温记录、复查炎症指标、病程记录
- **用途**：治疗规范符合度画像 / 治疗回顾段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核
