## S4 用药规则
用途：供用药疑点标签、用药规则符合度画像、治疗回顾段引用。红线：所有条目只输出适用情境与核查点提示，禁止生成"用药错误"结论；缺少病原学/适应证材料本身不能认定用药错误。

- **ID**：FY-S4-01
- **适用范围**：成人CAP住院患者
- **内容**：β-内酰胺类（青霉素类、头孢菌素类）：经验性覆盖肺炎链球菌等典型细菌，住院患者常与大环内酯类联用以覆盖非典型病原体。常见核查点：青霉素类皮试执行情况（注意：皮试要求因机构制度而异，CAP指南住院经验性治疗路径甚至写明不需皮试——不能仅凭未皮试提示问题）、给药频次与剂量是否按肾功能调整（品种差异大，如头孢曲松轻中度肾功能减退通常无需减量而头孢他啶需减量）、联用方案是否按患者分层覆盖非典型病原体。边界：病历未提供病原学与适应证材料本身不能认定用药错误。
- **锚定**：医嘱单药名与频次、皮试记录、肾功能检验（肌酐/eGFR）、病原学结果
- **用途**：用药规则符合度画像 / 治疗回顾段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：FY-S4-02
- **适用范围**：成人CAP住院患者
- **内容**：呼吸喹诺酮类（左氧氟沙星、莫西沙星等）：单药即可覆盖典型与非典型病原体，适用于无禁忌证的住院非重症CAP。常见核查点：年龄与禁忌（18岁以下人群禁用喹诺酮类）、基础病（癫痫史、心律失常/QT延长相关情况、糖尿病血糖波动风险）与合并用药中其他延长QT药物。边界：存在上述任一情形只生成"提示与医生确认"，不生成错误认定。
- **锚定**：年龄、合并诊断、合并用药清单、病原学结果
- **用途**：用药规则符合度画像 / 治疗回顾段 / 用药疑点标签
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S4-03
- **适用范围**：成人CAP住院患者
- **内容**：大环内酯类（阿奇霉素、克拉霉素等）：覆盖肺炎支原体、衣原体、军团菌等非典型病原体。核心口径：我国多数地区肺炎支原体对大环内酯类耐药率高，**不推荐大环内酯单药作为成人CAP常规经验性首选**；仅在大环内酯耐药率较低地区（如<25%）可用于单药经验治疗【数值待医学审核】。住院患者经验性方案中大环内酯主要作为β-内酰胺类基础上的联合用药（也以当地耐药率较低为前提），耐药率高地区改用呼吸喹诺酮类单药或β-内酰胺类联合四环素类（多西环素/米诺环素）。常见核查点：单药使用时患者分层是否符合指南情境、合并用药中其他影响QT间期药物。边界：耐药率是群体口径，个体药敏未回报前不能据此认定用药不当。
- **锚定**：联合用药医嘱、病原学结果（支原体核酸/抗体等）、心电图记录
- **用途**：用药规则符合度画像 / 用药疑点标签
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S4-04
- **适用范围**：成人CAP住院患者（流感流行季节或流感样起病情境）
- **内容**：抗流感病毒药物（奥司他韦等神经氨酸酶抑制剂）：流感检测阳性或流行季节流感样起病时，住院或重症患者通常考虑抗流感病毒治疗；重症者起病超过48小时仍可考虑使用，不因超时一律否定【数值待医学审核】。单纯病毒性肺炎是否联用抗菌药物需结合细菌感染证据判断——临床在无法排除合并细菌感染时经验联用属可解释情境，不是错误。
- **锚定**：发病日期、流感抗原/核酸检测结果、流行季节、是否ICU
- **用途**：用药规则符合度画像 / 用药疑点标签 / 治疗回顾段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S4-05
- **适用范围**：成人CAP住院患者
- **内容**：序贯（静脉转口服）核查点：符合S3-07条件后长期维持全静脉给药，会增加静脉炎、导管相关感染与费用负担；出院带药应与住院已用天数衔接、覆盖剩余疗程。核查输出仅为"可提示核对总疗程衔接"，不构成方案错误判断。
- **锚定**：给药途径变更记录、出院带药清单、抗感染总用药天数
- **用途**：用药规则符合度画像 / 费用解释段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S4-06
- **适用范围**：成人CAP住院患者
- **内容**：疗程与停药核查点：总疗程一般5–7天（重症/ICU或非典型病原体、有并发症者可延长）【数值待医学审核】，停药时机为退热后继续2–3天且主要呼吸道症状明显改善，或达到临床稳定（体温正常48–72小时且生命体征平稳）；多数指南强调总疗程至少5天。以临床稳定为基准而非固定天数；出院带药数量应能服完剩余疗程；患者提前自行停药属于依从性提示而非医方问题。输出时须与医嘱口径核对，医嘱有明确疗程说明的以医嘱为准。
- **锚定**：用药起止日期、出院带药数量与天数、出院医嘱
- **用途**：用药规则符合度画像 / 出院指引缺口标签
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S4-07
- **适用范围**：成人CAP住院患者
- **内容**：辅助用药情境：CAP住院常伴随祛痰药（如氨溴索）、退热镇痛药、支气管舒张剂（合并气道疾病时）等支持治疗；其中部分属可选对症治疗，其"有无"不构成规范缺陷。质子泵抑制剂等预防性用药是否与病情匹配可作为温和核查点输出。
- **锚定**：医嘱单全部药品、症状记录、合并诊断
- **用途**：用药规则符合度画像 / 费用解释段
- **来源**：国家卫生健康委社区获得性肺炎临床路径；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：FY-S4-08
- **适用范围**：成人CAP住院患者（老年、肾功能不全情境）
- **内容**：剂量调整核查点：老年人、肾功能不全者部分抗感染药物需调整剂量或间隔；核查用药前是否有肾功能记录、剂量是否按其调整。边界：材料未提供体重、肾功能或给药详情时，不得推断"剂量错误"，只能提示"材料不完整，无法核对剂量合理性"。
- **锚定**：年龄、肾功能检验结果、药物剂量与频次医嘱
- **用途**：用药规则符合度画像 / 用药疑点标签
- **来源**：《内科学》（人卫版）；《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》
- **状态**：draft-待医学审核

- **ID**：FY-S4-09
- **适用范围**：成人CAP住院患者
- **内容**：重复用药与相互作用核查点：同类抗菌药物重复联用（如两种同类喹诺酮）或三联以上抗感染联用需有重症/特殊病原依据，可作为核查提示；含相同解热成分的感冒药与退热药叠加使用提示过量风险。以上均为"提示核对"性质，须注明"以医嘱与药师意见为准"。
- **锚定**：全部住院医嘱与出院带药清单、药品成分
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《内科学》（人卫版）；国家卫生健康委社区获得性肺炎临床路径
- **状态**：draft-待医学审核
