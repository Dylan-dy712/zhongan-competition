## S1 疾病通俗解释

用途：为关怀报告“诊断通俗解释”段提供分层引用要点。引用时必须结合病例中的骨折部位、类型与治疗路径改写，不得整段照抄。条目按“一句话解释 → 发生了什么 → 为什么会得 → 住院期间发生了什么”层级组织。

- **ID**：FX-S1-01｜一句话解释：什么是骨折
- **适用范围**：全部四肢骨折
- **内容**：要点：①骨折＝骨的完整性或连续性部分或完全中断，通俗说法是“骨头断了/裂了”；②X线上看到的“骨折线”就是断裂的痕迹；③是否需要手术取决于断的部位、错开程度与稳定性，而不是“断没断”本身。
- **锚定**：影像报告中的骨折部位与分型；出院诊断
- **用途**：S1诊断解释段
- **来源**：《外科学》（人卫教材）骨折总论
- **状态**：draft-待医学审核

- **ID**：FX-S1-02｜发生了什么：断骨与周围组织
- **适用范围**：全部四肢骨折
- **内容**：要点：①断端可能错开（移位）、劈成多块（粉碎）或相互卡插（嵌插）；②骨折常伴周围软组织（肌肉、韧带、血管、神经）受累，因此肿胀淤青明显；③骨的愈合是身体自身修复过程，医生的作用是“把骨头对好并固定住，为愈合创造条件”。
- **锚定**：骨折形态学描述（移位/粉碎/嵌插）；有无合并神经血管损伤记录
- **用途**：S1诊断解释段
- **来源**：《外科学》（人卫教材）骨折总论
- **状态**：draft-待医学审核

- **ID**：FX-S1-03｜为什么会得：受伤机制分层
- **适用范围**：全部四肢骨折
- **内容**：要点：①最常见是外伤暴力：摔倒撑地、交通事故、高处坠落、重物砸伤等；②同一外力下是否骨折与骨质量有关：骨质疏松者轻微外力（如平地摔倒）即可骨折，称“脆性骨折”；③长期反复劳损可致应力性骨折（本包仅作术语级提示）。
- **锚定**：入院记录的受伤原因与机制；年龄；骨密度检查（如有）
- **用途**：S1诊断解释段
- **来源**：《外科学》（人卫教材）／《原发性骨质疏松症诊疗指南》
- **状态**：draft-待医学审核

- **ID**：FX-S1-04｜住院期间发生了什么：两条治疗路径
- **适用范围**：四肢骨折，区分保守/手术路径引用
- **内容**：要点：①保守路径：手法复位→石膏/支具固定（或持续牵引），配合消肿、镇痛与抗凝预防；②手术路径：麻醉下切开复位，用钢板螺钉/髓内钉/克氏针等把骨折固定在正确位置；③两条路径共同的部分：消肿、镇痛、预防血栓、预防感染、早期功能锻炼指导。
- **锚定**：治疗路径（保守/手术）、术式与固定材料、住院期间主要用药
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S1-05｜为什么恢复时间因人而异
- **适用范围**：全部四肢骨折
- **内容**：要点：①愈合速度与年龄、部位血供、骨质量、受伤能量、吸烟及合并症相关：血供差的部位（如腕舟骨、距骨、股骨颈）愈合更慢；②“影像上愈合”与“功能完全恢复”是两件事，后者常需更久；③总时长以月计，需按复查节奏动态评估，不宜给绝对承诺。
- **锚定**：年龄、部位、骨质疏松状态、吸烟史、合并症
- **用途**：S1诊断解释段 / 康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S1-06｜骨折愈合的自然过程
- **适用范围**：全部四肢骨折
- **内容**：要点：①愈合分三个阶段依次过渡：血肿炎症机化期→原始骨痂形成期→骨痂改造塑形期；②复查X线出现“骨痂形成”“骨折线模糊”代表愈合在推进，是积极信号；③塑形期可持续一至数年【数值待医学审核】，期间骨按受力逐步重塑。
- **锚定**：受伤/手术日期与复查日期的间隔；历次X线报告描述
- **用途**：S1诊断解释段 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

## S2 术语通俗对照

用途：为“术语解释动作”提供素材：当理赔材料术语出现在诊断、手术记录、影像报告中时，用对应条目做一句话通俗解释并指出患者常见误解点。每个条目对应设计表“术语/常见写法 | 通俗解释 | 患者为何困惑”的一行；为保持全包统一字段格式，后两栏并入内容字段。

- **ID**：FX-S2-01｜闭合性骨折
- **适用范围**：成人四肢骨折（本包主范围）；仅解释术语
- **内容**：通俗解释：骨折处皮肤完好，骨头断在皮肉里；多数闭合骨折走保守或常规手术路径。患者为何困惑：常误以为“没破皮就不严重”——严重程度取决于损伤能量与移位，不取决于皮肤是否破损。
- **锚定**：诊断中的“闭合性”字样
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）骨折总论
- **状态**：draft-待医学审核

- **ID**：FX-S2-02｜开放性骨折
- **适用范围**：仅作术语解释（本包不覆盖开放骨折复杂处理，见 exclusions）
- **内容**：通俗解释：骨折端刺破皮肤与外界相通，伤口可见或曾见深部组织外露；感染风险更高，处理更积极。患者为何困惑：以为“伤口大＝骨折重”，其实开放骨折的核心问题是感染与软组织损伤。
- **锚定**：诊断中的“开放性”；清创手术记录
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-03｜粉碎性骨折
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：骨折处碎成三块或更多，提示暴力较大；复位与固定的难度常更高，耗材使用可能更多。患者为何困惑：看到“粉碎”二字容易过度恐慌——现代固定技术下多数粉碎骨折仍可良好愈合。
- **锚定**：影像描述/术中所见“粉碎”；耗材清单
- **用途**：术语解释动作 / 费用解释段
- **来源**：《外科学》（人卫教材）／AO/OTA骨折通用分类
- **状态**：draft-待医学审核

- **ID**：FX-S2-04｜骨折移位
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：断端错开，可表现为短缩、侧方错开、旋转或重叠；“移位明显”常是手术指征之一。患者为何困惑：以为“有移位就必须手术”——是否手术取决于移位程度、部位与稳定性。
- **锚定**：影像报告中移位方向与程度；保守/手术路径选择
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-05｜成角畸形
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：断端纵轴形成夹角，像“折弯的尺子”；复位就是把角度纠正到可接受范围。患者为何困惑：对“成角多少度才算问题”无概念，报告带度数时容易自行对号入座。
- **锚定**：影像报告角度描述
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-06｜嵌插骨折
- **适用范围**：成人四肢骨折（肱骨外科颈、股骨颈等常见）
- **内容**：通俗解释：断端相互卡插在一起，通常相对稳定，有时甚至无需严格复位。患者为何困惑：直觉上觉得“插进去”比“错开”更吓人。
- **锚定**：影像描述“嵌插”
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-07｜不完全骨折/裂缝骨折
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：骨的连续性只有部分中断，如“竹子裂而未断”；通常更稳定、恢复更快。患者为何困惑：以为“只是裂缝不算骨折”而低估休养与复查要求。
- **锚定**：影像描述
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-08｜稳定型/不稳定型骨折
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：稳定型指复位后不容易再错位；不稳定型有再移位倾向，更多选择手术或更严格的固定与复查。患者为何困惑：不知道“稳定”是医学术语而非病情轻重的主观形容。
- **锚定**：诊断或影像中的稳定性描述；治疗路径
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-09｜复位（手法复位/闭合复位/切开复位）
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：把错开的骨头拉回对齐——不开刀叫手法复位（闭合复位），开刀直视下对齐叫切开复位。患者为何困惑：以为“没开刀就没治疗”；或把复位理解为“一次完成”，不理解复位后仍需固定维持、防止再移位。
- **锚定**：病程记录的复位方式与复位次数
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-10｜切开复位内固定术（ORIF）
- **适用范围**：成人四肢骨折手术路径
- **内容**：通俗解释：开刀直视下把骨头对好，再用钢板螺钉等金属物固定；“内固定”的“内”指固定物在体内。患者为何困惑：把“内固定”误解为“换了骨头”或“打了水泥”。
- **锚定**：手术记录术式名称
- **用途**：术语解释动作 / 费用解释段
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-11｜钢板螺钉内固定
- **适用范围**：成人四肢骨折手术路径
- **内容**：通俗解释：像“钢板＋螺丝”把断骨两侧夹住固定，材质多为钛合金等金属。患者为何困惑：担心金属“生锈”“要定期更换”，或不清楚是否必须取出。
- **锚定**：耗材清单中接骨板/螺钉条目
- **用途**：术语解释动作 / 费用解释段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-12｜髓内钉固定（交锁髓内钉）
- **适用范围**：长骨骨干骨折（股骨、胫骨、肱骨）常见
- **内容**：通俗解释：从骨中央的骨髓腔打入一根长钉固定，多用于股骨、胫骨等长骨；对软组织干扰小、固定轴线接近骨骼受力线。患者为何困惑：听到“钉子打进骨髓里”容易害怕，不理解这是长骨骨折常用且成熟的方式。
- **锚定**：术式名称（髓内钉/交锁髓内钉）
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-13｜克氏针固定
- **适用范围**：小骨块/辅助固定常见
- **内容**：通俗解释：细钢针穿过骨折块固定，常用于较小骨块或辅助固定；针尾有时留在皮肤外或皮下，多数需按期拔除。患者为何困惑：不知道针需要拔除，也不理解“针露在外面”是设计安排。
- **锚定**：术式名称；有无拔针记录
- **用途**：术语解释动作 / 复诊建议段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-14｜外固定架
- **适用范围**：软组织条件差或临时稳定情境；仅解释术语
- **内容**：通俗解释：钢针穿过骨头连到体外的支架上起固定作用；常见于软组织条件差或需要临时稳定的情形，条件允许后可能改为内固定。患者为何困惑：觉得“露在体外的机器”很吓人，也不理解为什么要分两步处理。
- **锚定**：术式名称
- **用途**：术语解释动作

- **ID**：FX-S3-01｜诊断标准要点

- **内容**：要点（常见对应，非绝对）：锁骨——保守或钢板；肱骨近端——保守/钢板/髓内钉；尺桡骨——钢板为主；桡骨远端——保守/克氏针/钢板/外固定；股骨颈——空心钉（年轻或嵌插型）或关节置换（置换另行扩展）；粗隆间——髓内钉为主；股骨干——髓内钉；髌骨——张力带或螺钉；胫腓骨——髓内钉或钢板；踝关节——钢板螺钉。术式与部位明显不匹配时（如股骨干仅用石膏）列为需核对情形。

## S4 用药规则

用途：为用药疑点标签与用药规则符合度画像提供核查点。本节总边界（适用于以下全部条目）：缺少适应证材料本身不能认定用药错误；本包不输出“用药错误”结论，所有“核查点”仅用于触发人工/模型复核。

- **ID**：FX-S4-01｜低分子肝素类（皮下注射抗凝）
- **适用范围**：下肢骨科大手术围术期、髋部骨折等高危患者

## S5 出院指引适用清单

用途：作为“出院小结缺乏康复指导”类标签的判定基准：以下任一条目对病例适用（锚定通过）但在出院材料中完全缺失时，可触发“出院指引缺口标签”。每个条目对应设计表“指引项 | 为什么要做 | 出院材料常见表述 | 若缺失时的建议动作”的一行；为保持统一字段格式，后三栏并入内容字段。

- **ID**：FX-S5-01｜功能锻炼计划
- **适用范围**：全部四肢骨折，保守/手术均适用
- **内容**：为什么要做：固定不等于静止；按阶段锻炼可防关节僵硬与肌肉萎缩。出院材料常见表述：“逐步行患肢功能锻炼”“遵医嘱康复训练”。若缺失时的建议动作：以S6对应分期要点生成个性化锻炼计划建议，并提示与主管医生确认。
- **锚定**：治疗路径（保守/手术）、固定方式、部位
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-02｜负重与制动要求
- **适用范围**：下肢骨折为主，上肢为负重限制
- **内容**：为什么要做：过早负重可致固定失效/再移位，过晚负重延缓恢复；下肢尤为关键。出院材料常见表述：“患肢禁负重X周”“扶拐部分负重”【具体数值待医学审核】。若缺失时的建议动作：按S6-04负重进阶要点生成“需与医生确认的负重问题清单”，不直接给出日期。
- **锚定**：受累肢体（上/下肢）、固定方式、术式
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《坎贝尔骨科手术学》

- **ID**：FX-S5-03｜伤口护理与拆线安排
- **适用范围**：手术路径
- **内容**：为什么要做：降低切口感染风险；拆线（或皮内缝合无需拆线）的时间与地点需明确。出院材料常见表述：“术后2周拆线（10–14天，关节周围可延长）”“保持敷料干燥”【数值待医学审核】。若缺失时的建议动作：生成拆线时间与伤口观察提示，标注需向医院确认。

- **ID**：FX-S5-04｜石膏/支具/牵引装置护理

## S6 康复/自我管理要点

用途：为“康复计划段”提供分期分场景要点。每条注明依赖的病例事实：生成时必须先核对锚定事实再引用；缺乏锚定事实的条目不得生成为“个体化计划”，只能作为通用提示并标注待确认。

- **ID**：FX-S6-01｜康复分期总则
- **适用范围**：全部四肢骨折
- **内容**：要点：①康复与愈合三阶段同步推进：制动期以消肿与等长收缩为主→骨痂期渐进关节活动与肌力→愈合后功能重塑；②总原则“循序渐进、以疼痛不加重为度”；③康复处方需与固定强度匹配——同样术式，固定牢靠者可更早活动。
- **锚定**：伤后/术后周数、固定方式、复查影像所见
- **用途**：康复计划段
- **来源**：《坎贝尔骨科手术学》／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S6-02｜固定期康复（保守/术后制动期）
- **适用范围**：石膏/支具/牵引固定期
- **内容**：要点：①固定范围外的关节主动活动（如前臂石膏固定时活动手指、肩）；②固定范围内肌肉等长收缩（绷紧—放松）；③抬高患肢消肿；④石膏内皮肤瘙痒勿伸物抓挠（关联FX-S9-10）。
- **锚定**：固定范围与固定物、伤后天数
- **用途**：康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S6-03｜术后早期康复
- **适用范围**：手术路径，固定稳定前提下
- **内容**：要点：①疼痛控制达标是早期活动前提（多模式镇痛）；②固定稳定的内固定术后可在医生指导下早期开始相邻关节活动，甚至部分负重（依术式与部位）【时机数值待医学审核】；③早期活动的目标是防血栓、防僵硬、保肌力，而非追求活动幅度。
- **锚定**：术式与固定稳定性、镇痛方案、恢复记录
- **用途**：康复计划段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S6-04｜下肢负重进阶
- **适用范围**：下肢骨折（髋/股/胫腓/踝等）
- **内容**：要点：①典型进阶：禁负重→触地/部分负重→完全负重，每级常以周计、以复查影像与医嘱为节点【各级时长数值待医学审核】；②髓内钉固定骨干骨折常可较早部分负重，关节内骨折通常更谨慎——仅为一般趋势，以医嘱为准；③可教患者用体重秤练习感知“部分负重”的力度。
- **锚定**：部位与术式、固定稳定性、复查影像、当前负重医嘱
- **用途**：康复计划段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S6-05｜上肢康复要点
- **适用范围**：锁骨、肱骨、尺桡骨、桡骨远端等
- **内容**：要点：①强调“未固定关节不停练”：手指抓握、肩肘活动，防僵硬；②抬臂/提物等负荷动作须待医嘱开放；③桡骨远端骨折恢复期常见腕关节僵硬与前臂旋转受限，需针对性锻炼【具体动作处方待医学审核/康复师确认】。
- **锚定**：上肢骨折部位、固定方式、外固定是否已拆除
- **用途**：康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S6-06｜髋部及下肢大手术后早期离床
- **适用范围**：髋部骨折、股骨干等下肢大手术
- **内容**：要点：①髋部骨折术后通常主张尽早离床站立/行走，以减少卧床并发症（肺炎、血栓、谵妄等）【具体离床时间数值待医学审核】；②离床训练分级进行：床边坐→站立→辅助行走，需镇痛与监护支持；③老年患者同步评估跌倒风险与营养状态。
- **锚定**：年龄、术式（内固定类型）、术后天数、并发症有无
- **用途**：康复计划段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S6-07｜关节周围骨折的活动度与肿胀管理
- **适用范围**：踝、肘、膝等关节内/关节周围骨折
- **内容**：要点：①关节内/关节周围骨折恢复期优先恢复活动度，关节僵硬是主要远期问题之一；②肿胀管理：抬高、踝泵/握拳泵、必要时弹力绷带；活动后肿胀加重属常见现象，休息抬高后缓解可继续，持续加重需就诊（关联FX-S9-09）。
- **锚定**：关节受累与否、术后周数
- **用途**：康复计划段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S6-08｜营养与生活方式
- **适用范围**：全部四肢骨折，骨质疏松者强化
- **内容**：要点：①每日足量元素钙（约800–1200毫克，随年龄与骨质疏松状态调整）与维生素D（常规400–800单位，防治需要时更高）【数值待医学审核】；②足量蛋白质摄入（奶、蛋、鱼、瘦肉、豆类）；③吸烟明确延缓骨愈合——戒烟应作为“康复处方”的一部分；④限酒。
- **锚定**：吸烟史、骨质疏松状态、饮食线索
- **用途**：康复计划段 / 长期随访加分项
- **来源**：《原发性骨质疏松症诊疗指南》／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S6-09｜辅具与居家环境
- **适用范围**：全部四肢骨折，下肢受累者强化
- **内容**：要点：①拐杖/助行器高度以“站立时握把约与髋同高、肘微屈”为参考【细节待医学审核】；②居家改造：清除地毯电线等绊倒隐患、卫生间防滑垫与扶手、夜间照明；③患肢期避免提重物（上肢）与单腿跳/跑（下肢）。

- **用途**：康复计划段
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S6-10｜心理支持要点
- **适用范围**：全部四肢骨折恢复期
- **内容**：要点：①常见担忧与安抚事实：恢复期疼痛波动属常见现象；“进度比别人慢”多与年龄/部位/基础状况有关，并非个人原因；②对恢复时间给区间预期而非承诺；③持续情绪低落、失眠等信号建议专业心理支持。生成“心理安抚”段引用本条时必须结合患者实际表述，不得虚构情绪状态。

## S7 复诊随访规范

用途：为“复诊建议段”提供通常节奏参考。总原则（FX-S7-01）优先：医嘱已提供复诊安排者以医嘱为准；医嘱未提供复诊日期时不生成确定日期，知识只提供通常节奏供确认与提醒。

- **ID**：FX-S7-01｜总原则：医嘱优先
- **适用范围**：全部四肢骨折
- **内容**：要点：①出院医嘱已写明复诊时间者，以医嘱为准，本节内容不覆盖；②医嘱未写明时，可按本节通常节奏生成“建议向医生确认的复查计划”，语言须为“通常/一般”，禁止生成确定日期承诺；③任何复查节奏都随愈合进度与并发症调整。
- **锚定**：出院医嘱复查条款有无
- **用途**：复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核
