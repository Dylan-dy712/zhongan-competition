1. 本知识包是"接地与核对依据"，不是科普文章库。报告中不得整段拼接本包内容；每条知识只能以要点形式、且被病例事实锚定后引用。
2. 用药条目（S4）一律不得生成"用药错误"类结论；只能生成"适用情境说明 + 核查点提示"，并须声明"缺少适应证/手术记录材料本身不能认定用药错误"。涉及双抗的表述一律包含"不得自行停药、调整前咨询医生"，不得生成任何鼓励停药的内容。
3. 优先级口径：主管医生书面医嘱/出院医嘱 > 本知识包一般口径。凡冲突，以医嘱为准并在报告中按医嘱表述。

5. 所有标注【数值待医学审核】的数值未经医学审核通过前，不得原样写入患者报告；费用条目（S8）不写具体金额、不生成"多收费/费用异常"结论。
6. 病例提示搭桥（CABG）、心衰、心肌病、瓣膜病时，先查 exclusions，不适用即转人工。

## S1 疾病通俗解释

用途：供报告"诊断通俗解释"段引用的分层要点（一句话解释 / 发生了什么 / 为什么会得 / 住院期间发生了什么），供生成器按病例事实（诊断分型、是否PCI、检查项目）选用，不得整段照搬。

- **ID**：GX-S1-01
- **适用范围**：全部（稳定性冠心病、ACS/PCI术后）
- **内容**：一句话解释：冠心病是"给心脏自己供血的血管变窄了"——心脏表面的冠状动脉内壁长出粥样硬化斑块，血管腔变窄或堵塞，心肌得不到足够的血液和氧气，出现胸痛胸闷，严重时心肌坏死；医学全称"冠状动脉粥样硬化性心脏病"，也称缺血性心脏病。
- **锚定**：出院诊断名称（冠心病/冠状动脉粥样硬化性心脏病）及其分型
- **用途**：S1诊断解释段
- **来源**：《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：GX-S1-02
- **适用范围**：全部（慢性阶段情境）
- **内容**：发生了什么（慢性阶段）：血液中的脂质等成分沉积在冠状动脉内壁形成斑块，斑块逐渐增大使血管变窄。狭窄到一定程度时，安静时供血尚可维持，而活动、饱餐、受凉、情绪激动时心肌需氧增加、供血跟不上，就出现劳力性心绞痛（胸痛胸闷），休息或含药后多可缓解。
- **锚定**：稳定性心绞痛诊断、造影提示的狭窄部位与程度、症状诱因记录（是否活动相关）
- **用途**：S1诊断解释段
- **来源**：《内科学》（人卫版）；《中国稳定性冠心病诊断与治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S1-03
- **适用范围**：全部（急性阶段情境）
- **内容**：发生了什么（急性阶段）：斑块变得不稳定、破裂或表面破损后，血液在破口处迅速凝固形成血栓，血管在短时间内被堵住或接近堵住，心肌急剧缺血——表现为不稳定型心绞痛或急性心肌梗死，统称"急性冠脉综合征（ACS）"。血管完全闭塞持续不缓解时，由它供血的心肌会逐步坏死（心肌梗死），"堵塞时间越长、坏死范围越大"。
- **锚定**：ACS/急性心肌梗死诊断、肌钙蛋白结果、心电图报告（ST段抬高/压低）、造影与血栓记录
- **用途**：S1诊断解释段
- **来源**：《内科学》（人卫版）；《急性ST段抬高型心肌梗死诊断和治疗指南》；《非ST段抬高型急性冠脉综合征诊断和治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S1-04
- **适用范围**：全部
- **内容**：为什么会得：冠心病是多种危险因素长期共同作用的结果，主要包括高血压、血脂异常（尤其"坏胆固醇"LDL-C升高）、糖尿病、吸烟、超重肥胖、缺乏运动、高龄、男性或绝经后女性、早发冠心病家族史（男性直系亲属55岁前、女性65岁前患病【数值待医学审核】）、长期精神紧张等。危险因素越多、控制越差，风险越高；反之，控制这些因素本身就是治疗的一部分。
- **锚定**：既往史（高血压/糖尿病/血脂异常）、吸烟史、家族史、身高体重/BMI
- **用途**：S1诊断解释段
- **来源**：《内科学》（人卫版）；《中国心血管病一级预防指南》
- **状态**：draft-待医学审核

- **ID**：GX-S1-05
- **适用范围**：稳定性冠心病（药物/评估路径）
- **内容**：住院期间发生了什么（药物与评估路径）：稳定性冠心病住院的目的通常是"查清楚、定方案"——做心电图、抽血（血脂、血糖、肌钙蛋白等）、心脏彩超，多数会经冠脉造影（或先做冠脉CTA）确认血管狭窄的部位与程度；医生据此决定以药物治疗为主还是需要植入支架，并调整抗血小板、他汀等长期用药。没有做支架不代表"白住院"，明确诊断本身就是住院的核心产出。
- **锚定**：住院经过记录、检查项目清单（造影/CTA/彩超）、出院诊断与带药清单
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《中国稳定性冠心病诊断与治疗指南》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：GX-S1-06
- **适用范围**：ACS/PCI术后路径
- **内容**：住院期间发生了什么（ACS/PCI路径）：急性发病入院后，通常先用心电图和肌钙蛋白明确分型；符合指征者行急诊或早期冠脉造影，通过球囊把狭窄处撑开并植入支架（PCI），术后进入心脏监护（CCU）观察心律与穿刺伤口，并启动双联抗血小板等药物治疗；出院前常复查心脏彩超评估心功能。这些是急性期的标准动作，监护与复查不是"过度医疗"。
- **锚定**：入院/急诊时间、造影与PCI手术记录、支架数量与类型、监护（CCU）记录、穿刺入路（桡/股）
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》；《非ST段抬高型急性冠脉综合征诊断和治疗指南》；《中国经皮冠状动脉介入治疗指南》
- **状态**：draft-待医学审核

## S3 诊疗规范要点

用途：供治疗回顾段核对住院经过是否符合规范路径、生成"检查疑点标签"与"治疗规范符合度画像"、供费用基线参考（住院天数）引用；条目只做"事实与情境核对"，不做病例级医疗质量结论。

- **ID**：GX-S3-01
- **适用范围**：全部
- **内容**：诊断标准要点：ACS诊断依赖三要素结合——缺血性胸痛等临床表现＋心电图动态改变＋心肌损伤标志物（肌钙蛋白）动态变化，并据此分为STEMI、NSTEMI、不稳定型心绞痛；稳定性冠心病的诊断依赖典型症状特点＋缺血证据＋解剖学证据（冠脉造影或冠脉CTA显示有意义狭窄）。诊断名称与检查结果互相印证，是报告核对的基本盘。
- **锚定**：入院记录症状描述、心电图报告、肌钙蛋白结果序列、造影/CTA报告、出院诊断分型
- **用途**：治疗回顾段 / 检查疑点标签 / 治疗规范符合度画像
- **来源**：《急性ST段抬高型心肌梗死诊断和治疗指南》；《非ST段抬高型急性冠脉综合征诊断和治疗指南》；《中国稳定性冠心病诊断与治疗指南》
- **状态**：draft-待医学审核

- **ID**：GX-S3-02
- **适用范围**：全部（疑似ACS情境）

## S6 康复/自我管理要点

用途：供康复计划段生成个性化、可执行的要点；每条标注依赖的病例事实，缺锚定事实时不得引用该条；心脏康复分期引用《中国心脏康复与二级预防指南》框架。

- **ID**：GX-S6-01
- **适用范围**：ACS/PCI术后住院期及出院即刻（Ⅰ期：院内康复期）
- **内容**：心脏康复Ⅰ期（院内康复期）：在评估与监护下的早期活动（床上活动→床边坐起→站立→步行，逐级推进）与健康宣教（戒烟、用药、危险因素认知），出院前完成运动能力初步评估与康复转介。活动进度由医护人员决定，患者不应自行加量；术后早期"多躺不动"与"过早用力"都不利于恢复。
- **锚定**：住院天数、CCU监护记录、出院前评估记录、是否转介康复科
- **用途**：康复计划段 / 长期随访加分项
- **来源**：《中国心脏康复与二级预防指南》
- **状态**：draft-待医学审核

- **ID**：GX-S6-02
- **适用范围**：出院后早期（Ⅱ期：院外早期康复/门诊康复期，通常出院后1–6个月【数值待医学审核】）
- **内容**：心脏康复Ⅱ期：在有评估与监护条件的门诊/康复中心进行规律运动训练（有氧为主，逐步加入抗阻训练），同步强化用药依从、危险因素与饮食管理；有条件的患者建议参加，尤其高危（LVEF下降、合并糖尿病、高龄）人群。
- **锚定**：出院日期、LVEF、合并症、是否PCI、居住地康复资源
- **用途**：康复计划段
- **来源**：《中国心脏康复与二级预防指南》
- **状态**：draft-待医学审核

- **ID**：GX-S6-03
- **适用范围**：Ⅱ期之后长期（Ⅲ期：院外长期康复/社区家庭期）
- **内容**：心脏康复Ⅲ期：在社区或家庭环境下长期维持Ⅱ期建立的运动习惯与生活方式（运动、饮食、戒烟、情绪、用药），定期复诊由医生调整方案；本期的核心是"不中断"，随访断档与擅自停药是常见退行点。
- **锚定**：出院时长、既往随访记录、社区资源
- **用途**：康复计划段 / 长期随访加分项
- **来源**：《中国心脏康复与二级预防指南》
- **状态**：draft-待医学审核

- **ID**：GX-S6-04
- **适用范围**：出院后运动指导情境
- **内容**：运动处方原则（供生成要点，非患者成段文案）：以有氧运动为主（快走、骑车、游泳等），辅以抗阻与柔韧训练；单次时长、每周频次与强度个体化，常用中等强度的简易判断是"运动中能说话、不能唱歌"；术后初期从低强度、短时间开始逐步递增。运动中出现胸痛、头晕、明显气促立即停止并就医。

- **用途**：康复计划段

- **ID**：GX-S6-06

- **ID**：GX-S6-07

## S7 复诊随访规范

用途：供复诊建议段引用；时间线仅描述"通常节奏"供用户与医生确认，医嘱优先——医嘱未提供复诊日期时不生成确定日期。

- **ID**：GX-S7-01
- **适用范围**：全部条目的总原则
- **内容**：原则声明：复诊时间与项目以主管医生出院医嘱为最高优先级；医嘱未提供复诊日期时，本知识包不生成确定日期，仅以"出院后通常节奏"供用户与医生确认，报告措辞使用"可与医生确认"而非"应当于X日复诊"。随访节奏受支架类型、心功能、合并症与出血风险影响，个体差异大。
- **锚定**：出院医嘱原文（是否含复诊时间与项目）
- **用途**：复诊建议段
- **来源**：《中国经皮冠状动脉介入治疗指南》（随访框架）；医嘱优先原则基于本项目知识包设计规范
- **状态**：draft-待医学审核

- **ID**：GX-S7-02
- **适用范围**：PCI术后随访节奏
- **内容**：PCI术后常见随访节奏：出院后1个月、3个月、6个月、12个月门诊随访【数值待医学审核】，此后通常每6–12个月一次【数值待医学审核】；每次随访核对症状（胸痛/气促/心悸）、用药依从（尤其双抗是否在服）、血压/血脂/血糖/体重与吸烟状态。仅当医嘱未给日期时，以出院日期推算提示"可确认"的节点，不写入确定日期。
- **锚定**：出院日期、出院医嘱随访安排、支架类型
- **用途**：复诊建议段 / 长期随访加分项
- **来源**：《中国经皮冠状动脉介入治疗指南》；《中国稳定性冠心病诊断与治疗指南》
