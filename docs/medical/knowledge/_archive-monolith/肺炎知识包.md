# 肺炎知识包（草稿）

**使用边界（对生成器的红线约束，优先级高于任何单条知识）：**

1. 本知识包是"接地与核对依据"，不是科普文章库。报告中不得整段拼接本包内容；每条知识只能以要点形式、且被病例事实锚定后引用。
2. 用药条目（S4）一律不得生成"用药错误"类结论；只能生成"适用情境说明 + 核查点提示"，并须声明"缺少病原学/适应证材料本身不能认定用药错误"。
3. 优先级口径：主管医生书面医嘱/出院医嘱 > 本知识包一般口径。凡冲突，以医嘱为准并在报告中按医嘱表述。
4. 复诊日期生成规则：出院医嘱提供了日期则用医嘱；未提供时不得生成确定日期，仅按 S7-01 提示"可与医生确认通常节奏"。
5. 所有标注【数值待医学审核】的数值未经医学审核通过前，不得原样写入患者报告。

## S1 疾病通俗解释

用途：供报告"诊断通俗解释"段引用的分层要点（一句话解释 / 发生了什么 / 为什么会得 / 住院期间发生了什么 / 严重度与预后），供生成器按病例事实选用，不得整段照搬。

- **ID**：FY-S1-01
- **适用范围**：成人CAP住院患者
- **内容**：一句话解释：肺炎是肺部（主要是肺泡和肺间质）的感染性炎症，多由细菌或病毒引起；"社区获得性肺炎"指在日常生活环境中获得的感染（区别于住院期间获得的肺部感染）。
- **锚定**：出院诊断名称（社区获得性肺炎/肺部感染）、入院方式（急诊/门诊入院）、入院主诉起病场景
- **用途**：S1诊断解释段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：FY-S1-02
- **适用范围**：成人CAP住院患者
- **内容**：发生了什么：病原体进入下呼吸道后，肺泡内出现炎性渗出（液体与炎症细胞聚集），影响氧气交换，因此出现发热、咳嗽、咳痰、气促、胸痛等症状；影像报告里的"片状影/渗出/实变"就是这种炎症的痕迹。
- **锚定**：影像报告术语、症状记录（咳嗽、咳痰、气促、发热）
- **用途**：S1诊断解释段 / 术语解释动作
- **来源**：《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：FY-S1-03
- **适用范围**：成人CAP住院患者
- **内容**：为什么会得：受凉、疲劳、感冒后、吸烟、年龄增长和慢性基础病（慢性肺病、糖尿病、心脏病、脑血管病等）都会削弱呼吸道防御能力，使常见病原体"趁虚而入"；多数病原体经口咽分泌物误吸或飞沫吸入进入肺部，并非"传染给别人那种传染病"的通常理解。
- **锚定**：年龄、吸烟史、基础疾病诊断、起病诱因记录
- **用途**：S1诊断解释段
- **来源**：《内科学》（人卫版）；《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》
- **状态**：draft-待医学审核

- **ID**：FY-S1-04
- **适用范围**：成人CAP住院患者
- **内容**：住院期间通常发生了什么：经验性抗感染治疗（先按最可能的病原体用药，再按培养/药敏结果调整）、按需氧疗、退热补液等支持治疗，以及复查血常规/炎症指标和胸片或CT来评估疗效——这些是CAP住院的标准动作，不是"过度检查"。
- **锚定**：医嘱单（抗感染药、吸氧、补液）、检验检查执行记录、住院天数
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；国家卫生健康委社区获得性肺炎临床路径
- **状态**：draft-待医学审核

- **ID**：FY-S1-05
- **适用范围**：成人CAP住院患者
- **内容**：严重度谱系：CAP可以从"门诊口服药即可"到"需要住院、吸氧甚至ICU支持"；轻重取决于病原体、肺部受累范围、血氧水平和基础病，医生常用CURB-65等工具评估治疗场所。住普通病房不等于病重，进ICU也不等于"没有希望"——多数CAP经规范治疗可完全康复。
- **锚定**：CURB-65或等效严重度评估记录、是否吸氧、是否入住ICU
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

- **ID**：FY-S1-06
- **适用范围**：成人CAP住院患者
- **内容**：与普通感冒的区别：感冒以上呼吸道症状（鼻塞、咽痛、打喷嚏）为主且多在一周左右自限；肺炎累及肺实质，常伴持续发热、脓性痰、气促、胸痛，且呈进行性加重不缓解——这正是需要影像和血液检查的原因。
- **锚定**：起病症状记录（发热天数、痰性状、是否气促）
- **用途**：S1诊断解释段
- **来源**：《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：FY-S1-07
- **适用范围**：成人CAP住院患者
- **内容**：预后口径：无严重基础病的轻中度CAP经规范治疗多可完全康复；影像吸收常滞后于症状好转（"人好了、片子上还没全好"是常见现象），不代表治疗失败，也不必为影像未完全吸收而延长住院。
- **锚定**：出院时症状、出院前是否复查影像及报告结论
- **用途**：S1诊断解释段 / 康复计划段
- **来源**：《中国成人社区获得性肺炎诊断和治疗指南（2016年版）》；IDSA/ATS成人CAP指南（2019）
- **状态**：draft-待医学审核

## S2 术语通俗对照

用途：术语解释动作——理赔材料中出现下列术语时查表生成通俗解释；部分条目同时供诊断解释段、检查/用药疑点标签引用。

说明：本节按槽位定义采用表格形式。每行是一个条目，逐条字段（ID、术语/常见写法、通俗解释、患者为何困惑、用途）在表中列明；统一字段以表后"公共字段声明"为准，与全文统一列表字段等效。

| ID | 术语/常见写法 | 通俗解释 | 患者为何困惑 | 用途 |
|---|---|---|---|---|
| FY-S2-01 | 社区获得性肺炎（CAP） | 在日常生活环境中感染的肺部炎症，是与"住院后才发生的肺部感染"相对的分类，也是最常见的住院肺炎类型 | "社区获得"听着像统计术语，患者容易误以为与"小区传染"有关；实际只描述感染发生的时间与地点 | 术语解释动作 / S1诊断解释段 |
| FY-S2-02 | 医院获得性肺炎（HAP）/呼吸机相关性肺炎（VAP） | 入院48小时以后才发生的肺部感染称HAP；使用呼吸机期间发生的肺炎称VAP，属于另一套诊疗规范 | "医院获得"易被理解为"在医院被传染"的追责表述，实际只是感染时间与地点的归类用语 | 术语解释动作 |
| FY-S2-03 | 病原学检查/病原送检 | 查明"到底是什么病原体引起"的一类检查，包括痰培养、血培养、涂片、抗原、核酸等 | 名词笼统，患者常分不清普通抽血≠查病原，也误以为"没查出结果=白查了" | 术语解释动作 / 检查疑点标签 |
| FY-S2-04 | 痰培养+药敏试验 | 把痰送实验室培养，看长出什么细菌，再测试哪种抗菌药能抑制它（药敏），供医生调整用药 | 通常需数天才有结果，患者会问"药早用了，这报告还有什么用"；其实它正是后续精准调整的依据 | 术语解释动作 / 治疗回顾段 |
| FY-S2-05 | 血培养 | 抽血查看血液中是否有细菌，用于判断感染是否入血，重症和发热患者常在用抗菌药前送检 | 易与普通抽血化验混淆；"结果阴性"也会被误读为白花钱，阴性本身对排除菌血症有信息价值 | 术语解释动作 / 检查疑点标签 |
| FY-S2-06 | 痰涂片（革兰染色） | 把痰直接染色后在显微镜下看细菌大类（球菌/杆菌等），比培养快但更粗略 | 分不清"涂片"与"培养"的区别，不明白为什么同一份痰要查两次 | 术语解释动作 |
| FY-S2-07 | 非典型病原体（支原体、衣原体、军团菌） | 一类在常规培养基上不易检出、对青霉素类天然不敏感的病原体，需要喹诺酮类或大环内酯类药物覆盖 | "非典型"易被理解为病情不典型或更严重，实际只是病原体的实验室特性描述 | 术语解释动作 / S1诊断解释段 |
| FY-S2-08 | 核酸检测（PCR等） | 直接检测病原体遗传物质的检查，速度快、灵敏度高，常用于支原体、流感病毒等 | 因新冠经历易与新冠核酸混淆；不同病原体的"阳性"含义和处置不同，需结合医嘱理解 | 术语解释动作 |
| FY-S2-09 | 尿抗原检测（肺炎链球菌/军团菌尿抗原） | 用尿液快速检测两种特定病原体，出结果快，多用于重症患者的早期病原判断 | 患者"查尿查肺"觉得不搭；阳性提示特定病原，通常意味着治疗可以更有针对性 | 术语解释动作 / 检查疑点标签 |
| FY-S2-10 | 白细胞计数（WBC） | 反映全身炎症/感染反应的血液指标，细菌性肺炎时常升高，治疗后回落 | 患者只看箭头不懂含义；部分重症白细胞可不升反降，"不高"不等于"没感染" | 术语解释动作 / 治疗回顾段 |
| FY-S2-11 | 中性粒细胞比例 | 白细胞中占比最高的一类，细菌感染时常升高，是感染方向的参考 | 与白细胞总数混淆；只看比例不看总数容易误读 | 术语解释动作 |
| FY-S2-12 | C反应蛋白（CRP） | 肝脏在炎症刺激下产生的急性期蛋白，升高提示炎症活动，常用于跟踪治疗反应 | 名字生僻，常被当成"肿瘤指标"或"特异性感染指标"；实际上它不区分感染种类 | 术语解释动作 / 治疗回顾段 |
| FY-S2-13 | 降钙素原（PCT） | 严重细菌感染时明显升高的指标，用于辅助判断细菌感染可能、评估严重程度并支持抗菌药物的启用与停用 | 名字含"钙"易被误解为与补钙、甲状腺相关；实际是感染严重度与抗菌药物管理的参考指标 | 术语解释动作 / 用药疑点标签 |
| FY-S2-14 | 片状影/斑片影 | 影像上对肺部炎症渗出的常见描述，如玻璃上的"哈气"状阴影，是肺炎在影像上的直接表现 | "影"字容易让人联想到肿瘤；肺炎的片状影多数随治疗吸收 | 术语解释动作 / S1诊断解释段 |
| FY-S2-15 | 渗出/炎性渗出 | 炎症时血管内液体和炎症细胞进入肺泡、影响氧气交换，是影像"影子"的来源 | 抽象词，患者不明白"渗出"与自己咳嗽发热的直接关系 | 术语解释动作 |
| FY-S2-16 | 实变 | 肺泡内充满渗出物、空气被替代，影像上呈致密阴影；范围较大时常提示炎症较重 | 字面像"肺变实了、变坏了"，易引起恐慌；多数经治疗可复张吸收 | 术语解释动作 / S1诊断解释段 |
| FY-S2-17 | 胸腔积液 | 胸膜腔内出现异常液体；肺炎可合并反应性积液，少量多随炎症消退自行吸收 | 以为"有积液一定要抽"；是否穿刺引流取决于积液量与性质 | 术语解释动作 / 检查疑点标签 |
| FY-S2-18 | 磨玻璃影 | 影像上云雾状、淡如磨砂玻璃的阴影，可见于炎症早期或病毒性肺炎等，意义需结合临床 | 在新冠语境下被过度联想；单凭磨玻璃影不能判断病因与预后 | 术语解释动作 |
| FY-S2-19 | 血氧饱和度（SpO₂） | 指尖血氧仪测出的"血液携带氧气能力的百分比"，通常正常在95%以上【数值待医学审核】 | 不知道夹手指的小仪器是做什么的；数值小幅波动常引起不必要的紧张 | 术语解释动作 |
| FY-S2-20 | 低氧血症 | 血液中氧含量低于正常，是判断肺炎严重程度和是否需要吸氧的关键依据 | 无明显不适时也可能有轻度低氧；"我自己觉得呼吸没事"与仪器读数不一致时，以测量为准 | 术语解释动作 / 治疗回顾段 |
| FY-S2-21 | 呼吸衰竭（I型/II型） | 肺部气体交换严重受损：I型以缺氧为主，II型同时伴二氧化碳潴留，是重症标志之一 | "衰竭"一词引发强烈恐惧，被理解为不可逆；肺炎相关的呼吸衰竭多数随治疗改善 | 术语解释动作 / S1诊断解释段 |
| FY-S2-22 | 鼻导管吸氧 | 从鼻孔给氧的细管，低流量给氧，是肺炎最常用的氧疗方式 | 常见误解"吸氧会上瘾/有依赖"；按病情需要短期氧疗不存在依赖问题 | 术语解释动作 / 治疗回顾段 |
| FY-S2-23 | 面罩吸氧/经鼻高流量 | 比鼻导管供氧量更大的氧疗方式，用于缺氧更明显时 | 设备看起来"很重"，家属易据此认定病危；需结合整体病情理解 | 术语解释动作 / 治疗回顾段 |
| FY-S2-24 | CURB-65评分 | 医生使用的肺炎严重度评分工具，基于意识、呼吸、血压、年龄等要素，用于决定门诊/普通病房/ICU的治疗场所 | 患者看不到"打分"过程，也不理解其含义；担心低分被"轻视"、高分"没救"，实际只是分诊工具 | 术语解释动作 / 治疗回顾段 / 治疗规范符合度画像 |
| FY-S2-25 | 经验性治疗/降阶梯/目标治疗 | 先按最可能的病原体使用覆盖面较广的方案（经验性），待培养药敏回报后再精准收窄（目标治疗/降阶梯） | 不明白"为什么先上广谱药""为什么又换药"，误以为医生在盲目试错 | 术语解释动作 / 治疗回顾段 |
