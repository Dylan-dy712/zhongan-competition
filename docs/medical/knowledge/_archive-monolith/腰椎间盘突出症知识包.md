## S1 疾病通俗解释

用途：为关怀报告“诊断通俗解释”段提供分层引用要点。引用时必须结合病例中的责任节段、突出类型与治疗路径改写，不得整段照抄。条目按“一句话解释 → 发生了什么 → 为什么会得 → 住院期间发生了什么”层级组织。

- **ID**：YZ-S1-01｜一句话解释：什么是腰椎间盘突出症
- **适用范围**：成人腰椎间盘突出症，保守/手术路径均适用
- **内容**：要点：①腰椎间盘突出症＝椎间盘（两节椎骨之间的“减震软垫”）中央的髓核部分越出正常边界，压迫或刺激邻近神经根（重者累及马尾神经），引起腰痛伴下肢放射痛、麻木或无力的常见脊柱疾病；②是否需要手术取决于神经受压情况与规范保守治疗的效果，而不是“有没有突出”本身——多数患者经保守治疗可以缓解。
- **锚定**：出院诊断、MRI/CT报告的责任节段与突出类型、保守/手术路径
- **用途**：S1诊断解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S1-02｜发生了什么：软垫、破口与神经
- **适用范围**：成人腰椎间盘突出症
- **内容**：要点：①椎间盘外层是坚韧的“外胎”（纤维环），中央是胶冻状的“芯”（髓核）；②退变或劳损使纤维环出现薄弱或破口，髓核经此外凸（膨出/突出/脱出，程度不同）；③突出物压迫或刺激神经根，并引发局部炎症反应——腿痛腿麻来自神经受累，不是“腰断了”也不是“骨刺”；④影像报告看到“突出”与真正患病是两回事：症状取决于是否压迫神经及压迫程度。
- **锚定**：影像报告形态学描述（膨出/突出/脱出、硬膜囊/神经根受压）、责任节段
- **用途**：S1诊断解释段 / 术语解释动作
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S1-03｜为什么会得：退变加诱因
- **适用范围**：成人腰椎间盘突出症
- **内容**：要点：①椎间盘随年龄退变（含水量下降、韧性变差）是基础，“人到中年间盘先老”属普遍现象；②长期久坐、经常弯腰负重、搬运重物、长时间驾驶等加速退变并增加突出风险；③突然的弯腰扭转发力（如搬重物、猛起身）可以是急性发作的诱因；④遗传倾向、吸烟、肥胖相关。它不是“受凉坐月子落下的病”，也不是单纯“缺钙”。
- **锚定**：年龄、职业与生活史记录、起病诱因描述
- **用途**：S1诊断解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／NASS腰椎间盘突出症伴神经根病临床指南（2012）
- **状态**：draft-待医学审核

- **ID**：YZ-S1-04｜住院期间发生了什么：保守治疗路径
- **适用范围**：保守治疗路径
- **内容**：要点：①保守住院的规范动作通常包括：药物镇痛抗炎、必要时短期卧床后恢复活动、牵引/理疗等辅助、神经营养药、活动指导与宣教；②目的不是“把突出的髓核推回去”——突出的椎间盘大多无法经保守治疗完全复位，缓解来自炎症消退与神经适应；③保守住院主要是为了让规范治疗集中进行并观察效果，不等于“病得重”。
- **锚定**：保守治疗记录（用药、理疗、牵引、卧床与活动医嘱）、住院天数
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《腰椎间盘突出症诊疗中国疼痛专家共识》
- **状态**：draft-待医学审核

- **ID**：YZ-S1-05｜住院期间发生了什么：手术路径
- **适用范围**：手术路径（微创/减压/融合）
- **内容**：要点：①微创路径（椎间孔镜等）：经皮肤小切口置入工作通道，镜下直接摘除压迫神经的髓核组织，创伤小、恢复快；②开放减压路径：咬除部分椎板（椎板减压）扩大神经通道后摘除髓核；③融合内固定路径：在减压基础上于椎体间植骨并用椎弓根螺钉等固定，让病变节段长牢，用于合并不稳、狭窄或复发者；④共同部分：术前评估（以MRI为主）、麻醉、术后镇痛与引流、轴线翻身、佩戴腰围渐进下床、康复指导。
- **锚定**：术式名称（微创/减压/融合）、手术日期、引流与翻身护理记录
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S1-06｜症状与恢复的对应关系
- **适用范围**：成人腰椎间盘突出症
- **内容**：要点：①典型表现是腰痛＋一侧下肢放射痛（自臀部向大腿后侧、小腿走行），伴麻木或无力——因为受压神经根支配特定区域（如L4/5节段常累及小腿外侧至足背、L5/S1常累及小腿后外侧至足外侧，定性表述）；②直腿抬高试验阳性支持神经根受压；③多数患者经规范保守治疗可在数周至数月内明显改善【数值待医学审核】；④恢复顺序通常是疼痛先减轻、麻木与肌力恢复更慢——“还剩点麻”不代表治疗无效，麻木完全消退可能以月计。
- **锚定**：症状记录（放射痛、麻木、肌力）、责任节段、治疗日期与症状变化记录
- **用途**：S1诊断解释段 / 康复计划段 / 复诊建议段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

| YZ-S2-12 | 硬膜囊/硬脊膜 | 包裹神经的连续膜性“袖套”；MRI报告“硬膜囊受压”指突出物顶到了这层膜 | “受压”字样引发紧张；轻度受压而无神经症状很常见，不等于必须手术 | 术语解释动作 / 检查疑点标签 |
| YZ-S2-13 | 直腿抬高试验（SLR/Lasègue征） | 医生平卧抬起患者伸直的下肢，未达70°左右即诱发沿坐骨神经走行的放射痛为阳性【数值待医学审核】，是神经根受压的经典体征 | 误以为“腿抬不高＝阳性”；阳性看的是是否诱发沿神经走向的放射痛，不是活动度本身 | 术语解释动作 / 治疗回顾段 |
| YZ-S2-14 | 间歇性跛行 | 走一段距离后下肢酸胀、沉重、无力，蹲下或弯腰休息后缓解、可继续行走；是腰椎管狭窄的典型表现 | 常被归因为“老了腿脚不好”或关节炎而延迟就诊；也易与下肢血管问题混淆，需医生鉴别 | 术语解释动作 / S1诊断解释段 |
| YZ-S2-15 | 神经根性痛/坐骨神经痛 | 神经根受刺激引起的沿神经走行的疼痛：自腰部经臀部向大腿后侧、小腿放散，可伴麻木无力 | 以为“坐骨神经痛”是独立疾病；实际是描述疼痛走行的一类表现，病因需结合影像定位 | 术语解释动作 / S1诊断解释段 |
| YZ-S2-16 | 马尾综合征 | 支配会阴与大小便功能的神经束（马尾神经）受压：鞍区麻木、大小便障碍、双下肢无力、性功能障碍，属需紧急处理的急症 | 名词陌生且症状涉及隐私，患者常羞于表述而延误；本包列为🔴级信号（见S9） | 术语解释动作 / 优先行动 |
| YZ-S2-17 | 椎板减压（椎板开窗/半椎板切除/全椎板切除） | 咬除部分椎板骨质、扩大神经通道以解除压迫的手术步骤；“开窗”即只开一个小骨窗，创伤相对小 | 以为“骨头被切掉一块腰就垮了”；椎板部分切除通常不影响脊柱整体稳定性，需结合是否融合理解 | 术语解释动作 / 治疗回顾段 |
| YZ-S2-18 | 髓核摘除 | 手术直接取出压迫神经的突出/脱出髓核组织，是各类减压手术的共同核心动作 | 误以为是“把整个椎间盘切掉换新的”；实际只摘除压迫神经的那一部分 | 术语解释动作 / 治疗回顾段 |
| YZ-S2-19 | 椎间融合术（融合内固定，PLIF/TLIF等） | 摘除椎间盘后在椎体间植入融合器/骨材并固定，让病变节段长为一体；用于需广泛减压或节段不稳定者 | 最易恐慌“打了钉子腰就不能动了”；单节段融合对整体活动影响有限，但恢复节奏更慢 | 术语解释动作 / 费用解释段 |
| YZ-S2-20 | 椎弓根螺钉（内固定系统） | 经椎弓根拧入椎体的螺钉加连接棒，起临时稳定作用、为植骨融合创造条件；材质多为钛合金 | 担心金属“生锈、要定期更换、不能过安检或做磁共振”；钛合金性质稳定，具体注意事项遵医嘱 | 术语解释动作 / 费用解释段 |
| YZ-S2-21 | 椎间孔镜髓核摘除（PELD等微创术式） | 经皮肤约数毫米至1厘米左右切口置入内镜通道，镜下摘除突出髓核的微创术式；创伤小、恢复快【切口尺寸数值待医学审核】 | “微创”易被理解为“不用养”；同样需要恢复期保护，且并非所有突出类型都适合 | 术语解释动作 / 治疗回顾段 |
| YZ-S2-22 | 腰围（腰部支具） | 术后或急性期短期佩戴的腰部支撑具，限制过度屈伸、辅助稳定与保护 | 两个常见误区：全程佩戴“越久越好”（可致腰背肌萎缩）或完全不用；佩戴时限应遵医嘱 | 术语解释动作 / 康复计划段 |
| YZ-S2-23 | 轴线翻身 | 保持头、颈、肩、腰、髋呈一条直线整体同步翻身，避免脊柱扭转；是腰椎术后翻身的标准方法 | 不理解“为什么要像木头一样翻”；扭转可能牵拉手术节段，轴线翻身正是为了保护 | 术语解释动作 / 出院指引缺口标签 |
| YZ-S2-24 | 腰椎牵引 | 用持续或间歇拉力放松腰背肌、增大椎间隙的辅助保守治疗手段 | 以为牵引能“把突出的髓核拉回去”；实际以缓解肌肉痉挛与疼痛为主，个体差异大 | 术语解释动作 / 费用解释段 |
| YZ-S2-25 | 理疗/物理因子治疗 | 热疗、电刺激（中频/低频）、超声等物理手段，缓解疼痛与肌肉紧张，属保守治疗的辅助 | 费用单据上理疗项目名目繁多，患者以为重复收费；不同理疗目的相近但机制互补，是否叠加由医嘱决定 | 术语解释动作 / 费用解释段 |
| YZ-S2-26 | 腰椎MRI与CT | MRI显示椎间盘、神经与软组织最清楚，是定位责任节段的主力；CT更擅长骨性结构（增生、钙化、术后评估） | 分不清“为什么做了CT还要做MRI”或相反；两者看的东西不同，不能简单互相替代 | 术语解释动作 / 检查疑点标签 / 费用解释段 |
| YZ-S2-27 | 肌电图（EMG） | 记录神经肌肉电活动，客观判断神经根损害的部位与严重程度，与影像互为补充 | 检查时电刺激略不适，误以为“电击治疗”；常问“影像都做了为什么还要做”——它看的是神经功能而非结构 | 术语解释动作 / 检查疑点标签 |
| YZ-S2-28 | 疼痛/功能评分（VAS、ODI） | VAS是0–10分的疼痛强度自评分；ODI是腰椎功能障碍问卷指数；用于治疗前后的对比随访 | 不知道病历上的分数是“自己打的主观分”，误以为是仪器测量；分数用于前后对比，单次高低不代表病情全部 | 术语解释动作 / 治疗回顾段 |
| YZ-S2-29 | 甲钴胺（神经营养药） | 维生素B12的活性制剂，常用于神经根受压伴麻木、放射痛者的辅助治疗 | 误当“补药”长期吃，或相反认为“没用”；属辅助用药，用法与疗程遵医嘱 | 术语解释动作 / 用药疑点标签 |
| YZ-S2-30 | NSAIDs类（塞来昔布、洛索洛芬钠等） | 一线镇痛抗炎药，通过抑制炎症介质减轻神经根炎症与疼痛；有口服、注射、外用等剂型 | 担心“止痛药伤胃伤肾、会上瘾”；短期规范使用整体可控，但有消化道、肾、心血管风险者需医生评估 | 术语解释动作 / 用药疑点标签 |
| YZ-S2-31 | 甘露醇（脱水药） | 静脉输注后使组织脱水、减轻神经根水肿的急性期用药，常与糖皮质激素短期联用 | 听到“脱水”担心“身体被脱干”；用药时间短、有监测，属急性期对症手段 | 术语解释动作 / 用药疑点标签 |

## S3 诊疗规范要点

用途：为“治疗过程回顾段”提供规范事实底稿；为检查与诊断不匹配的情形提供“检查疑点标签”判定依据；为“治疗规范符合度画像”提供基准。引用前必须锚定病例中的节段、突出类型与治疗路径；所有“疑点提示”均为需核对线索，不构成错误结论。

- **ID**：YZ-S3-01｜诊断三要素
- **适用范围**：成人腰椎间盘突出症
- **内容**：要点：①典型症状：腰痛伴下肢放射痛、麻木（坐骨神经痛为主）；②神经定位体征：相应皮区感觉异常、肌力下降、反射改变，直腿抬高试验等阳性；③影像学证据：MRI等显示相应节段突出，且与症状、体征的责任节段一致。三者结合方可确立诊断。
- **锚定**：入院记录症状与查体、直腿抬高试验结果、MRI节段
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-02｜影像与症状一致性原则
- **适用范围**：成人腰椎间盘突出症
- **内容**：要点：①无症状人群中MRI也可检出较高比例的椎间盘膨出/突出，影像所见必须与症状体征一致才有责任病灶意义；反之，影像轻微而症状明显者也需排查其他原因；②检查疑点提示：影像节段与神经定位体征明显不符、或仅凭影像（无症状记录）即行手术——列为需人工核对情形（不构成错误结论）。
- **锚定**：MRI报告节段与描述、查体记录、症状记录
- **用途**：检查疑点标签 / 治疗回顾段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／NASS腰椎间盘突出症伴神经根病临床指南（2012）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-03｜MRI适用情境（初诊并非人人必查）
- **适用范围**：成人腰椎间盘突出症
- **内容**：要点：①MRI是显示椎间盘与神经受压的首选影像，但初诊不强制人人检查；②适用情境：规范保守治疗无效需评估是否手术、神经体征进行性加重、怀疑马尾综合征/肿瘤/感染需鉴别等；③CT多用于骨性结构评估或MRI禁忌者；④疑点提示：起病极短、无危险信号且未经任何保守治疗即行MRI，或MRI结论与后续处置方向完全脱节——列为需核对情形。
- **锚定**：MRI检查日期、起病/保守治疗时长、手术决策记录
- **用途**：检查疑点标签 / 治疗回顾段 / 费用解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／NASS腰椎间盘突出症伴神经根病临床指南（2012）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-04｜保守治疗总则：活动调整而非绝对卧床
- **适用范围**：保守治疗路径
- **内容**：要点：①指南不推荐长时间严格卧床；急性疼痛期可短期卧床缓解，之后在可耐受范围内保持日常活动（活动调整）；②健康宣教与活动管理是保守治疗的基础；③保守治疗是多数无手术指征患者的首选路径，绝大多数急性发作可在保守治疗下改善——保守不是“没治”。
- **锚定**：保守治疗记录、卧床与活动医嘱、住院天数
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／NASS腰椎间盘突出症伴神经根病临床指南（2012）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-05｜保守治疗药物构成
- **适用范围**：保守治疗路径
- **内容**：要点：常用药物组合为NSAIDs等镇痛抗炎药、肌肉松弛剂、神经营养药；急性期神经根水肿明显者可短期使用糖皮质激素/脱水药（详见S4各条目）；药物组合的具体选择属医生判断，“用了几类”本身不构成规范结论。
- **锚定**：医嘱单药物清单
- **用途**：治疗回顾段 / 用药规则符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《腰椎间盘突出症诊疗中国疼痛专家共识》
- **状态**：draft-待医学审核

- **ID**：YZ-S3-06｜牵引与理疗的定位
- **适用范围**：保守治疗路径
- **内容**：要点：①牵引、热疗、电刺激等物理治疗是保守治疗的辅助手段，一般与药物、活动调整同期短程应用；②理疗项目的有无与多少受医保目录、医院条件影响，其本身不构成规范缺陷；③具体参数与疗程由医嘱确定【参数待医学审核】。
- **锚定**：理疗/牵引医嘱与执行记录
- **用途**：治疗回顾段 / 费用解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／腰椎间盘突出症临床路径
- **状态**：draft-待医学审核

- **ID**：YZ-S3-07｜手术时机之一：规范保守治疗无效
- **适用范围**：保守转手术情境
- **内容**：要点：①规范保守治疗（药物＋活动调整等系统方案，而非仅间断口服止痛药数天）无效、症状严重影响生活者可评估手术，常见观察期以6–12周为参考【数值待医学审核】；②“保守无效”须以“规范保守治疗”为前提核对；③疑点提示：保守时长不足与过度保守（长期拖延出现神经损害）两个方向都列为需核对情形。
- **锚定**：起病/保守开始日期、手术日期、保守治疗记录完整性
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／NASS腰椎间盘突出症伴神经根病临床指南（2012）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-08｜手术指征（急诊级）：马尾综合征
- **适用范围**：全部病例
- **内容**：要点：①马尾综合征（鞍区麻木、大小便功能障碍、双下肢无力、性功能障碍）是需急诊手术减压的情况；②本条同时是S9中的🔴级信号：出现即立即急诊，不能按“择期手术”理解或等待门诊；③住院材料中马尾综合征相关诊断/病程记录应与急诊入院、尽快手术的时间线一致。
- **锚定**：急诊记录、入院时间与手术时间、症状描述
- **用途**：治疗回顾段 / 优先行动 / 治疗规范符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-09｜手术指征之二：进行性神经功能损害
- **适用范围**：全部病例
- **内容**：要点：①进行性肌力下降（如足背伸无力、足下垂）或神经体征持续加重，通常建议尽快手术干预，争取在神经功能发生不可逆损害前处理；②查体记录中的肌力分级变化是核对关键；③材料中出现肌力下降却无任何处理决策记录时，列为需核对情形。
- **锚定**：肌力查体记录、病程记录
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-10｜手术指征之三：坐骨神经痛为主的持续症状
- **适用范围**：保守转手术情境
- **内容**：要点：①坐骨神经痛为主要表现、规范保守治疗无效且严重影响生活者可考虑手术；②术前应有与责任节段一致的影像学证据（MRI）；③术后症状改善情况（疼痛、功能评分变化）是治疗回顾段的核对素材。
- **锚定**：保守治疗时长、影像节段、术前术后症状记录
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／NASS腰椎间盘突出症伴神经根病临床指南（2012）
- **状态**：draft-待医学审核

- **ID**：YZ-S3-11｜术式选择原则
- **适用范围**：手术路径，供术式合理性核对

## S4 用药规则

用途：为用药疑点标签与用药规则符合度画像提供核查点。本节总边界（适用于以下全部条目）：缺少适应证材料本身不能认定用药错误；本包不输出“用药错误”结论，所有“核查点”仅用于触发人工/模型复核。

- **ID**：YZ-S4-01｜NSAIDs类（塞来昔布、洛索洛芬钠、布洛芬等）
- **适用范围**：保守治疗与围手术期，全部路径
- **内容**：适用情境：腰椎间盘突出症镇痛抗炎的一线药物，保守治疗与术后均常用，有口服/注射/外用剂型。常见核查点：①消化道溃疡/出血史、肾功能、心血管风险、高龄者使用需评估；②住院期间是否两种NSAIDs重复联用；③疗程与出院带药量是否匹配。常见联用情境：与肌松剂、神经营养药同方；与PPI联用做胃保护。边界：缺少适应证材料不能认定用药错误；反之NSAIDs禁忌者未用NSAIDs也属正常。
- **锚定**：镇痛类医嘱、消化道/肾功能/心血管病史、出院带药
- **用途**：用药疑点标签 / 用药规则符合度画像 / 费用解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／药品说明书（CDE目录集）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-02｜肌肉松弛剂（乙哌立松、氯唑沙宗类）
- **适用范围**：伴明显腰背肌痉挛/紧张者
- **内容**：适用情境：急性期肌肉痉挛性疼痛的辅助用药。常见核查点：①嗜睡、头晕——与阿片类或镇静药叠加时镇静作用增强，老年患者需提示跌倒风险；②驾驶与高空作业提醒；③肝功能异常者注意。常见联用情境：常与NSAIDs联用。边界：同本节总边界。
- **锚定**：医嘱药物、年龄、镇静类合并用药
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／药品说明书（CDE目录集）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-03｜神经营养药（甲钴胺类）
- **适用范围**：伴神经根症状（放射痛、麻木）者
- **内容**：适用情境：神经根受压伴麻木、放射痛者的常用辅助用药（甲钴胺口服/注射，或同类B12制剂）。常见核查点：①属辅助用药定位，其“有无”不构成规范缺陷；②长期使用需有症状依据；③与同类B12制剂重复联用可作提示。边界：同本节总边界。
- **锚定**：神经根症状记录、用药时长
- **用途**：用药疑点标签 / 用药规则符合度画像 / 费用解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／药品说明书（CDE目录集）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-04｜糖皮质激素（地塞米松、甲泼尼龙等）
- **适用范围**：急性期神经根水肿/炎症明显情境
- **内容**：适用情境：急性期疼痛剧烈、神经根炎症水肿明显时的短期使用（静脉或口服，疗程短）。常见核查点：①疗程是否偏长；②糖尿病、消化道溃疡、感染风险者是否评估；③是否联用胃保护药。常见联用情境：急性期与脱水药（甘露醇）短程联用。边界：未用激素完全正常；短期使用属指南与共识提及的选项之一，疗程偏长不单独构成错误结论。
- **锚定**：急性期症状记录、血糖、用药起止日期
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《腰椎间盘突出症诊疗中国疼痛专家共识》／《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-05｜脱水药（甘露醇）
- **适用范围**：急性期神经根水肿情境
- **内容**：适用情境：急性期神经根水肿明显的短期静脉脱水治疗，常与糖皮质激素联用。常见核查点：①肾功能与电解质监测记录；②疗程通常很短，长程使用列为核查点；③老年人肾功能基础上使用需谨慎。边界：同本节总边界。
- **锚定**：急性期症状、肾功能/电解质结果、用药天数
- **用途**：用药疑点标签 / 用药规则符合度画像 / 费用解释段
- **来源**：《腰椎间盘突出症诊疗中国疼痛专家共识》
- **状态**：draft-待医学审核

- **ID**：YZ-S4-06｜阿片类与曲马多
- **适用范围**：NSAIDs控制不佳的重度疼痛短期情境
- **内容**：适用情境：重度疼痛的短期、按需使用，作为镇痛组合一环而非唯一方案。常见核查点：①恶心、呕吐、便秘、头晕等常见反应，配套缓泻剂/止吐药属合理联用；②老年患者镇静与跌倒风险；③出院带药天数与减停安排；④不作为长期方案使用，长期延续列为核查点。常见联用情境：与非阿片镇痛构成阶梯组合。边界：短期按需使用不能与“药物依赖”画等号；报告解释应避免污名化表述。
- **锚定**：疼痛评估记录、用药天数、年龄与镇静类合并用药
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／药品说明书（CDE目录集）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-07｜外用NSAIDs制剂（氟比洛芬凝胶贴膏等）
- **适用范围**：局部腰痛辅助镇痛
- **内容**：适用情境：局部腰背痛的辅助镇痛，居家常用。常见核查点：①与口服NSAIDs叠加时的总量提示；②皮肤过敏/破损处不贴。边界：同本节总边界。
- **锚定**：出院带药明细
- **用途**：用药疑点标签 / 费用解释段
- **来源**：药品说明书（CDE目录集）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-08｜质子泵抑制剂（PPI）
- **适用范围**：NSAIDs联用或应激状态预防
- **内容**：适用情境：与NSAIDs/激素联用时的胃黏膜保护；手术应激等高危情形的短期预防。常见核查点：无明确指征的长期使用属常见核查点，但不单独认定错误。常见联用情境：常与NSAIDs、激素同方出现。边界：同本节总边界。
- **锚定**：NSAIDs/激素使用记录、PPI用药时长
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《应激性溃疡防治专家建议》（版本待医学审核确认）／药品说明书（CDE目录集）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-09｜中成药与中药注射剂（活血化瘀、舒筋活络类）
- **适用范围**：保守治疗常见辅助处方
- **内容**：适用情境：国内保守治疗常见中成药（活血化瘀、舒筋活络类），部分住院病例使用中药注射剂。常见核查点：①费用解读时宜单列“辅助类”，与治疗必需药分开呈现；②同类重复联用可作提示；③中药注射剂出现时核对过敏史与输液反应监测记录。边界：辅助用药的使用本身不能认定不合理，也不用于评价诊疗质量。

- **用途**：费用解释段 / 用药疑点标签
- **来源**：国内临床常规（仅作归类依据，非疗效背书）／药品说明书（CDE目录集）
- **状态**：draft-待医学审核

- **ID**：YZ-S4-10｜给药途径切换（静脉转口服）

- **内容**：适用情境：保守住院常静脉给药（脱水、激素、神经营养、活血类），症状缓解后转口服完成疗程；术后镇痛由静脉转口服。常见核查点：①静脉用药天数与症状改善节点是否匹配；②长期无明确指征输液可作为温和核查提示。边界：同本节总边界。
- **锚定**：给药途径变更记录、住院天数
- **用途**：用药规则符合度画像 / 费用解释段
- **来源**：腰椎间盘突出症临床路径
- **状态**：draft-待医学审核

- **ID**：YZ-S4-11｜输出规则总条目：用药类标签的边界
- **适用范围**：全部病例
- **内容**：要点：①“用药与诊断不匹配”类标签只能输出需核实线索，进入医学复核，不得对患者宣称“医生开错药”；②缺少适应证材料本身不能认定用药错误；③本病保守治疗药费中辅助类占比偏高属常见现象，费用解读按“治疗必需/预防/辅助可选”分层呈现（关联S8），不构成对处方合理性的评价。

- **用途**：用药规则符合度画像 / 用药疑点标签 / 费用解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）＋产品红线（spec 6.2、AC-10）

## S6 康复/自我管理要点

用途：为“康复计划段”提供分期分场景要点。每条注明依赖的病例事实：生成时必须先核对锚定事实再引用；缺乏锚定事实的条目不得生成为“个体化计划”，只能作为通用提示并标注待确认。

- **ID**：YZ-S6-01｜康复分期总则
- **适用范围**：全部病例
- **内容**：要点：①康复分三期推进：急性/保护期（控制炎症、避免诱发动作）→恢复期（活动度与核心稳定渐进恢复）→强化期（腰背肌与核心力量强化、防复发）；②总原则“循序渐进、以疼痛不明显加重为度”；③康复节奏与路径强相关（保守/微创/融合节奏不同），引用前必须先核对锚定事实，不得混用节奏。
- **锚定**：治疗路径（保守/微创/融合）、起病或术后周数、年龄、合并症
- **用途**：康复计划段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）

- **ID**：YZ-S6-02｜保守治疗期：活动管理
- **适用范围**：保守治疗路径
- **内容**：要点：①避免长时间卧床，在可耐受范围内保持日常活动；②急性期避免弯腰提物、久坐软沙发；坐位可用腰靠并定时起身活动；③症状急性加重期短时休息后尽早恢复活动——活动的恢复本身就是治疗的一部分。

- **ID**：YZ-S7-06｜特殊情境：腰椎内固定的取出问题

- **内容**：要点：①与四肢内固定不同，腰椎椎弓根螺钉系统通常无需常规取出，多数长期留置属正常；②仅在螺钉松动断裂、感染、融合失败或患者要求等特定情形由手术医生评估取出；③生成器不得以“内固定未安排取出”生成疑点，也不得预测取出日期。
- **锚定**：术式（融合/非融合）、术后恢复情况
- **用途**：复诊建议段 / 长期随访加分项
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

## S8 费用结构参考

用途：为“费用解读段”与“费用基线参考”提供结构维度与口径说明。本包不提供金额、不定义“自付比例异常”阈值（该判定基准来自理赔数据集），只提供让费用数字变得可解释的结构事实。费用对比必须先按治疗路径分层（保守/微创/融合），再谈总额。

- **ID**：YZ-S8-01｜住院费用构成总览
- **适用范围**：全部病例
- **内容**：要点：①腰椎间盘突出症住院费用大致由六类构成：手术/麻醉治疗类（手术路径）、内固定与器械耗材类（融合/微创路径）、药品类、检查检验类（以MRI/CT为主）、床位护理类、康复理疗类；②保守路径无耗材大类，理疗与药费占比相对更高；③费用解读先对齐结构，再谈总额，不得跨路径直接对比。
- **锚定**：费用清单科目分布、治疗路径
- **用途**：费用解释段 / 费用基线参考
- **来源**：腰椎间盘突出症临床路径／基本医疗保险“三大目录”口径
- **状态**：draft-待医学审核

- **ID**：YZ-S8-02｜保守治疗费用构成
- **适用范围**：保守治疗路径
- **内容**：要点：①构成：检查费（MRI/CT多在门诊或入院时完成）、药品费（镇痛、神经营养、脱水/激素等）、理疗费（牵引、电疗、针灸推拿等中医项目常见）、床位护理费；②理疗项目数量与医保目录限定在地区间差异较大，是同类病例费用差异的常见来源；③住院天数是保守路径总费用的主要驱动因素。
- **锚定**：费用清单明细、住院天数、理疗项目清单
- **用途**：费用解释段 / 费用基线参考
- **来源**：腰椎间盘突出症临床路径
- **状态**：draft-待医学审核

- **ID**：YZ-S8-03｜微创手术费用构成（椎间孔镜等）
- **适用范围**：微创手术路径
- **内容**：要点：①构成：手术费＋麻醉费、内镜系统使用与镜下器械耗材费（占比明显高于常规开放器械）、住院天数短是总费用相对可控的原因；②内镜相关耗材在医保目录内的报销口径存在地区差异，可解释自付比例差异；③“微创费用高/低”不能脱离开放与保守两条基线单独评价。
- **锚定**：耗材清单（内镜器械条目）、术式、住院天数
- **用途**：费用解释段 / 费用基线参考
- **来源**：腰椎间盘突出症临床路径／基本医疗保险“三大目录”口径
- **状态**：draft-待医学审核

- **ID**：YZ-S8-04｜融合内固定费用构成
- **适用范围**：融合手术路径
- **内容**：要点：①开放融合手术费用中内固定耗材（椎弓根螺钉系统、椎间融合器）通常占较大比例，是同类病例费用差异的最大来源；②影响耗材费用的因素：融合节段数、螺钉数量、材质与品牌；③“耗材占比高”与“过度医疗”是两回事——耗材选择主要由病变类型与节段稳定性决定，解读时应分开表述。
- **锚定**：耗材清单明细与数量、融合节段数
- **用途**：费用解释段 / 费用基线参考
- **来源**：腰椎间盘突出症临床路径
- **状态**：draft-待医学审核

- **ID**：YZ-S8-05｜集采背景说明
- **适用范围**：融合/内固定相关病例
- **内容**：要点：①国家组织骨科脊柱类耗材集中带量采购已落地（约2022年前后，以当期政策为准），椎弓根螺钉、融合器等价格较集采前大幅下降；②跨期比较费用须注意手术时间在集采前后，避免用旧价格直觉判断“贵得异常”；③可引用的解读表述：“脊柱内固定耗材费用近年因集中采购明显下降，具体以手术当期政策为准。”
- **锚定**：手术日期、耗材名称（如可获取）
- **用途**：费用解释段
- **来源**：国家组织骨科脊柱类耗材集中带量采购政策
- **状态**：draft-待医学审核

- **ID**：YZ-S8-06｜检查检验费用（以MRI为主）
- **适用范围**：全部病例
- **内容**：要点：①MRI是本病核心检查，单次费用高于X线属合理情境；MRI可在门诊或住院期间完成，跨时间点重复MRI需有症状变化等理由——单次MRI不构成“非必要检查”；②CT多用于骨性结构评估或MRI禁忌者；③术前常规化验与心电图属标准流程，费用解读时不应单列为异常项（关联YZ-S3-16）。
- **锚定**：影像与化验项目明细及次数
- **用途**：费用解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／腰椎间盘突出症临床路径
- **状态**：draft-待医学审核

- **ID**：YZ-S8-07｜药费与康复费用结构
- **适用范围**：全部病例
- **内容**：要点：①药费建议按“治疗必需/预防/辅助可选”三层呈现：镇痛必需、胃保护预防、活血/营养类辅助（关联YZ-S4-09）；②康复理疗费在住院后期与出院后均可发生，术后患者康复需求更高，属合理支出结构；③三层划分是解释视角，不构成对处方合理性的评价。
- **锚定**：药品明细与金额分布、康复项目明细
- **用途**：费用解释段
- **来源**：《外科学》（人卫教材）围手术期处理章节＋国内临床常规（归类依据）
- **状态**：draft-待医学审核

- **ID**：YZ-S8-08｜费用口径与自付比例异常判定边界
- **适用范围**：全部病例通用
- **内容**：要点：①总费用＝全部医疗费用；②医保目录内费用按政策报销后个人承担部分为“自付”；③目录外（或完全自费项目）为“自费”；④患者口中的“花了多少”常混用三者——生成费用解读前必须先核对费用清单口径；⑤“自付比例异常”判定阈值来自理赔数据集基线，本包不定义：偏离基线时先走结构解释（耗材占比、集采前后、口径错配、医保目录内外、路径分层），仍无法解释再进入人工核对——不直接生成“费用异常”结论。
- **锚定**：费用清单的统筹/自付/自费分列、治疗路径
- **用途**：费用解释段 / 费用基线参考
- **来源**：基本医疗保险“三大目录”口径（国家医疗保障局）＋理赔数据集（阈值另行维护，不在本包）
- **状态**：draft-待医学审核

## S9 危险信号

用途：为“优先行动”模块与情感支持段的安全边界提供分级红旗要点。生成患者可见内容时按要点转译并附就医途径，禁止整段照搬；分级不得擅自上调或下调。分级含义：🔴立即急诊 / 🟠24–48小时内就诊 / 🟢常规复诊时告知。

- **ID**：YZ-S9-01｜马尾综合征征象（🔴立即急诊）
- **适用范围**：全部病例，术前与术后任何时期
- **内容**：分级：🔴立即急诊。观察要点：①鞍区（会阴部/肛门周围）麻木、感觉减退；②大小便功能障碍（尿潴留、尿失禁、大便失禁或排不出）；③双下肢无力加重、性功能障碍。行动：立即拨打急救电话或就近急诊——马尾综合征是需尽快手术减压的急症，勿等待门诊；术后新发同样按此处理。
- **锚定**：随访主诉、术后天数、既往神经功能基线
- **用途**：优先行动
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S9-02｜进行性下肢无力/足下垂（🟠24–48小时内就诊）
- **适用范围**：全部病例
- **内容**：分级：🟠24–48小时内就诊（快速进展或伴马尾征象按🔴处理）。观察要点：下肢力量进行性下降（如脚背翘不起来、走路拖步、频繁绊脚）或麻木范围快速扩大——提示神经功能恶化。行动：24–48小时内尽快骨科/脊柱外科就诊评估，携带既往影像资料。
- **锚定**：肌力记录、症状变化描述
- **用途**：优先行动
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S9-03｜发热伴切口红肿渗液（🟠24–48小时内就诊）
- **适用范围**：手术路径
- **内容**：分级：🟠24–48小时内就诊（高热寒战伴全身恶化按🔴处理）。观察要点：切口红肿范围扩大、渗液增多或呈脓性、裂开，伴发热——提示切口感染可能；内固定在位者更应尽早处理。行动：24–48小时内骨科/脊柱外科复诊。
- **锚定**：手术切口情况、体温记录
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S9-04｜术后新发剧烈头痛或伴颈项强直（🟠24–48小时内就诊）
- **适用范围**：手术路径，出院后早期
- **内容**：分级：🟠24–48小时内就诊（伴意识改变或高热按🔴处理）。观察要点：术后早期出现与体位相关的剧烈头痛（坐起加重、平卧减轻）或伴恶心呕吐、颈项发硬——需排查脑脊液漏、椎管内感染等情况。行动：24–48小时内尽快就诊复查。
- **锚定**：术式、术后天数、主诉描述
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）术后并发症章节
- **状态**：draft-待医学审核

- **ID**：YZ-S9-05｜疼痛不减反增且镇痛无效（🟠24–48小时内就诊）
- **适用范围**：恢复期
- **内容**：分级：🟠24–48小时内就诊。观察要点：恢复期疼痛不减反增、夜间痛突出、现有止痛方案失效，或突发与既往性质不同的剧烈腰腿痛——需排除再突出、感染、血肿等（与YZ-S9-01/02/03征象交叉时升级）。行动：按分级就诊，携带用药记录与既往影像供医生核对。
- **锚定**：疼痛轨迹（随访记录）、镇痛用药
- **用途**：优先行动
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S9-06｜残留麻木/轻度疼痛波动（🟢常规复诊时告知）
- **适用范围**：恢复期
- **内容**：分级：🟢常规复诊时告知。观察要点：术后/保守治疗后残留轻度麻木、酸痛，活动后有波动但总体趋势向好——神经恢复慢属常见现象。行动：按康复计划继续观察并记录趋势，复诊时向医生描述；麻木范围扩大或肌力下降则升级（关联YZ-S9-02）。
- **锚定**：症状变化记录、治疗日期
- **用途**：优先行动 / 复诊建议段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S9-07｜活动后轻度伤口痛与腰背酸胀（🟢常规复诊时告知）
- **适用范围**：术后恢复期
- **内容**：分级：🟢常规复诊时告知。观察要点：活动后切口周围轻度疼痛、腰背肌酸胀，休息后缓解，无红肿发热——术后早期常见现象。行动：按康复计划渐进活动即可，复诊时告知；出现红肿渗液或发热则升级（关联YZ-S9-03）。
- **锚定**：术后天数、康复计划执行情况
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核
