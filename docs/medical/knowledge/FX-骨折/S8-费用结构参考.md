## S8 费用结构参考
用途：为“费用解读段”与“费用基线参考”提供结构维度与口径说明。本包不提供金额、不定义“自付比例异常”阈值（该判定基准来自理赔数据集），只提供让费用数字变得可解释的结构事实。

- **ID**：FX-S8-01｜住院费用构成总览
- **适用范围**：全部四肢骨折住院病例
- **内容**：要点：①四肢骨折手术住院费用大致由六类构成：手术/麻醉治疗类、内固定耗材类、药品类、检查检验类、床位护理类、康复治疗类；②保守治疗无耗材类，但可能含多次复位固定操作与较长随访期的影像支出；③费用解读先对齐结构，再谈总额。
- **锚定**：费用清单科目分布
- **用途**：费用解释段 / 费用基线参考
- **来源**：国家卫生健康委骨科相关病种临床路径／基本医疗保险“三大目录”口径
- **状态**：draft-待医学审核

- **ID**：FX-S8-02｜内固定耗材对费用的影响
- **适用范围**：手术路径
- **内容**：要点：①钢板螺钉系统、髓内钉等内固定耗材常占手术住院费用的较大比例，是同类病例费用差异的最大来源；②影响耗材费用的因素：骨折部位与固定数量（多块钢板/长节段）、髓内钉规格、材质与品牌等；③“耗材占比高”与“过度医疗”是两回事——耗材选择主要由骨折形态决定，解读时应分开表述。
- **锚定**：耗材清单明细与数量
- **用途**：费用解释段 / 费用基线参考
- **来源**：国家卫生健康委骨科相关病种临床路径
- **状态**：draft-待医学审核

- **ID**：FX-S8-03｜集采背景说明
- **适用范围**：手术路径，涉及创伤类耗材
- **内容**：要点：①近年来接骨板、髓内钉等创伤类骨科耗材已有多省联盟集中采购落地（部分品类随国家/联盟集采推进），中标价格较集采前明显下降；②跨期比较费用时须注意手术发生时间在集采前后，避免用旧价格直觉判断“贵得异常”；③可引用的解读表述：“内固定耗材费用近年因集中采购明显下降，具体以手术当期政策为准。”
- **锚定**：手术日期、耗材名称（如可获取）
- **用途**：费用解释段
- **来源**：国家及省际联盟高值医用耗材集中采购政策
- **状态**：draft-待医学审核

- **ID**：FX-S8-04｜手术费与麻醉费的影响因素
- **适用范围**：手术路径
- **内容**：要点：①手术费随部位、入路数量、粉碎复杂度、是否多部位同期手术而变化；②麻醉费与麻醉方式（全麻/椎管内/神经阻滞）及手术时长相关；③同一诊断下手术费差异多属合理，解读时避免简单横向对比。
- **锚定**：术式、麻醉方式、手术时长记录
- **用途**：费用解释段
- **来源**：国家卫生健康委骨科相关病种临床路径
- **状态**：draft-待医学审核

- **ID**：FX-S8-05｜检查检验费用（多次影像）
- **适用范围**：全部四肢骨折
- **内容**：要点：①骨折住院期间多次X线乃至CT属常见且符合规范：术前评估、术后确认、出院前与随访对比各有目的（关联FX-S3-02/03）；②费用解读时可将“影像次数”解释为“愈合管理的必要环节”，而非重复检查；③本包不设单次费用基准。
- **锚定**：影像项目明细与次数
- **用途**：费用解释段
- **来源**：《外科学》（人卫教材）／国家卫生健康委骨科相关病种临床路径
- **状态**：draft-待医学审核

- **ID**：FX-S8-06｜药费结构：必需、预防与辅助
- **适用范围**：全部四肢骨折
- **内容**：要点：①骨科住院药费常见构成：抗凝预防、镇痛、抗菌药物预防、消肿/改善循环/促骨愈合类辅助用药（关联FX-S4-08）；②解读时建议按“治疗必需/预防/辅助可选”三层呈现，帮助患者理解费用结构；③三层划分是解释视角，不构成对处方合理性的评价。
- **锚定**：药品明细与金额分布
- **用途**：费用解释段
- **来源**：《外科学》（人卫教材）围手术期处理章节
- **状态**：draft-待医学审核

- **ID**：FX-S8-07｜康复治疗费用
- **适用范围**：住院后期及出院后康复
- **内容**：要点：①住院后期与出院后可能产生康复治疗费用（理疗、运动治疗等）；②关节周围骨折、老年患者康复需求更高，属合理支出结构；③费用解读时应提示商业保险对康复项目覆盖存在差异，具体以保单为准（由理赔环节核对）。
- **锚定**：康复项目明细、部位与年龄
- **用途**：费用解释段
- **来源**：国家卫生健康委骨科相关病种临床路径
- **状态**：draft-待医学审核

- **ID**：FX-S8-08｜费用口径说明：总费用/自付/自费
- **适用范围**：全部病例通用
- **内容**：要点：①总费用＝全部医疗费用；②医保目录内费用按政策报销后，个人承担部分为“自付”；③目录外（或完全自费项目）为“自费”；④患者口中的“花了多少”常混用三者——报告生成前必须先核对费用清单口径，再生成解释，避免口径错配（与理赔环节的费用归集规则衔接）。
- **锚定**：费用清单的统筹/自付/自费分列
- **用途**：费用解释段
- **来源**：基本医疗保险“三大目录”口径（国家医疗保障局）
- **状态**：draft-待医学审核

- **ID**：FX-S8-09｜自付比例异常判定的边界
- **适用范围**：理赔环节费用画像
- **内容**：要点：①“自付比例异常”的判定阈值来自理赔数据集基线，本包不定义；②本包提供的解释维度：耗材占比（FX-S8-02）、集采前后（FX-S8-03）、口径错配（FX-S8-08）、医保目录内外结构；③当自付比例偏离基线时，先走上述结构解释，仍无法解释再进入人工核对——不直接生成“费用异常”结论。
- **锚定**：自付比例数值与费用结构明细
- **用途**：费用解释段 / 费用基线参考
- **来源**：基本医疗保险“三大目录”口径＋理赔数据集（阈值另行维护，不在本包）
- **状态**：draft-待医学审核
