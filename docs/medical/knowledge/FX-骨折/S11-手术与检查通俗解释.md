## S11 手术与检查通俗解释
用途：为治疗回顾段提供"这项手术/检查是什么、大致怎么做、患者会经历什么"的过程级通俗解释。总边界（适用于以下全部条目）：①只解释目的与过程，**不评价该患者手术/检查是否必要、做得好不好**（必要性判断属医生）；②不承诺效果与恢复时间；③过程描述为"一般情形"，个体差异以病历为准；④与病例事实冲突时不引用。

- **ID**：FX-S11-01｜X线检查
- **适用范围**：诊断与随访通用
- **内容**：是什么：用X光给骨骼"拍照"，看骨头有没有断、断的位置和形状。怎么做：在放射科摆好体位拍几张片，几分钟完成，无痛无创。为什么做：骨折诊断首选，复查时判断对位对线和骨痂生长（关联 FX-S7-03）。患者会经历：即可完成，备孕/怀孕者提前告知。
- **锚定**：诊断或复查医嘱
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《外科学》（人卫教材）；影像学通行临床实践
- **状态**：draft-待医学审核

- **ID**：FX-S11-02｜CT检查
- **适用范围**：复杂骨折、关节内骨折、术前评估
- **内容**：是什么：断层扫描，像把骨头"切片"看细节，可三维重建。怎么做：躺在检查床上随床进扫描孔，数分钟完成，无痛；有时需注射对比剂增强（提前告知过敏史）。为什么做：复杂/关节内骨折需要看清碎块位置与移位，帮助制定手术方案。
- **锚定**：检查医嘱、骨折部位与复杂程度
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S11-03｜MRI检查
- **适用范围**：隐匿性骨折、软组织损伤评估
- **内容**：是什么：磁共振成像，不用X射线，对骨髓水肿、韧带软骨等"X光看不见的损伤"最敏感。怎么做：躺入圆筒状机器约15-30分钟，噪音较大可戴耳塞，需保持不动；体内有心脏起搏器等金属植入物者需提前告知评估。为什么做：X光阴性但症状明显时排查隐匿骨折、评估韧带损伤。
- **锚定**：检查医嘱、X光结果
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S11-04｜切开复位内固定术（钢板/螺钉）
- **适用范围**：移位明显或手法复位不稳定的骨折
- **内容**：是什么：把移位的骨折块"拼回原位"（复位），再用钢板螺钉等"内部夹板"固定住（内固定），让骨头在正确位置愈合。怎么做：麻醉后切开皮肤显露骨折端、复位、上固定物、缝合，术后伤口留有引流可能。为什么做：恢复骨骼的力线与稳定性，便于早期康复。患者会经历：术后伤口疼痛数日（有镇痛方案）、逐步恢复活动（衔接 FX-S6）。
- **锚定**：手术记录（术式、部位、内固定类型）
- **用途**：治疗回顾段 / S1诊断解释段
- **来源**：《坎贝尔骨科手术学》；《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S11-05｜髓内钉内固定
- **适用范围**：股骨、胫骨等长骨骨折
- **内容**：是什么：从骨髓腔中央插入一根长钉固定骨折，像"骨头里的钢筋"，属于中心型固定。怎么做：多在牵引床复位后经骨端小切口插入髓内钉并上锁钉。特点：对长骨骨折力学上更稳定，常可更早负重（以医嘱为准）。
- **锚定**：手术记录（髓内钉、部位）
- **用途**：治疗回顾段 / S1诊断解释段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S11-06｜石膏/支具外固定
- **适用范围**：保守治疗或术后辅助保护
- **内容**：是什么：用石膏或支具从身体外部把骨折部位固定住。怎么做/患者体验：石膏定型时会先感觉温热（属正常现象，过烫需告知）；定型后需保持干燥。注意：出现持续麻木、发紫发凉按 FX-S9-07 处理。
- **锚定**：外固定方式
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S11-07｜内固定取出术
- **适用范围**：已行内固定且符合取出指征者
- **内容**：是什么：骨折愈合后将体内的钢板/螺钉/髓内钉取出的二次手术。为什么做：多因局部不适、年轻患者或特殊部位需求；无症状者部分可终身留置（衔接 FX-S7-06）。过程与首次手术类似，恢复通常快于第一次。
- **锚定**：内固定类型、植入日期、有无症状
- **用途**：治疗回顾段 / 复诊建议段
- **来源**：《坎贝尔骨科手术学》（经氢离子平台查证）
- **状态**：draft-待医学审核
