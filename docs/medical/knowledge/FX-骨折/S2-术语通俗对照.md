## S2 术语通俗对照
用途：为“术语解释动作”提供素材：当理赔材料术语出现在诊断、手术记录、影像报告中时，用对应条目做一句话通俗解释并指出患者常见误解点。每个条目对应设计表“术语/常见写法 | 通俗解释 | 患者为何困惑”的一行；为保持全包统一字段格式，后两栏并入内容字段。

- **ID**：FX-S2-01｜闭合性骨折
- **适用范围**：成人四肢骨折（本包主范围）；仅解释术语
- **内容**：通俗解释：骨折处皮肤完好，骨头断在皮肉里；多数闭合骨折走保守或常规手术路径。患者为何困惑：常误以为“没破皮就不严重”——严重程度取决于损伤能量与移位，不取决于皮肤是否破损。
- **锚定**：诊断中的“闭合性”字样
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）骨折总论
- **状态**：draft-待医学审核

- **ID**：FX-S2-02｜开放性骨折
- **适用范围**：仅作术语解释（本包不覆盖开放骨折复杂处理，见 exclusions）
- **内容**：通俗解释：骨折端刺破皮肤与外界相通，伤口可见或曾见深部组织外露；感染风险更高，处理更积极。患者为何困惑：以为“伤口大＝骨折重”，其实开放骨折的核心问题是感染与软组织损伤。
- **锚定**：诊断中的“开放性”；清创手术记录
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-03｜粉碎性骨折
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：骨折处碎成三块或更多，提示暴力较大；复位与固定的难度常更高，耗材使用可能更多。患者为何困惑：看到“粉碎”二字容易过度恐慌——现代固定技术下多数粉碎骨折仍可良好愈合。
- **锚定**：影像描述/术中所见“粉碎”；耗材清单
- **用途**：术语解释动作 / 费用解释段
- **来源**：《外科学》（人卫教材）／AO/OTA骨折通用分类
- **状态**：draft-待医学审核

- **ID**：FX-S2-04｜骨折移位
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：断端错开，可表现为短缩、侧方错开、旋转或重叠；“移位明显”常是手术指征之一。患者为何困惑：以为“有移位就必须手术”——是否手术取决于移位程度、部位与稳定性。
- **锚定**：影像报告中移位方向与程度；保守/手术路径选择
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-05｜成角畸形
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：断端纵轴形成夹角，像“折弯的尺子”；复位就是把角度纠正到可接受范围。患者为何困惑：对“成角多少度才算问题”无概念，报告带度数时容易自行对号入座。
- **锚定**：影像报告角度描述
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-06｜嵌插骨折
- **适用范围**：成人四肢骨折（肱骨外科颈、股骨颈等常见）
- **内容**：通俗解释：断端相互卡插在一起，通常相对稳定，有时甚至无需严格复位。患者为何困惑：直觉上觉得“插进去”比“错开”更吓人。
- **锚定**：影像描述“嵌插”
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-07｜不完全骨折/裂缝骨折
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：骨的连续性只有部分中断，如“竹子裂而未断”；通常更稳定、恢复更快。患者为何困惑：以为“只是裂缝不算骨折”而低估休养与复查要求。
- **锚定**：影像描述
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-08｜稳定型/不稳定型骨折
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：稳定型指复位后不容易再错位；不稳定型有再移位倾向，更多选择手术或更严格的固定与复查。患者为何困惑：不知道“稳定”是医学术语而非病情轻重的主观形容。
- **锚定**：诊断或影像中的稳定性描述；治疗路径
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-09｜复位（手法复位/闭合复位/切开复位）
- **适用范围**：成人四肢骨折
- **内容**：通俗解释：把错开的骨头拉回对齐——不开刀叫手法复位（闭合复位），开刀直视下对齐叫切开复位。患者为何困惑：以为“没开刀就没治疗”；或把复位理解为“一次完成”，不理解复位后仍需固定维持、防止再移位。
- **锚定**：病程记录的复位方式与复位次数
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-10｜切开复位内固定术（ORIF）
- **适用范围**：成人四肢骨折手术路径
- **内容**：通俗解释：开刀直视下把骨头对好，再用钢板螺钉等金属物固定；“内固定”的“内”指固定物在体内。患者为何困惑：把“内固定”误解为“换了骨头”或“打了水泥”。
- **锚定**：手术记录术式名称
- **用途**：术语解释动作 / 费用解释段
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-11｜钢板螺钉内固定
- **适用范围**：成人四肢骨折手术路径
- **内容**：通俗解释：像“钢板＋螺丝”把断骨两侧夹住固定，材质多为钛合金等金属。患者为何困惑：担心金属“生锈”“要定期更换”，或不清楚是否必须取出。
- **锚定**：耗材清单中接骨板/螺钉条目
- **用途**：术语解释动作 / 费用解释段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-12｜髓内钉固定（交锁髓内钉）
- **适用范围**：长骨骨干骨折（股骨、胫骨、肱骨）常见
- **内容**：通俗解释：从骨中央的骨髓腔打入一根长钉固定，多用于股骨、胫骨等长骨；对软组织干扰小、固定轴线接近骨骼受力线。患者为何困惑：听到“钉子打进骨髓里”容易害怕，不理解这是长骨骨折常用且成熟的方式。
- **锚定**：术式名称（髓内钉/交锁髓内钉）
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-13｜克氏针固定
- **适用范围**：小骨块/辅助固定常见
- **内容**：通俗解释：细钢针穿过骨折块固定，常用于较小骨块或辅助固定；针尾有时留在皮肤外或皮下，多数需按期拔除。患者为何困惑：不知道针需要拔除，也不理解“针露在外面”是设计安排。
- **锚定**：术式名称；有无拔针记录
- **用途**：术语解释动作 / 复诊建议段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-14｜外固定架
- **适用范围**：软组织条件差或临时稳定情境；仅解释术语
- **内容**：通俗解释：钢针穿过骨头连到体外的支架上起固定作用；常见于软组织条件差或需要临时稳定的情形，条件允许后可能改为内固定。患者为何困惑：觉得“露在体外的机器”很吓人，也不理解为什么要分两步处理。
- **锚定**：术式名称
- **用途**：术语解释动作
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-15｜石膏固定与石膏托
- **适用范围**：保守治疗路径
- **内容**：通俗解释：石膏硬化后把肢体定型在正确姿势；“管型”是整圈包裹，“石膏托”是半片，为肿胀留出余地。患者为何困惑：以为“只打一半”是偷工减料；不理解石膏松紧会随肿胀变化、需要观察调整。
- **锚定**：保守治疗方式记录（石膏托/管型石膏）
- **用途**：术语解释动作 / 康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-16｜支具/夹板固定
- **适用范围**：保守治疗或恢复期保护
- **内容**：通俗解释：可调节的定型支架，常用于稳定骨折或拆石膏后的过渡保护。患者为何困惑：分不清支具与石膏哪个更“牢”，误以为支具可以随意穿脱。
- **锚定**：出院小结中的外固定方式
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-17｜牵引（骨牵引/皮牵引）
- **适用范围**：术前临时措施或不宜手术者
- **内容**：通俗解释：用持续拉力对抗肌肉收缩、维持长度与对位；通过皮肤（皮牵引）或穿针到骨（骨牵引）实现，多作术前临时措施或不宜手术者的治疗手段。患者为何困惑：不理解“挂个重物”也是治疗，或担心骨牵引“打洞”很痛。
- **锚定**：病程/护理记录的牵引方式与天数
- **用途**：术语解释动作 / 治疗回顾段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-18｜术中C臂透视
- **适用范围**：手术路径
- **内容**：通俗解释：手术室里的移动X光机，边复位边“实时拍片”确认位置，属手术常规步骤。患者为何困惑：看到“透视/放射”字样担心辐射伤害，或误以为影像科检查被重复收费。
- **锚定**：手术记录或麻醉记录中的C臂使用情况
- **用途**：术语解释动作 / 费用解释段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-19｜骨痂
- **适用范围**：愈合期复查影像
- **内容**：通俗解释：骨折修复过程中在断端周围新生成的骨性“桥梁组织”，复查X线看到骨痂代表愈合在推进，是好消息。患者为何困惑：把“骨痂”误读成“长了不该长的东西”。
- **锚定**：复查X线报告“骨痂形成”字样
- **用途**：术语解释动作 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-20｜对位对线
- **适用范围**：影像报告通用术语
- **内容**：通俗解释：“对位”指断端接触的位置，“对线”指骨头整体轴线的方向；“对位对线良好”＝接得正。患者为何困惑：以为“良好”必须和原来一模一样，稍有偏差就担心“接歪了”。
- **锚定**：影像报告用语
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-21｜骨折线模糊
- **适用范围**：愈合期复查影像
- **内容**：通俗解释：骨折裂缝在X线上越来越看不清，说明骨头正在长拢，属愈合征象。患者为何困惑：以为“还有骨折线＝没长好”，其实完全消失常需更久，恢复活动以临床愈合判断为准。
- **锚定**：复查影像描述
- **用途**：术语解释动作 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-22｜临床愈合与骨性愈合
- **适用范围**：愈合评估
- **内容**：通俗解释：临床愈合＝局部无压痛、无异常活动，可逐步承力活动；骨性愈合＝结构上完全长牢，时间更久。患者为何困惑：复查说“愈合了”就立刻当没事，或相反担心“片子上还有线就永远不好”。
- **锚定**：复查记录与功能评估描述
- **用途**：术语解释动作 / 康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-23｜延迟愈合
- **适用范围**：愈合异常情境
- **内容**：通俗解释：超过该部位通常愈合时间仍未长好，但仍有愈合趋势；常见相关因素：吸烟、部位血供差、固定不牢、感染。患者为何困惑：以为延迟愈合＝骨不连＝治不好。
- **锚定**：受伤时间与历次影像对比；吸烟史
- **用途**：术语解释动作 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-24｜骨不连（骨折不愈合）
- **适用范围**：愈合异常情境
- **内容**：通俗解释：骨折超过预期时间仍未愈合（常以“骨折后9个月且连续3个月影像无愈合进展”为参考定义【数值待医学审核】），可能需要再次手术（再固定、植骨等）。患者为何困惑：不了解骨不连有明确的诊断节奏，容易被“就是没长”的说法吓到。
- **锚定**：受伤日期、历次影像“无进展”证据
- **用途**：术语解释动作 / 复诊建议段 / 长期随访加分项
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-25｜畸形愈合
- **适用范围**：愈合异常情境
- **内容**：通俗解释：骨头长上了但位置不正（成角/短缩/旋转），可能影响外观与功能，严重者可评估矫形手术。患者为何困惑：把“愈合了”与“愈合得正”混为一谈。
- **锚定**：影像角度/长度/旋转测量描述
- **用途**：术语解释动作
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-26｜骨筋膜室综合征
- **适用范围**：前臂、小腿等高发部位，伤后/术后早期
- **内容**：通俗解释：肢体骨与筋膜围成的“封闭间隔”内压力急剧升高，压迫血管神经，属需紧急处理的并发症；早期最可靠的警报是“越来越痛、被动扳动手指/脚趾时剧痛”。患者为何困惑：把早期警报当作“正常的术后痛”而延误就医。
- **锚定**：骨折部位（胫腓骨、前臂双骨折等高发）、伤后/术后早期病程记录
- **用途**：术语解释动作 / 优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-27｜深静脉血栓（DVT）/静脉血栓栓塞症（VTE）
- **适用范围**：下肢手术、长期制动情境
- **内容**：通俗解释：下肢深静脉内形成血栓，引起肢体肿胀疼痛；血栓脱落可到肺（肺栓塞），故骨科术后要主动预防。筛查常用下肢静脉彩超。患者为何困惑：不理解骨科手术后为什么要“打抗凝针/吃抗凝药”。
- **锚定**：下肢手术史、卧床天数、抗凝用药记录、下肢静脉彩超报告
- **用途**：术语解释动作 / 用药疑点标签
- **来源**：《中国骨科大手术静脉血栓栓塞症预防指南》
- **状态**：draft-待医学审核

- **ID**：FX-S2-28｜废用性萎缩与废用性骨质疏松
- **适用范围**：制动期及恢复期
- **内容**：通俗解释：“不用就退化”：制动使肌肉缩小、骨量流失；属可逆过程，恢复期通过锻炼与营养逐步逆转。患者为何困惑：把患肢变细误认为“神经坏了/肌肉坏了”，过度恐慌。
- **锚定**：制动时长、拆除固定后的肌力与肢体周径描述
- **用途**：术语解释动作 / 康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S2-29｜负重术语（禁负重/触地负重/部分负重/完全负重）
- **适用范围**：下肢骨折为主
- **内容**：通俗解释：医学上的“负重”按踩地重量分级：一点不踩（禁负重）、脚尖点地（触地）、部分体重（部分负重）、全部体重（完全负重）；由医嘱按愈合进度逐级开放。患者为何困惑：把“能走了”理解为“可以正常踩地”，或反之长期不敢踩地拖延恢复。
- **锚定**：部位与术式、固定稳定性、复查影像、医嘱负重表述
- **用途**：术语解释动作 / 康复计划段 / 出院指引缺口标签
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S2-30｜骨质疏松（合并/病因术语）
- **适用范围**：中老年、低能量损伤情境
- **内容**：通俗解释：骨量减少、骨微结构变差，骨“变脆”，轻微外力即可骨折（脆性骨折）；骨折后管理骨质疏松是为了防“下一次骨折”。患者为何困惑：以为骨质疏松是“缺钙、喝骨头汤”就行，不了解它是需要评估和长期管理的疾病。
- **锚定**：年龄（绝经后女性/高龄男性优先）、骨密度报告、受伤能量
- **用途**：术语解释动作 / 长期随访加分项
- **来源**：《原发性骨质疏松症诊疗指南》
- **状态**：draft-待医学审核
