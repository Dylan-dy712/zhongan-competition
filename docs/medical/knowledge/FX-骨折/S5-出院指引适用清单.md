## S5 出院指引适用清单
用途：作为“出院小结缺乏康复指导”类标签的判定基准：以下任一条目对病例适用（锚定通过）但在出院材料中完全缺失时，可触发“出院指引缺口标签”。每个条目对应设计表“指引项 | 为什么要做 | 出院材料常见表述 | 若缺失时的建议动作”的一行；为保持统一字段格式，后三栏并入内容字段。

- **ID**：FX-S5-01｜功能锻炼计划
- **适用范围**：全部四肢骨折，保守/手术均适用
- **内容**：为什么要做：固定不等于静止；按阶段锻炼可防关节僵硬与肌肉萎缩。出院材料常见表述：“逐步行患肢功能锻炼”“遵医嘱康复训练”。若缺失时的建议动作：以S6对应分期要点生成个性化锻炼计划建议，并提示与主管医生确认。
- **锚定**：治疗路径（保守/手术）、固定方式、部位
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-02｜负重与制动要求
- **适用范围**：下肢骨折为主，上肢为负重限制
- **内容**：为什么要做：过早负重可致固定失效/再移位，过晚负重延缓恢复；下肢尤为关键。出院材料常见表述：“患肢禁负重X周”“扶拐部分负重”【具体数值待医学审核】。若缺失时的建议动作：按S6-04负重进阶要点生成“需与医生确认的负重问题清单”，不直接给出日期。
- **锚定**：受累肢体（上/下肢）、固定方式、术式
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S5-03｜伤口护理与拆线安排
- **适用范围**：手术路径
- **内容**：为什么要做：降低切口感染风险；拆线（或皮内缝合无需拆线）的时间与地点需明确。出院材料常见表述：“术后2周拆线（10–14天，关节周围可延长）”“保持敷料干燥”【数值待医学审核】。若缺失时的建议动作：生成拆线时间与伤口观察提示，标注需向医院确认。
- **锚定**：手术日期、缝线类型、伤口情况
- **用途**：出院指引缺口标签 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-04｜石膏/支具/牵引装置护理
- **适用范围**：保守治疗路径、术后仍带外固定者
- **内容**：为什么要做：松紧不当可致压迫或固定失效；石膏受潮变形、皮肤瘙痒处置不当均有风险。出院材料常见表述：“抬高患肢、观察末梢血运、勿自行拆石膏、石膏勿沾水”。若缺失时的建议动作：按本条与S9相关条目生成护理要点与异常就医提示。
- **锚定**：保守方式、固定部位、出院时是否仍带石膏/支具
- **用途**：出院指引缺口标签
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-05｜内固定留置注意
- **适用范围**：手术路径
- **内容**：为什么要做：避免剧烈碰撞与过早超负荷受力；识别感染征象；知晓是否需取出。出院材料常见表述：“内固定在位，避免外伤”“伤口红肿渗液及时就诊”。若缺失时的建议动作：生成内固定注意要点与取出时机询问清单（关联FX-S7-06）。
- **锚定**：内固定类型（钢板/髓内钉/克氏针）
- **用途**：出院指引缺口标签 / 长期随访加分项
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S5-06｜复查影像时间点
- **适用范围**：全部四肢骨折
- **内容**：为什么要做：对位维持与愈合进度需影像确认；错过窗口可能延误发现再移位或愈合停滞苗头。出院材料常见表述：“术后1个月、3个月、6个月复查X线”【数值待医学审核】。若缺失时的建议动作：按S7通常节奏生成建议复查节奏，并明确标注“以医嘱为准”。
- **锚定**：手术/受伤日期、末次复查日期
- **用途**：出院指引缺口标签 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-07｜带药与用药指导
- **适用范围**：出院带药者
- **内容**：为什么要做：抗凝疗程、镇痛方案、抗骨质疏松用药需明确用法与疗程，防漏服/误服。出院材料常见表述：“利伐沙班 Xmg 每日一次，共X周”【数值待医学审核】。若缺失时的建议动作：按S4核查点生成“用药确认清单”。
- **锚定**：出院带药明细
- **用途**：出院指引缺口标签
- **来源**：《中国骨科大手术静脉血栓栓塞症预防指南》／《原发性骨质疏松症诊疗指南》
- **状态**：draft-待医学审核

- **ID**：FX-S5-08｜居家疼痛管理
- **适用范围**：全部四肢骨折
- **内容**：为什么要做：疼痛影响睡眠与锻炼依从性；患者需知道何时自我处理、何时就医。出院材料常见表述：“疼痛明显时口服止痛药，如疼痛持续加重及时就诊”。若缺失时的建议动作：按FX-S4-03/04/05生成居家镇痛要点与升级就医提示（关联FX-S9-08）。
- **锚定**：出院时疼痛评估、镇痛带药
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《骨科常见疼痛管理临床实践指南》
- **状态**：draft-待医学审核

- **ID**：FX-S5-09｜肿胀与末梢血运观察
- **适用范围**：全部四肢骨折
- **内容**：为什么要做：术后早期肿胀常见，但需能识别异常（进行性肿胀、麻木、末梢发紫）。出院材料常见表述：“抬高患肢、观察足趾/手指颜色与活动”（冰敷/热敷时机因术式与时期而异，需医嘱明确）。若缺失时的建议动作：生成观察要点与分级就医提示（关联FX-S9-01/05/07）。
- **锚定**：部位（上/下肢）、固定方式、出院时肿胀程度
- **用途**：出院指引缺口标签
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-10｜营养指导（钙/维生素D/蛋白）
- **适用范围**：全部四肢骨折，骨质疏松者强化
- **内容**：为什么要做：骨愈合需要足量钙、维生素D与蛋白质；吸烟明确延缓骨愈合，应戒烟。出院材料常见表述：“加强营养、多晒太阳、戒烟限酒”（或缺失）。若缺失时的建议动作：按FX-S6-08生成营养要点；对吸烟者生成戒烟提示。
- **锚定**：吸烟史、营养状况、骨质疏松状态
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《原发性骨质疏松症诊疗指南》／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-11｜跌倒预防与辅具使用
- **适用范围**：全部四肢骨折，老年人及下肢受累者强化
- **内容**：为什么要做：患肢期跌倒可致再骨折/固定失效；老年人风险尤高。出院材料常见表述：“使用助行器/拐杖、穿防滑鞋、避免湿滑地面”（或缺失）。若缺失时的建议动作：按FX-S6-09生成居家防跌倒改造清单与辅具使用要点。
- **锚定**：年龄、下肢受累、辅具配置记录
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-12｜紧急联系与就医指征
- **适用范围**：全部四肢骨折
- **内容**：为什么要做：出院后并发症的早识别依赖患者知晓红旗症状。出院材料常见表述：“如有发热、剧烈疼痛、麻木等及时就诊”（多数出院小结仅泛化表述）。若缺失时的建议动作：按S9生成三级分级就医提示（面向患者转译时保持要点式，不整段照搬）。
- **锚定**：出院小结中的就医提示完整度
- **用途**：出院指引缺口标签 / 优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S5-13｜康复转诊建议
- **适用范围**：关节内骨折、老年人、僵硬高风险者优先
- **内容**：为什么要做：功能恢复复杂（关节僵硬高风险部位）时，专业康复可显著改善结局。出院材料常见表述：“建议康复科门诊随诊”（常见缺失）。若缺失时的建议动作：按部位生成“是否需要康复科评估”的建议提示（关节内骨折、老年、僵硬度高风险者优先）。
- **锚定**：部位、关节内受累与否、康复治疗记录有无
- **用途**：出院指引缺口标签 / 康复计划段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S5-14｜内固定取出与长期随访提示
- **适用范围**：手术路径
- **内容**：为什么要做：部分内固定需取出（如克氏针）、部分可终身留置；患者需要知道“以后还有什么安排”。出院材料常见表述：“骨折愈合后视情况取出内固定”（或缺失）。若缺失时的建议动作：按FX-S7-06生成随访提示，不生成确定日期。
- **锚定**：内固定类型、年龄、愈合进度
- **用途**：出院指引缺口标签 / 长期随访加分项
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核
