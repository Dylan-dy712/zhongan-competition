## S3 诊疗规范要点
用途：为“治疗过程回顾段”提供规范事实底稿；为检查/治疗与诊断不匹配的情形提供“检查疑点标签”判定依据；为“治疗规范符合度画像”提供基准。引用前必须锚定病例中的部位、类型与路径，不得拿通用规范直接指责个体化决策。

- **ID**：FX-S3-01｜诊断标准要点
- **适用范围**：全部四肢骨折
- **内容**：要点：①明确外伤史（时间、机制、能量）；②典型体征：局部肿痛、压痛、畸形、功能障碍，可伴异常活动与骨擦感（不应刻意诱发骨擦音/骨擦感，以免加重损伤）；③影像学证实（X线为首选）。三者结合方可确立诊断。
- **锚定**：入院记录受伤机制、查体记录、影像报告
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S3-02｜X线：初筛与随访主力
- **适用范围**：全部四肢骨折
- **内容**：要点：①首选检查，常规含正侧位并包含相邻关节；②也是保守与术后随访的常规手段（判断对位维持与愈合进度）。检查疑点提示：全程无任何X线报告却诊断骨折、或手术出院前无一次影像记录——列为需核对情形（不构成错误结论）。
- **锚定**：影像报告张数与日期分布；复查记录
- **用途**：检查疑点标签 / 治疗回顾段 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S3-03｜CT：复杂骨折与术前规划
- **适用范围**：复杂关节内骨折等情境
- **内容**：要点：①适用：复杂关节内骨折（跟骨、胫骨平台、髋臼、踝关节、桡骨远端关节内受累等）、术前计划与三维重建；②CT费用高于X线属合理情境，费用解读时不应把CT单列为“异常项”；③疑点提示：简单骨干骨折常规CT并非必需——仅作核对提示，不构成错误结论。
- **锚定**：骨折部位与是否关节内受累、CT报告
- **用途**：检查疑点标签 / 费用解释段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S3-04｜MRI：隐匿骨折与软组织
- **适用范围**：X线阴性但临床怀疑、软组织评估情境
- **内容**：要点：①适用：X线阴性但临床高度怀疑的隐匿性骨折、应力性骨折；韧带、软骨等软组织合并伤评估；②多数骨折不需要MRI；③疑点提示：MRI结论与骨折诊断/处置方向明显不一致时（如MRI阴性而长期按骨折治疗）列为需人工核对情形。
- **锚定**：MRI报告结论与临床处置的一致性
- **用途**：检查疑点标签 / 治疗回顾段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S3-05｜保守治疗路径与适应概要
- **适用范围**：保守治疗路径
- **内容**：要点：①适应概要：移位轻微或手法复位后稳定者；重要脏器功能不能耐受手术者；患者知情选择；②典型方法：手法复位＋石膏/支具固定，或持续牵引；③典型部位：多数桡骨远端骨折、多数锁骨骨折、部分肱骨近端骨折、部分踝关节骨折；④保守不等于不处理：必须按期复查以防再移位。
- **锚定**：骨折部位与移位程度、复位与固定方式记录
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S3-06｜手术治疗路径与适应概要
- **适用范围**：手术路径
- **内容**：要点：①适应概要：手法难以复位或复位后不稳定；关节内明显移位；合并神经血管损伤需探查；保守治疗中再移位；老年髋部骨折通常倾向尽早手术以便离床（长期卧床本身是老年人重大风险）【具体时限要求待医学审核】；②核心步骤：麻醉→复位→固定→（必要时）透视确认→早期康复。
- **锚定**：术前评估记录、术式、麻醉方式
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核

- **ID**：FX-S3-07｜常见部位与术式对应概览
- **适用范围**：手术路径，供术式合理性核对
- **内容**：要点（常见对应，非绝对）：锁骨——保守或钢板；肱骨近端——保守/钢板/髓内钉；尺桡骨——钢板为主；桡骨远端——保守/克氏针/钢板/外固定；股骨颈——空心钉（年轻或嵌插型）或关节置换（置换另行扩展）；粗隆间——髓内钉为主；股骨干——髓内钉；髌骨——张力带或螺钉；胫腓骨——髓内钉或钢板；踝关节——钢板螺钉。术式与部位明显不匹配时（如股骨干仅用石膏）列为需核对情形。
- **锚定**：出院诊断部位、手术记录术式
- **用途**：治疗回顾段 / 治疗规范符合度画像 / 费用解释段
- **来源**：《坎贝尔骨科手术学》／AO/OTA骨折通用分类
- **状态**：draft-待医学审核

- **ID**：FX-S3-08｜VTE风险评估与预防规范
- **适用范围**：下肢大手术、长期卧床情境
- **内容**：要点：①髋膝关节置换、髋部骨折手术及骨盆、股骨等下肢大手术统称骨科大手术，属VTE高危情境，应评估风险并采取预防；②预防三层次：基本预防（早期活动、宣教）＋物理预防（间歇充气加压、弹力袜）＋必要时药物预防（低分子肝素、利伐沙班等）；③药物预防疗程常延续至出院后数周【数值待医学审核】；④疑点提示：下肢大手术住院全程无任何预防记录时列为核查点（可能存在出血风险考量或院外执行，需核对而非判定）。
- **锚定**：手术部位、卧床天数、抗凝用药与物理预防执行记录
- **用途**：治疗回顾段 / 用药疑点标签 / 治疗规范符合度画像
- **来源**：《中国骨科大手术静脉血栓栓塞症预防指南》
- **状态**：draft-待医学审核

- **ID**：FX-S3-09｜住院天数参考（定性区间）
- **适用范围**：全部四肢骨折
- **内容**：要点：①定性参考：无移位稳定骨折保守治疗可短期住院甚至门诊处理；闭合骨折内固定无并发症者住院常在数天至两周内【数值待医学审核】；②住院延长的常见合理原因：老年合并内科病、围术期并发症（血栓、感染）、伤口处理、社会因素；③标签原则：住院天数本身不构成规范符合度结论，必须结合并发症与合并症判断。
- **锚定**：入院/出院日期、并发症记录、合并症
- **用途**：治疗规范符合度画像 / 费用基线参考
- **来源**：国家卫生健康委骨科相关病种临床路径／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S3-10｜抗菌药物预防适用条件
- **适用范围**：内固定等植入物手术（清洁切口）
- **内容**：要点：①闭合骨折内固定涉及植入物，属预防用药的常规指征，以一、二代头孢为常用；②给药时机：静脉输注在切皮前短时间内完成（约0.5–1小时窗口）【数值待医学审核】；③总预防用药时间一般不超过24小时【数值待医学审核】；④开放性骨折属治疗性用药、按污染程度分级处理，不在本包展开；⑤边界：缺少预防用药记录或疗程偏长本身不能认定用药错误，需结合术中情况核对。
- **锚定**：手术类型与植入物、用药医嘱时间线、药物过敏史
- **用途**：用药规则符合度画像 / 用药疑点标签
- **来源**：《抗菌药物临床应用指导原则（2015年版）》
- **状态**：draft-待医学审核

- **ID**：FX-S3-11｜出院标准要点
- **适用范围**：全部四肢骨折
- **内容**：要点：①生命体征平稳、全身情况稳定；②疼痛经口服药物可控；③无需要住院处理的活动性并发症；④伤口/外固定状态稳定，无需住院级处理；⑤已明确康复计划、复查安排与带药。出院材料缺失第⑤类内容时触发“出院指引缺口”系列标签（见S5）。
- **锚定**：出院小结内容完整度
- **用途**：治疗规范符合度画像 / 出院指引缺口标签
- **来源**：《外科学》（人卫教材）／国家卫生健康委骨科相关病种临床路径
- **状态**：draft-待医学审核

- **ID**：FX-S3-12｜保守治疗复位与早期复查要点
- **适用范围**：保守治疗路径
- **内容**：要点：①复位目标按部位执行“功能复位”标准：不强求解剖复位，对线、短缩、旋转的可接受范围因部位与年龄而异【具体标准数值待医学审核】；②石膏固定后通常在1–2周内复查影像，以发现再移位与石膏松动【数值待医学审核】；③疑点提示：保守治疗患者出院后长期无任何复查记录时列为随访缺口。
- **锚定**：保守方式（石膏/牵引）、复位记录、复查影像日期
- **用途**：复诊建议段 / 治疗规范符合度画像 / 检查疑点标签
- **来源**：《外科学》（人卫教材）／《坎贝尔骨科手术学》
- **状态**：draft-待医学审核
