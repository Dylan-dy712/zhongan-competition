# 骨折知识包（KP-FX）草稿

> **定位与红线（全文适用）**
> - 本知识包是“接地与核对依据”：为通俗解释提供权威口径、为痛点标签提供医学规则、为报告生成提供标准照护事实。
> - **不是科普文章库**：生成关怀报告时按条目引用要点并个性化改写，禁止整段拼接科普内容。
> - 每条知识必须能被病例事实锚定，或用于核对病例事实；“锚定”字段列明引用前必须确认的病例要素。
> - 所有具体数值均带【数值待医学审核】；未带标记的定性表述亦需医学审核通过后方可投产。
> - 用药条目不输出“用药错误”结论，仅提供适用情境与核查点；“缺少适应证材料本身不能认定用药错误”。
> - “用途”字段取值固定为：S1诊断解释段 / 术语解释动作 / 治疗回顾段 / 检查疑点标签 / 用药疑点标签 / 费用解释段 / 费用基线参考 / 出院指引缺口标签 / 康复计划段 / 复诊建议段 / 优先行动 / 治疗规范符合度画像 / 用药规则符合度画像 / 长期随访加分项。

## 调取指引

1. 先读本文件：核对病例病种与 scope/exclusions；命中 exclusions 时停止调取并转医学人工，不读任何槽位文件。
2. 按本次能力需要选槽位文件（槽位→用途映射见下），不需要的槽位不加载。
3. 在槽位文件内按条目'适用范围'与'锚定'字段对照病例事实筛选，只把命中条目注入生成/规则上下文。
4. 引用条目时以条目 ID 作为 knowledge_refs 的定位依据；含'【数值待医学审核】'的条目未获准前不得注入患者可见内容。
