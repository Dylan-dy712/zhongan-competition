## S4 用药规则
用途：为用药疑点标签与用药规则符合度画像提供核查点。本节总边界（适用于以下全部条目）：缺少适应证材料本身不能认定用药错误；本包不输出“用药错误”结论，所有“核查点”仅用于触发人工/模型复核。

- **ID**：FX-S4-01｜低分子肝素类（皮下注射抗凝）
- **适用范围**：下肢骨科大手术围术期、髋部骨折等高危患者
- **内容**：适用情境：下肢骨科大手术围术期VTE药物预防，住院期间常用。常见核查点：①与椎管内麻醉/镇痛（腰麻、硬膜外置管）的时间窗要求——置管/拔管前后须按规范停药观察，需核对麻醉记录与给药时间【具体间隔数值待医学审核】；②出血倾向、血小板、肾功能；③出院后是否有延续疗程安排（转口服或继续注射）。常见联用情境：与物理预防（间歇充气、弹力袜）同用；与其他抗凝药叠加须有转换说明。边界：缺少适应证材料不能认定用药错误；反之，无抗凝记录也可能因出血风险评估而合理停用。
- **锚定**：手术类型、麻醉方式与日期、用药医嘱、凝血与肾功能结果
- **用途**：用药疑点标签 / 用药规则符合度画像 / 费用解释段
- **来源**：《中国骨科大手术静脉血栓栓塞症预防指南》
- **状态**：draft-待医学审核

- **ID**：FX-S4-02｜口服Xa因子抑制剂（利伐沙班等）
- **适用范围**：骨科大手术后VTE预防的口服延续
- **内容**：适用情境：骨科大手术后VTE预防的常用口服方案，出院带药常见。常见核查点：①预防剂量与治疗剂量不同，核对出院带药剂量是否符合“预防”定位【剂量数值待医学审核】；②肾功能调整；③与低分子肝素的衔接日期是否重叠或断档；④疗程是否与医嘱一致。常见联用情境：通常不与其他抗凝药叠加；与NSAIDs同用增加出血风险属可接受但需知情的组合。边界：同本节总边界。
- **锚定**：出院带药明细、剂量与疗程、肾功能
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国骨科大手术静脉血栓栓塞症预防指南》
- **状态**：draft-待医学审核

- **ID**：FX-S4-03｜NSAIDs类（塞来昔布、布洛芬、氟比洛芬酯等）
- **适用范围**：围手术期镇痛，保守/手术均适用
- **内容**：适用情境：骨折围手术期多模式镇痛的基础成分之一，短期规律使用。常见核查点：①消化道溃疡/出血史、肾功能、心血管风险；②是否同时存在两种NSAIDs联用；③疗程与出院带药量。常见联用情境：与对乙酰氨基酚、阿片类构成多模式镇痛；与PPI联用做胃保护。边界：部分医生基于骨愈合顾虑回避NSAIDs属合理谨慎——相关证据存在争议，“用或不用”均不能单独判定不当；含“影响骨折愈合”的表述仅作背景知识，不用于标签。
- **锚定**：镇痛类医嘱、消化道/肾功能病史
- **用途**：用药疑点标签 / 用药规则符合度画像 / 费用解释段
- **来源**：《骨科常见疼痛管理临床实践指南》
- **状态**：draft-待医学审核

- **ID**：FX-S4-04｜对乙酰氨基酚
- **适用范围**：基础镇痛、NSAIDs禁忌时的替代
- **内容**：适用情境：基础镇痛；NSAIDs禁忌（如胃溃疡史、肾功能不全）时的常用替代。常见核查点：①成人每日总量上限通常不超过4克，与含对乙酰氨基酚的复方镇痛药同用或肝功能异常时应更低【数值待医学审核】；②核对全部处方是否存在重复成分叠加。常见联用情境：多模式镇痛组合常客，与NSAIDs错时联用属常规策略。边界：同本节总边界。
- **锚定**：全部镇痛类医嘱的成分清单
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《骨科常见疼痛管理临床实践指南》
- **状态**：draft-待医学审核

- **ID**：FX-S4-05｜阿片类与曲马多
- **适用范围**：中重度疼痛短期按需使用
- **内容**：适用情境：中重度疼痛的短期、按需使用，作为多模式镇痛一环而非唯一镇痛。常见核查点：①恶心、呕吐、便秘、头晕等常见反应，配套缓泻剂/止吐药属合理联用；②老年患者跌倒与镇静风险；③出院带药天数与减停安排；④呼吸抑制风险因素（高龄、合用镇静催眠药）。常见联用情境：与非阿片镇痛构成阶梯组合。边界：短期按需使用不能与“药物依赖”画等号；报告解释应避免污名化表述。
- **锚定**：疼痛评估记录、用药天数、年龄与镇静类合并用药
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《骨科常见疼痛管理临床实践指南》
- **状态**：draft-待医学审核

- **ID**：FX-S4-06｜预防性抗菌药物
- **适用范围**：闭合骨折内固定等植入物手术
- **内容**：适用情境：闭合骨折内固定等植入物手术的常规预防（参见FX-S3-10）。常见核查点：①过敏史与皮试记录是否支持品种选择；②常用一、二代头孢，β-内酰胺过敏者换用替代品种属正常；③给药时机与疗程（24小时上限为常规）【数值待医学审核】；④术后出现感染征象转为治疗性用药则疗程另计。常见联用情境：一般单一品种；多药联用需有感染依据。边界：疗程偏长或偏短均不构成错误结论，需结合术中情况核对；开放骨折不在本包范围。
- **锚定**：手术类型、用药时间线、感染相关化验
- **用途**：用药疑点标签 / 用药规则符合度画像 / 费用解释段
- **来源**：《抗菌药物临床应用指导原则（2015年版）》
- **状态**：draft-待医学审核

- **ID**：FX-S4-07｜骨质疏松防治用药（钙剂/维生素D/双膦酸盐类/地舒单抗等）
- **适用范围**：脆性骨折或确诊骨质疏松者
- **内容**：适用情境：脆性骨折（低能量骨折）或已确诊骨质疏松者——基础方案为钙剂＋维生素D；确诊者由医生评估启动抗骨质疏松药物（双膦酸盐类、地舒单抗等，选择属医学判断）。常见核查点：①出院前是否评估骨密度或血钙、维生素D水平；②出院带药或转诊建议是否覆盖；③双膦酸盐类使用前的口腔检查提醒（部分剂型）。常见联用情境：钙＋维生素D为基础；药物疗程长（数年以上），随访依从性是关键。边界：未立即启动药物治疗不等于错误——可能需先完善检查或分科处理。
- **锚定**：年龄与受伤能量、骨密度检查、出院带药明细
- **用途**：用药规则符合度画像 / 长期随访加分项
- **来源**：《原发性骨质疏松症诊疗指南》
- **状态**：draft-待医学审核

- **ID**：FX-S4-08｜消肿、改善循环与促骨愈合类辅助用药
- **适用范围**：围手术期常见辅助处方
- **内容**：适用情境：国内围手术期常见辅助处方：消肿类（如七叶皂苷类、地奥司明等）、改善微循环类、活血化瘀/接骨类中成药。常见核查点：①费用解读时宜单列“辅助类”，与治疗必需药分开呈现，避免患者误以为全部为必需支出；②同类重复联用情况可作提示。常见联用情境：常与镇痛、抗凝药同方出现。边界：辅助用药的使用本身不能认定不合理，也不用于评价诊疗质量。
- **锚定**：全部药品明细、费用归类
- **用途**：费用解释段 / 用药疑点标签
- **来源**：《外科学》（人卫教材）围手术期处理章节＋国内临床常规（仅作归类依据，非疗效背书）
- **状态**：draft-待医学审核

- **ID**：FX-S4-09｜质子泵抑制剂（PPI）
- **适用范围**：NSAIDs联用或应激性溃疡高危者
- **内容**：适用情境：与NSAIDs联用时的胃黏膜保护；重大手术、重症等应激性溃疡高危者短期预防。常见核查点：①无明确指征的长期使用属常见核查点，但不单独认定错误；②与其他药物的相互作用提示。常见联用情境：常与NSAIDs同方出现。边界：同本节总边界。
- **锚定**：NSAIDs使用记录、PPI用药时长
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《应激性溃疡防治专家建议》（版本待医学审核确认）
- **状态**：draft-待医学审核

- **ID**：FX-S4-10｜骨骼肌松弛药
- **适用范围**：急性期痉挛性疼痛辅助
- **内容**：适用情境：急性期肌肉痉挛性疼痛的辅助（如乙哌立松、氯唑沙宗类）。常见核查点：①嗜睡、头晕——与阿片类叠加时镇静作用增强，老年患者需提示跌倒风险；②驾驶与高空作业提醒。常见联用情境：常与NSAIDs/对乙酰氨基酚联用。边界：同本节总边界。
- **锚定**：年龄、镇静类合并用药
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《骨科常见疼痛管理临床实践指南》
- **状态**：draft-待医学审核
