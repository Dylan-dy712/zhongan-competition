## S9 危险信号
用途：为“优先行动”模块与情感支持段的安全边界提供分级红旗要点。生成患者可见内容时按要点转译并附就医途径，禁止整段照搬；分级不得擅自上调或下调。

- **ID**：FX-S9-01｜骨筋膜室综合征征象（🔴立即急诊）
- **适用范围**：前臂、小腿等高发部位，伤后/术后早期
- **内容**：分级：🔴立即急诊。观察要点：①患肢进行性剧痛、常规镇痛无效，尤其被动牵拉手指/足趾时剧痛；②麻木加重、皮肤发紧发亮、感觉减退；③注意：远端脉搏仍存在不能排除早期骨筋膜室综合征。行动：立即急诊，勿等待复诊。
- **锚定**：骨折部位（高发部位）、伤后/术后早期（多为数小时至数天内）【时间窗数值待医学审核】
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S9-02｜肺栓塞征象（🔴立即急诊）
- **适用范围**：下肢手术、长期卧床者
- **内容**：分级：🔴立即急诊。观察要点：突发胸痛、呼吸困难、咯血、晕厥或心悸大汗（可为下肢血栓脱落所致肺栓塞表现）。行动：立即拨打急救电话或就近急诊，勿自行驾车赴院（防途中恶化）。
- **锚定**：下肢手术史、卧床时长
- **用途**：优先行动
- **来源**：《中国骨科大手术静脉血栓栓塞症预防指南》
- **状态**：draft-待医学审核

- **ID**：FX-S9-03｜高热寒战伴全身情况恶化（🔴立即急诊）
- **适用范围**：术后/伤后任何时期
- **内容**：分级：🔴立即急诊。观察要点：高热伴寒战、意识模糊、尿少、血压下降等全身恶化表现——需警惕严重感染（含内固定深部感染）与脓毒症；术后1–3天低中度吸收热常见【阈值数值待医学审核】，但伴寒战与全身恶化不是吸收热。行动：立即急诊。
- **锚定**：术后天数、体温记录、伤口情况
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S9-04｜再外伤后剧痛与畸形加重（🔴立即急诊）
- **适用范围**：恢复期再次受伤者
- **内容**：分级：🔴立即急诊。观察要点：恢复期再次摔倒/撞击后出现剧痛、畸形、固定物部位异常活动或石膏断裂移位——警惕再骨折或固定失效。行动：立即急诊，并携带既往影像资料。
- **锚定**：受伤事件描述（随访中获得）、固定方式
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S9-05｜单侧肢体肿胀疼痛（🟠24–48小时内就诊）
- **适用范围**：下肢手术、制动期
- **内容**：分级：🟠24–48小时内就诊。观察要点：单侧小腿/大腿肿胀、紧胀感、压痛、皮温升高，与对侧对比周径差异明显——提示深静脉血栓可能；勿按摩、勿热敷患肢。行动：24–48小时内骨科/血管外科就诊，评估下肢静脉彩超（持续加重或伴胸痛呼吸困难按🔴处理）。
- **锚定**：下肢手术史、制动时长、抗凝用药执行情况
- **用途**：优先行动
- **来源**：《中国骨科大手术静脉血栓栓塞症预防指南》
- **状态**：draft-待医学审核

- **ID**：FX-S9-06｜伤口红肿渗液或发热（🟠24–48小时内就诊）
- **适用范围**：手术路径
- **内容**：分级：🟠24–48小时内就诊。观察要点：切口红肿范围扩大、渗液增多或呈脓性、裂开，伴中度发热——提示切口感染可能；内固定在位者更应尽早处理。行动：24–48小时内骨科复诊（渗脓明显或发热快速上升者按🔴处理）。
- **锚定**：手术切口、出院后伤口护理记录
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S9-07｜石膏/支具压迫征象（🟠24–48小时内就诊）
- **适用范围**：带石膏/支具出院者
- **内容**：分级：🟠24–48小时内就诊（持续麻木加重或末梢颜色改变者按🔴处理）。观察要点：固定部位持续性麻木、针刺感、局部压迫痛，手指/足趾发紫、发凉、活动无力——提示固定过紧压迫。行动：尽快就诊调整固定，勿自行拆改石膏。
- **锚定**：外固定方式与松紧描述
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S9-08｜疼痛持续加重且止痛无效（🟠24–48小时内就诊）
- **适用范围**：恢复期
- **内容**：分级：🟠24–48小时内就诊。观察要点：恢复期疼痛不减反增、夜间痛突出、现有止痛方案失效——需排除再移位、感染、血栓等（与FX-S9-01/05/06征象交叉时升级）。行动：按分级就诊，并携带用药记录供医生核对。
- **锚定**：疼痛轨迹（随访记录）、镇痛用药
- **用途**：优先行动
- **来源**：《骨科常见疼痛管理临床实践指南》
- **状态**：draft-待医学审核

- **ID**：FX-S9-09｜活动后轻度肿胀（🟢常规复诊时告知）
- **适用范围**：恢复期功能锻炼者
- **内容**：分级：🟢常规复诊时告知。观察要点：锻炼后患肢轻度肿胀、休息与抬高后缓解，无麻木发紫——多为恢复期常见现象。行动：继续按计划锻炼并观察；复诊时向医生描述即可。
- **锚定**：锻炼计划执行情况
- **用途**：优先行动 / 复诊建议段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S9-10｜石膏下皮肤瘙痒或轻微不适（🟢常规复诊时告知）
- **适用范围**：带石膏/支具者
- **内容**：分级：🟢常规复诊时告知。观察要点：石膏内局限瘙痒、轻度磨蹭感——常见；勿伸入异物抓挠，可轻拍石膏外或咨询护理人员。行动：常规复诊时告知；出现异味、发热感或渗出感则升级（关联FX-S9-06）。
- **锚定**：外固定方式、固定时长
- **用途**：优先行动
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：FX-S9-11｜局部麻木/瘢痕区感觉减退与天气相关酸胀（🟢常规复诊时告知）
- **适用范围**：术后恢复期
- **内容**：分级：🟢常规复诊时告知。观察要点：切口周围麻木、感觉迟钝（浅神经末梢恢复慢，多可缓慢改善）；内固定部位天气变化时酸胀不适——常见，多数不提示固定失败。行动：复诊时告知并记录变化趋势；麻木范围扩大或肌力下降则升级就诊。
- **锚定**：手术入路（可能累及浅感觉神经分支）、天气相关主诉
- **用途**：优先行动 / 复诊建议段
- **来源**：《坎贝尔骨科手术学》
- **状态**：draft-待医学审核
