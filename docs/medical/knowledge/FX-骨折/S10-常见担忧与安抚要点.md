## S10 常见担忧与安抚要点
用途：为情感支持段提供"常见担忧→事实性安抚锚点→边界"的对应关系。总边界（适用于以下全部条目）：①安抚必须落在可解释的医学事实上（愈合过程、随访安排、可管理的风险），不得使用"放心吧/没事的"类空洞保证；②不得承诺治愈、时间表或功能结局；③不得替用户断言情绪，只能承接其明确表达的担忧；④担忧涉及红旗症状时转入 S9 分级处理，安抚不得替代就医提示。

- **ID**：FX-S10-01｜"会不会留下残疾、以后不能正常活动"
- **适用范围**：四肢骨折恢复期
- **内容**：承接担忧后可引用的事实：多数四肢骨折经规范治疗和循序渐进康复可恢复日常生活功能；功能恢复节奏与骨折部位、固定方式、康复依从性相关，具体以复查影像和医生评估为准。边界：不预测个体结局、不承诺完全恢复；若用户自述关节活动明显受限或持续加重，衔接 S9 与复诊建议。
- **锚定**：骨折部位、保守/手术、康复阶段、用户自述担忧
- **用途**：情感支持段 / S1诊断解释段
- **来源**：《外科学》（人卫教材）骨折愈合与康复总论
- **状态**：draft-待医学审核

- **ID**：FX-S10-02｜"恢复太慢了，是不是有问题"
- **适用范围**：全部路径（保守/术后）
- **内容**：承接担忧后可引用的事实：骨愈合本身是数周到数月的过程（不同部位差异大），康复早期"感觉慢"常见；愈合进度以 X 线骨痂生长等影像证据为准（衔接 FX-S7 复查节奏），而不是以"感觉"判断。边界：不编造该患者的愈合时间；若同时存在剧痛、麻木、肿胀加重等表现，先按 S9 分级处理再谈安抚。
- **锚定**：受伤/手术日期、最近复查结果、用户自述担忧
- **用途**：情感支持段
- **来源**：《外科学》（人卫教材）骨折愈合过程
- **状态**：draft-待医学审核

- **ID**：FX-S10-03｜"内固定要不要取？不取行不行"
- **适用范围**：内固定手术后
- **内容**：承接担忧后可引用的事实：内固定是否取出、何时取出由手术医生结合愈合与症状评估；无症状者部分可长期留置，属正常选择而非疏漏（衔接 FX-S7-06）。边界：不代医生做取/不取的决定，只提供"可以向医生确认"的问题清单。
- **锚定**：内固定类型、植入日期、有无局部不适
- **用途**：情感支持段 / 复诊建议段
- **来源**：《坎贝尔骨科手术学》（经氢离子平台查证：无症状者多可保留）
- **状态**：draft-待医学审核

- **ID**：FX-S10-04｜"怕再次骨折、怕摔倒"
- **适用范围**：全部路径，中老年及骨质疏松者优先
- **内容**：承接担忧后可引用的事实：防跌倒环境改造（光线、防滑、扶手）、循序渐进的力量与平衡练习、钙/维生素D 与骨质疏松管理都是可操作的降低再骨折风险的手段（衔接 FX-S6-08/S6-09）。边界：不使用"绝对不会再骨折"类保证；表述为"可以把可控的风险管起来"。
- **锚定**：年龄、骨质疏松状态、居住环境、用户自述担忧
- **用途**：情感支持段 / 康复计划段 / 优先行动
- **来源**：《原发性骨质疏松症诊疗指南》
- **状态**：draft-待医学审核

- **ID**：FX-S10-05｜"康复期疼痛反复，正常吗"
- **适用范围**：全部路径
- **内容**：承接担忧后可引用的事实：康复期活动相关的一过性酸痛较常见，随功能进步多逐步改善；疼痛的管理手段（按时镇痛、冰敷/抬高、循序渐进负荷）可主动参与（衔接 S4/S6）。边界：疼痛的"正常波动"与红旗表现（静息剧痛、麻木加重、肿胀发热）的界线按 S9 判断，不做二选一的口头承诺。
- **锚定**：疼痛部位/诱因/变化趋势、镇痛用药、用户自述
- **用途**：情感支持段
- **来源**：《骨科常见疼痛管理临床实践指南》
- **状态**：draft-待医学审核

- **ID**：FX-S10-06｜"行动不便，拖累家人"（照护压力）
- **适用范围**：下肢骨折、术后制动期
- **内容**：承接担忧后可引用的事实：康复目标是分阶段的逐步自理（从床边活动到辅助行走），照护需求随阶段递减；辅具与居家改造可减少对他人的依赖（衔接 FX-S6-09）。可建议：把"需要家人帮什么"写进优先行动，向客服/家属分配（owner_role=caregiver）。边界：不替用户表达愧疚情绪；不承诺恢复到受伤前水平。
- **锚定**：骨折部位与负重状态、家庭照护情况、用户自述担忧
- **用途**：情感支持段 / 优先行动
- **来源**：《外科学》（人卫教材）康复总论；骨科护理实践常规
- **状态**：draft-待医学审核
