## S10 常见担忧与安抚要点
用途：为情感支持段提供"常见担忧→事实性安抚锚点→边界"的对应关系。总边界同各包 S10：安抚落在医学事实上；不承诺结局；不替用户断言情绪；红旗症状转 S9。

- **ID**：YZ-S10-01｜"神经压久了会不会瘫痪"
- **适用范围**：全部路径（保守/术后）
- **内容**：承接担忧后可引用的事实：绝大多数腰椎间盘突出症不导致瘫痪；真正需要立即处理的是马尾综合征等急症——鞍区麻木、大小便功能障碍、双下肢明显无力，这些已在"立即就医"清单中（衔接 YZ-S9）。把"哪些信号要立刻就医"讲清楚本身就是缓解这类担忧的主要手段。边界：不使用"绝对不会"类绝对化保证；不评价手术医生的决定。
- **锚定**：当前神经症状（肌力/感觉/大小便）、保守或手术状态、用户自述担忧
- **用途**：情感支持段 / 优先行动
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S10-02｜"术后还会复发吗"
- **适用范围**：手术路径
- **内容**：承接担忧后可引用的事实：复发风险客观存在，但可控因素明确——规律腰背肌与核心锻炼、避免久坐弯腰负重、体重管理（衔接 YZ-S6/S5-05）。随访计划（衔接 S7）能在症状变化时早评估。边界：不引用具体复发率数字（证据异质性大，避免误读）；表述为"可以把可控的部分管起来"。
- **锚定**：术式、术后时间、锻炼依从性、用户自述担忧
- **用途**：情感支持段 / 康复计划段 / 长期随访加分项
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S10-03｜"手脚麻木什么时候能好"
- **适用范围**：保守与术后均有神经症状者
- **内容**：承接担忧后可引用的事实：神经受压后的麻木、感觉异常恢复慢于疼痛，部分残留症状可持续较长时间并逐步改善；恢复趋势以随访评估为准（衔接 S7），而非以"当天感觉"判断。边界：不承诺麻木完全消失；进行性加重或新发无力按 S9 升级处理。
- **锚定**：症状部位与持续时间、手术/保守日期、随访记录、用户自述
- **用途**：情感支持段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）；《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S10-04｜"还能干重活/运动吗"
- **适用范围**：恢复期及长期
- **内容**：承接担忧后可引用的事实：恢复是分阶段的——先恢复日常活动，再在指导下逐步强化腰背肌，多数人可回归适合的工作与运动（衔接 YZ-S6 分期与 S5-05 锻炼计划）；需要长期注意的限制是久坐、弯腰负重等特定姿势负荷，而非"不能动"。边界：返岗/负重标准由医生结合影像与功能评估决定；不替患者开"康复完成证明"。
- **锚定**：术式/保守状态、康复阶段、职业需求、用户自述担忧
- **用途**：情感支持段 / 康复计划段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S10-05｜"保守治疗这么久没好，是不是该直接手术"
- **适用范围**：保守治疗路径
- **内容**：承接担忧后可引用的事实：无显著神经损害者规范保守治疗6–12周是国内外指南的首选路径，多数患者在此期间改善（衔接 YZ-S3-07）；手术指征有明确标准（规范保守无效、进行性神经损害、马尾综合征等），由脊柱外科医生结合影像与症状评估。可建议：把"复诊时请医生评估是否继续保守"写成优先行动。边界：不催促也不劝阻手术；不评判已发生的治疗选择。
- **锚定**：保守治疗起始时间与内容、症状变化趋势、最近影像、用户自述担忧
- **用途**：情感支持段 / 复诊建议段 / 优先行动
- **来源**：《腰椎间盘突出症诊疗指南》（2020）（经氢离子平台查证：6–12周观察口径）
- **状态**：draft-待医学审核
