## S11 手术与检查通俗解释
用途：为治疗回顾段提供过程级通俗解释。总边界同各包 S11：只解释目的与过程；不评价该患者手术/检查是否必要、成功与否；过程为"一般情形"，与病例事实冲突时不引用。

- **ID**：YZ-S11-01｜腰椎MRI
- **适用范围**：诊断与术前评估的核心检查
- **内容**：是什么：磁共振成像，不用X射线，能清楚看到椎间盘、神经根和马尾神经这些"软组织"——哪一节突出、压没压到神经，看MRI最清楚。怎么做：躺入圆筒状机器15-30分钟，噪音较大可戴耳塞，需保持不动；体内有心脏起搏器等植入物者提前告知。
- **锚定**：检查报告（节段与压迫描述）
- **用途**：治疗回顾段 / S1诊断解释段 / 术语解释动作
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S11-02｜腰椎CT与X线
- **适用范围**：骨性结构评估、术前规划
- **内容**：是什么：CT看骨头细节（椎板、关节突、钙化），X光看整体序列与稳定性；三者（X光/CT/MRI）互补而非替代。
- **锚定**：检查医嘱/报告
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S11-03｜直腿抬高试验（体格检查）
- **适用范围**：神经根受压的体格检查
- **内容**：是什么：平躺在床上，医生抬起伸直的下肢看放射痛是否被诱发（正常可抬至60-70度以上无痛）。意义：坐骨神经牵拉试验，阳性提示神经根受压，是诊断的重要体征之一；结果需与影像和症状互相印证。
- **锚定**：病历体格检查记录
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S11-04｜椎间孔镜髓核摘除（PELD等微创术式）
- **适用范围**：适合微创路径的椎间盘突出
- **内容**：是什么：在腰侧开一个约7毫米左右的小口，把一根带摄像头的"钥匙孔内镜"送到椎间盘旁，直视下摘除压迫神经的髓核组织。怎么做：多为局麻或全麻，全程或大部分时间清醒，皮肤仅需缝1-2针；术后当天或次日即可戴腰围下床（按医嘱）。特点：创伤小、恢复快，但适应证由医生评估。
- **锚定**：手术记录（术式、节段）
- **用途**：治疗回顾段 / S1诊断解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S11-05｜椎板开窗/椎板减压
- **适用范围**：需要直接减压的病例
- **内容**：是什么：从后方切开，咬除少量椎板骨质形成"窗口"，摘除压迫神经的髓核、松解神经根——"开门取出压迫物"。
- **锚定**：手术记录（术式、节段）
- **用途**：治疗回顾段 / S1诊断解释段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S11-06｜融合内固定手术（TLIF等）
- **适用范围**：腰椎不稳定、多节段或复发病例
- **内容**：是什么：摘除病变椎间盘后，在相邻椎体间放入骨性"垫块"（融合器）促两节椎体长成一体，并用螺钉钛棒内固定临时稳定——"搭桥+支架"。特点：稳定性好但创伤与费用高于微创摘除，恢复期更长（衔接 YZ-S5-02 腰围分层口径）。患者会经历：术后引流管1-2天、戴腰围下床、逐步功能锻炼。
- **锚定**：手术记录（融合节段、内固定）
- **用途**：治疗回顾段 / S1诊断解释段 / 费用解释段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）；《外科学》（人卫教材）
- **状态**：draft-待医学审核
