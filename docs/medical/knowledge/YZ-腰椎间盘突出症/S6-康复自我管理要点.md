## S6 康复/自我管理要点
用途：为“康复计划段”提供分期分场景要点。每条注明依赖的病例事实：生成时必须先核对锚定事实再引用；缺乏锚定事实的条目不得生成为“个体化计划”，只能作为通用提示并标注待确认。

- **ID**：YZ-S6-01｜康复分期总则
- **适用范围**：全部病例
- **内容**：要点：①康复分三期推进：急性/保护期（控制炎症、避免诱发动作）→恢复期（活动度与核心稳定渐进恢复）→强化期（腰背肌与核心力量强化、防复发）；②总原则“循序渐进、以疼痛不明显加重为度”；③康复节奏与路径强相关（保守/微创/融合节奏不同），引用前必须先核对锚定事实，不得混用节奏。
- **锚定**：治疗路径（保守/微创/融合）、起病或术后周数、年龄、合并症
- **用途**：康复计划段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-02｜保守治疗期：活动管理
- **适用范围**：保守治疗路径
- **内容**：要点：①避免长时间卧床，在可耐受范围内保持日常活动；②急性期避免弯腰提物、久坐软沙发；坐位可用腰靠并定时起身活动；③症状急性加重期短时休息后尽早恢复活动——活动的恢复本身就是治疗的一部分。
- **锚定**：保守治疗记录、症状程度
- **用途**：康复计划段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-03｜保守治疗期：锻炼时机与方向
- **适用范围**：保守治疗路径
- **内容**：要点：①疼痛明显缓解后开始核心稳定与腰背肌锻炼；②锻炼宜在专业人员评估后个体化进行（方向性练习等），生成器不代拟具体动作处方；③锻炼以不诱发下肢放射痛为度——诱发腿痛的动作应暂停并复诊咨询。
- **锚定**：症状缓解程度、有无专业康复指导记录
- **用途**：康复计划段
- **来源**：《腰椎间盘突出症诊疗中国疼痛专家共识》
- **状态**：draft-待医学审核

- **ID**：YZ-S6-04｜术后早期（出院后数周内）：保护原则
- **适用范围**：手术路径
- **内容**：要点：①佩戴腰围下床活动，避免腰部屈曲、旋转与负重（融合术后更严格）；②床上轴线翻身、踝泵与下肢活动防血栓；③坐位时间从短到长渐进；④具体时限与动作以手术医生医嘱为准。
- **锚定**：术式（微创/融合）、术后天数、腰围医嘱
- **用途**：康复计划段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-05｜术后恢复期：渐进活动恢复
- **适用范围**：手术路径
- **内容**：要点：①腰围佩戴时限内逐步恢复日常活动，步行是最主要的早期锻炼；②避免过早恢复体力劳动、剧烈运动与颠簸驾驶；③恢复节奏个体差异大，以复查评估为准，不给绝对时间承诺。
- **锚定**：术后周数、腰围佩戴医嘱、复查记录
- **用途**：康复计划段
- **来源**：《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-06｜术后强化期：腰背肌锻炼
- **适用范围**：手术路径，恢复期
- **内容**：要点：①常见锻炼形式：五点支撑、“小燕飞”、平板支撑等，恢复期在指导下逐步开始【具体动作时机与处方待医学审核/康复师确认】；②融合术后开始时间通常更晚，并需结合复查影像评估融合进展；③强化锻炼是长期防复发的核心，需长期坚持，属“长期随访加分项”的观察内容。
- **锚定**：术式、术后月数、复查影像
- **用途**：康复计划段 / 长期随访加分项
- **来源**：《腰椎间盘突出症诊疗中国疼痛专家共识》／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-07｜融合手术与微创手术的康复差异
- **适用范围**：手术路径
- **内容**：要点：①融合术后康复节奏整体更慢：下床、腰围佩戴、恢复工作时间通常长于微创髓核摘除【具体差异待医学审核】；②微创摘除术后恢复快，但同样需恢复期保护——“手术小”不等于“可以立刻干重活”；③生成康复计划时不得混用两条路径的节奏。
- **锚定**：术式
- **用途**：康复计划段 / 治疗回顾段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-08｜生活方式管理
- **适用范围**：全部病例
- **内容**：要点：①控制体重以减轻腰椎负荷；②戒烟（吸烟影响椎间盘血供与营养，融合术者更应戒烟）；③避免久坐软沙发、窝坐、长时间驾驶；搬重物采用屈膝下蹲、物贴身体、保持腰部直立的方式；④硬板床加薄垫、侧卧屈髋屈膝等睡姿调整可作为提示。
- **锚定**：吸烟史、体重、职业与生活史
- **用途**：康复计划段 / 长期随访加分项
- **来源**：《腰椎间盘突出症诊疗指南》（2020）／《外科学》（人卫教材）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-09｜工作与生活恢复
- **适用范围**：全部病例
- **内容**：要点：①恢复工作时间因术式与职业性质差异大（坐位工作早于体力劳动）【数值待医学审核】；②驾驶一般建议在疼痛明显缓解、反应灵活后再恢复【数值待医学审核】；③久坐职业建议分段工作、工位调整（座椅支撑、定时起身）。
- **锚定**：职业记录、术式、恢复进度
- **用途**：康复计划段
- **来源**：《外科学》（人卫教材）／NASS腰椎间盘突出症伴神经根病临床指南（2012）
- **状态**：draft-待医学审核

- **ID**：YZ-S6-10｜心理与预期管理
- **适用范围**：全部病例
- **内容**：要点：①常见担忧与安抚事实：术后残留麻木恢复慢（神经恢复以月计）；恢复期症状有波动，不代表治疗失败；②恢复预期给区间不给承诺；③对“怕动致瘫”的过度恐惧与“急于恢复”的过度锻炼两类倾向都需引导；④持续情绪低落、失眠等信号建议专业心理支持。生成“心理安抚”段必须结合患者实际表述，不得虚构情绪状态。
- **锚定**：患者主诉与情绪线索（如有）、恢复进度与预期的差距、症状残留
- **用途**：康复计划段
- **来源**：《腰椎间盘突出症诊疗指南》（2020）（患者教育与恢复预期常识口径）
- **状态**：draft-待医学审核
