# 腰椎间盘突出症知识包（KP-YZ）草稿

**使用边界（对生成器的红线约束，优先级高于任何单条知识）：**

1. 本知识包是“接地与核对依据”，不是科普文章库。报告中不得整段拼接本包内容；每条知识只能以要点形式、且被病例事实锚定后引用；若某段报告去掉病例事实后仍成立，即为模板化，应重写。
2. “用途”字段取值固定为：S1诊断解释段 / 术语解释动作 / 治疗回顾段 / 检查疑点标签 / 用药疑点标签 / 费用解释段 / 费用基线参考 / 出院指引缺口标签 / 康复计划段 / 复诊建议段 / 优先行动 / 治疗规范符合度画像 / 用药规则符合度画像 / 长期随访加分项。
3. 用药条目（S4）一律不得生成“用药错误”类结论；只能生成“适用情境说明＋核查点提示”，并须声明“缺少适应证材料本身不能认定用药错误”。检查类疑点（S3）同理，只输出“需核实线索”进入医学复核，不得对患者宣称“医生做了非必要检查/开错药”。
4. 优先级口径：主管医生书面医嘱/出院医嘱 > 本知识包一般口径。凡冲突，以医嘱为准并在报告中按医嘱表述。
5. 复诊日期生成规则：出院医嘱提供了日期则用医嘱；未提供时不得生成确定日期，仅按 S7-01 提示“可与医生确认通常节奏”。
6. 所有标注【数值待医学审核】的数值未经医学审核通过前，不得原样写入患者报告；未带标记的定性表述亦需医学审核通过后方可投产。
7. 危险信号（S9）三级分级不得擅自上调或下调；生成患者可见内容时按要点转译并附就医途径，禁止整段照搬。

**转人工规则（exclusions 触发，任一命中即停止自动生成、转人工医学审核）：**

- 理赔材料提示腰椎骨折（含压缩骨折、爆裂骨折）——本包不适用。
- 以腰椎滑脱为主症者（峡部裂性/退变性滑脱为主要诊断）——本包不适用。
- 提示脊柱肿瘤或感染性病变（脊柱结核、椎间隙感染、椎旁脓肿等）——本包不适用。
- 颈椎间盘突出或其他部位（胸椎等）椎间盘突出——本包不适用。
- 18岁以下患者、妊娠期、显著脊柱畸形矫形手术——本包不适用。
- 命中以上任一情形时，相关解释内容回退为通用提示并明确标注“待人工审核”，不得生成个体化医学解释。
