## S2 术语通俗对照
用途：术语解释动作——理赔材料中出现下列术语时查表生成通俗解释；部分条目同时供诊断解释段、检查/用药疑点标签引用。

说明：本节按槽位定义采用表格形式。每行是一个条目，逐条字段（ID、术语/常见写法、通俗解释、患者为何困惑、用途）在表中列明；统一字段以表后"公共字段声明"为准，与全文统一列表字段等效。

| ID | 术语/常见写法 | 通俗解释 | 患者为何困惑 | 用途 |
|---|---|---|---|---|
| TN-S2-01 | 糖化血红蛋白（HbA1c，"糖化"） | 反映近2~3个月平均血糖水平的指标，不要求空腹，是评价长期血糖控制好坏的核心指标 | 与"血糖"混淆；以为前一天吃了甜食就会立刻影响它；不理解它是"平均分"而非"当下值" | 术语解释动作 / S1诊断解释段 |
| TN-S2-02 | 空腹血糖（FPG，化验单常写 GLU） | 禁食8小时以上（一般过夜后晨起）测的血糖，反映基础状态下的血糖水平 | 不清楚"空腹"的具体定义；抽血前是否停药不清楚（应遵医嘱，不可自行停降糖药） | 术语解释动作 |
| TN-S2-03 | 餐后2小时血糖（2hPG/餐后血糖） | 从吃第一口饭开始计时2小时测的血糖，反映进餐后血糖高峰的控制情况 | 误以为从"吃完饭"才开始计时，导致复测值不可比 | 术语解释动作 |
| TN-S2-04 | 随机血糖 | 一天中任意时间点测的血糖，不论是否进餐；达到很高值且有典型症状时可提示糖尿病 | 不明白它与空腹/餐后血糖的用途差别；被"随便什么时候抽"的说法搞得不确定结果是否可信 | 术语解释动作 |
| TN-S2-05 | OGTT（口服葡萄糖耐量试验） | 喝下规定浓度的糖水后分时间点抽血，观察血糖变化，用于诊断糖尿病或评估血糖调节能力 | 把"耐量试验"听成"糖不耐受"；不理解为什么要"喝糖水验血" | 术语解释动作 |
| TN-S2-06 | 低血糖 | 血糖低到引起不适的程度（一般界定值约3.9 mmol/L 以下【数值待医学审核】），典型表现为心慌、出汗、手抖、饥饿感、乏力，严重时可意识模糊甚至昏迷 | 不知道降糖药也会"降过头"；把低血糖症状误当心脑血管病发作，或反过来延误处理 | 术语解释动作 / 优先行动 |
| TN-S2-07 | 胰岛素抵抗 | 身体组织对胰岛素"不敏感"，同样量的胰岛素"打不开细胞之门"，是2型糖尿病的核心机制之一 | 把"抵抗"误听为"对胰岛素耐药/失效"，因而对使用胰岛素产生不必要的抗拒 | 术语解释动作 / S1诊断解释段 |
| TN-S2-08 | 胰岛素分泌不足（β细胞功能减退） | 胰腺内分泌胰岛素的β细胞功能逐渐下降，"产能"跟不上身体需求；是随病程进展的常见过程 | 误以为"用胰岛素就是病到晚期"；不理解这是渐进过程、及时补充反而保护自身功能 | 术语解释动作 / S1诊断解释段 |
| TN-S2-09 | C肽（胰岛素释放试验） | 与胰岛素由同一前体物质生成、同步分泌的物质，抽血查它可评估自身胰岛素分泌能力，也用于辅助分型 | 不懂为什么查"肽"而不是直接查胰岛素；误以为C肽就是胰岛素本身 | 术语解释动作 |
| TN-S2-10 | 糖尿病肾病（DKD；CKD分期） | 长期高血糖损伤肾小球的滤网，早期表现为尿中微量白蛋白增多，晚期肾功能下降；医生常按慢性肾脏病（CKD）分期描述严重程度 | 看到"尿蛋白+"不明白含义；把"CKD分期"直接等同于"要透析"；肾病专科处置不属本包范围 | 术语解释动作 / 检查疑点标签 |
| TN-S2-11 | 糖尿病视网膜病变（DR） | 高血糖损伤眼底视网膜血管，早期可毫无症状，晚期可出血、牵拉脱离而严重影响视力 | "现在看得见就没问题"是常见误区；把老花与视网膜病变混为一谈；眼底治疗转人工/对应知识包 | 术语解释动作 / 检查疑点标签 |
| TN-S2-12 | 糖尿病周围神经病变（DPN） | 高血糖损伤周围神经，常见双脚麻木、刺痛、蚁走感或袜套样感觉减退；感觉减退时足部受伤也不易察觉 | 与腰腿痛、脑血管病混淆；不理解"不痛"反而可能更危险（痛觉保护减弱） | 术语解释动作 |
| TN-S2-13 | 糖尿病足 | 糖尿病合并下肢血管和/或神经病变基础上发生的足部溃疡、感染甚至坏疽，是截肢的重要原因 | 把足部小伤口当普通外伤硬扛；不知道"破溃不愈"需要专科及时处理（专科内容转对应知识包） | 术语解释动作 / 优先行动 |
| TN-S2-14 | 尿微量白蛋白 / 尿白蛋白肌酐比（UACR/ACR） | 比"尿常规尿蛋白"更灵敏的早期肾损伤指标，用尿白蛋白与肌酐的比值校正尿量影响 | 分不清"尿蛋白"与"微量白蛋白"两个指标；不懂为何同一份尿还要查肌酐 | 术语解释动作 / 检查疑点标签 |
| TN-S2-15 | 血肌酐 / 肾小球滤过率（eGFR） | 反映肾功能的血液指标：eGFR越低肾功能越差；eGFR还直接决定部分降糖药（如二甲双胍）能否用、怎么调 | 肌酐"只高一点"被忽视；不知道肾功能结果与降糖药方案直接挂钩 | 术语解释动作 / 用药疑点标签 |
| TN-S2-16 | 尿酮体 / 酮症 | 体内脂肪分解过多产生的酸性物质，从尿中排出；明显酮症提示胰岛素严重不足或进食严重不足 | 与流行的"生酮饮食"混淆，误以为酮体是好事；不知道持续酮症需要就医 | 术语解释动作 |
| TN-S2-17 | 酮症酸中毒（DKA）/高渗高血糖状态（HHS） | 糖尿病最危险的两种急性并发症，表现为脱水、腹痛呕吐、意识改变等，属内科急症；本知识包不覆盖其救治细节 | 材料中出现时易被当作普通"血糖高"理解，低估其严重性 | 术语解释动作 / 优先行动 |
| TN-S2-18 | 指尖血糖（末梢血糖、快速血糖、POCT） | 用采血针取指尖血、以血糖仪测的血糖，用于日常自我监测；与静脉血结果存在系统性差异，诊断以静脉血为准 | 与静脉结果不一致就怀疑血糖仪坏了或医院测错了；不知两者本就有可解释的差异 | 术语解释动作 |
| TN-S2-19 | 动态血糖监测（CGM）/葡萄糖目标范围内时间（TIR） | 贴在身上的传感器连续多日记录组织间液葡萄糖水平，可看到全天波动趋势（含夜间）；TIR是"血糖落在目标范围内的时间占比" | 把CGM数值与指尖血糖完全等同（两者有滞后差）；看到传感器以为在"抽血" | 术语解释动作 |
| TN-S2-20 | 血糖控制目标 | 医生根据年龄、病程、并发症、低血糖风险给每个人定的"目标区间"，不是统一一个数 | 拿别人的目标数字比自己的；以为"越接近正常越好"，忽视低血糖代价 | 术语解释动作 / S1诊断解释段 |
| TN-S2-21 | 基础胰岛素 | 模拟人体全天缓慢基础分泌的中长效胰岛素（如甘精、地特、德谷胰岛素，睡前中效NPH），一般每天固定时间注射1次 | 与"餐时胰岛素"分不清；不知道基础胰岛素解决不了单餐进食后的血糖高峰 | 术语解释动作 / 用药疑点标签 |
| TN-S2-22 | 餐时胰岛素（速效/短效胰岛素） | 针对进餐后血糖高峰、在餐前注射的胰岛素（如门冬、赖脯、谷赖胰岛素，普通胰岛素RI） | 打了针没及时吃饭会低血糖；漏餐时该不该补打不清楚 | 术语解释动作 / 用药疑点标签 |
| TN-S2-23 | 预混胰岛素（30R/50R、门冬30等） | 把中长效与短/速效成分按比例预先混合的胰岛素，一般早、晚餐前注射；要求两餐时间与进食量相对固定 | 以为一天两针就"全天全覆盖"，午餐后易高；进餐不规律时低血糖风险增加 | 术语解释动作 / 用药疑点标签 |
| TN-S2-24 | 胰岛素笔 / 笔芯 / 特充 | 笔是注射装置，笔芯是装入笔内的药芯，特充是整支预填充不可换芯的产品；注射针头是一次性耗材 | 笔与笔芯型号不匹配装不上；误以为针头可以反复用（应一针一换） | 术语解释动作 / 用药疑点标签 |
| TN-S2-25 | 胰岛素泵（持续皮下胰岛素输注，CSII） | 随身佩戴的小型设备，通过埋在皮下的软管持续输入胰岛素，住院调糖时可能短期使用，剂量由医嘱设定 | 以为可以自己按键加量；管路脱落、堵管会影响输注而不自知 | 术语解释动作 |
| TN-S2-26 | 糖化白蛋白（GA） | 反映近2~3周平均血糖水平的指标；在贫血等情况影响HbA1c准确性时，医生可能改查它 | 与糖化血红蛋白混淆，看到两个"糖化"结果不同以为化验有错 | 术语解释动作 |
| TN-S2-27 | 低密度脂蛋白胆固醇（LDL-C） | 血脂中最需要控制的指标，与糖尿病的心脑血管并发症直接相关；糖尿病患者的LDL-C目标通常比普通体检标准更严格 | 以为"血糖控制好就够"；拿体检报告的正常参考范围对照，认为血脂正常无需治疗 | 术语解释动作 / 检查疑点标签 |
| TN-S2-28 | 代谢综合征 | 超重/腹型肥胖、高血压、血糖异常、血脂异常等多个心血管风险因素聚集出现的状态，2型糖尿病患者中很常见 | 以为是一组独立疾病；不理解它提示的是整体心脑血管风险，需要一起管 | 术语解释动作 / S1诊断解释段 |

**S2公共字段声明（等效于逐条字段）：**
- **适用范围**：成人2型糖尿病住院及出院后患者的理赔材料解读；DKA/HHS、糖尿病足、糖尿病肾病、视网膜病变等条目仅作术语级解释，专科处置见 exclusions 转人工
- **锚定**：理赔材料原文出现该术语（出院诊断、检验报告、医嘱单、用药明细、护理记录、费用清单）
- **来源**：《内科学》（人卫版）；《中国2型糖尿病防治指南（2020年版）》；《中国糖尿病药物注射技术指南（2016年版）》（胰岛素器械相关条目）
