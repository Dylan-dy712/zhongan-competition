## S8 费用结构参考
用途：供费用解释段、费用基线参考引用；不写任何具体金额与自付比例阈值，异常判定基准来自理赔数据集。

- **ID**：TN-S8-01
- **适用范围**：成人2型糖尿病住院患者
- **内容**：住院费用构成大类：化验检查（血糖相关密集监测、HbA1c、并发症筛查）、药品（降糖药、胰岛素及合并症用药）、耗材（血糖试纸、采血针、胰岛素针头、CGM传感器如使用）、护理与床位、合并症/并发症相关治疗。控糖住院与并发症住院的费用结构重心不同，解读时先看住院原因。
- **锚定**：费用清单科目汇总、住院原因（控糖/并发症/围手术期）
- **用途**：费用解释段 / 费用基线参考
- **来源**：《中国住院患者血糖管理专家共识》（诊疗项目构成口径）；基本医疗保险"三大目录"口径
- **状态**：draft-待医学审核

- **ID**：TN-S8-02
- **适用范围**：成人2型糖尿病住院患者（控糖住院情境）
- **内容**：监测相关费用为何密集：住院调糖期间每日多次床旁血糖测定（试纸、采血针按次计费）加静脉血糖/生化复查，是此类住院费用的重要构成；这属于调糖治疗本身要求的监测密度，费用占比高不等于过度检查。
- **锚定**：护理记录血糖测量次数、费用清单中血糖测定/试纸条目
- **用途**：费用解释段
- **来源**：《中国住院患者血糖管理专家共识》
- **状态**：draft-待医学审核

- **ID**：TN-S8-03
- **适用范围**：成人2型糖尿病住院患者（胰岛素情境）
- **内容**：胰岛素与耗材费用：使用胰岛素者费用中"药品+耗材"（笔芯/特充、一次性针头、部分情况输液泵/CGM）占比明显升高；住院"基础+餐时"强化方案的费用高于口服药方案。这解释了同为糖尿病住院、账单结构差异大的常见疑问。
- **锚定**：是否使用胰岛素、住院药费与耗材费占比、有无泵/CGM使用
- **用途**：费用解释段
- **来源**：《中国住院患者血糖管理专家共识》；《中国糖尿病药物注射技术指南（2016年版）》（针头一次性使用口径）
- **状态**：draft-待医学审核

- **ID**：TN-S8-04
- **适用范围**：成人2型糖尿病住院患者（筛查情境）
- **内容**：并发症筛查相关费用：规范要求的出院前筛查（眼底检查/照相、尿微量白蛋白、肾功能、血脂、足部评估）是糖尿病住院的合理组成部分，用于发现无症状并发症；费用清单中出现这些项目属可解释范围。
- **锚定**：费用清单中的筛查项目、住院中有无对应报告
- **用途**：费用解释段 / 检查疑点标签
- **来源**：《中国2型糖尿病防治指南（2020年版）》（并发症筛查口径）
- **状态**：draft-待医学审核

- **ID**：TN-S8-05
- **适用范围**：成人2型糖尿病出院患者（长期用药情境）
- **内容**：门诊/住院口径差异提示：2型糖尿病长期用药通常在门诊解决，多数地区有门诊慢病/门特待遇；住院主要用于调糖或并发症处理。同一药物门诊与住院的报销比例、起付线规则不同，解读费用时须区分口径，不能把住院账单结构直接套到门诊取药上。
- **锚定**：费用发生地（门诊/住院）、患者医保类型与门诊慢病待遇资格
- **用途**：费用解释段 / 费用基线参考
- **来源**：基本医疗保险"三大目录"及门诊慢病待遇通行口径（地区差异大，仅作定性提示）
- **状态**：draft-待医学审核

- **ID**：TN-S8-06
- **适用范围**：成人2型糖尿病住院患者（结算口径说明）
- **内容**：口径说明：费用清单常见"总费用=医保统筹/基金支付+个人支付"；个人支付内部又分"自付"（医保目录内个人承担部分，含起付线与共付段比例）与"自费"（目录外项目）。费用解读必须区分"总费用"与"个人实际支出（自付+自费）"，防止用户把总费用误认为自己的负担。
- **锚定**：费用清单结算字段（总费用、统筹支付、个人自付、自费）
- **用途**：费用解释段
- **来源**：理赔费用清单常见结算口径（行业通行结构）
- **状态**：draft-待医学审核

- **ID**：TN-S8-07
- **适用范围**：成人2型糖尿病住院患者（自付异常提示情境）
- **内容**：自付比例异常的判定：基准来自理赔数据集的分层统计（病种、住院原因、地区口径），本知识包不提供金额或比例阈值；本包仅提供"哪些科目构成与住院原因/方案相关"的解释口径（见 TN-S8-01~04），供异常提示触发时引用，不输出"费用异常"结论。
- **锚定**：结算单据字段、统筹/自付明细、理赔数据集基线（外部数据，非本包）
- **用途**：费用基线参考
- **来源**：理赔数据集口径（由数据侧提供，本包不定义）
- **状态**：draft-待医学审核
