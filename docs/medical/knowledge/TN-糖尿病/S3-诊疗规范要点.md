## S3 诊疗规范要点
用途：供治疗回顾段、检查疑点标签、治疗规范符合度画像、费用基线参考（住院天数）引用；条目只做"事实与情境核对"，不做病例级诊断评价。

- **ID**：TN-S3-01
- **适用范围**：成人2型糖尿病住院患者（诊断与分型核对）
- **内容**：诊断标准要点：典型"三多一少"症状（多饮、多食、多尿、体重下降）加随机血糖≥11.1 mmol/L，或空腹血糖≥7.0 mmol/L，或 OGTT 2小时血糖≥11.1 mmol/L，或 HbA1c≥6.5%（需采用标准化检测）；无典型症状者需改日复测确认【数值待医学审核】。具体诊断与时间以病历记载为准，本条只用于解释"为什么当时的化验足以确诊"。
- **锚定**：入院/出院诊断、确诊时间、诊断依据的化验结果
- **用途**：S1诊断解释段 / 治疗回顾段 / 治疗规范符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；ADA糖尿病诊疗标准
- **状态**：draft-待医学审核

- **ID**：TN-S3-02
- **适用范围**：成人糖尿病住院患者（分型决定知识包适用性）
- **内容**：分型要点：2型多为成人起病、进展缓慢、常合并超重与代谢异常，通常口服药可控制（后期可联合胰岛素）。材料中出现以下特征提示可能为1型或其他特殊类型：年轻起病且体型偏瘦、起病即明显酮症/酮症酸中毒、C肽水平明显降低、胰岛自身抗体阳性。出现任一特征时应转人工核实分型，再决定本包是否适用，不直接生成解释。
- **锚定**：发病年龄、BMI、C肽与自身抗体结果、起病方式、是否长期依赖胰岛素
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：TN-S3-03
- **适用范围**：成人2型糖尿病住院患者（控糖住院情境）
- **内容**：住院调糖常见流程要点：按血糖监测结果调整方案（口服药联合、起始基础或餐时胰岛素）→治疗期间密集监测（胰岛素治疗者通常每日多次、含睡前与必要时夜间【数值待医学审核】）→同步完成营养与运动教育、并发症筛查→出院前方案相对稳定并完成教育。方案在住院期间多次调整属正常过程，不是"治疗混乱"。
- **锚定**：住院原因、住院天数、血糖监测医嘱与护理执行记录、胰岛素起始记录、教育记录
- **用途**：治疗回顾段 / 治疗规范符合度画像
- **来源**：《中国住院患者血糖管理专家共识》
- **状态**：draft-待医学审核

- **ID**：TN-S3-04
- **适用范围**：成人2型糖尿病住院患者（目标分层）
- **内容**：血糖控制目标的一般分层（住院期间以床旁血糖为目标）：严格——空腹/餐前4.4–6.1、餐后2小时或随机6.1–7.8 mmol/L，适用年轻、新诊断、无严重并发症、低血糖风险小者；一般——空腹/餐前6.1–7.8、餐后7.8–10.0 mmol/L，适用多数手术/普通住院患者；宽松——空腹/餐前7.8–10.0、餐后10.0–13.9 mmol/L，适用低血糖高危、高龄（如≥75岁）、重症、肝肾功能不全、预期寿命有限者【数值待医学审核】。多数住院患者采用偏宽松目标以避免低血糖。HbA1c 反映近2–3个月平均血糖，住院期间不作为动态调糖的主要依据，主要用于出院后长期管理目标（一般<7.0%、宽松约<8.0%~8.5%、严格<6.5%）。报告引用时必须注明"以医嘱/医生评估为准"，不得用统一数值评价个体。
- **锚定**：年龄、病程、并发症与低血糖记录、医嘱或病程记录中明示的目标值
- **用途**：治疗回顾段 / 检查疑点标签 / S1诊断解释段
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《中国住院患者血糖管理专家共识》；ADA糖尿病诊疗标准
- **状态**：draft-待医学审核

- **ID**：TN-S3-05
- **适用范围**：成人2型糖尿病住院患者
- **内容**：监测方式与频率：住院常用床旁指尖血糖（胰岛素治疗者通常三餐前+睡前，必要时加测夜间与餐后）【数值待医学审核】、静脉血糖与生化复查、HbA1c，方案复杂或血糖波动大者可用 CGM；出院后监测频率显著低于住院期、按方案个体化。住院期监测次数多是调糖治疗本身的要求，不是额外负担。
- **锚定**：监测医嘱、护理记录中的血糖测量次数、有无CGM使用
- **用途**：治疗回顾段 / 费用解释段
- **来源**：《中国住院患者血糖管理专家共识》
- **状态**：draft-待医学审核

- **ID**：TN-S3-06
- **适用范围**：成人2型糖尿病住院患者（出院标准）
- **内容**：出院标准要点：一般需满足——血糖方案相对稳定且无明显波动、无未处理的严重低血糖风险（如有过反复低血糖已纠正并有对策）、患者/照护者完成基本教育（注射技术、低血糖识别处理、监测方法）、出院带药与医嘱明确。达到上述即可转门诊管理，不以"血糖完全正常"为出院前提。
- **锚定**：出院记录、教育记录、近几日血糖趋势、出院带药清单
- **用途**：治疗回顾段 / 出院指引缺口标签 / 治疗规范符合度画像
- **来源**：《中国住院患者血糖管理专家共识》；《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核

- **ID**：TN-S3-07
- **适用范围**：成人2型糖尿病住院患者（出院前筛查）
- **内容**：出院前应完成（或近期已有）的并发症筛查：眼底检查（或眼底照相）、尿白蛋白/肌酐比与肾功能（eGFR）、足部检查（视触诊，必要时神经/血管评估）、血压与血脂。住院期间未做且近一年内亦无记录时，可提示"筛查缺口"——作为随访建议输出，不生成医疗缺陷指控。
- **锚定**：住院医嘱与报告清单、既往门诊/住院记录中有无同类筛查
- **用途**：检查疑点标签 / 复诊建议段 / 治疗规范符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《国家基层糖尿病防治管理指南》
- **状态**：draft-待医学审核

- **ID**：TN-S3-08
- **适用范围**：成人2型糖尿病住院患者（治疗路径概览）
- **内容**：治疗路径总体顺序：生活方式干预贯穿始终→首选二甲双胍（无禁忌且可耐受时）→单药不达标联合第二类口服药→仍不达标起始胰岛素（常为基础胰岛素）；合并动脉粥样硬化性心血管病、心衰或慢性肾病时，SGLT2抑制剂、GLP-1受体激动剂等有心血管/肾脏获益证据的药物可优先考虑。这是一般顺序，医生可依据个体情况调整顺序与组合。
- **锚定**：出院带药方案、合并症诊断（冠心病/心衰/CKD）、HbA1c水平
- **用途**：治疗回顾段 / 用药规则符合度画像 / 用药疑点标签
- **来源**：《中国2型糖尿病防治指南（2020年版）》；ADA糖尿病诊疗标准
- **状态**：draft-待医学审核

- **ID**：TN-S3-09
- **适用范围**：合并症/围手术期高血糖住院情境
- **内容**：因其他疾病或手术住院伴高血糖时：管理要点是血糖平稳、避免低血糖与大幅波动，围手术期常改用胰岛素方案、目标偏宽松（具体由医嘱决定）；此时"调糖"不是住院主要目的，治疗回顾应以本次住院的主要疾病为主线，血糖管理作为保障性内容解释。
- **锚定**：本次住院主要诊断与手术记录、血糖管理医嘱、是否改用胰岛素
- **用途**：治疗回顾段 / 检查疑点标签
- **来源**：《中国住院患者血糖管理专家共识》
- **状态**：draft-待医学审核

- **ID**：TN-S3-10
- **适用范围**：成人2型糖尿病住院患者（住院天数参考）
- **内容**：住院天数参考：单纯调糖住院多在5–10天左右，无统一固定天数【数值待医学审核】；实际天数受入院血糖水平、是否启动/强化胰岛素及方案稳定时间（如转院外方案前需至少1天7次血糖谱评估）、出院教育与随访安排、合并感染等诱因影响。出院衔接：建议出院后1个月内复诊，出院时方案有调整或血糖未达标者1–2周内复诊。不能以住院天数长短直接判断治疗是否充分；明显偏离时只生成"提示核对"，不生成结论。
- **锚定**：入出院日期、住院天数、住院原因
- **用途**：费用解释段 / 费用基线参考 / 检查疑点标签
- **来源**：《中国住院患者血糖管理专家共识》（管理流程口径，具体天数区间为草稿估计，须医学审核）
- **状态**：draft-待医学审核

- **ID**：TN-S3-11
- **适用范围**：成人2型糖尿病住院患者（出院前教育）
- **内容**：出院前教育应包含：降糖方案讲解（每种药何时吃/打、剂量）、低血糖识别与处理、血糖自我监测方法、饮食与运动要点、足部自查、复诊计划。出院小结或护理记录中应能看到相应教育记录或指引；缺失时按 S5 对应条目生成"出院指引缺口标签"。
- **锚定**：出院小结、护理教育记录、出院医嘱
- **用途**：出院指引缺口标签 / 治疗回顾段 / 治疗规范符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《国家基层糖尿病防治管理指南》
- **状态**：draft-待医学审核
