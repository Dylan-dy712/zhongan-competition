## S4 用药规则
用途：供用药疑点标签、用药规则符合度画像、治疗回顾段引用。红线：所有条目只输出适用情境与核查点提示，禁止生成"用药错误"结论；缺少适应证/肾功能等材料本身不能认定用药错误。

- **ID**：TN-S4-01
- **适用范围**：成人2型糖尿病（口服药，一线）
- **内容**：二甲双胍（含缓释剂型）：2型糖尿病一线首选药，无禁忌且可耐受时贯穿治疗全程，常与其他口服药及胰岛素联用。常见核查点：①用药前后应核对肾功能（eGFR），肾功能明显下降时需减量或停用（eGFR<30 为公认禁用界值【数值待医学审核】）；②常见胃肠道反应（恶心、腹泻、腹胀），随餐服用或换缓释剂型可减轻；③长期使用可能影响维生素B12吸收，长期用药者可关注相关检查；④行碘造影检查前后是否临时停用视肾功能而定。边界：缺少肾功能记录或适应证材料本身不能认定用药错误；胃肠道反应不是过敏，也不构成"必须停药"的证据。
- **锚定**：出院带药（药名、剂量）、eGFR/血肌酐结果、胃肠道症状记录、造影检查记录、有无胰岛素联用
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；ADA糖尿病诊疗标准
- **状态**：draft-待医学审核

- **ID**：TN-S4-02
- **适用范围**：成人2型糖尿病（口服促泌剂——磺脲类）
- **内容**：磺脲类（格列本脲、格列美脲、格列齐特等）：通过刺激自身胰岛素分泌降糖，用于二甲双胍不耐受或单药不足时，价格低、基层常用。常见核查点：①低血糖风险相对较高，老年、肾功能不全、进食不规律、出院后活动量增加者尤需注意；②不同品种经肾/肝代谢程度不同，肾功能下降时部分品种需调整；③可能引起体重增加。边界：老年患者使用磺脲类不等于用药不当，但属于应核对"低血糖教育是否到位、随访是否安排"的核查点；缺材料不能认定错误。
- **锚定**：年龄、肾功能、住院及出院后有无低血糖记录、教育记录、出院带药
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：TN-S4-03
- **适用范围**：成人2型糖尿病（口服促泌剂——格列奈类）
- **内容**：格列奈类（瑞格列奈、那格列奈）：短效促泌剂，主要降餐后血糖，需餐前服用，适合进餐不规律或以餐后血糖升高为主者。常见核查点：①"餐前服、不进餐不服"的使用逻辑是否向患者交代（漏餐仍服药会增加低血糖风险）；②有低血糖风险，程度相对磺脲类轻。边界：缺材料不能认定错误。
- **锚定**：服药医嘱与时间、进食规律性、有无低血糖记录、教育记录
- **用途**：用药疑点标签 / 用药规则符合度画像 / 康复计划段
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：TN-S4-04
- **适用范围**：成人2型糖尿病（口服药，餐后血糖为主）
- **内容**：α-糖苷酶抑制剂（阿卡波糖、伏格列波糖、米格列醇）：延缓肠道碳水化合物吸收，以降低餐后血糖为主，适合以米面为主食的饮食习惯，可单用或联合。常见核查点：①需与第一口主食同服；②常见腹胀、排气增多，多随使用时间减轻；③单用极少低血糖，但与磺脲类或胰岛素联用发生低血糖时应直接补充葡萄糖而非普通糖果/饼干（淀粉分解被抑制，升糖慢）——这是关键教育点。边界：缺材料不能认定错误。
- **锚定**：服药时间与进餐关系、联合用药方案、低血糖教育记录
- **用途**：用药疑点标签 / 出院指引缺口标签 / 用药规则符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：TN-S4-05
- **适用范围**：成人2型糖尿病（口服药，联合用药）
- **内容**：DPP-4抑制剂（西格列汀、沙格列汀、维格列汀、利格列汀、阿格列汀）：葡萄糖依赖性促进胰岛素分泌，单用低血糖风险低、不增加体重，常作为联合治疗选择。常见核查点：①多数品种在肾功能下降时需调整剂量（利格列汀无需调整），应核对 eGFR 与医嘱剂量；②注意少见不良反应报告（如关节痛）。边界：剂量未标注具体调整值时按医嘱核对；缺材料不能认定错误。
- **锚定**：eGFR结果、出院带药（具体品种与剂量）、联用方案
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核

- **ID**：TN-S4-06
- **适用范围**：成人2型糖尿病（口服药，有心肾获益指征情境）
- **内容**：SGLT2抑制剂（达格列净、恩格列净、卡格列净等）：经尿排糖降血糖，合并动脉粥样硬化性心血管病、心衰或慢性肾病时往往优先考虑（心血管/肾脏保护证据），并有助于减重。常见核查点：①泌尿生殖道感染风险增加（有相关病史者关注）；②尿量增多可致脱水/容量不足，老年人注意口渴、头晕、血压；③罕见但严重的酮症酸中毒（可发生在血糖不太高时），出现恶心、呕吐、乏力、腹痛应就医；④围手术期一般需按医嘱提前停用。边界：缺材料不能认定错误；该药导致尿糖阳性是药物机制内的正常现象，不是病情恶化。
- **锚定**：合并症诊断（ASCVD/心衰/CKD）、尿常规与感染记录、有无手术计划、肾功能、住院原因
- **用途**：用药疑点标签 / 用药规则符合度画像 / 检查疑点标签
- **来源**：《中国2型糖尿病防治指南（2020年版）》；ADA糖尿病诊疗标准
- **状态**：draft-待医学审核

- **ID**：TN-S4-07
- **适用范围**：成人2型糖尿病（注射类，肥胖或心血管获益指征情境）
- **内容**：GLP-1受体激动剂（利拉鲁肽、司美格鲁肽、度拉糖肽、艾塞那肽等）：注射剂型为主（个别口服剂型），降糖同时减重显著，合并动脉粥样硬化性心血管病或肥胖时优先考虑。常见核查点：①起始阶段常见恶心、呕吐、食欲下降，规范做法是小剂量起始逐步递增；②严重呕吐、进食困难时注意脱水与血糖变化；③甲状腺髓样癌个人史或家族史（MEN2综合征）者禁用，此为说明书明确事项。边界：起始期胃肠道反应不等于"药物不耐受必须停药"；缺材料不能认定错误。
- **锚定**：BMI、合并症诊断、胃肠症状记录、甲状腺疾病史、住院原因
- **用途**：用药疑点标签 / 用药规则符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；ADA糖尿病诊疗标准
- **状态**：draft-待医学审核

- **ID**：TN-S4-08
- **适用范围**：成人2型糖尿病（胰岛素——基础）
- **内容**：基础胰岛素（甘精/地特/德谷胰岛素，睡前中效NPH）：口服药控制不佳时的常用起始胰岛素，每天固定时间注射1次（NPH可1~2次），主要控制整体基础血糖（含空腹血糖）。常见核查点：①起始与调整期需按医嘱监测空腹血糖并记录；②剂量调整应循序渐进，避免盲目大幅加减；③低血糖多发生在夜间或餐前，需教育识别与处理。边界：出院时空腹血糖仍偏高不必然是治疗不当，可能处于调整期；缺材料不能认定错误。
- **锚定**：胰岛素种类与剂量、注射时间、空腹血糖趋势、有无低血糖记录、有无胰岛素（起始/带出）
- **用途**：用药疑点标签 / 用药规则符合度画像 / 复诊建议段
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《中国住院患者血糖管理专家共识》
- **状态**：draft-待医学审核

- **ID**：TN-S4-09
- **适用范围**：成人2型糖尿病（胰岛素——餐时）
- **内容**：餐时胰岛素（速效：门冬、赖脯、谷赖；短效：普通胰岛素RI）：控制餐后血糖高峰。速效类似物一般餐前0–15分钟注射，必要时可餐后即刻补打；短效一般餐前约30分钟注射（起效约30–60分钟，注射后延迟进餐易低血糖）【数值待医学审核】；预混胰岛素餐前10–30分钟，含速效成分的预混可更贴近餐时、含短效者约餐前30分钟。具体以说明书与医嘱为准。常见核查点：①"打针—进餐"的时间关系必须交代清楚（打了针不吃饭会低血糖）；②住院强化多针方案（基础+餐时）出院后应明确简化方案与监测安排。边界：缺材料不能认定错误。
- **锚定**：注射医嘱与时间、进餐时间记录、有无低血糖、出院方案是否简化、有无胰岛素
- **用途**：用药疑点标签 / 出院指引缺口标签 / 用药规则符合度画像
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《中国住院患者血糖管理专家共识》
- **状态**：draft-待医学审核

- **ID**：TN-S4-10
- **适用范围**：成人2型糖尿病（胰岛素——预混）
- **内容**：预混胰岛素（门冬30/50、精蛋白锌人胰岛素30R/50R等）：一针同时提供基础+餐时成分，一般早、晚餐前注射，适合作息与两餐较规律者。常见核查点：①注射前需充分混匀（笔芯按说明书滚搓，避免絮状物不匀导致剂量不准）；②午餐及两餐间血糖可能控制不足，两餐时间与进食量固定很重要；③作息不规律、漏餐时低血糖风险升高；④注射与进餐的时间间隔依剂型不同。边界：预混与"基础+餐时"方案的优劣需结合整体情况判断，缺材料不能认定错误。
- **锚定**：胰岛素剂型与剂量、注射时间与进餐规律、混匀动作教育记录、午餐后血糖记录、有无胰岛素
- **用途**：用药疑点标签 / 用药规则符合度画像 / 康复计划段
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《中国糖尿病药物注射技术指南（2016年版）》
- **状态**：draft-待医学审核
