## S11 手术与检查通俗解释
用途：为治疗回顾段提供过程级通俗解释。总边界同各包 S11：只解释目的与过程；不评价必要性与结果；过程为"一般情形"，与病例事实冲突时不引用。

- **ID**：TN-S11-01｜糖化血红蛋白（HbA1c）检测
- **适用范围**：血糖长期管理评估
- **内容**：是什么：抽血测"过去2-3个月的平均血糖水平"——红细胞带着糖的记忆，反映的是长期趋势而非当天表现，不受当天吃饭运动影响。怎么做：静脉抽血一管，无需空腹。为什么重要：是医生判断控糖是否达标、要不要调方案的主要依据（衔接 TN-S3-04 出院后目标口径）。
- **锚定**：检验报告（数值与日期）
- **用途**：治疗回顾段 / 复诊建议段 / 术语解释动作
- **来源**：《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核

- **ID**：TN-S11-02｜指尖血糖与动态血糖监测（CGM）
- **适用范围**：日常自我监测
- **内容**：是什么：指尖血糖是扎手指取一滴血即时读数（反映"此刻"血糖）；CGM是贴在手臂/腹部的传感器，每几分钟自动记录一次，连续看几天到十几天的血糖"走势图"，能发现指尖测不到的夜间低血糖。怎么做：指尖采血针轻微刺痛；CGM为无创/微创贴敷。
- **锚定**：监测记录/设备医嘱
- **用途**：治疗回顾段 / 术语解释动作 / 康复计划段
- **来源**：《中国2型糖尿病防治指南（2020年版）》；ADA糖尿病诊疗标准
- **状态**：draft-待医学审核

- **ID**：TN-S11-03｜口服葡萄糖耐量试验（OGTT）
- **适用范围**：诊断评估情境
- **内容**：是什么：空腹喝下定量糖水（75克葡萄糖），分别在喝前和喝后2小时抽血看血糖变化——用来判断糖代谢处于正常、糖尿病前期还是糖尿病。怎么做：前一天晚餐后空腹8-10小时，检查中静坐不吸烟；整个过程约2小时抽血2次。
- **锚定**：检验报告
- **用途**：治疗回顾段 / 术语解释动作
- **来源**：《中国2型糖尿病防治指南（2020年版）》诊断标准章节
- **状态**：draft-待医学审核

- **ID**：TN-S11-04｜眼底检查（眼底照相/OCT）
- **适用范围**：年度并发症筛查
- **内容**：是什么：用特殊相机给视网膜"拍照"（有时先散瞳，点药水后看东西模糊数小时属正常），看糖尿病有没有"伤到眼睛血管"。为什么做：糖尿病视网膜病变早期自己没有感觉，靠年度筛查才能早发现（衔接 TN-S7 年度筛查与 TN-S10-02）。
- **锚定**：检查医嘱/报告
- **用途**：治疗回顾段 / 复诊建议段 / 术语解释动作
- **来源**：《中国2型糖尿病防治指南（2020年版）》并发症筛查章节
- **状态**：draft-待医学审核

- **ID**：TN-S11-05｜尿微量白蛋白/尿蛋白检测
- **适用范围**：糖尿病肾病筛查
- **内容**：是什么：留尿检查"尿里有没有漏出本不该漏的蛋白质"——肾脏的微小损伤最早表现为尿里微量白蛋白增多。怎么做：留随机尿或晨尿送检，无痛；有的报告给"尿白蛋白/肌酐比值（ACR）"。为什么做：肾病早发现可以通过控制血压血糖和药物显著延缓进展。
- **锚定**：检验报告
- **用途**：治疗回顾段 / 复诊建议段 / 术语解释动作
- **来源**：《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核

- **ID**：TN-S11-06｜糖尿病足筛查（10克尼龙丝/踝肱指数）
- **适用范围**：年度足部评估
- **内容**：是什么：两项无创检查——用10克尼龙丝轻触足底测试保护性感觉是否减退（感觉变迟钝=溃疡高危）；踝肱指数（ABI）用袖带测脚踝与上臂血压比值，评估下肢供血。怎么做：脱鞋袜配合检查约10-15分钟，无痛。为什么做：感觉减退+供血差是足溃疡的两大土壤，筛查阳性者进入强化足部管理（衔接 TN-S5-09/S9-05）。
- **锚定**：筛查记录、周围神经/血管病变诊断
- **用途**：治疗回顾段 / 复诊建议段 / 术语解释动作
- **来源**：《中国糖尿病足防治指南（2019版）》；《国家基层糖尿病防治管理指南》
- **状态**：draft-待医学审核
