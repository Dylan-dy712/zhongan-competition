## S7 复诊随访规范
用途：供复诊建议段引用；时间线仅描述"通常节奏"供用户与医生确认，医嘱优先——医嘱未提供复诊日期时不生成确定日期。

- **ID**：TN-S7-01
- **适用范围**：成人2型糖尿病出院患者（全部条目的总原则）
- **内容**：原则声明：复诊时间与项目以主治医生出院医嘱为最高优先级；医嘱未提供复诊日期时，本知识包不生成确定日期，仅以"通常节奏"供用户与医生确认，报告措辞使用"可与医生确认"而非"应当于X日复诊"。
- **锚定**：出院医嘱原文（是否含复诊时间与项目）
- **用途**：复诊建议段
- **来源**：《中国2型糖尿病防治指南（2020年版）》（随访框架；医嘱优先原则基于临床管理惯例）
- **状态**：draft-待医学审核

- **ID**：TN-S7-02
- **适用范围**：成人2型糖尿病出院患者
- **内容**：出院后首次复诊：建议出院后1个月内完成门诊复诊；出院时方案有调整或血糖未达标者1–2周内复诊【数值待医学审核】。核对出院方案执行情况、带回血糖记录并完成首轮调整。住院期间起始或大幅调整过胰岛素者更需要在近期复诊，报告可据此提高复诊提示优先级。
- **锚定**：出院日期、出院方案（是否新起始/调整胰岛素）、出院医嘱有无复诊安排
- **用途**：复诊建议段 / 治疗规范符合度画像
- **来源**：《中国住院患者血糖管理专家共识》；《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核

- **ID**：TN-S7-03
- **适用范围**：成人2型糖尿病出院患者（HbA1c复查）
- **内容**：HbA1c复查节奏：通常约每3~6个月一次——未达标或方案调整期约3个月复查，稳定达标者可延长至6个月【数值待医学审核】。引用时必须结合最近一次 HbA1c 的日期与数值，判断下一次复查是否临近。
- **锚定**：最近一次HbA1c日期与数值、达标情况、出院医嘱
- **用途**：复诊建议段 / 检查疑点标签
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《国家基层糖尿病防治管理指南》
- **状态**：draft-待医学审核

- **ID**：TN-S7-04
- **适用范围**：成人2型糖尿病出院患者（年度筛查）
- **内容**：年度并发症筛查清单：每年至少一次——眼底检查（视网膜病变）、尿白蛋白/肌酐比与肾功能（肾病）、足部检查（溃疡/血管/神经）、血压与血脂评估；已有并发症者按专科要求加密随访。住院期间刚完成的项目以本次为最近一次，不重复计缺。
- **锚定**：住院中各项筛查有无记录及日期、既往年度筛查记录、已有并发症
- **用途**：复诊建议段 / 检查疑点标签 / 长期随访加分项
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《国家基层糖尿病防治管理指南》
- **状态**：draft-待医学审核

- **ID**：TN-S7-05
- **适用范围**：成人2型糖尿病出院患者（长期用药情境）
- **内容**：服药依从性随访：慢性病长期用药易出现"自行减停"，随访时核对取药记录、剩余药量与实际服用情况；依从性下降是出院后血糖反弹的常见原因，属关怀提示而非指责性表述。
- **锚定**：取药/购药记录、复诊血糖趋势、出院带药天数
- **用途**：复诊建议段 / 长期随访加分项
- **来源**：《国家基层糖尿病防治管理指南》
- **状态**：draft-待医学审核

- **ID**：TN-S7-06
- **适用范围**：成人2型糖尿病出院患者（特殊情境）
- **内容**：需要提前复诊（不等常规节奏）的情境：反复低血糖、新发感染、新确诊并发症、计划手术或长途旅行、明显血糖波动。出现任一情形提示"提前联系医生"，进入优先行动而非按期复诊口径。
- **锚定**：出院后新发事件记录（如出院后再入院、感染、手术）
- **用途**：复诊建议段 / 优先行动
- **来源**：《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核
