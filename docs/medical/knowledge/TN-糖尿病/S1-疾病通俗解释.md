## S1 疾病通俗解释
用途：供报告"诊断通俗解释"段引用的分层要点（一句话解释 / 发生了什么 / 为什么会得 / 住院期间发生了什么 / 长期管理 / 并发症机制），供生成器按病例事实选用改写，不得整段照搬。

- **ID**：TN-S1-01
- **适用范围**：成人2型糖尿病住院及出院后患者
- **内容**：一句话解释：2型糖尿病是最常见的糖尿病类型，特点是身体（肌肉、肝脏、脂肪组织）对胰岛素"反应变差"（胰岛素抵抗），加上胰腺分泌胰岛素的能力逐渐跟不上，导致血糖升高；多见于成人，常与超重、缺乏运动、家族史相关。它可以长期管理得很好，但一般需要终身随访。
- **锚定**：出院诊断（2型糖尿病）、发病年龄、体重/BMI、家族史有无记录
- **用途**：S1诊断解释段
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：TN-S1-02
- **适用范围**：成人2型糖尿病住院及出院后患者
- **内容**：发生了什么：血液中的葡萄糖本应在胰岛素帮助下进入细胞被利用；2型糖尿病时胰岛素"打不开细胞之门"，同时胰岛素分泌相对不足，葡萄糖滞留在血液里并随尿排出，长期偏高还会逐渐损伤血管。化验单上血糖、糖化血红蛋白（HbA1c）升高就是这一过程的直接痕迹。
- **锚定**：血糖与HbA1c检查结果；用药方案中是否已含胰岛素（提示自身分泌能力相对不足更明显）
- **用途**：S1诊断解释段 / 术语解释动作
- **来源**：《内科学》（人卫版）；《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核

- **ID**：TN-S1-03
- **适用范围**：成人2型糖尿病住院及出院后患者
- **内容**：为什么会得：目前认为是遗传易感性与生活方式共同作用的结果——超重/肥胖（尤其腹型）、饮食结构、缺乏运动、年龄增长、吸烟等都有参与；不是"糖吃多了"单一原因，也不应把病因完全归咎于患者个人。这种"多因素"属性决定了管理必须是长期的、多方面的。
- **锚定**：BMI/腰围、吸烟史、家族史记录
- **用途**：S1诊断解释段
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核

- **ID**：TN-S1-04
- **适用范围**：成人2型糖尿病住院患者（区分住院原因引用）
- **内容**：住院期间通常发生了什么：2型糖尿病住院通常是为了集中调整血糖方案（调整口服药、起始或调整胰岛素）、急性并发症恢复后的过渡观察、评估筛查慢性并发症，或因其他疾病/手术住院期间把血糖稳住；常见动作包括密集血糖监测、药物调整、营养与运动教育、并发症筛查（眼底、尿蛋白、足部）。这些是规范要求的标准动作，不是"过度检查"。
- **锚定**：住院原因（控糖/并发症恢复/围手术期）、住院天数、血糖监测医嘱与执行记录、有无胰岛素起始、有无并发症筛查医嘱
- **用途**：S1诊断解释段 / 治疗回顾段
- **来源**：《中国住院患者血糖管理专家共识》；《中国2型糖尿病防治指南（2020年版）》
- **状态**：draft-待医学审核

- **ID**：TN-S1-05
- **适用范围**：成人2型糖尿病住院及出院后患者
- **内容**：为什么需要长期管理：2型糖尿病目前无法根治，但可控——长期把血糖、血压、血脂管理好，能显著减少眼、肾、神经、足和心脑血管并发症；出院时血糖平稳不等于治愈，擅自停药后血糖常会回升。这解释了"为什么住院治好了还要一直吃药复诊"。
- **锚定**：有无并发症诊断、出院带药方案、随访安排有无记录
- **用途**：S1诊断解释段 / 康复计划段 / 长期随访加分项
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《国家基层糖尿病防治管理指南》
- **状态**：draft-待医学审核

- **ID**：TN-S1-06
- **适用范围**：成人2型糖尿病住院及出院后患者（筛查/并发症情境引用）
- **内容**：并发症为什么会发生：长期高血糖像"糖水泡血管"，先损伤小血管（眼底视网膜、肾小球、周围神经），再损伤大血管（心、脑、下肢血管），出现视力下降、蛋白尿、麻木、足部破溃、心梗脑梗等风险升高。这也是出院前要做眼底、尿蛋白/肾功能、足部检查的原因——很多并发症早期没有症状，筛查是为了"在没有感觉时发现"。
- **锚定**：出院诊断中有无并发症、住院中有无相应筛查及结果
- **用途**：S1诊断解释段 / 检查疑点标签
- **来源**：《中国2型糖尿病防治指南（2020年版）》；《内科学》（人卫版）
- **状态**：draft-待医学审核
