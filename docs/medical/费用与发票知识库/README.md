# 费用与发票知识库（国内医疗费用·发票·报销）

> 适用地区：中国大陆　|　版本：v1.0-draft　|　更新：2026-10-02
> 定位：围绕**医疗收费票据（发票）与医疗费用分摊**的详细知识库，覆盖"哪些能报、哪些不能报、发票上每栏是什么、医保报多少、商保怎么接、自付自费怎么分"。
> 服务对象：暖愈智护类理赔关怀场景的费用/术语解释，以及人工学习参考。

---

## 0. 使用前的三条边界声明

1. **地方差异**：医保为市级统筹，起付线、报销比例、封顶线、目录细化、备案规则均以**参保地医保局最新文件**为准。本库一律给"通行口径/常见区间"，涉及具体数值处均标注"以当地为准"，不得直接引用为患者的确定结论。
2. **不推算个人负担**：本库解释规则与票面字段含义；**用户实际负担**必须依据其真实结算单/理赔决定书核算，缺少证据时不可推算（延续既有知识库 spec 6.1 原则）。
3. **非投保/理赔建议**：产品形态描述为市场通行样貌，具体以保险条款为准。

**政策时效**：核心事实（全国统一票据式样、自付口径、社保法 30 条、异地就医 22 号文、大病保险、电子票据效力）已于 2026-10-02 检索核实，来源见各文末"来源"节与本文第 5 节。

## 1. 核心概念速览（先读这一节）

一张医疗发票上的钱，按两个维度切（详解第 07 章）：

```
总费用 = 医保统筹基金支付 + 个人负担
个人负担 = 个人自付（目录内：起付线/乙类先行自付/比例自担）+ 个人自费（目录外全自担）
个人支付 = 个人账户支付（自己的钱，不是报销）+ 个人现金支付
商业保险赔付：不出现在发票上（记录在保险公司理赔决定书），发票是申请凭证
```

报销公式：`医保报销 = (政策范围内费用 − 起付线) × 报销比例，封顶线封顶`；"政策范围内费用"由三目录决定（药品甲类全额/乙类先行自付后/目录外全不进，第 05 章）。

顺位铁律：**先医保 → 报销型商保（原件+分割单，补偿原则）→ 给付型随时**（第 09、10 章）。

## 4. 与既有医学知识库的关系

- 本库与既有 `docs/medical/knowledge/` 下 `KP-TY（通用-费用与医保术语，TY-COST-01~10）` 同源互补：TY 包面向装配器的短条目（术语解释），本库是**长文参考层**（规则、流程、场景）。
- 本库**未接入** `tools/build_knowledge_jsonl.py` 编译管线（该管线条目 ID 仅支持 `TY-COST-\d{2}` 等模式，且当前工作区 `docs/medical/knowledge/` 源文件处于删除状态）。如需接入，可从本库提炼 `TY-COST-11+` 条目（发票字段、分割单、异地就医、电子票据等），并恢复源包后重建 JSONL——本库不擅自改动编译产物。
- 检索入口建议：费用解释段（cost_explanation）与术语解释动作（EXP_TERMINOLOGY_BARRIER）在 TY 包未命中时回退本库 07/14 两章。
