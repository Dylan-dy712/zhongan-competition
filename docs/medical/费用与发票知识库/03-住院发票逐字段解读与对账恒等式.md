# 03 住院发票逐字段解读与对账恒等式

> 适用地区：中国大陆　|　更新：2026-10-02　|　定位：读懂"医疗住院收费票据"，并学会用恒等式对账
> 边界：各省票据版式在字段名与排列上有差异（如北京称"医事服务费"、部分省份称"诊察费"）；文中数字均为**虚构示例**。

---

## 1. 住院结算的完整流程（发票只是最后一环）

```
住院中：每天可能收到"一日清单"（当日费用明细）
   ↓
出院时：结算窗口结清预交金（多退少补）
   ↓
拿到三样东西：
  ① 医疗住院收费票据（发票）   ← 钱的凭证
  ② 医保结算单（用了医保时）   ← 医保怎么分的
  ③ 费用明细清单（汇总清单）   ← 每项收费与甲乙丙属性
   ↓
出院后：医院病案室打印 出院小结/诊断证明（复印件盖章）
```

> 患者手里最容易缺的是 ③ 和"出院小结"——商保理赔三样都要（见第 09 章）。

## 2. 住院票据的收费项目区（全国统一式样常见大类）

| 项目大类 | 包含什么 | 报医保吗 |
| --- | --- | --- |
| 床位费 | 普通病房床位 | 目录内按**服务设施标准**限额内报（超标差额自费，如单人间差额） |
| 诊察费/医事服务费 | 医生查房、诊疗 | 甲类为主 |
| 检查费 | CT/MRI/B超/内镜等 | 目录内项目；部分大型检查有先行自付（地方规定） |
| 化验费 | 血、尿、病理等 | 目录内项目为主 |
| 治疗费 | 换药、注射、理疗、呼吸机等 | 目录内项目为主 |
| 手术费 | 手术操作（含麻醉） | 甲/乙类均有 |
| 护理费 | 护理服务 | 目录内 |
| 卫生材料费 | 支架、钢板、缝线、留置针等 | 差异最大：普通耗材目录内，**高值耗材部分乙类、部分目录外** |
| 西药费/中成药费/中药饮片费 | 住院用药（29 号文口径写作"中草药费"） | 按药品目录甲/乙类，目录外全自费 |
| 输氧费、输血费 | 氧气、血制品 | 血制品部分为乙类、部分目录外（以当地目录为准） |
| 陪床位费/陪护费 | 家属陪护床 | **自费**（生活性费用） |
| 伙食费/营养餐 | 住院餐费 | **多数地区自费**（个别地区有小额伙食补助，以当地为准） |
| 其他 | 病历工本、空调降温等杂项 | 部分自费 |

> 看清"**卫生材料费**"和"**西药费**"是读懂住院费用的关键：住院贵，往往贵在目录外的耗材与新药，而不是床位和诊查（见第 05、08 章）。

## 3. 医保结算区字段（住院票据）

与门诊票据同一套字段，住院场景下它们的构成更复杂（示例为**虚构数字**，用于演示口径）：

```
合计金额：30000.00
医保统筹基金支付：18000.00
其他支付：0.00
个人账户支付：2000.00
个人自付：7000.00        ← 其中约：起付线 1500 ＋ 乙类先行自付 1000 ＋ 按比例自担 4500
个人自费：5000.00        ← 目录外耗材/药品
个人现金支付：10000.00
```

## 4. 对账恒等式（两张"切分法"）

```
切分①（钱从哪里出）：
  总费用 30000 = 统筹支付 18000 + 个人账户支付 2000 + 个人现金支付 10000

切分②（医保要不要管）：
  总费用 30000 = 统筹支付 18000 + 个人自付 7000 + 个人自费 5000

推论：个人支付总额 = 自付 + 自费 = 12000 = 账户 2000 + 个人现金 10000
```

**两张恒等式同时成立**。任何一张对不上，可能是：票据字段列示口径不同（个别统筹区不打印分段）、票据打印截断、或收费差错——直接找收费处重打/核对，并对照医保结算单。

### 4.1 "个人自付 7000"是怎么凑出来的

以职工医保某统筹区**虚构参数**演示（真实起付线/比例以当地为准）：

| 组成 | 金额 | 说明 |
| --- | --- | --- |
| 起付线以下 | 1500 | 三级医院次住院起付线（虚构示例值） |
| 乙类先行自付 | 1000 | 乙类药/耗材按地方规定比例（常见 10%~30%）先扣（虚构示例值） |
| 按比例自担 | 4500 | 政策范围内费用按比例报销（本例 80%）后个人承担的部分 |

> 结论："**报销比例 80%**"≠"自己只出 20%"。起付线、封顶线、乙类先行自付、目录外费用都会让实际自担比例高于票面报销比例——本例总费用 30000，个人实际负担 12000（40%），其中 5000 还是目录外自费（见第 06 章）。

### 4.2 医保结算单上的额外信息

住院票据不一定显示分段细节，**医保结算单**会显示：起付线累计、统筹支付、大额/大病支付、个人账户支付、自付一、自付二、自费、年度累计等。读账时"**票据看总额、结算单看分段**"（结算单详见第 04 章）。

## 5. 住院发票常见异常与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 票据金额 ≠ 预交金总额 | 预交金是押金，结算多退少补 | 看结算后的"多退少补"小票；正式票据才是最终费用 |
| 没有医保结算区 | 全自费结算（未持卡/异地未备案/急诊未刷卡） | 想转医保结算：出院结算前找医保窗口补备案或按参保地规定补办（见第 11 章），已自费结算的在多数地区仍可申请手工报销，但时限短 |
| 名字/身份证号错 | 录入错误 | 当场冲正重开；离院后只能由医院按票据作废流程处理，耗时 |
| "重复打印"导致两笔 | 不会发生：同一票据代码+号码唯一 | 拿到的电子票据可反复下载打印，但都是同一张票 |
| 大额自费耗材没有明细 | 只拿了发票没拿清单 | 回医院收费处/病案室补打"费用明细清单"（免费或小额工本费） |

## 6. 给商保理赔做准备的出院动作清单

1. 结算当场：确认发票、结算单、费用明细清单三样齐全，字段对账（用第 4 节恒等式）。
2. 确认票据上姓名、医保类型、住院号无误。
3. 问清病案室打印"出院小结、诊断证明"的办理方式（通常出院数个工作日后，本人身份证代领/邮寄）。
4. 发票原件只此一张：若要同时向多家报销（医保手工报销＋商保），先想好顺序并准备"分割单"方案（见第 09 章）。
5. 手机留存电子票据（医院公众号/自助机），纸质丢失还有备份渠道（见第 12 章）。
