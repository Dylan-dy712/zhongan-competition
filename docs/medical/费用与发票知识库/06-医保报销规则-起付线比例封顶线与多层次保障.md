# 06 医保报销规则——起付线、报销比例、封顶线与多层次保障

> 适用地区：中国大陆　|　更新：2026-10-02　|　定位：解释"医保到底怎么算、为什么实际报销比例总比宣传的低"
> 边界：本文给出**通行规则与常见区间**；起付线、比例、封顶线的具体数值**各统筹区不同且逐年调整**，一律以参保地医保局最新文件为准。文中数字均为虚构示例。

---

## 1. 一条公式讲清医保报销

```
医保报销金额 = ( 政策范围内费用 − 起付线 ) × 报销比例，且年度累计不超过封顶线
```

四个变量：

| 变量 | 含义 | 通俗解释 |
| --- | --- | --- |
| 政策范围内费用 | 三目录过滤后的费用（第 05 章） | "能上秤的重量" |
| 起付线 | 个人先承担的门槛，分次住院/门诊、按年度累计（各地规则不同） | "秤的去皮" |
| 报销比例 | 各统筹区按医院等级、参保类型、人群设定 | "打折力度" |
| 封顶线 | 统筹基金一个年度内最高支付限额 | "折扣上限" |

> 为什么"宣传报销 90%、实际自己掏 30%"？——宣传比例作用于"政策范围内费用"，而总费用里的**目录外费用、乙类先行自付、起付线以下、封顶线以上**都不参与打折。四层漏斗叠加后，自担比例自然上移（分层演示见第 03 章 4.1）。

## 2. 门诊与住院待遇的一般形态

### 2.1 门诊
- **普通门诊统筹**：职工医保经改革已普遍建立门诊统筹（共济保障），居民医保多数地区也有基层门诊统筹；一般基层医院起付线低/比例高、限额小，三甲门诊起付线高/限额更低。
- **门诊慢特病（门特/门慢）**：高血压、糖尿病、恶性肿瘤门诊治疗、透析、器官移植抗排异等病种，经**备案/鉴定**后按病种享受接近住院的报销待遇——门诊大额费用的关键出口。
- **"两病"门诊用药保障**：高血压、糖尿病患者的降糖降压药门诊专项保障（基层为主）。

### 2.2 住院
- 医院等级越高报销比例越低（引导分级诊疗）：常见形态为一级 > 二级 > 三级，差值多在 5~20 个百分点。
- 参保类型差异（国家医保局官方定档口径）：
  - **政策范围内**住院费用基金支付比例：职工医保稳定在 **80% 左右**、居民医保 **70% 左右**（"十四五"全民医疗保障规划定档，"十五五"延续；各地按医院等级、人群浮动，退休人员多上浮）；
  - 但**实际报销比例**（把目录外自费也算进总费用后）更低：2023 年全国职工医保住院实际报销约 **71.8%**、居民医保约 **59.7%**（国家医保局数据）——这就是"政策范围内 ≠ 实际"的直接量化证据。
- 起付线：一级医院数百元、三级医院千元上下为常见量级；年度内多次住院起付线逐次递减或按年累计的规定各地不同。
- 封顶线：统筹基金一个年度内最高支付限额，各地差异大；国家要求**居民医保封顶线达到统筹地区居民人均可支配收入的 6 倍以上**。

## 3. 职工医保 vs 居民医保

| 维度 | 职工医保 | 居民医保 |
| --- | --- | --- |
| 缴费 | 单位+个人按月缴费（退休后累计年限达标不再缴） | 个人+财政补贴按年缴 |
| 个人账户 | **有**（可用于门诊/购药/家属共济） | **无** |
| 门诊统筹 | 有（改革后全面建立） | 多数地区有，待遇较低 |
| 住院报销比例 | 高（约 80%~95% 常见区间） | 低（约 60%~80% 常见区间） |
| 大病保障名称 | 大额医疗费用补助（各地名称不一） | 大病保险 |
| 断缴影响 | 次月多即停止统筹待遇（各地宽限规则不同） | 错过集中缴费期有等待期或不予补缴 |

## 4. 多层次保障金字塔（基本医保之上还有谁）

```
第⑥层  个人自费（目录外，全自担）
第⑤层  商业医疗险/意外医疗（自愿投保，见第 10 章）
第④层  惠民保（城市定制型商业补充医保，自愿投保、门槛宽松）
第③层  医疗救助（特困、低保等困难群体，政府托底）
第②层  居民大病保险 / 职工大额医疗费用补助（自动覆盖，无需另行缴费）
第①层  基本医保统筹基金（起付线以上按比例报，封顶线以下）
```

### 4.1 居民大病保险（第②层要点）
- 参加居民医保即**自动同步参加大病保险，个人无需另行缴费、无需申报**（国家医保局明确口径）。
- 机制：基本医保报销后，对参保人年度**个人自付**（政策范围内个人负担）累计超过**大病起付线**的部分，**分段计算、累加支付**做二次报销。
- 常见形态：起付线约 1~2 万元量级；分段比例自 60% 起逐段上浮（如 60%/65%/70%/75%，示例为某地口径，各地不同）。
- 困难群体（特困、低保、返贫致贫人口等）倾斜：**起付线减半、各段比例提高 5~10 个百分点、取消封顶线**（国家统一要求，具体数值以当地为准）。
- 大病保险多由医保结算系统**自动结算**（出院即含在票据/结算单的"大病支付"栏），个别地区需事后申请。

### 4.2 职工大额医疗费用补助
功能对应大病保险，覆盖职工医保统筹封顶线以上的合规费用，多由单位/个人缴少量费用建立，具体待遇当地规定。

### 4.3 医疗救助
对特困人员、低保对象、返贫致贫人口等的托底保障（资助参保＋费用救助）；救助后有倾斜支付政策（第 4.1 节）。

### 4.4 惠民保（第④层）
- 城市政府指导、保险公司承保的城市定制型补充医疗保险（各地叫法如"XX 惠保""XX 保"）。
- 通行特点：投保门槛低（不限年龄职业、多数不问健康状况或对既往症有限赔付）、保费低（数十至数百元/年）。
- 常见责任：**医保目录内个人自付**超免赔额部分、**目录外自费**部分、**指定特药清单**，各责任分别设免赔额与比例。
- 与发票的关系：理赔时同样要看发票＋结算单，区分"自付/自费"两栏分别对应其责任（见第 07 章）。

## 5. 全流程数字演示（虚构示例，与第 03 章住院示例同一套口径）

> 参数（均为虚构）：总费用 30000，其中目录外自费 5000；乙类先行自付 1000；起付线 1500；政策范围内报销比例 80%。

```
纳入计算的政策范围内费用 = 30000 − 5000(自费) − 1000(乙类先行自付) = 24000
统筹支付 = (24000 − 1500[起付线]) × 80% = 18000
个人负担 = 30000 − 18000 = 12000
  ├─ 自付（目录内个人承担）= 7000
  │    ├─ 起付线以下 1500
  │    ├─ 乙类先行自付（自付二）1000
  │    └─ 比例自担（自付一）4500
  └─ 自费（目录外）= 5000
个人支付 12000 = 个人账户 2000 + 现金 10000
```

若该患者年度"个人自付"累计超过当地大病保险起付线，大病保险再对超出部分分段报销；之后还有惠民保、商业医疗险按各自条款接续（第 10 章）。真实报销分段以医保结算单为准。
