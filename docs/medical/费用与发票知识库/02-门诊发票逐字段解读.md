# 02 门诊发票逐字段解读

> 适用地区：中国大陆　|　更新：2026-10-02　|　定位：拿到一张"医疗门诊收费票据"，从上到下每个字段是什么意思
> 边界：字段名称与列示顺序以财综〔2019〕29 号统一式样为基准，各统筹区省版票据措辞略有差异；文中数字均为**虚构示例**，仅演示读法。

---

## 1. 门诊票据长什么样（结构分区）

```
┌────────────────────────────────────────────────┐
│ 票据代码：xxxxxxxx  票据号码：xxxxxxxx  校验码：xxxx │ ← 验真三件套
│ （省财政厅监制章）     医疗门诊收费票据                │
├────────────────────────────────────────────────┤
│ 姓名：张三  性别：男  医保类型：城镇职工基本医疗        │ ← 患者信息区
│ 社会保障号码：xxxxx  门诊号：xxxxx                  │
├────────────────────────────────────────────────┤
│ 项目            金额(元)                          │ ← 收费项目区
│ 一般诊疗费        10.00                           │
│ 检查费           230.00                          │
│ 西药费           156.40                          │
│ 合计（大写）：叁佰玖拾陆元肆角    （小写）￥396.40    │ ← 金额区
├────────────────────────────────────────────────┤
│ 医保统筹基金支付：180.00  其他支付：0.00           │ ← 医保结算区
│ 个人账户支付：116.40                              │
│ 个人自付：166.40  个人自费：50.00                  │
│ （个人现金支付：100.00）                           │
├────────────────────────────────────────────────┤
│ 收款单位：XX医院（章）  收款人：xxx  日期：2026-..   │
└────────────────────────────────────────────────┘
```

## 2. 逐字段解释

### 2.1 验真三件套
- **票据代码/票据号码/校验码**：财政票据的"身份证号"。商保理赔或单位报销核查真伪时，在财政部全国财政电子票据查验平台（pjcy.mof.gov.cn）或省财政厅平台输入这三项即可验证。电子票据上通常还有二维码，扫码直达验真。

### 2.2 患者信息区
- **姓名**：必须与参保人/被保险人一致。姓名打错当场要求医院作废重开，**事后不可涂改**。
- **医保类型**：本次就诊用的什么身份结算。常见值：
  - 城镇职工基本医疗保险（职工医保，有个人账户）
  - 城乡居民基本医疗保险（居民医保，无个人账户）
  - 离休人员（另行保障，全免）
  - 自费（未用医保结算——注意：**商保理赔常因此降低赔付比例**，见第 10 章）
- **社会保障号码**：即医保身份识别号，一般为身份证号（有的省版印作"医保编号"）。
- **门诊号/就诊卡号**：在该医院的就诊档案号。

### 2.3 收费项目区（门诊常见大类）

| 项目大类 | 包含什么 | 通俗解释 |
| --- | --- | --- |
| 一般诊疗费 / 挂号费 | 挂号、门急诊留观诊查 | 基层医疗机构的打包收费；大城市三甲多为"医事服务费"（北京等）或"诊查费" |
| 诊查费 / 医事服务费 | 医生问诊劳务 | 医生"看病"本身的收费 |
| 检查费 | CT、MRI、B 超、心电、内镜等 | "查"的费用 |
| 化验费 | 血常规、生化、病理等检验 | "验"的费用 |
| 治疗费 | 换药、注射、理疗、清创等 | 处置操作类 |
| 手术费 | 门诊小手术 | 体表肿物切除、清创缝合等 |
| 卫生材料费 | 纱布、石膏、留置针、注射器 | 一次性耗材 |
| 西药费 | 化学药、生物药 | 药费大头 |
| 中成药费 | 中成药 | |
| 中药饮片费 | 中草药饮片（29 号文口径写作"中草药费"） | 代煎费可能单列"其他" |
| 其他费 | 输氧、输液、煎药等杂项 | |

> 注意：**票据上只显示大类金额**，每个大类的具体明细（药名、规格、数量、单价、甲乙类属性）在配套的"**费用明细清单**"上（见第 04 章）。

### 2.4 金额区
- **合计金额**：本次就诊应收总额（政策内＋目录外全部在内）。大写汉字与小写数字必须一致。

### 2.5 医保结算区（核心）

以本文虚构示例：合计 396.40 元。

| 字段 | 示例值 | 含义（详见第 07 章） |
| --- | --- | --- |
| 医保统筹基金支付 | 180.00 | 医保基金实报的部分，即"医保报了 180" |
| 其他支付 | 0.00 | 大额医疗/大病保险、公务员医疗补助、医疗救助等（29 号文设此栏；部分省版单列明细） |
| 个人账户支付 | 116.40 | 从本人医保卡个人账户里扣的钱。**这是自己的钱，不是报销** |
| 个人自付 | 166.40 | 目录内、按政策必须个人承担的部分（起付线/乙类先行自付/按比例自担） |
| 个人自费 | 50.00 | 完全在医保目录外、全自费的部分 |
| 个人现金支付 | 100.00 | 以现金/银行卡/移动支付实付的金额 |

对账恒等式（应恒成立，对不上先找医院收费处核对）：

```
合计 = 医保统筹基金支付 + 其他支付 + 个人账户支付 + 个人现金支付   （按"钱从哪里出"切分）
合计 = 医保统筹基金支付 + 个人自付 + 个人自费                      （按"医保要不要管"切分）
```

示例验算：180.00 ＋ 0 ＋ 116.40 ＋ 100.00 ＝ 396.40 ✓；180.00 ＋ 166.40 ＋ 50.00 ＝ 396.40 ✓

> 两套切分的交点：**个人支付总额＝自付 166.40＋自费 50.00＝216.40 元**，这 216.40 元由个人账户出了 116.40、现金出了 100.00。换句话说，"医保卡里刷的钱"本身就是个人负担的一部分——那是自己的钱，不是医保报销的钱。若票据上"账户＋现金"与"自付＋自费"对不上，先找医院收费处或以医保结算单（见第 04 章）核对，不要自行推算。

### 2.6 落款区
- **收款单位＋收费专用章**：无章无效（电子票据为电子签章，验真时可核验）。
- **开票日期**：商保理赔、医保手工报销均对**费用发生/结算日期**有时限要求，妥善留存。

## 3. 读门诊发票的三步法

1. **先看合计**：这次总共花了多少。
2. **再看统筹支付**：医保实报了多少；合计减统筹就是自己负担（含账户里的钱）。
3. **最后对现金**：真正当时掏出去的钱是多少；同时把"自费"那栏圈出来——目录外花了多少，直接决定商保"不限社保"条款的价值（见第 10 章）。

## 4. 门诊常见疑问

- **为什么挂号费也要单独一张票？** 部分医院挂号时先出挂号费凭证，就诊后缴费再出正式门诊票据；商保理赔以正式"医疗门诊收费票据"为准。
- **同一天看病怎么有两张发票？** 一次就诊多次缴费（如先检查后开药）会按缴费次数出票，每张都是有效报销凭证。
- **发票上没有"医保统筹基金支付"字段？** 说明本次未用医保结算（自费/未持卡/异地未备案），票据上无医保结算区。想改成医保结算通常需在退费后重新结算，时限极短，当场发现当场处理。
- **体检中心的发票为什么不能报医保？** 健康体检不属于基本医保支付范围（见第 08 章），票据上不会有医保结算区；能否商保报销看具体产品责任（多数百万医疗险不含体检）。
