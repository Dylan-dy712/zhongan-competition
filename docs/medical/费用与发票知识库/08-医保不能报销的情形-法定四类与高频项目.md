# 08 医保不能报销的情形——法定四类与高频自费项目清单

> 适用地区：中国大陆　|　更新：2026-10-02　|　定位：明确"哪些费用医保根本不管"，以及商保通常也不管什么
> 边界：法定排除全国统一；"高频自费项目"为通行口径，个别地区有地方性纳入试点（如部分地区将部分康复、口腔项目有限纳入），以当地目录为准。

---

## 1. 法定不纳入医保基金支付的四类费用（《社会保险法》第三十条）

下列医疗费用**不纳入基本医疗保险基金支付范围**：

1. **应当从工伤保险基金中支付的**——工作中的事故伤害、职业病走工伤保险（医疗费、伤残待遇由工伤基金管，不走医保）。
2. **应当由第三人负担的**——交通事故、他人伤害等第三方责任造成的医疗费，由责任人（或其交强险/商业三责险）赔偿，医保不报。
3. **应当由公共卫生负担的**——国家免疫规划疫苗、传染病防治、妇女儿童保健等公共卫生项目，由公共卫生经费保障。
4. **在境外就医的**——境外（含港澳台）医疗费用医保不支付。

**重要例外（第三十条第二款）**：应当由第三人负担、但第三人不支付或**无法确定第三人**（如肇事逃逸）的，由基本医疗保险基金**先行支付**，支付后有权向第三人追偿。也就是说"被撞了对方跑了"不必全额硬扛，可向参保地医保经办申请先行支付（保留好交警责任认定等材料）。

来源：《中华人民共和国社会保险法》第三十条（条文见 https://guangdong.chinatax.gov.cn/gdsw/zjfg/2020-02/10/content_41ba5685090a44d0b2359b1a8127c66a.shtml ；北京医保局解读 https://ybj.beijing.gov.cn/2020_zwfw/2020_cjwt/202607/t20260717_4768278.html ）

## 2. 诊疗项目目录明确排除的高频自费项目（通行口径）

### 2.1 非治疗性/预防性
- 健康体检、入职体检、高端体检套餐
- 非国家免疫规划的疫苗（HPV 疫苗、流感自费疫苗等；多地允许职工医保**个人账户**支付自费疫苗，统筹基金不报；狂犬疫苗在部分地区可按当地规定报销——均以当地为准）
- 健康管理、保健按摩、足疗推拿等养生类服务

### 2.2 美容、矫形、改善性
- 医疗美容（双眼皮、隆鼻、吸脂等）
- 牙齿正畸（牙套）、牙齿美白、烤瓷牙美容性修复
- **种植牙**：多数地区不在医保目录（2022 年以来国家开展口腔种植价格专项治理，收费大幅规范下降，但"降价≠纳入医保"）
- 近视激光手术、验光配镜、OK 镜
- 减重代谢手术的非病理性情形（病理性肥胖部分地区可按目录报，需符合医学指征）

### 2.3 康复器具与生活性项目
- 轮椅、助听器、义眼、假肢、矫形器具等**康复器具**（部分康复**治疗项目**在目录内，但器具一般不在）
- 陪护费/护工费、陪床位费
- 住院伙食费、营养费、奶粉尿布等生活用品
- 交通费、误工费、护理人误工损失（这些属"人身损害赔偿"项目，找责任方或意外险，不走医保）

### 2.4 服务与舒适类
- 特需医疗服务、国际医疗部、VIP 病房及其床位差额
- 点名手术费、加急费、院外会诊差额
- 病历复印费、证明工本费

### 2.5 目录外医疗资源
- 未进医保目录的进口药、新特药、高价抗肿瘤药（未谈判成功者）
- 医院没有、凭处方**外购**的药品（多数统筹区不报；"双通道"定点药店外购可报，见第 05 章 2.1）
- 非定点医疗机构、非协议药店发生的费用
- 境外及港澳台就医（法定，见第 1 节）

### 2.6 特殊人群待遇通道
- **生育**：产检、分娩、计划生育费用走**生育保险**待遇（职工）或居民医保生育待遇（部分地区并入基本医保基金支付），不是"不报销"而是"另一条报销通道"，材料与流程不同（生育服务证/出生医学证明等）。
- **工伤**：走工伤保险，需工伤认定决定书；未认定的"工伤医疗费"医保不报。
- **疫苗伤害/预防接种异常反应**：由预防接种异常反应补偿机制处理，不走医保。

## 3. 商业保险通常也不赔的情形（概览，详见第 09、10 章）

| 情形 | 说明 |
| --- | --- |
| 等待期内出险 | 医疗险一般 30~90 天等待期，等待期内疾病出险不赔（意外通常无等待期） |
| 既往症 | 投保前已患疾病及其并发症——多数百万医疗险免责；部分惠民保/高端险对既往症有限赔付 |
| 非合理必要医疗 | 与诊断无关的检查用药、过度医疗、疗养康复性质住院 |
| 免责行为 | 酒驾、毒驾、无证驾驶、斗殴、吸毒、违法犯罪行为导致的医疗费 |
| 高风险活动 | 潜水、跳伞、攀岩、赛车等高危运动（普通医疗险免责，需专门意外险/户外险） |
| 精神疾病、康复科长期住院、职业培训性质的医疗 | 多数百万医疗险条款免责或限额 |
| 先天性与遗传性疾病 | 多数医疗险免责（重疾险以条款为准） |
| 未按要求提供材料 | 缺发票原件、缺清单、缺病历——"非责任拒赔"中最常见，可补件重申 |

## 4. 患者视角的三条自保建议

1. **知情选择要留痕**：医生使用目录外药品/耗材时，患者有知情同意环节；住院中收到"自费项目告知单"要仔细看并签字确认，对费用有疑问当场问医保办。
2. **外购药两样都留**：处方原件＋药店发票原件（缺一不可，商保特药责任与医保双通道都要）。
3. **涉及第三方责任时**：先走责任认定（交警/派出所），医疗费按事故处理渠道索赔；若自己买了意外险，意外医疗责任凭发票报销，与第三方赔偿的顺序按条款约定（一般遵循损失补偿原则）。
