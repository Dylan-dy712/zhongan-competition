# 07 自付、自费、自付一、自付二……一张发票上的钱逐词拆解

> 适用地区：中国大陆　|　更新：2026-10-02　|　定位：本库最核心一章——把发票/结算单上所有"钱字段"逐个讲透，并说明商保理赔时每个字段算谁的账
> 高频误区先行：**"医保卡刷的钱"不是医保报销，是自己的钱（个人账户支付）**；**"个人自付"与"个人自费"不是一个意思**；**商保赔付不出现在发票上**。

---

## 1. 总图：一张发票的钱，先按两个维度切

```
                      ┌───────────── 总费用 ─────────────┐
                      │                                  │
          【维度一：医保要不要管】              【维度二：钱从哪里出】
                      │                                  │
        ┌─────────────┴────────────┐      ┌──────────────┬─────────────┐
   医保统筹基金支付             个人负担            统筹基金      个人账户      个人现金
   （医保报的钱）                    │              （统筹支付）   （账户支付）  （现金支付）
                      ┌─────────────┴────────────┐
                 个人自付（目录内个人承担）      个人自费（目录外全自担）
                      │
        ┌─────────────┼──────────────────┐
   起付线以下       乙类先行自付          按比例自担＋封顶线以上
  （门槛段）        （自付二）             （自付一的部分）
```

两个维度描述的是**同一笔钱**：
- 维度一回答"这笔钱医保管不管"→ 出现"统筹支付 / 自付 / 自费"；
- 维度二回答"这笔钱从哪个口袋出"→ 出现"统筹 / 个人账户 / 现金"。
- 恒等式：总费用 = 统筹支付 + 自付 + 自费 = 统筹支付 + 账户支付 + 现金支付（见第 02、03 章验算）。

## 2. 逐词拆解

### 2.1 医保统筹基金支付（统筹支付）
- **是什么**：医保统筹基金（大家缴费形成的"大池子"）为本次费用实报的金额，即"医保报了多少钱"。
- **在哪看**：发票"医保统筹基金支付"栏；结算单同名栏。
- **商保视角**：这钱不能再向商保重复索赔（补偿原则）；它也是"经社保结算"的证明。

### 2.2 个人账户支付（账户支付）
- **是什么**：从**本人医保卡个人账户**余额里划扣的钱。职工医保有个人账户，**居民医保没有**。
- **是不是报销**：**不是**。个人账户里的钱本就来自个人（个人缴费＋单位缴费划入部分），刷账户＝花自己的钱。
- **商保视角**：多数保司在理赔实务中把"个人账户支付"计入**个人实际负担**参与免赔额计算（它毕竟是本人实际发生的支出），也有产品只认"个人现金支付"部分——此为**行业实务观察，没有统一规定**，务必以保单条款和保司客服口径为准。
- 常见困惑："我医保卡刷的钱，保险公司为什么不赔？"——不是不赔，是要先弄清产品免赔额怎么算、账户支付算不算；以及账户支付对应的可能是目录内自付（可赔）或目录外自费（限社保内产品不赔）。

### 2.3 个人现金支付（现金支付）
- **是什么**：以现金、银行卡、微信、支付宝等**账户外方式**实付的钱。
- **商保视角**：理赔"实际支出"的直接证据之一，与账户支付合计构成个人支付。

### 2.4 个人自付（自付）
- **是什么**：**医保目录内**的费用里，按政策必须由个人承担的部分。
- **构成**（三块，见总图）：
  1. **起付线以下**：门槛段，统筹不报；
  2. **乙类先行自付**：乙类药品/项目先按比例扣个人的那一段（即"自付二"）；
  3. **按比例自担**：统筹按比例报销后剩下的个人份额，以及**封顶线以上/超支付范围**的部分。
- **商保视角**："限社保内"的医疗险主要就是赔这一块（扣除免赔额）；"不限社保"产品连自费一起赔。

### 2.5 个人自费（自费）
- **是什么**：**完全在医保目录外**的费用——目录外药品、耗材、项目、超标床位差额等，统筹基金一分不报。
- **别与"自付"混用**：自付=目录内医保管了一部分；自费=目录外医保根本不管。两者混称是费用解读最常见的错误（"自费比例异常"误判多源于此）。
- **商保视角**：这是"不限社保"条款（百万医疗险、中高端医疗险、惠民保的目录外责任）的价值所在；限社保内产品对自费分文不赔。
- 外购药提醒：凭处方在院外药店购买的自费药**不会出现在住院发票/清单里**，会形成另一张药店发票——算"实际总支出"时别漏（见第 08 章第 4 节）。

### 2.6 自付一 / 自付二（地方结算单分法）
- 部分统筹区（如北京等地）在结算单上把"个人自付"再拆两栏：
  - **自付二**：乙类药品、部分先行自付项目中，个人**先按比例**承担的部分（"先行自付"段）；
  - **自付一**：目录内除先行自付外个人承担的部分——起付线以下、按比例自担、封顶线以上等。
- 通行速记：**自付二=乙类"先扣"的钱；自付一=目录内"打折后剩下的"钱**。
- 各地字段命名与归集口径存在差异（个别地区含义相反或有第三栏），**以参保地结算单说明为准**；全国统一发票上通常只合并显示"个人自付"。
- 总自付 = 自付一 + 自付二（当地分法成立时）。

### 2.7 先行自付
- 2.4/2.6 中"乙类先扣"机制的正式名称：乙类药品/部分诊疗项目按地方规定比例（常见 10%~30%）先由个人承担，剩余部分再进入统筹按比例报销。
- 在发票/清单上可能体现为"先行自付"栏，或并入自付二。

### 2.8 大额（大病）支付 / 公务员补助 / 医疗救助支付
- 票据/结算单上可能出现的其他基金支付栏：
  - **大额医疗费用补助支付 / 大病保险支付**：超过基本统筹封顶线或个人自付超标后的第二层报销（第 06 章 4.1/4.2）；
  - **公务员医疗补助**、**补充医保**、**医疗救助支付**：相应人群的再报销层。
- 商保视角：同属"已报销金额"，补偿原则下不能重复赔。

### 2.9 商业保险支付
- **默认情况：发票上没有这一栏**。商保赔付的官方记录是保险公司《理赔决定通知书》（第 04 章第 4 节）。
- 例外：个别城市试点商保直付/理赔直连（如北京医疗电子票据理赔试点），以及高端医疗险的**直付网络**（医院与保险公司直接结算，患者签字走人）——此时患者拿到的票据可能体现"第三方支付/直付"信息，但不属于通用式样。

## 3. 一张对照表收尾（建议与发票对照着看）

| 字段 | 钱是谁的 | 医保管了吗 | 商保（限社保内） | 商保（不限社保） |
| --- | --- | --- | --- | --- |
| 统筹基金支付 | 医保基金 | 已报 | 不重复赔 | 不重复赔 |
| 个人账户支付 | 本人账户 | 不管（自己的钱） | 计入个人负担（多数产品） | 计入个人负担 |
| 个人自付 | 本人 | 管了一部分，剩这部分 | **主要赔付对象**（扣免赔额） | 赔 |
| 个人自费 | 本人 | 完全不管 | **不赔** | **主要赔付对象** |
| 其他支付（大病/大额/救助等） | 其他基金 | 已报 | 不重复赔 | 不重复赔 |
| 商业保险支付 | 保险公司 | — | （理赔后才有） | （理赔后才有） |

## 4. 三个实战推论

1. **看自费栏判断产品价值**：总费用中自费占比越高，"不限社保"的商业医疗险越有用；自费为 0 时，限社保内产品与不限社保产品差距不大。
2. **免赔额的口径要确认**：免赔额从"个人负担（自付+自费）"里扣，还是从"现金支付"里扣，还是"医保统筹后剩余"——同一张发票在不同条款下算出的可赔金额不同。
3. **"经社保结算"影响赔付比例**：多数百万医疗险条款为"经社保结算 100%/未经社保 60%"（常见形态，以条款为准）。急诊未刷卡、异地未备案导致全自费的，除按未备案规则手工报销外，也直接影响商保赔付比例（见第 10、11 章）。
