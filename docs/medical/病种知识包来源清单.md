## 0. 官方命题对照

命题 KR2 给出的五个痛点示例与 spec 六类候选标签的对应关系，决定了知识包必须覆盖的槽位：

| 命题痛点示例 | spec 候选标签 | 依赖的知识槽位 |
| --- | --- | --- |
| 用药与诊断不匹配 | CLIN_MEDICATION_CONTEXT_REVIEW | 槽位4 用药规则 |
| 非必要检查 | CLIN_EXAM_JUSTIFICATION_REVIEW | 槽位3 诊疗规范/临床路径（检查适用性） |
| 自费比例异常 | COST_SELF_PAY_DEVIATION | 槽位8 费用基线 |
| 诊断术语晦涩 | EXP_TERMINOLOGY_BARRIER | 槽位1 通俗解释、槽位2 术语对照 |
| 出院小结缺乏康复指导 | EXP_DISCHARGE_GUIDANCE_GAP | 槽位5 出院指引适用清单、槽位6 康复要点 |

KR4 五维示例（费用效率、用药合理性、治疗规范性、再入院率、患者反馈）中，前三者的"符合/规范"判定依据分别来自槽位8、槽位4、槽位3——知识包同时服务画像指标，不只是关怀报告。

### 知识包使用红线（来自命题"AI 原生度红线"与"备注"）

- 命题最大陷阱："做成通用的医学科普内容生成器……不是'写一篇骨折康复指南'。每份指引必须锚定在该用户的具体病历、费用、治疗过程上。"因此知识条目是**生成的接地与核对依据**，不得整段把科普内容拼进患者报告；报告中引用知识必须走 `professional_explanation` claim（带 `knowledge_refs`），并与病例事实分开。
- 温度指引的个性化来自病例事实 + 用户自述关注点 + 表达偏好；知识包只提供"解释什么、核对什么、指引缺什么"的医学口径。若盲评发现某段报告去掉病例事实后仍成立，该段即疑似模板化。
- 临床疑点（用药/检查类标签）只能输出"需核实线索"，进入医学复核，不得对患者宣称"医生开错药/做了非必要检查"（spec 6.2、AC-10）。

## 1. 知识槽位 → 项目用途映射

每个病种的知识包按以下槽位组织，每个条目需登记：来源、版本号、适用范围、获准状态。

| 知识槽位 | 服务的项目能力 |
| --- | --- |
| 1. 疾病通俗解释 | KR3 `diagnosis_explanation` 段；体验类标签建议动作 |
| 2. 术语通俗对照表 | `EXP_TERMINOLOGY_BARRIER`（记录中重要术语缺通俗说明→给解释，不断言患者理解能力） |
| 3. 诊疗规范/临床路径 | KR3 `treatment_review` 段；`CLIN_EXAM_JUSTIFICATION_REVIEW`（检查适用性/重复性疑点，须排除合理复查）；KR4 治疗规范符合度 |
| 4. 用药规则（适应证/禁忌/常见联用） | `CLIN_MEDICATION_CONTEXT_REVIEW`；KR4 用药规则符合度 |
| 5. 出院指引适用清单 | `EXP_DISCHARGE_GUIDANCE_GAP`（出院材料相对适用清单的缺项，不声称医生没口头指导）；KR4 出院指引记录完整度 |
| 6. 康复/自我管理要点 | KR3 `recovery_plan` 段 |
| 7. 复诊随访规范 | KR3 `next_visit_advice` 段（医嘱无复诊日期时 `due_at=null`，不编日期） |
| 8. 费用基线与结构参考 | `COST_SELF_PAY_DEVIATION`（须有可比基准，否则不可判异常）；KR3 `cost_explanation` 段；KR4 费用水平/自付负担 |
| 9. 危险信号（红旗症状） | 优先行动的安全边界；`emotional_support` 段"何时必须就医"边界 |

## 4. 落地方式与合规注意

1. **知识条目格式**：按 T19 要求，每条知识 = {要点内容, 来源文献, 版本号, 适用范围, 生效/复核日期}；写成"要点 + 引用"，不整篇复制指南正文（著作权与 token 成本双重原因）。
2. **审核流程**：本清单全部条目须经医学审核人员（H2）确认后写入 `docs/medical/knowledge-manifest.md` 并赋版本；未审核条目只能作为候选复核线索，不得进入患者报告。
3. **费用基线口径**：主基线从官方脱敏数据集按病种/病组/机构层级自建（命题要求"方案无需额外数据源即可运行"）；统计年鉴、DRG 分值等外部数据仅作解释与演示对照。用于 `COST_SELF_PAY_DEVIATION` 前必须登记口径与时间边界，无可比基准时输出"不可判断"，不得硬判异常（spec 6.2）。
4. **OPEN-02 建议**：五个病种均有国家临床路径与权威指南支撑，知识可得性不是选择瓶颈；首批三病种应主要由赛方标注数据量与标签可覆盖性决定。
5. 本清单不替代医学审核，也不改变 spec 中"不得据此自动改变理赔结论、不得要求用户停换药"的产品边界。
