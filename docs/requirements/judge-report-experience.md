# 固定评委样例报告体验

仅对已授权评委账号、完整固定样例文件和已准备的通用申请提供预生成报告。后台核验样例版本、每份文件校验值、逐页可读材料、字段处理和报告提示版本、知识版本、原始申请内容。新增材料、个性化问题、个人补充或记忆上下文不命中此模式。

准备包包含多个已通过来源复核和阅读质量检查的报告版本。保存时将案例专属引用改为文件校验值、页码、原文摘要；使用时绑定当前案件的新引用 ID，并重新检查账号授权、材料、引用锚点和知识版本。结构化报告仍执行原有来源绑定与校验；不确定字段和复核状态保留。

界面明确标为“评委体验 · 示例报告”，展示约八秒的演示进度后打开报告。它不表示实时模型正在识别或复核。后续追问不使用预生成答复，继续通过现有实时对话、原文引用和知识检索流程回答。普通用户报告流程不变。

准备包只写入服务器的私有识别目录，不提交材料、报告正文、账号身份或凭据到代码仓库。缺失、损坏或失配的准备包回到原有实时流程。
