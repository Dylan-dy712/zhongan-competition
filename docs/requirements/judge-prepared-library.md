# 评委固定材料预处理

固定样例提前准备逐页识别和文档字段，评委上传完全相同的材料时复用；报告和引用 ID 仍按本次案件生成。普通用户、未授权账号、撤回授权及不匹配的文件不会读取共享结果。

发布前核验样例版本、原文件 SHA-256、完整页数、识别包摘要及字段处理版本。识别来源和页码保留原值，切换线上 OCR 不会将历史识别结果伪装成新 OCR。低清晰度警告、视觉转录标识和部分成功状态保留。字段模型或提示版本变化后须重新准备。

维护人员可在服务器项目目录使用 `python -m scripts.prepare_judge_library --source-profile <已核验识别包配置摘要>`。命令读取正在运行的 Worker 配置，复用已存在的固定样例 OCR，并准备当前文档字段；不创建账号、案件、报告，不调用实时 OCR。逐页保存进度，全部文档通过后原子发布私有目录中的 `prepared-library.json`。不得将样例内容、缓存或模型密钥提交仓库。
