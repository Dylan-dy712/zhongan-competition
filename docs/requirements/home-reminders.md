# 首页复诊与用药提醒

首页按当前关怀对象读取就医档案和最近六次对话，补充最近三份档案中最多两批资料的对话作为来源。新增空白对话、新案件尚未整理完成、单条对话没有复诊或用药信息时，继续汇集其他可用来源；不会在遇到第一条医疗对话后停止。读取并发最多三个，单次最多十二条对话。

优先展示已发布安排与本次有效材料中的医嘱，保留原有日期、相对时间、剂量、频次、疗程和不确定表述。相同内容去重，复诊与用药各优先保留一项，每项均可回到对应记录或查阅原文。相同案件使用最新分析任务，已替换的任务、已完成或取消的安排不通过旧对话重新出现。

切口换药、伤口照护和拆线归入护理安排，避免把伤口换药误作药物用法；包含抗生素与复诊要求的同一段原文保留为“复诊与用药”。

近期聊天只用于发现待核对的复诊、用药问题，不将用户问题中的药量或时间变成医嘱。没有明确医嘱时，结合有出处的档案诊断或就医机构显示准备事项；完全没有资料或正在读取时，也显示复诊准备和用药核对入口。准备事项不生成具体治疗、剂量或复诊日期，不增加首页模型调用。

同一账号、同一成员刷新期间保留已读安排，部分来源读取失败时显示可用内容并允许重试。账号或人员切换、资料授权被撤回时清除旧资料。新任务进行中按原有间隔刷新，晚到的读取或原文响应不能覆盖另一成员的提醒。

回归检查覆盖新增八条对话后仍通过档案找到已有安排、多个案件汇集、无明确医嘱和空档案兜底、原文与记录导航、相同案件的任务替换及取消动作、部分和全部读取失败、授权撤回、人员隔离和异步响应顺序。
