# 医疗服务推荐与报告引导

2026-10-16，依据用户本轮要求新增。既有临床报告、材料引用与授权规则不变。

## 范围与行为

- 材料解读和已发布关怀报告末尾展示温和的服务引导，支持一键询问权益、附近机构、互联网医院。
- 普通聊天由模型结合用户当前问题与本对话上下文调用医疗服务工具，选择权益、线下、公立/私立、互联网医院或组合；不以关键词固定回复。
- 本次演示默认具备中高端权益。呈现为中高端服务参考，不写成已经读取、核保或确认真实保单；互斥套餐、加油包和具体资格仍按资料说明。
- 复查不等于健康体检；新发或加重不适先了解情况或建议适当线下评估；急症优先急救，不展示优惠/体检/线上问诊促销卡。
- 地区只使用用户在本对话明确提供的信息。缺地区先询问城市/区或附近地标。以公开源地址进行同城/区匹配，缺坐标不显示公里或声称最近。
- 私立名单、康复名单与公立官网信息保留独立来源及适用范围，不宣称质量排名或全部可直付。
- 权益、医院和互联网医院提供可点击卡片，打开本地模拟服务弹窗；不发送病历、不开方、不真实预约或扣费。
- 回答中的结构化服务卡随原有JSON回答保存，恢复历史可展示；切换账号/对话不保留服务弹窗。

## 验收

- 解读末尾可见引导，点击会进入当前对话发送相应问题，不覆盖输入草稿或上传材料。
- 工具覆盖复查、预防体检、住院/术后照护、康复、普通咨询、用药服务等需求；支持仅显示适用的一类或多类卡。
- 缺位置、位置并非用户提供、没有同城数据、急症及需线下评估各有可验证结果。
- 医院卡包含来源、地址/位置匹配说明、服务适用边界；不生成未知的距离、号源、价格。
- 模拟弹窗有明确演示说明、关闭和键盘操作；窄屏不横向溢出；后端工具与浏览器交互测试通过。
