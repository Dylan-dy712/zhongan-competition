# 问暖暖：解读报告与普通附件消息

- 新建入口分为“新建解读报告”和“新建对话”。报告入口选择已授权人员后创建独立会话并立即打开材料上传窗口，确认材料后沿用现有分析、校验与报告续写流程。
- 普通对话及报告生成后的对话中，选取图片或文档只加入本地待发送列表。用户可继续输入问题、追加或移除附件，点击发送后才上传并结合识别文字回复。
- 普通消息附件独立保存，不纳入报告案件文档，不创建分析任务、不使已有报告失效。普通消息不能调用生成报告的工具；完整报告通过报告入口显式创建。
- 附件上传、读取、缓存和消息重试均校验当前会话所有者及有效授权。OCR 在数据库事务外运行；低置信度文字继续沿用现有隔离规则，识别失败如实提示，不编造图片内容。
- 验收覆盖：报告选人后自动弹窗、多文件上传后生成报告、普通附件选择后零请求、图片与问题同次发送、追加/移除、失败重试、报告后图片追问、跨会话/身份拒绝、无报告任务副作用及既有登录/导航回归。测试仅使用合成内容。
