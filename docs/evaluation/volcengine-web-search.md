# 火山搜索补充一般医学解释

入口位于 worker 的本地知识检索之后、报告草稿生成之前。模型仍使用千帆 GLM；搜索通过独立火山 Custom Web Search API 获取网页正文，不调用搜索总结模型。

仅使用字段抽取中可逐字核对的诊断/手术候选，映射到代码中的公共医学术语词表；不发送病历、姓名、费用、日期、联系方式或用户表达。未被词表覆盖的名称暂不联网，后续可在审核后扩充。否定、既往和未知候选不触发搜索；疑似词只用于一般术语查询，不能成为确诊依据。

只在该术语缺少本地解释时查询。默认每份报告最多两个查询、全站每天最多40次外部请求（北京时间自然日）；失败请求计数，不自动重试。API和worker共享SQLite计数和缓存。成功结果缓存30天，空结果缓存一小时；缓存命中不增加搜索次数。数据库故障、权限错误、超时或额度用尽返回状态并继续本地报告链路。

检索限定医院、卫生部门和专业机构的站点，结果再次校验域名边界、正文、标题相关性和可用适用范围；不把Summary或Snippet当原文，不访问返回URL，避免任意URL抓取。明确有独立再利用限制的百科路径不入库。保留完整原始段落/句子，单来源摘录最多2200字符、每个查询最多两条引用。

引用ID与版本绑定来源URL和摘录哈希；缓存过期、篡改、未知ID均拒绝复用。网络参考不标记为医学批准，结构化解释仍需原有审核流程，对话正文仍经过独立事实和阅读质量复核。不能从网页生成新的个体处方、剂量、疗程、活动强度、复诊时间或医院优劣判断。来源角标显示摘录、原网页和获取时间。

配置文件为服务器 `/home/ubuntu/.config/zhongan/web-search.env`，权限600，由systemd加载；不写入Git。`ZHONGAN_WEB_SEARCH_ENABLED=1`启用，设0并重启API/worker即可关闭。缓存目录位于 `/home/ubuntu/zhongan-data/web-search`，不包含Key或患者记录。

验证包括公共词的真实搜索权限、虚构病例缺失知识的联网补充、重复查询零新增请求、并发日限额、来源域名伪装/注入/摘要拒绝、引用哈希和过期校验，以及报告生成至交付的复核链路。搜索成功不等于医学专家审核或人工温度盲评达标。
