# 清晰费用行直接转录

仅在恰好一个名称列和一个总金额列、每个名称都有同一行单独金额单元格、两格置信度均至少90、金额可直接解析时，跳过费用转录LLM调用。不计算金额，不合并重复名称，不推断类别。候选行出现歧义时整段退回已有模型流程。

直接转录仍经过相同的行列绑定和逐行证据校验；异常名称仍触发局部视觉复核。attempts.input_method区分direct_verified_cells与llm_cell_transcription。这里的confidence来自OCR引擎，不是经校准的正确率。

本项依赖局部名称纠错PR。既有相关检查14项通过，无新增测试；效果与耗时以固定七页实际对照为准，不以减少模型调用代替准确率验收。
