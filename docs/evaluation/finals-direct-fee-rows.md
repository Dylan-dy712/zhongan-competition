# 清晰费用行直接转录

本实验默认关闭，仅ZHONGAN_DIRECT_FEE_ROWS=1显式开启。仅在恰好一个名称列和一个总金额列、每个名称都有同一行单独金额单元格、两格置信度均至少90、金额可直接解析时，跳过费用转录LLM调用。不计算金额，不合并重复名称，不推断类别。候选行出现歧义时整段退回已有模型流程。

直接转录仍经过相同的行列绑定和逐行证据校验；异常名称仍触发局部视觉复核。attempts.input_method区分direct_verified_cells与llm_cell_transcription。这里的confidence来自OCR引擎，不是经校准的正确率。

本项依赖局部名称纠错PR。既有相关检查14项通过，无新增测试；效果与耗时以固定七页实际对照为准，不以减少模型调用代替准确率验收。

2026-10-18固定材料实跑发现，引擎对错误文字也可给出100分；一页密集清单启用直接转录后F1从0.493降至0.147。因此不将此实验放入默认决赛链路。运行器记录开关状态，禁止跨配置误复用预测结果。原始实验输出保留在仓库外，不能把速度收益写成准确率收益。
