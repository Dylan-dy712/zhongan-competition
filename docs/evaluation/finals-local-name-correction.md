# 局部费用名称纠错

多行名称或腾讯原始单元格置信度低于90时触发既有局部图像复核，不以模型自报高置信度跳过。原图名称可与OCR名称不同，但金额仍必须等于同一来源行的总金额单元格。

应用写入raw_ocr_name、visual_source_box和visual_correction_method；模型不得自行提供这些来源标记。修正后的状态为verified_amount_visual_name，含义是金额绑定验证、名称来自模型局部视觉转录，不代表独立人工确认或医学事实验证。不删除所有换行续文，不使用金标纠正识别文本。

固定七页开发回归材料在改动前锁定，含一页已知倾斜费用单、三页既有表格恢复材料、前三页临床范围材料；不是独立测试集。所有医疗输入和运行输出位于仓库外。既有相关检查14项通过，未增加或修改测试，未验证原图哈希。
