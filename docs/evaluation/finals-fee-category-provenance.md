# 收费原文与统一语义分类

sourceCategoryName和sourceCategoryCells仅来自明确标注费用类别/收费类别/费用分类/收费分类/项目类别的原始表格列，要求与名称处于同一来源行。不将医保类别误认为费用类别，不推断未知原文分组。

itemCategoryCode及itemCategoryName继续表示统一医学语义分类；分类器接收原始收费类别作为上下文，两者不覆盖。明确规范类别与推断结果不一致，或者分类置信度低于0.85，标记category_requires_review。无法判断时保留未知并要求复核，不用其他类替代未知。

提示词补充检查与治疗、手术与标本检查、手术与植入材料的用途边界。这些是通用语义约束，不由当前金标答案生成。若官方金标与医学语义存在分歧，应确认评测口径或走标注修订流程，不在代码中针对答案特判。

依赖前两项优化。既有相关检查31项通过，无新增或修改测试。实际效果以固定七页的同模型、同OCR、同评分器对照记录为准；这些开发样本不能证明新数据泛化或官方KR1达标。
