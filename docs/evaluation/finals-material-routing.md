# P0：页级材料分类与抽取路由

在原生文字或第一遍通用OCR之后，使用标题区域的可追溯规则判断保单、发票、结算单、费用清单、出院记录、手术记录、检查报告、临床记录。该阶段不声称是首次OCR之前的视觉分类。

单一命中标likely，多种命中标mixed、没有命中标unknown；后两者走general，不猜唯一类别。匹配不是校准后的分类概率。

类型提示进入文档抽取器；明确保单不产生患者诊断、手术、药物或费用候选。worker仍保存原页与证据，但保单文字不进入患者事实抽取。混合页保留通用处理，不因包含保险词就删掉临床内容。

输出material_routing记录分类版本、类型、确定性、抽取profile与建议OCR策略。费用/结算候选建议table；专用表格第二遍识别由独立P0 PR接入，不在本PR暗中切换收费服务。

验证：19项既有文档/worker检查通过，未新增或编辑测试。三份真实OCR缓存执行类型路由，另检查虚构保单和混合标题分支；没有独立材料类型金标，不报告分类准确率或KR1提升。

本PR基于#95；医疗材料、API凭据及本地评测产物不入库。
