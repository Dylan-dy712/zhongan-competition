# 前置 VLM 材料布局实验协议

本轮在费用错项实验结束后独立进行，基线为 PR #173 的 v55。采用用户提出的“VLM 判断材料模板 → 按模板规范进行 PP OCR → VLM 复核结构化”的顺序。

## 固定对照

- 继续使用 `fee-row-fixed17.json` 的全部十七页、十三个病例、823 个评分原子与修订金标 v3，不按分数筛选。
- 基线为 `fee-v55-predictions17/` 的新鲜模型结果，总体 F1 0.716798。
- PP-OCRv6 medium GPU960、GLM-5.3-Flash、最终 vision 开启、bbox 辅助文本和原计分规则保持一致。
- 不校验原图哈希，不改金标、类别定义或计分器，不编写或主动运行测试。

## 本轮变量

1. OCR 前仅根据原图判断材料类型、正文阅读朝向、表头角色，以及名称是否附带收费编码/产品规格。布局分析不接触 OCR、参考答案或任何既有抽取结果，不输出医疗事实、金额或患者信息。
2. 朝向判断足够明确时，将逆时针旋转角度交给 PP OCR；不确定时保留原方向并标记待复核。不按医院或病例编号编写模板。
3. 模板规范作用于原图朝向与结构化字段边界。PP 检测识别模型本身不接收语言提示词。本轮不启用此前退化的整页高分辨率或区域裁剪模型。
4. 最后的 VLM 接收相同原图、PP OCR 结果与布局假设；布局仅为辅助，不能作为费用或临床事实。可分辨的附加规格与收费编码独立保存，原始名称与证据保留。陌生或识别失败的布局保留通用抽取路径，不排除页面。

## 验收与记录

原生 OCR 与最终抽取使用独立缓存/预测目录，保存前置布局输出、置信度的自报性质、原方向/采用方向、模型用量与时间。新鲜模型结果与任何重放分别说明。

报告十七页总体、原七页及扩展十页的 F1、名称金额配对 F1、类别复合 F1、失败/部分/完整页面数、空费用页和耗时。所有失败纳入分母；发现费用表但没有可用费用行时不能只凭运行状态宣称完成。

优先判断：横置页面是否正确识别并缩短解析时间、费用名称与附加信息是否更清楚、总体及费用配对是否改善。单次涨分不声称稳定泛化或官方达标。当前五类 KR1 关键字段尚未完整独立标注。
