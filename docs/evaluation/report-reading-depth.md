# 完整正文验收

正文与六段结构化草稿分别验收。实际页面复用 patient_analysis.text，不能因为 sections 有解释而放行一段摘要。

资料充分且涵盖至少三个主题时，正文目标为 900–1500 字，最低 650 个非空白字符、四个编号主题；中等材料最低 350 字、两个主题。少量单主题材料不设篇幅下限。篇幅检查只用于拦截明显压缩，诊断含义、治疗目的、费用口径、康复行动、真实关切和复诊准备仍由独立阅读质量检查评价。禁止重复和补造事实凑字数。

有匹配的诊断、治疗和费用知识时，正文须绑定相应知识引用。缓存复用也做格式和篇幅检查；事实复核后裁剪的正文重新接受阅读质量检查。原文复核与用户授权检查保持独立，篇幅合格不等于医学合格或人工盲评分达标。

新增 HJ 成人股骨头坏死与髋关节置换的一般参考包，出处为 AAOS OrthoInfo 原始页面。保留待医学审核状态，只提供一般解释；不新增具体训练量、药物剂量或疗程。通用费用术语对未覆盖病种也进入参考选择。网页核对不等于人工医学批准。

自动联网补充的边界：查询仅用医学术语，不发送病历或身份信息；优先原始权威来源；记录 URL、获取时间、适用范围与审核状态；通过引用和原文复核后缓存。当前版本提供核对后编译入库的 HJ 引用，尚未接入运行时自动联网搜索服务。
