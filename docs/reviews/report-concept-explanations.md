# 前三部分要解释概念并减少理解负担

实际阅读发现，长篇报告也可能只是重述诊断、用药和收费，末尾另加一句安慰。原来的布尔阅读评分会将“请医生解释这些术语”判为合格；联网补充又未识别“乳腺恶性肿瘤”等名称，没有提供医学概念解释来源。

检索入口增加经过原文核对的公共同义词映射，以及明确记载的靶向治疗、化疗、放射治疗词。只发送固定词表中的公开术语，主诊断与已记录治疗优先占用两次查询，不从药名反推 HER2 等检测结果。NCI 原始机构域名与英文别名可用于参考；原有域名、适用范围、缓存、配额和引用校验保留。甲乙类药品标签出现时优先保留专门的目录分类条目，不能将药品规则直接套入检查服务。

报告和阅读复核都要求：解释通俗含义、联系本人明确记录、给具体理解或核对帮助。每个已有知识依据的前三主题，复核必须逐字指出三句不同的正文；概念解释句须关联该主题实际知识引用。主题齐全、字数够、列了引用 ID 均不能代替实质解释。医学事实仍由独立原文复核检查，明确区分开立处方与执行完成、科室名称与实际治疗、病理样本描述与当前病情，不承诺疗效或更少副作用。

这属于模型阅读质量检查，不是人工温度盲评，也不替代医学审批。缺乏可引用知识的陌生术语不允许靠背景常识编造个人诊断和医嘱。已经完成的旧报告只在用户请求时生成新版本；总览提供“重新生成解读”入口，正在分析时禁用。

公开解释来源示例：

- NCI 乳腺癌概述：https://www.cancer.gov/types/breast/what-is-breast-cancer
- NCI 靶向治疗一般说明：https://www.cancer.gov/about-cancer/treatment/types/targeted-therapies
- 北京协和医院靶向治疗科普：https://www.pumch.cn/detail/41329.html
- 国家医保局目录分类说明：https://www.nhsa.gov.cn/art/2026/1/5/art_14_19235.html

验证包括同义词与治疗查询的真实公开搜索、最多两次且缓存复用、纯复述反例拒绝、正文引句与引用关联校验、伪造引句拒绝、旧生成策略刷新，以及仅使用虚构病例的完整模型联调。
