## 实际验证范围

本轮在合并后的源代码重新运行：`python -m unittest discover -s tests`，94项通过；`npm run build --prefix apps/web`，TypeScript/Vite通过。

PR #11 交付时，在隔离 PGlite schema 运行审核 HTTP/SQL 检查、43项聊天/真实Worker检查、57项发布/通知/反馈检查。均为合成材料；模型相关路径采用明确测试替身。浏览器确认泛化通知、报告已查看、求助反馈“等待处理”，界面报告明确标为非医学测试。上述结果证明对应程序路径，不能证明 KR 的医学质量或官方分数。

PGlite输出保留 `sql_error_rollback=not_tested_pglite_protocol_limit`、`concurrency=not_tested`。发布测试实际验证的是应用异常触发的事务回滚；原生 SQL 触发器异常用例保留但未在本轮原生 PostgreSQL 跑通。界面样例同时运行时曾发生一次提醒检查失败，停止界面进程后顺序套件通过，根因未定；不得据此声称多连接可靠。
