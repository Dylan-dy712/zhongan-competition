# Reading quality is advisory

A valid report used to fail entirely when its reading review rejected depth,
structure, explanation or warmth. The new policy delivers the original draft
with a short improvement note, records the assessment, and does not request a
whole-report rewrite solely to raise the grade. Review timeout, unavailable
provider, malformed review JSON or exhausted review budget also preserve a valid
draft and record that the reading review was not completed.

The worker persists the draft as completed, so the normal material-report and
conversation continuation routes remain available. The conversation reuses the
draft and its reading note; minimum length and topic coverage no longer discard
a source-valid cached draft. Fresh and fact-corrected conversation prose follows
the same advisory policy. The UI shows the actual report and the note together.

This does not approve clinical claims. Ownership, consent, current document
versions, unsafe advice checks, strict JSON contracts, authorized references,
citation binding and independent source-fidelity review remain mandatory. A
factual defect still follows the existing bounded correction / verified partial
delivery path. Pending professional claims and actions remain pending review.
Malformed drafts or missing readable sources do not become completed reports.

Verification uses invented records only. Tests cover advisory rejection, missing
or timed-out quality review, exhausted review budget, cached short prose, carried
notes, retained source/factual guards and successful frontend report display.
