# 报告格式修复保留真实引用

千帆草稿存在两种已观察到的格式偏差：根对象多出 `review_notes`，以及将单句知识 ID 放在 citation 的 `knowledge_refs` 而非 `source_refs`。原逻辑先拒绝整份 JSON，再让模型泛化重写；后者还可能删除真实知识链接，导致费用解释的阅读质量检查失败。

解析入口仅兼容这两种明确的元数据变体：内部备注不进入报告；单句的知识引用只有属于本轮实际提供的知识 ID 时才合并到该句的 `source_refs`。正文、金额、医学事实和引句不改写，不从报告级引用列表猜测单句来源。原始模型输出仍保存，记录仅含规范化类型。

其余未知字段、错误类型、未授权来源、引用歧义、条数上限仍严格拒绝。结构错误修复提示提供错误路径和类型，而非只要求修复引用；首轮提示明确给出知识解释句的来源关联要求。阅读质量检查、独立原文复核和两次草稿请求上限保留。

验证包含两种格式偏差的合并、未知来源拒绝、未知字段和错误类型拒绝、报告级列表不自动生成单句链接、无需重写即可进入费用解释检查，以及不复制敏感值的具体修复反馈。真实失败草稿只做离线格式及来源校验，不重新向模型发送患者数据；模型联调仅使用虚构病例。
