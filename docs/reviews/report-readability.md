# 对话材料解读：重点排版和原文复核

新解读采用“总述—编号解读—下一步”框架：开头用两三句说明整体情况，再按实际材料分主题解释，最后单独呈现“接下来，可以这样做”。每点用通俗短段落解释记录与限定，结尾优先转述原文医嘱，或给具体的核对方向，不增加原文没有的诊疗建议。没有固定医学六段模板，只有费用材料时不补齐病情章节。关键事实、金额及完整限定用深色加粗，移除绿色文字和绿色强调底色；编号使用中性灰色。正文使用安全的编号与双星号强调子集，React 按文字节点渲染；不执行 HTML、链接或脚本。结尾单独分块，避免被并入最后一个编号。历史普通段落只增加编号，不改动事实；新的内容框架适用于之后生成的解读。

语气面向用户本人：看过资料后先讲用户这次就医的重点，以“你这次”“咱们先看”“医生在出院时交代了”等自然表达衔接，只在需要限定事实来源时提记录。不以“这些资料包含什么”盘点文件，不套同一句开场，不编造用户的情绪或经历。

进度涵盖材料整理和对话文字解读两部分。材料可读取时进入95%–99%的“写好解读”阶段；只有当前分析任务对应的完整文字回答可显示时才到100%，同时关闭进度并呈现解读。聊天上传和理赔资料入口都遵循此条件。解读失败可以只重试文字生成，无需重新上传或重新解析材料；既有后台完成状态不代表文字已经生成。

快速转述后的独立原文比对读取同一批完整证据，去除复核不需要的重复来源编号。最多三个问题必须附可逐字核对的原文和草稿引句；本地核对引句后，将问题交给保留思考的集中裁定。裁定只比较已引用的事实，不进行新诊断，不把假设性批评用于改写。确认问题后修正，再复核；最多两次草稿、两次原文比对和两次集中裁定。结构、引用、危险建议和源版本访问检查保留。二次草稿仍有确认错误时，移除该完整重点；明确金额仅可按已引用的原文标签原句保留，不猜表格列、不推算。剩余内容连同局部核对说明必须再次复核通过才交付，最多增加一次比对与一次集中裁定。没有可保留重点、复核或裁定失败、复核原文引句一次重试仍无法核对时，不用该意见修正事实，只将能定位的对应重点暂不交付，剩余部分再复核；无法定位草稿重点、剩余内容未通过时仍不交付。普通聊天流程和正式报告审核设置保持原状。

实测发现费用表格中的乙类费用与乙类先行自付有错配可能，修正策略不继续猜测次要金额，只保留能够直接核对的总额。禁止费用相加推算，检验值缺参考范围时不自行判正常；住院和出院阶段、否定、疑似、既往均保留，强调时也包含限定。

真实配置模型的合成反例矩阵通过：疑似改确诊、否定变肯定、既往变本次、住院药变出院方案、支付口径错配、无范围检验判断、误导加粗七项均被拦截；两个正确转述被接受。这是有限案例的回归验证，不是医疗正确性的保证或人工专家审核。原文 OCR 和复杂表格仍可能需要核实。

同组实际材料只读测得一次必要修正后约18.5秒交付，857条来源、7304字符保留，正文1335字符、20个真实引用；包含两轮复核和集中裁定，比单纯约5.5秒的转述增加了核对时间。另一轮测得约40秒，模型延时会变化，不能把18.5秒视为承诺。未计上传、OCR、排队或数据库写入。320/390/1440像素真实页面布局与 HTML 注入保护已检验。


线上复测发现通用模型复核仍可能放过“抗体数值都在参考范围内”的无原文评价判断，因此另加确定性边界：材料没有明确记载“参考范围内/正常范围内”评价时，相应肯定转述作为未核对重点暂不交付；数字或参考范围表头不会被当作评价。否定这种推断的说明可保留。没有增加临床阈值或医学推断，仍需核对剩余报告后交付。
