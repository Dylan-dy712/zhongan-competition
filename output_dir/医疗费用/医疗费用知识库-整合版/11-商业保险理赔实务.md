# 11 商业保险理赔实务——材料、原件、分割单与拒赔点

> 定位：拿着医疗发票去保险公司报销，材料怎么备、顺序怎么排、原件被收走怎么办、哪些情形会被拒。
> 边界：通用流程与通行要求，具体产品以保险条款、保司理赔指南为准。时效依据《保险法》通行规定。

---

## 1. 报销型商业医疗险的标准材料清单 [KB-CLAIM-001]

| # | 材料 | 说明 | 原件要求 |
| --- | --- | --- | --- |
| 1 | 理赔申请书 | 保司 App/官网在线填写或纸质 | — |
| 2 | 被保险人有效身份证件 | 身份证；未成年人用户口本/出生证 | 复印件或影像件（各保司口径不同） |
| 3 | 银行账户信息 | 被保险人本人账户 | — |
| 4 | **医疗费用发票（医疗收费票据）** | 门诊/住院票据；电子票据打印件 | **原则上原件**（见第 3 节） |
| 5 | **费用明细清单** | 住院汇总清单/门诊明细 | 原件或医院盖章件 |
| 6 | **医保结算单/分割单** | 已走医保时；证明医保已报金额 | 原件或盖章件 |
| 7 | 病历资料 | 门诊病历；住院出院小结（出院记录） | 医院盖章件 |
| 8 | 诊断证明书 | 重疾/津贴类必需 | 医院盖章件 |
| 9 | 检查报告/病理报告/手术记录 | 视病种（重疾险尤其重要） | 医院盖章件 |
| 10 | 意外事故说明/证明 | 意外医疗需（何时何地何因）；交通事故责任认定、公安/单位证明 | — |
| 11 | 被保险人关系证明 | 代报案/未成年（监护人）案件 | — |
| 12 | 特药/外购药补充 | 特药服务申请表/处方、病理与基因检测报告、指定药店发票及明细、领药凭证 | — |
| 13 | 残疾/死亡类另需 | 鉴定报告、户口注销/死亡证明 | — |

**提交前自查三件套：发票原件 ＋ 清单 ＋ 病历。** 三缺一是"补件退回"的头号原因。

> **材料要点** [KB-CLAIM-002]：**医保结算单对商保理赔尤其重要**——同时承载"社保身份核验"与"免赔额计算"两项关键信息。缺失结算单可能导致降比例赔付或延迟结案。

> **法律口径**：保险公司不得仅以未提供票据原件为由拒赔；加盖医保公章的票据复印件 + 结算单可作为理赔依据（最高法公报案例、中国法院网案例口径）。

## 2. 理赔流程与时限（通行规则）[KB-CLAIM-010]

```
① 报案（出险后及时通知，App/客服/代理人；部分条款限定 X 日内）
② 索赔材料准备（见第 1 节）
③ 提交索赔（线上影像件/线下原件）
④ 保险公司审核
   ├─ 责任认定（是否属保险责任）
   ├─ 费用核减（是否合理且必要）
   ├─ 社保身份核验
   └─ 免赔额与赔付比例适用
⑤ 核赔结论与给付：达成赔付协议后 10 日内支付；
   情形复杂的，应当自收到请求之日起 30 日内核定
⑥ 不属于责任：核定后发出拒赔通知书并说明理由
⑦ 争议处理（协商 / 调解 / 诉讼）
```

- 依据：《保险法》第 23 条（及时核定、30 日复杂核定时限、达成协议 10 日内履行）；第 26 条：人寿保险以外的保险（含医疗险）**索赔诉讼时效 2 年**，自知道或应当知道保险事故发生之日起算。
- 实操提示：报案并提交材料后可在 App 查进度；补件通知按清单一次性补齐，避免多次往返。

## 3. 发票原件规则——一张原件多处报销怎么办

### 3.1 基本规则

- 报销型产品受**损失补偿原则**约束：累计赔付 ≤ 实际医疗支出。发票是"实际支出"的唯一凭证，所以**谁收原件谁赔钱，赔过的部分不能再赔**。
- 保险公司收取发票原件后通常两种处理：留存归档；或在原件上加盖"**已理赔/已报销**"章后退还。

### 3.2 顺位策略（有医保＋多份商保时）

```
第 1 顺位：基本医保（直接结算，多数地区不收走发票原件）← 几乎永远先走
第 2 顺位：保额最高/比例最优的报销型商保（交原件）
第 3 顺位：剩余商保（交分割单＋盖章复印件，只赔剩余未赔部分）
任意顺位：给付型（重疾/津贴）独立申请，不占原件
```

- 顺序：医保（收原件、出分割单）→ A 保险公司（用原件或盖章复印件，理赔后出具**理赔计算书/分割单并退回盖章复印件**）→ B 保险公司（凭 A 的分割单 + 再盖章复印件）。
- 只有一份原件时：医保用原件；商保凭**医保盖章的票据复印件 + 医保结算单**；交件时主动索要盖章复印件与分割单。
- 津贴型、重疾险与其他公司产品不冲突，可同时申请。

### 3.3 分割单（理赔分割单/医疗保险费用分割单）

- **是什么**：收走发票原件的单位开具的"这张发票总金额 X 元，本方已支付 Y 元，剩余 Z 元由其他机构处理"的分割证明。
- **谁开**：医保手工报销后由**参保地医保经办机构**开具；第一家保险公司赔付后由**该保险公司**开具。
- **不是医院开的**：医院只负责出票、清单、病历，不参与费用分割。
- **怎么用**：分割单 ＋ 发票**复印件加盖红章**（收原件方盖章）＋ 本方理赔决定书（保险公司情形），交给下一顺位保险公司。
- 典型场景：职工医保手工报销（异地未直接结算回参保地报销）后申请商保——向医保经办窗口索取分割单，连同盖章发票复印件提交商保。

### 3.4 电子票据的特殊性

- 财政电子票据与纸质票据同等法律效力（财政部令）；同一票号的电子票据**可反复下载打印**——改变了"原件唯一"的形态。
- 保司通行做法：接受电子票据打印件，部分要求同时提供**验真截图**（pjcy.mof.gov.cn）或电子票据原件文件（PDF/OFD）。
- 由于电子票据"可重复打印"，防重复理赔靠保司间理赔信息联网核查与发票票号登记——**不要心存侥幸重复索赔**，会被识别为欺诈并影响征信与续保（见第 14、15 章）。

## 4. 报销型理赔计算（可执行）

```
[F8] 商保赔付额 = (实际发生合理且必要的医疗费用
                  − 医保统筹基金支付
                  − 其他支付（大病保险等）
                  − 免赔额余额)
                 × 约定赔付比例，受年度保额限制
```

1. 汇总责任内费用 R（按条款逐项判定医院、项目、社保内外、合理性）。
2. 扣除医保统筹、其他支付（大病/救助/补助）已付金额，得剩余责任内费用 R1。
3. 扣除免赔额余额 D（其他商保/单位已补偿可抵扣，社保已付不可抵扣）。
4. 乘赔付比例 p（社保结算因子 + 社保内外因子）：赔付 = (R1 − D) × p。
5. 若已从其他商业保险获赔，按剩余未补偿部分赔付，确保累计 ≤ R。
6. 津贴/重疾：并行定额给付，不进入上述扣减。

## 5. 高频退件/拒赔点（报销型）[KB-CLAIM-020]

| 卡点 | 原因 | 预防/补救 |
| --- | --- | --- |
| 缺费用明细清单 | 只交了发票 | 回医院收费处/自助机补打，理赔撤回补件重申 |
| 缺病历/出院小结 | 没打印 | 病案室打印盖章；门诊病历就诊时向医生索要或诊后补打 |
| 未经医保结算 | 急诊未刷卡/异地未备案 | 商保常按"未经社保"降比例（如 60%）；部分费用仍可回参保地手工报销后再理赔 |
| 免赔额争议 | 不知道免赔额怎么扣 | 理赔前问清：免赔额从"个人负担"还是"现金支付"中扣、年度累计还是单次 |
| 既往症/等待期 | 投保前疾病、等待期内出险 | 属责任范围外，核对条款定义；投保时如实告知是前提 |
| 限社保目录内产品报销自费药 | 条款约定限社保内 | 核对条款"社保目录内/不限社保"表述 |
| 费用不合理 | 超出合理且必要范围 | 保留医嘱与必要性证明 |
| 超保额 | 超过年度/终身保额 | 核对保额与已用额度 |
| 定点医院限制 | 未在约定医院就医 | 核对医院范围；急诊除外条款 |
| 发票抬头/姓名错误 | 录入错误未冲正 | 当场冲正重开（见第 03 章） |
| 拼团/赠险不理赔 | 保障范围与预期不符 | 出险前看清保障责任与免赔 |

**核赔三大关注点** [KB-CLAIM-021]：① **是否属于保险责任**（含责任免除排除）；② **费用是否合理且必要**；③ **社保身份与免赔额**。

**等待期/犹豫期混淆**：犹豫期（可全额退保）与等待期（不赔）是两个概念。

## 6. 给被保险人的时间线建议

1. **就诊前**：确认保单生效、等待期已过；确认医院在保障范围（多数产品要求二级及以上公立医院普通部）。
2. **就诊中**：主动出示医保卡/医保码结算；外购药留处方＋发票；自费项目告知单仔细看。
3. **出院时**：三样单据当场拿齐（发票、结算单、费用明细清单，见第 04 章清单）。
4. **出院后**：报案→备材料→申请；一套材料全部扫描备份后再寄出原件。
5. **获赔后**：保存《理赔决定通知书》；原件被收走的索取分割单，供后续顺位使用。

## 7. 保险代理人/经纪人实务提示 [KB-CLAIM-040]

| 场景 | 建议要点 |
| --- | --- |
| 客户住院前 | 提示**先备案、走医保**，避免未走社保身份被降比例赔付 |
| 客户选择药品/耗材时 | 提示**支付标准与超限价自付**机制，询问是否有替代品种 |
| 客户出院时 | 提示索取**发票 + 费用明细 + 医保结算单**三件套 |
| 客户理赔时 | 核对**免赔额、社保身份、责任范围、目录约定**四项 |
| 客户咨询惠民保 | 提示这是"补充品"而非"替代品"，关注免赔额与限社保目录规则 |

## 8. 医保 + 商保"一站式"结算 [KB-CLAIM-030]

| 模式 | 说明 |
| --- | --- |
| 医保 + 惠民保一站式 | 多地已试点数据打通，出院同步完成两项结算，**无需申请、自动获赔** |
| 医保 + 工伤保险 + 商保一站式 | 有条件的地区探索（政策明确鼓励） |
| 医保个账支付商保保费 | 部分地区支持个人账户为本人及直系亲属缴纳惠民保等保费 |

> **趋势** [KB-CLAIM-031]：政策鼓励探索医保、工伤保险与商保"一站式"结算，"先垫付后报销"的场景将逐步减少。北京已开展医疗电子票据直接用于商业保险理赔的试点。
