# 14 关联制度与基金监管——个税、生育、工伤、长护险、DRG/DIP 与骗保

> 定位：与医疗费用相关但独立于基本医保的制度，以及医保基金监管与合规红线。

---

## 1. 个人所得税大病医疗专项附加扣除 [KB-TAX-001]

### 1.1 政策要点

| 要点 | 内容 |
| --- | --- |
| **扣除项目** | 个税专项附加扣除中的「**大病医疗**」项（《个人所得税专项附加扣除暂行办法》） |
| **扣除依据** | 与基本医保相关的医药费用支出，**扣除医保报销后个人负担**（**指医保目录范围内的"个人自付"部分**） |
| **起扣门槛** | 一个纳税年度内，个人负担累计**超过 15,000 元**的部分 |
| **扣除限额** | 在 **80,000 元**限额内**据实扣除** |
| **办理时点** | 次年 3 月 1 日—6 月 30 日办理**年度汇算清缴**时扣除，数据可由医保系统归集核验（个税 APP） |
| **数据来源** | 全国统一医疗收费票据「其他信息」栏中的「**个人自付**」金额 [KB-TAX-002] |
| **扣除人** | 本人或配偶择一扣除；未成年子女由父母择一扣除；纳税人、配偶、未成年子女的支出**分别计算、分别扣除**（夫妻可同时各扣各的） |

### 1.2 计算式 [KB-TAX-005]

```
可扣除金额 = min( 年度内个人负担的医保目录范围内自付部分累计额 − 15,000 , 80,000 )
（结果 ≤ 0 时不可扣除）
```

### 1.3 三个关键界定 ★ [KB-TAX-010]

| 界定 | 说明 |
| --- | --- |
| **① 只算"目录范围内自付部分"** | 即发票/结算单上的「**个人自付**」口径；**目录外的「个人自费」不计入** |
| **② 只算"与基本医保相关"** | 需为基本医保覆盖范围内的医药费用支出 |
| **③ 累计计算** | 同一纳税年度内多次就医的自付部分**累加**，非单次计算 |

> **制度意义** [KB-TAX-011]：财政部规范**明确要求**将"个人自付"作为信息项在票据上直接列示，正是为纳税人统计和计算大病扣除提供便利，同时防范虚假票据——该字段具有**税务凭证属性**。
>
> **与商保关系**：商业医疗险赔付**不影响**本扣除；以票据"个人自付"栏金额为准（该栏即本项信息项）。

### 1.4 与税优健康险的区分 [KB-TAX-015]

| 对比项 | 大病医疗专项附加扣除 | 税优健康险 |
| --- | --- | --- |
| 扣除依据 | **医疗费用支出**（个人自付） | **保险费支出** |
| 数据来源 | 医疗收费票据「个人自付」栏 | 保单与缴费凭证 |
| 性质 | 专项附加扣除 | 税前扣除 |
| 两者关系 | **可并存**，规则分别适用 |

### 1.5 高频问答 [KB-TAX-020]

| 问题 | 答复 |
| --- | --- |
| 发票"个人自付"能直接用来抵扣吗？ | 是，但需年度累计超 15,000 元的部分、80,000 元限额内 |
| "个人自费"能抵扣吗？ | **不能**，目录外自费不属于该口径 |
| 商保赔款后还能扣除吗？ | 扣除口径核心看票据「个人自付」栏；商保赔款与扣除的衔接按现行税收政策执行，建议咨询税务机关 |
| 只有结算单没有发票怎么办？ | 建议取得医疗收费票据（或电子票据），以「个人自付」栏金额为准 |
| 家庭成员的医疗费用能扣除吗？ | 本人、配偶及未成年子女发生的医药费用支出可按规定扣除（分别计算） |

## 2. 生育保险 [KB-TYPE-200]

### 2.1 参保与缴费 [KB-TYPE-201]

| 要点 | 内容 |
| --- | --- |
| **覆盖范围** | 参加职工基本医保的单位在职职工**同步参加生育保险**，统一征缴、合并计算缴费费率（多地已与职工医保合并征缴） |
| **个人缴费** | **单位职工个人不缴纳生育保险费** [KB-PAY-011] |
| **费率** | 各地不同（如某地 0.5%），由单位缴纳 |
| **灵活就业人员** | 可自愿在参加职工医保时**选择参加生育保险**，参保后享受与职工相同待遇 |
| **领取失业金人员** | 失业保险基金代缴生育保险；生育医疗待遇**无等待期**；申领津贴仍可能需满足连续缴费要求 |
| **财政供养人员** | 部分地区规定生育保险基金**不予支付生育津贴** |
| **居民医保** | 对符合规定的生育医疗给予一次性/定额补助；**无生育津贴** |

### 2.2 生育医疗待遇 [KB-TYPE-205]（医保发〔2025〕20 号方向）

| 项目 | 待遇 |
| --- | --- |
| **产前检查** | 建立覆盖城乡的产前检查费保障制度；对参加基本医保人员门诊产前检查费用实施**定额保障**；部分地区按《门诊产前检查项目基本服务包推荐目录》**不设起付线、全额保障**，超出服务包的项目按门诊统筹政策报销 |
| **住院分娩 / 终止妊娠** | 政策范围内药品、医疗服务项目和医用耗材**不设起付标准**，在限额内**全额保障**（多按定额/限额支付，超出自付） |
| **流产、节育、绝育、复通手术** | 门诊/住院政策范围内合规费用，多**不设起付线**，全额或定额报销 |
| **危急重症孕产妇** | 分娩期间政策范围内医疗费用由基本医保按规定支付 |
| **辅助生殖** | 部分地区已将 **8 项辅助生殖项目**纳入生育保险支付范围（各地放开进度不同） |
| **无痛分娩** | 部分地区已纳入医保支付 |
| **三孩生育** | 相关生育医疗费用同等纳入报销 |

### 2.3 生育津贴 ★ [KB-TYPE-210]

| 要点 | 内容 |
| --- | --- |
| **性质** | 对女职工产假期间**收入损失**的补偿，**非医疗费用报销**（产假工资性质，不重复领取） |
| **计算公式** | `生育津贴 = 单位上年度职工月平均工资 ÷ 30 × 计发天数` |
| **新成立单位** | 上年度无征缴记录的，按公司所在地上年度**全口径城镇单位就业人员月平均工资** ÷ 30 × 计发天数 |
| **灵活就业/农民工/新就业形态** | 计发基数同本人参加职工基本医保的缴费基数 |
| **申领条件** | 生育前**连续缴费满一定期限**（原则上**不超过 12 个月**），生育时正常参保 |
| **计发天数** | 顺产 98 天；难产/剖宫产 +15 天；多胞胎每多 1 个婴儿 +15 天；怀孕未满 4 个月流产 15 天；满 4 个月流产 42 天 |
| **免申即享** | 部分地区定点医院分娩、出院完成医保联网结算后，系统自动校验资格并核算津贴，约 10 个工作日拨付 |
| **不享受津贴的情形** | ① 仅参加城乡居民医保；② 连续缴费不足规定期限；③ 部分地区对财政供养人员 |

**算例** [EX-015]：单位上年度职工月平均工资 8,000 元，顺产 → 津贴 = 8,000 ÷ 30 × 98 ≈ **26,133.33 元**；剖宫产（113 天）≈ **30,133.33 元**。

### 2.4 男职工生育待遇 [KB-TYPE-215]

| 情形 | 待遇 |
| --- | --- |
| 男职工本人实施计划生育手术 | 相关医疗费用和生育津贴可按规定享受 |
| 男职工配偶（未就业） | 参照城乡居民医保享受生育医疗费用待遇；配偶参加居民医保的，生育医疗费用政策范围内个人自付部分由财政补助；未参加的不补助 |
| 男方职工医保 + 女方居民医保 | 女方住院分娩可按居民医保报销目录内费用 |

> **生育保险领域专项违规** [KB-SUP-011]：伪造证明材料"造假申领"津贴、虚构劳动关系"挂靠参保"、虚报缴费基数"抬高待遇"骗取更高津贴——均属骗保（见第 6 节）。

## 3. 工伤保险医疗 [KB-TYPE-220]

| 要点 | 内容 |
| --- | --- |
| **支付主体** | **工伤保险基金**（由用人单位缴纳，职工不缴） |
| **适用目录** | 工伤保险诊疗项目目录、药品目录、住院服务标准 |
| **覆盖范围** | 治疗工伤所需的挂号费、医疗康复费、药费、住院费等（合规费用**全额支付、个人不担比例**）、工伤康复、住院伙食补助、跨统筹区就医交通食宿、辅助器具配置 |
| **与基本医保的关系** | **基本医保不予支付**（《社会保险法》第 30 条第 1 项）；同一费用不得工伤、医保重复报销 |
| **甲乙类限制** | 工伤保险支付**不受甲乙类限制** |
| **认定前提** | 需先经**工伤认定**（工伤认定决定书）；经劳动能力鉴定丧失劳动能力的，享受伤残待遇 |
| **单位承担** | 停工留薪期工资福利、护理等；伤残按等级发伤残津贴/一次性伤残补助金等 |

**算例** [EX-022]：职工工作受伤住院 30,000 元 → 工伤认定 → 工伤保险基金支付（工伤目录内全额），基本医保不支付。

## 4. 长期护理保险（长护险）

- 2026 年中办、国办印发《关于加快建立长期护理保险制度的意见》，由试点转向制度建立。
- **保障对象**：按规定参保缴费、失能状态长期持续（一般 6 个月以上）、经申请评估认定的失能人员；起步阶段保障**重度失能**，逐步扩大到中度。
- **服务目录**：全国统一 **36 项**——20 项生活照护类（协助进食/沐浴/口腔清洁等）＋ 16 项基础医疗护理类（吸痰/导尿等）。
- **支付**：机构护理按床日、居家护理按服务时长，基金按比例/定额支付，个人承担剩余。
- 定位：**不是医疗费用报销，不替代医保**；结算单为长护险费用结算单（第 01 章票据全谱第 10 项）。

## 5. DRG / DIP 支付方式改革对个人费用的影响 [KB-CLASS-060]

- **DRG（按疾病诊断相关分组）/ DIP（按病种分值）**：医保对医疗机构按病组/病种**打包付费**，超支医院自担、结余留用。另有按床日（长期住院、精神科）、按病种（日间手术）、按人头（基层门诊）等打包方式。
- **对患者**：仍按实际发生项目取得收费票据、按当地医保待遇结算（起付线、比例、封顶线不变）；**医院不得因打包付费将合规费用转嫁给患者、降低服务或分解住院/推诿重症**。
- **打包付费定额的归属**：按病种、病组、床日等打包付费方式且**由患者定额付费**的费用，计入「**个人自付**」（财政部规范明确）。
- 个人自付通常更可预期；出现医院要求自费外购本应由院内保障的药品耗材、或让未达出院标准患者出院，可向医保部门投诉。
- **商保创新药目录内药品**：不计入 DRG/DIP 病种付费考核、不计入自费率考核与集采监测，以鼓励创新药使用 [KB-CLASS-062]。

## 6. 特殊与新型服务 [KB-TYPE-250]

| 类型 | 报销情况 |
| --- | --- |
| **互联网医院复诊** | 部分地区纳入医保支付（限复诊、限常见病慢性病） |
| **上门服务 / 家庭病床** | 视当地政策，部分纳入 |
| **特需医疗（特需门诊/特需病房）/ 国际部 / VIP 病房** | 一般**不予支付**（高端医疗险可覆盖） |
| **健康管理服务** | 一般不予支付 |
| **长期护理保险服务** | 由长护险制度覆盖，不属基本医保 |
| **安宁疗护** | 部分地区纳入 |
| **互联网+药品配送** | 药费按药品目录，配送费一般自费 |

## 7. 医保基金监管与合规 [KB-SUP-001]

### 7.1 监管法规体系

| 层级 | 文件 | 关键内容 |
| --- | --- | --- |
| **法律** | 《社会保险法》第 88 条 | 以欺诈、伪造证明材料或其他手段骗取社保待遇的，责令退回，处**骗取金额二倍以上五倍以下**罚款 |
| **法律** | 《刑法》第 266 条 | 诈骗公私财物数额较大处 3 年以下；数额巨大 3—10 年；数额特别巨大 10 年以上或无期 |
| **行政法规** | 《医疗保障基金使用监督管理条例》（国务院令第 735 号） | 基金使用、监督检查、法律责任 |
| **规范性文件** | 医保待遇清单制度 | 明确基金不予支付清单 |

### 7.2 违规情形清单 [KB-SUP-010]

**（1）定点医药机构常见违规**：分解住院（一次住院拆多次、重复收起付线）、挂床住院、过度诊疗、超标准收费、重复收费、串换项目（不可报串换为可报）、虚记费用、诱导住院。

**（2）参保人常见违规**：

| 类型 | 具体表现 |
| --- | --- |
| 冒名就医 | 使用他人医保卡/医保码就医（"钱可以共济，卡不能共用"） |
| 转卖药品 | 骗取医保药品后倒卖 |
| 伪造票据 | 伪造、变造医疗收费票据骗取报销 |
| 重复报销 | 同一费用重复向医保、商保、单位报销 |
| 虚开票据 | 与机构合谋虚开医疗费用 |

**（3）生育保险领域专项违规** [KB-SUP-011]：造假申领津贴、挂靠参保、虚报缴费基数（见第 2 节）。

### 7.3 法律责任 [KB-SUP-020]

| 责任类型 | 内容 |
| --- | --- |
| **行政责任** | 责令退回骗取金额；处**2—5 倍**罚款；暂停联网结算；解除服务协议 |
| **刑事责任** | 骗取医保基金数额较大的，可能构成**诈骗罪**（刑法第 266 条） |
| **信用责任** | 纳入失信名单，影响信用记录 |

> **提示** [KB-SUP-021]：**提供虚假备案材料**（含异地就医承诺制备案）造成基金损失的，按《医疗保障基金使用监督管理条例》等处理。
