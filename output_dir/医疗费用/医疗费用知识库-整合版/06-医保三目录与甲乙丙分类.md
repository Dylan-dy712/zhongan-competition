# 06 医保三目录与甲乙丙分类——"哪些能报"的底层规则

> 定位：搞懂"政策范围内费用"，这是所有报销比例的前提。覆盖药品目录（2025 版）、目录调整机制、支付标准、限定支付、双通道、商保创新药目录、诊疗项目、耗材与服务设施。
> 边界：药品目录国家统一、每年动态调整（现行为 2025 版，2026-01-01 执行）；诊疗项目与医疗服务设施由各省（统筹区）细化。具体项目以"国家医保服务平台"APP 查询结果与当地医保局口径为准。

---

## 1. 三目录：医保的"菜单"

基本医保能报什么，由三张目录决定：

| 目录 | 管什么 | 制定层级 |
| --- | --- | --- |
| ① **药品目录**（国家基本医疗保险、工伤保险和生育保险药品目录） | 能报的药品 | **国家统一**，每年调整（含西药、中成药、中药饮片、协议期内谈判药品） |
| ② **诊疗项目目录**（医疗服务项目） | 能报的检查、治疗、手术等 | 国家框架 + 各省细化（含排除项与部分支付项） |
| ③ **医疗服务设施标准** | 住院床位、留观床位等服务设施 | 各省规定（限额内报，超标自费） |

（医用耗材目录：国家定政策，**省级**确定目录，常并入"三目录"表述中一起讲。）

不在三目录内 ⇒ **全自费**（俗称"丙类"——注意：**官方目录只有甲、乙两档，"丙类"是行业俗称**）。

**目录管理的制度逻辑** [KB-COV-001]：目录内费用由医保基金与患者个人按比例分担；目录外费用医保基金一律不予支付。实行目录管理的理由：① 防止"福利陷阱"；② 坚持"保障基本"，遏制过度医疗；③ 提高基金购买效益，促进"三医"协同 [KB-COV-002]。

**三种技术方法** [KB-COV-003]：**准入法**（明列可报清单，如药品目录）、**排除法**（明列不报情形，如部分诊疗项目）、**负面清单**（法定禁止情形，如《社会保险法》第 30 条）。

**权限划分** [KB-COV-004]：
- 药品目录：国家统一制定并动态调整（原则上每年一次）；省级可增补民族药、医疗机构制剂、中药饮片。
- 医用耗材目录、医疗服务项目目录：国家定政策，**原则上由省级医保部门**采取准入法与排除法确定。
- 医疗服务设施标准：各省制定。

## 2. 药品目录（第一目录）

### 2.1 目录构成与规模（2025 版）[KB-COV-030]

| 指标 | 2025 版数据 |
| --- | --- |
| 目录内药品总数 | **3,253 种** |
| 其中：西药 | 1,857 种 |
| 其中：中成药 | 1,396 种 |
| 本轮新增 | **114 种**（其中 50 种为 1 类创新药；111 个为 5 年内新上市品种，占 97.3%） |
| 本轮调出 | 29 种（临床无供应或可被更好替代） |
| 协议期内谈判药品 | **472 个**（西药 411 个、中成药 61 个） |
| 中药饮片 | 另有单独目录（近年口径约 890 余种） |
| 执行时间 | **2026 年 1 月 1 日**全国执行（2024 版同时废止） |
| 调整次数 | 国家医保局成立以来**第 8 次**调整 |

**新增药品领域分布** [KB-COV-031]：114 种新增中，36 个肿瘤用药、12 个糖尿病等慢性病用药、10 个罕见病用药，重点提升恶性肿瘤、慢性病、罕见病、儿童用药保障水平。

**过渡期安排** [KB-COV-032]：对续约失败被调出的谈判药品，给予 **6 个月过渡期**（2026 年 6 月底前医保基金按原支付标准继续支付）；2025 年 12 月 31 日前住院并使用 2024 版目录药品的，在本住院周期内可继续按规定支付（部分地区规定最长截止 2026 年 1 月 31 日）。

### 2.2 甲类 / 乙类 / 丙类判定 ★ [KB-COV-035]

| 类别 | 官方定义 | 支付规则 | 患者负担结构 | 通俗理解 |
| --- | --- | --- | --- | --- |
| **甲类** | 临床治疗**必需**、使用**广泛**、疗效确切、同类药品中价格或治疗费用**较低** | **全额**纳入政策范围，再按当地比例报销，**无先行自付** | 只承担"报销比例之外"的部分 | "直接按比例报" |
| **乙类** | 可供临床治疗**选择使用**、疗效确切、同类药品中比甲类价格或治疗费用**略高** | **先自付一定比例**，剩余部分纳入再按比例报销 | 先行自付（自付二）＋ 比例自担（自付一） | "先自付一小部分，剩下的再按比例报" |
| **目录外（俗称丙类）** | 未进入药品目录 | 医保基金**一分不报** | 全额自费 | "完全自费" |

甲/乙分类适用于目录内的**西药和中成药**；中药饮片采用专家评审方式调整、单独管理 [KB-COV-036]。

**重要例外与补充规则** [KB-COV-037]：
1. **谈判药品统一按乙类支付**（协议期内）；
2. **工伤保险和生育保险**支付**不受甲/乙类限制**，保障范围更灵活；
3. 乙类先行自付比例**由各统筹区确定**并逐步规范统一，**不区分险种和类别**；全国无统一比例，**常见约 10%，区间约 3%–30%**（深圳市内乙类药品/项目约 1%；湖北已全省统一为 10%，中药配方颗粒 20%；进口耗材更高）；
4. 中药饮片常见按**甲类**报销；中药配方颗粒常见按**乙类**管理；
5. 支付前提：须凭医生处方或住院医嘱；药品"备注栏"含**限定支付范围**（见 2.6）。

### 2.3 目录调整机制（五环节）[KB-COV-040]

国家医保局建立**动态调整机制，原则上每年调整一次**，流程五大环节：

| 环节 | 时间（参考） | 主要工作 |
| --- | --- | --- |
| ① 准备阶段 | 年初 | 组建工作专班；修改申报指南；制定规则；信息化系统调试 |
| ② 申报阶段 | 6 月起 | 企业申报 → **形式审查** → 结果**公示**（接受意见并复核）→ 正式公告 |
| ③ 评审阶段 | 7—8 月 | 综合组与专业组专家逐个药品评审；对拟纳入商保目录的药品组织商保专家专门评审 |
| ④ 测算谈判阶段 | 8—9 月 | 企业提交资料 → 抽取测算专家 → **医保测算与商保评估** → 一对一沟通 → **现场谈判/竞价/价格协商** |
| ⑤ 公布阶段 | 11 月下旬 | 编排新版目录并发布 |

> **形式审查的效力** [KB-COV-041]：通过形式审查**只代表符合申报条件、具备参与后续流程的资格，不代表已纳入目录**。高频误读点。
> **公示内容** [KB-COV-042]：公示药品基本信息、有效性、安全性、创新性、公平性（**不含经济性**）及摘要幻灯片。

**目录内药品的评审意见类型** [KB-COV-043]：目录外药品 → 拟谈判调入（独家）/ 拟竞价调入（非独家）/ 拟直接调入（集采和政府定价范围内）/ 未通过；目录内药品 → 拟纳入常规目录 / 拟调出 / 拟简易续约 / 拟谈判续约。

### 2.4 准入方式四种 [KB-COV-045]

| 准入方式 | 适用对象 | 特点 |
| --- | --- | --- |
| **谈判准入** | **独家药品** | 通过准入谈判确定支付标准；"以价换量" |
| **竞价准入** | **非独家药品**（非集采中选） | 企业准入竞价确定支付标准 |
| **直接调入** | 国家**集中带量采购中选药品**、**政府定价药品** | 经专家评审后可直接纳入 |
| **续约** | 目录内协议期届满谈判药品 | 简易续约 / 谈判续约 |

> 执行政府定价的**麻醉药品和第一类精神药品**，支付标准按政府定价确定 [KB-COV-046]。

### 2.5 支付标准体系 [KB-COV-048]

| 规则 | 内容 |
| --- | --- |
| **同步确定** | 除中药饮片外，新纳入目录的药品**同步确定支付标准** |
| **谈判药品** | 执行**全国统一的医保支付标准** |
| **集采中选药品/耗材** | 以**中选价格**作为支付标准 |
| **价格与支付标准的关系** | 实际价格**高于**支付标准的，**超出部分由参保人承担**；**低于**支付标准的，**按实际价格和医保规定报销** |
| **挂网要求** | 谈判药品挂网价**不高于支付标准**；竞价药品在支付标准有效期内挂网价不高于竞价报价 |

> **实务含义** [KB-COV-049]：这是"**超限价自付**"产生的制度根源——选择单价高于医保支付标准的药品/耗材时，差额即为超限价自费/分类自负，计入个人负担（见第 08 章）。

### 2.6 限定支付范围 ★ [KB-COV-060]

**核心规则**：**只有诊断、治疗与病情相符，符合药品法定说明书适应症及医保限定支付范围的，方可支付**。

| 限定类型 | 说明 | 举例方向 |
| --- | --- | --- |
| **适应症限定** | 仅限特定疾病/病理类型 | 抗肿瘤药限定病理类型 |
| **治疗线数限定** | 仅限一线/二线及以后治疗 | 部分靶向药 |
| **人群限定** | 限儿童/限成人/限特定人群 | 儿童专用剂型 |
| **险种限定** | 限工伤保险/限生育保险 | 部分骨科材料 |
| **医疗机构等级限定** | 限二级及以上医疗机构使用 | 部分高值药品 |
| **疗程/剂量限定** | 限支付疗程或剂量 | 部分生物制剂 |
| **联合用药限定** | 限与特定药物联用 | 部分方案性用药 |

**典型案例** [KB-COV-062]：司美格鲁肽、替尔泊肽等 GLP-1 类药物——**医保报销仅限糖尿病相关适应症，减重用途不在医保支付范围内**。

> **应答要点** [KB-COV-063]：「药品在目录内」≠「一定可报」。必须叠加"**适应症/限定支付范围**"校验。这是医保审核与商业保险核赔的**常见拒付点**。

**调整规则** [KB-COV-064]：缩小限定支付范围、或扩大但对基金影响较小的，可直接调整；扩大且影响较大的，需提交药物经济学等资料。

### 2.7 中药饮片、医疗机构制剂、民族药 [KB-COV-065]

| 类别 | 管理方式 | 支付规则 |
| --- | --- | --- |
| **中药饮片** | 专家评审方式调整，另有单独目录 | 常见按**甲类**报销，无个人先行自付（部分饮片不予支付） |
| **中药配方颗粒** | 纳入省级管理 | 常见按**乙类**管理，先行自付比例较高（如 20%） |
| **医疗机构制剂** | 省级医保部门可按权限和程序纳入本地支付范围 | 按省级规定 |
| **民族药** | 同上 | 按省级规定 |

### 2.8 商保创新药目录 ★ [KB-COV-075]

| 维度 | 内容 |
| --- | --- |
| **设立依据** | 2025-06-30 国家医保局会同国家卫健委《支持创新药高质量发展的若干措施》，提出**增设商业健康保险创新药品目录** |
| **定位** | 重点纳入**创新程度高、临床价值大、患者获益显著且超出基本医保保障范围**的创新药，推荐商保、医疗互助等多层次保障体系参考使用 |
| **医保支付** | **基本医疗保险不予报销** |
| **首版规模** | **19 种**药品，覆盖 **18 家**创新药企，其中 **9 个**为 1 类新药 |
| **覆盖领域** | **5 款 CAR-T** 产品全部入围；神经母细胞瘤、戈谢病等罕见病治疗药品；阿尔茨海默病治疗药品 |
| **落地政策** | ① 挂网、配备**参照医保谈判药品**执行；② **不纳入**医疗机构基本医保**自费率指标**；③ **不纳入集采**中选可替代品种监测范围；④ **不计入 DRG/DIP 的病种付费考核** |
| **与基本医保的关系** | **互补衔接、错位发展**："基本医保保基本、商保目录保创新"的分工格局正式制度化 |
| **配套机制** | 支持商保机构据目录设计新产品；鼓励有条件地区探索医保、工伤保险与商保"**一站式**"结算 |
| **查询渠道** | 国家医保局微信公众号"微服务"→"商保创新药目录查询" |

### 2.9 双通道管理 [KB-COV-080]

| 维度 | 内容 |
| --- | --- |
| **定义** | 纳入"双通道"管理的**国家医保谈判药品（国谈药）**，可通过**定点医疗机构 + 定点零售药店**两个渠道购买，执行**相同医保支付政策（同报销比例）** |
| **目的** | 解决谈判药品"进院难"，提升可及性 |
| **处方流转** | 必须通过**电子处方中心**流转"双通道"药品处方（责任医师开具） |
| **准入范围** | ① 协议期内国谈药；② 与谈判药**同通用名、同剂型、同规格**的药品；③ 谈判药转乙类常规药品的（部分地区继续纳入） |
| **起付标准** | 部分地区对门诊使用双通道药品单独设起付标准（如某地 500 元/年），并与门诊慢特病、普通门诊统筹年度起付标准**合并计算** |
| **地方数量示例** | 福建双通道药品 603 种；漯河执行 361 种特药待遇 [地区数值] |
| **结算示例** | 漯河职工特药不设起付线、统筹支付约 85% [地区数值] |
| **跨省** | 不能直接结算时，凭备案表、处方、药店票据回参保地手工报销 |

**门诊特药（特定药品）资格管理**：对象为治疗癌症、罕见病等重特大疾病、临床必需、价格高、适于门诊使用的国谈药。流程：**特药资格认定 → 选定 1 家特药定点医疗机构（或 1 家双通道药店 + 1 家处方医院，原则上同一统筹区）→ 责任医师按取药周期开电子处方 → 购药直接结算**。定点医院与双通道药店执行统一支付标准。

> **对患者的意义** [KB-COV-081]：医院没药时，凭电子处方到"双通道"定点药店购药同样享受医保报销，避免全额自费。

## 3. 诊疗项目（医疗服务项目）目录 [KB-COV-090]

按支付政策分**三类**：

| 类别 | 支付规则 | 常见示例 |
| --- | --- | --- |
| **全额统筹项目（甲类）** | 全部纳入统筹支付，按比例报销 | 常规诊察、血常规等基础检查 |
| **部分统筹项目（乙类）** | 个人先负担一定比例后再纳入统筹 | 部分大型设备检查（CT、MRI、PET-CT 等）、特殊治疗 |
| **范围外项目（丙类）** | 医保不予支付，全额个人负担 | 美容整形、非疾病必需项目、特需服务 |

**典型不予支付（丙类）诊疗项目**（国家通用口径，各地目录略有增减）：
- **服务项目类**：挂号费（诊察费另有规定）、院外会诊费、病历工本费；出诊费、检查治疗加急费、点名手术附加费、优质优价费、自请特别护士等特需医疗服务。
- **非疾病治疗类**：美容、健美、非功能性整容矫形、减肥、增胖、增高；健康体检；预防、保健性诊疗；各种咨询、鉴定（医疗鉴定、司法鉴定）。
- **诊疗设备及材料类**：PET、电子束 CT 等大型设备检查（部分地区特定情形除外）；眼镜、义齿、义眼、义肢、助听器等康复性器具；自用保健理疗设备；未列入限定支付范围的一次性医用材料。
- **治疗项目类**：各类器官/组织移植的器官源/组织源（除特定规定）；除肾脏、心脏瓣膜、角膜、皮肤、血管、骨、骨髓移植外的其他器官/组织移植；近视眼矫形术；气功、音乐、保健性营养疗法、磁疗等辅助治疗。
- **不育（孕）症、性功能障碍治疗、科研/临床验证性诊疗**。
- 部分项目各地有放开（如部分 PET-CT、辅助生殖纳入地方医保），以当地最新目录及限定支付为准。

## 4. 医用耗材目录 [KB-COV-095]

| 要点 | 内容 |
| --- | --- |
| **管理权限** | 国家定政策，**省级**确定目录 |
| **分类** | 可报销 / 部分报销（先行自付）/ 不予支付 |
| **集采影响** | 集采中选耗材以**中选价格**为支付标准，价格显著下降 |
| **超限价** | 实际价格高于支付标准的部分由参保人承担；低于的按实际价格报销 |
| **高值耗材** | 常见设支付限额 + 较高先行自付比例（支架、关节、晶体等） |
| **进口 vs 国产** | 若均在目录内，报销规则一致；部分地市对进口材料设更高先行自付比例（示例口径：国产/合资先自付约 20%、进口先自付约 50%，武威旧规 [地区数值]，各地不同） |

## 5. 医疗服务设施目录 [KB-COV-098]

覆盖住院等环节的**服务设施与环境**，以"**必需、适量**"为原则：
- 纳入：住院床位费、门（急）诊留观床位费——按**当地标准限额**报销；超标差额（三人间升单人间、特需病房、高干病房、国际部差价）自付。
- **不予支付的生活服务项目和设施**（劳社部发〔1999〕22 号，五类）：
  1. 就（转）诊交通费、急救车费；
  2. 空调费、电视费、电话费、婴儿保温箱费、食品保温箱费、电炉费、电冰箱费及损坏公物赔偿费；
  3. 陪护费、护工费、洗理费、门诊煎药费；
  4. 膳食费；
  5. 文娱活动费及其他特需生活服务费用。
  （各地目录略有增减。）

## 7. "政策范围内费用"（合规费用）的构成

```
政策范围内费用 = 甲类费用全额
             ＋ 乙类费用 × (1 − 先行自付比例)
             ＋ 符合规定的诊疗项目与服务设施费用
（目录外费用、乙类先行自付部分均不在其中）
```

报销公式（见第 07 章）作用在"政策范围内费用"上，而不是发票"合计"上。

## 8. 怎么查一个项目能不能报

1. **药品**：国家医保服务平台 APP → "药品目录查询" → 输入药品名（**通用名**）→ 显示甲/乙类、支付限定、协议期。
2. **诊疗项目/耗材**：部分省份在"国家医保服务平台"或省医保 APP/小程序开放查询；拿不准时问医院医保办（每个医院都设有医保办公室，患者可直接咨询窗口）。
3. **医院端确认**：住院时可要求医生/医保办预估"目录内外大致比例"，出院清单会逐项标注。
4. **看结算单标注**：无自付/有自付/全自付，最直接。
5. **通用名 + 剂型双匹配** [KB-CLASS-030]：同通用名不同剂型可能分类不同。

## 9. 与商保的接口

商业医疗险按"是否受医保目录限制"分两类产品形态（详见第 10 章）：
- **限社保内**：只对"政策范围内费用"产生的个人自付部分赔付——自费部分不赔。
- **不限社保**：自付＋自费都在赔付范围内（百万医疗险普遍卖点，但有免责与免赔额）。
- **扩展社保外药品/特定药品清单**：仅限条款附列的特定药品清单。
- 发票/清单上的"自费"栏金额，就是判断"不限社保"条款价值的直接依据。

## 10. 医保待遇清单制度 [KB-COV-115]

| 要点 | 内容 |
| --- | --- |
| **制度目的** | 统一规范全国医保待遇范围，防止各地"超范围保障"造成基金风险 |
| **主要内容** | ① 基本制度清单（基本医保、大病保险、医疗救助）；② 基本政策清单（待遇项目、支付范围）；③ **不予支付清单**（负面清单） |
| **与三目录的关系** | 待遇清单是"**制度级**"边界，三目录是"**项目级**"边界，二者叠加构成完整报销边界 |
