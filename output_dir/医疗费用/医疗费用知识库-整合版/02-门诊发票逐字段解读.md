# 02 门诊发票逐字段解读

> 定位：拿到一张"医疗门诊收费票据"，从上到下每个字段是什么意思、怎么对账。
> 边界：字段名称与列示顺序以财综〔2019〕29 号统一式样为基准，各统筹区省版票据措辞略有差异；文中数字均为**虚构示例**，仅演示读法。

---

## 1. 门诊票据长什么样（结构分区）

```
┌────────────────────────────────────────────┐
│ 票据代码：xxxxxxxx  票据号码：xxxxxxxx  校验码：xxxx │ ← 验真三件套
│ （省财政厅监制章）     医疗门诊收费票据                │
├────────────────────────────────────────────┤
│ 姓名：张三  性别：男  医保类型：城镇职工基本医疗        │ ← 患者信息区
│ 社会保障号码：xxxxx  门诊号：xxxxx                  │
├────────────────────────────────────────────┤
│ 项目            金额(元)                          │ ← 收费项目区
│ 一般诊疗费        10.00                           │
│ 检查费           230.00                           │
│ 西药费           156.40                           │
│ 合计（大写）：叁佰玖拾陆元肆角    （小写）￥396.40    │ ← 金额区
├────────────────────────────────────────────┤
│ 医保统筹基金支付：180.00  其他支付：0.00           │ ← 医保结算区
│ 个人账户支付：116.40                              │
│ 个人自付：166.40  个人自费：50.00                  │
│ （个人现金支付：100.00）                           │
├────────────────────────────────────────────┤
│ 收款单位：XX医院（章）  收款人：xxx  日期：2026-..   │ ← 落款区
└────────────────────────────────────────────┘
```

## 2. 逐字段解释

### 2.1 票头字段（验真三件套）[KB-FIELD-001]

| 字段 | 定义 | 取值/格式 | 常见误读 |
| --- | --- | --- | --- |
| **票据名称** | 票据类别标识 | 「医疗门诊收费票据」或「医疗住院收费票据」 | 误以为两者通用 |
| **票据代码** | 按财政票据编码规则编制，标识种类、年度、地区 | 串号；位段规则以当地财政票据管理机构为准 | 误当票据号码使用 |
| **票据号码** | 本份票据的**唯一流水编号**（财政票据系统生成，跨机构唯一） | 串号 | 与"业务流水号"混淆 |
| **校验码** | 电子票据用于官方平台验证真伪的校验字符串 | 字符串；位数以票据为准 | 误认为密码 |

- 商保理赔或单位报销核查真伪时，在财政部全国财政电子票据查验平台（pjcy.mof.gov.cn）或省财政厅平台输入这三项即可验证；电子票据上通常还有二维码，扫码直达验真。
- **票据号码 ≠ 业务流水号** [KB-FIELD-002]：票据号码由财政票据系统生成（跨机构唯一）；业务流水号由医疗机构收费系统生成（院内流水），用于院内查询对账。

### 2.2 主体信息区（患者信息字段）[KB-FIELD-010]

| 字段 | 权威定义 | 取值规则 | 实务要点 |
| --- | --- | --- | --- |
| **交款人（姓名）** | 支付医疗费用的一方 | 患者本人/家属/单位；**与参保人可能不一致** | 必须与参保人/被保险人一致，打错当场要求作废重开 |
| **交款人证件号/统一社会信用代码** | 按规定填列患者有效证件号码（如身份证号），**隐去涉及隐私的部分字段** [KB-FIELD-011] | 脱敏串号 | 商保核验被保险人身份时使用 |
| **性别** | 患者性别 | — | — |
| **医保类型** | 参保类别 [KB-FIELD-014] | ① 职工基本医疗保险；② 城乡居民基本医疗保险（含原城镇居民、新农合）；③ 其他医疗保险/离休/自费 | 决定适用哪套待遇政策；**自费结算（未用医保）商保理赔常降比例**（见第 10 章） |
| **社会保障号码/医保编号** | 参保人在医保系统中的唯一标识 [KB-FIELD-015] | 一般为身份证号（有的省版印作"医保编号"） | 商保"社保身份"核验、理赔比对用 |
| **门诊号/就诊卡号** | 在该医院的就诊档案号 | 串号 | 院内查询 |
| **业务流水号** | 收费系统自动生成 [KB-FIELD-013] | 串号 | 院内对账 |
| **收款单位（医疗机构名称）** | 开具票据的医疗卫生机构 | 机构规范全称 | 应与实际就诊机构一致，是判断"是否定点"的依据之一 |
| **医疗机构类型** | 按《医疗机构管理条例实施细则》确定的类别 [KB-FIELD-012] | 综合医院/专科医院/社区卫生服务中心/乡镇卫生院等 | **直接影响报销比例**（等级越高比例越低） |
| **开票日期** | 票据开具日期 | 日期 | 商保理赔时效、个税扣除**年度归属**的依据 |

### 2.3 收费项目区（门诊常见大类，逐项详解）[KB-FIELD-020]

| 项目大类 | 包含什么 | 通俗解释 | 报销共性 |
| --- | --- | --- | --- |
| 挂号费 / 一般诊疗费 | 挂号、门急诊留观诊查；基层打包收费（含挂号、诊查、注射） | 基层打包收费；大城市三甲多为"医事服务费"（北京等）或"诊察费" | 多数地区可报；基层常设单次定额 |
| 诊查费 / 医事服务费 | 医师问诊劳务 | 医生"看病"本身的收费 | 属医疗服务项目，一般可报 |
| 检查费 | 影像与仪器检查：CT、MRI、X 线、B 超、心电、内镜、造影 | "查"的费用 | 分全额/部分统筹；大型设备检查常需先行自付 |
| 化验费 | 实验室检验：血/尿/便常规、生化、免疫、微生物、标志物、合规基因检测 | "验"的费用 | 多为全额统筹 |
| 治疗费 | 注射、输液、换药、吸氧、理疗、透析、放化疗操作、康复、清创 | 处置操作类 | 分全额/部分统筹 |
| 手术费 | 门诊小手术（体表肿物切除、清创缝合等），含麻醉、术中监测 | 手术操作 | 按诊疗项目目录 |
| 卫生材料费 | 一次性耗材（纱布、石膏、留置针、注射器）＋植入/介入材料 | 一次性耗材 | 按耗材目录；高值耗材需先行自付 |
| 西药费 | 化学药、生物制品（含靶向药、免疫制剂） | 药费大头 | 按甲/乙/丙类 |
| 中成药费 | 中成药 | — | 按甲/乙/丙类 |
| 中药饮片 | 中草药饮片（29 号文口径写作"中草药费"） | 代煎费可能单列"其他" | 常见按甲类（部分饮片不予支付） |
| 其他费 | 输氧、输液、煎药、救护车等杂项 | — | 视项目，多为自费或限额 |

> **注意**：票据上只显示**大类金额**，每个大类的具体明细（药名、规格、数量、单价、甲乙丙属性）在配套的"**费用明细清单**"上（见第 04 章）。

### 2.4 金额区

- **合计金额（数字小写＋汉字大写）**：本次就诊应收总额（政策内＋目录外全部在内）。大写与小写必须一致。

### 2.5 医保结算区（核心，虚构示例）

合计 396.40 元：

| 字段 | 示例值 | 含义（详见第 08 章） |
| --- | --- | --- |
| 医保统筹基金支付 | 180.00 | 医保基金实报的部分，即"医保报了 180" |
| 其他支付 | 0.00 | 大额医疗/大病保险、公务员医疗补助、医疗救助等基金性支付（部分省版单列明细） |
| 个人账户支付 | 116.40 | 从本人医保卡个人账户里扣的钱。**这是自己的钱，不是报销** |
| 个人自付 | 166.40 | 目录内、按政策必须个人承担的部分（起付线/乙类先行自付/按比例自担） |
| 个人自费 | 50.00 | 完全在医保目录外、全自费的部分 |
| 个人现金支付 | 100.00 | 以现金/银行卡/移动支付实付的金额 |

**对账恒等式**（应恒成立，对不上先找医院收费处核对）：

```
[F1] 合计 = 统筹支付 + 其他支付 + 个人账户支付 + 个人现金支付   （按"钱从哪里出"切分）
[F3] 合计 = 统筹支付 + 其他支付 + 个人自付 + 个人自费            （按"医保要不要管"切分）
[F2] 个人账户支付 + 个人现金支付 = 个人自付 + 个人自费 = 个人负担
```

示例验算：180.00＋0＋116.40＋100.00＝396.40 ✓；180.00＋166.40＋50.00＝396.40 ✓

> 两套切分的交点：**个人负担总额＝自付 166.40＋自费 50.00＝216.40 元**，其中个人账户出了 116.40、现金出了 100.00。"医保卡里刷的钱"本身就是个人负担的一部分。若"账户＋现金"与"自付＋自费"对不上，先找医院收费处或以医保结算单核对，**不要自行推算**。

### 2.6 落款区

- **收款单位＋收费专用章/财务专用章**：无章无效（电子票据为电子签章，验真时可核验）。
- **收款人、复核人、开票日期、备注**：商保理赔、医保手工报销均对**费用发生/结算日期**有时限要求，妥善留存。

## 3. 读门诊发票的三步法

1. **先看合计**：这次总共花了多少。
2. **再看统筹支付**：医保实报了多少；合计减统筹（及其他支付）就是自己负担（含账户里的钱）。
3. **最后对现金**：真正当时掏出去的钱是多少；同时把"自费"那栏圈出来——目录外花了多少，直接决定商保"不限社保"条款的价值（见第 10 章）。

## 4. 门诊常见疑问

- **为什么挂号费也要单独一张票？** 部分医院挂号时先出挂号费凭证，就诊后缴费再出正式门诊票据；商保理赔以正式"医疗门诊收费票据"为准。
- **同一天看病怎么有两张发票？** 一次就诊多次缴费（如先检查后开药）按缴费次数出票，每张都是有效报销凭证。
- **发票上没有"医保统筹基金支付"字段？** 说明本次未用医保结算（自费/未持卡/异地未备案），票据上无医保结算区。想改成医保结算通常需退费后重新结算，时限极短，当场发现当场处理。
- **体检中心的发票为什么不能报医保？** 健康体检不属于基本医保支付范围（见第 12 章），票据上不会有医保结算区；能否商保报销看具体产品责任（多数百万医疗险不含体检）。
