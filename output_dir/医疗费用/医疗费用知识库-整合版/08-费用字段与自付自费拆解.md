# 08 费用字段与自付、自费逐词拆解（核心章）

> 定位：把发票/结算单上所有"钱字段"逐个讲透，说明双维度模型、自付一/自付二/分类自负、超限价自付、个人负担全景，并给出可执行的费用分层算法与商保视角。
> 高频误区先行：**"医保卡刷的钱"不是医保报销，是自己的钱（个人账户支付）**；**"个人自付"与"个人自费"不是一个意思**；**商保赔付不出现在发票上**。

---

## 1. 总图：一张发票的钱，先按两个维度切

**维度 A —— 资金维度（谁出钱）**：

```
医疗费用总额
├── 医保统筹基金支付            （基本医保统筹基金）
├── 其他支付                    （第二、三支柱：大病保险、医疗救助、
│                                公务员补助、大额补充、企业补充等）
└── 个人负担
    ├── 个人账户支付            （医保个人账户的钱，职工医保独有）
    └── 个人现金支付            （现金/银行卡/微信/支付宝）
```

**维度 B —— 目录属性维度（医保管不管）**：

```
医疗费用总额
├── 医保统筹基金支付
├── 其他支付
├── 个人自付                    （目录内，个人按政策承担部分）
│   ├── 起付线以下
│   ├── 乙类先行自付（自付二/分类自负）
│   └── 按比例自担 + 封顶线以上 + 目录内超限价
└── 个人自费                    （目录外，全额个人承担）
```

两个维度描述的是**同一笔钱**：维度一回答"这笔钱医保管不管"，维度二回答"这笔钱从哪个口袋出"。

> **核心结论** [KB-PAY-002]：`个人账户支付 + 个人现金支付 = 个人自付 + 个人自费`。前者是**钱包维度**，后者是**目录维度**，二者交叉而非并列。回答"个人自付算不算个人账户扣款"这类问题时，正确表述是：**个人自付可由个人账户或现金支付，与支付渠道无关**。

## 2. "其他信息"栏支付字段（逐字段权威定义）★ [KB-FIELD-060]

| 字段 | 权威定义（财政部规范，财综〔2019〕29 号口径） | 报销语义 | 陷阱提示 |
| --- | --- | --- | --- |
| **医保统筹基金支付** | 本次费用中按规定由**基本医疗保险统筹基金**支付的金额 | 医保实际报销金额（统筹部分） | 不含个人账户支付；也不等于"医保体系支付总额"（= 统筹 + 其他支付） |
| **其他支付** | 按规定由**大病保险、医疗救助、公务员医疗补助、大额补充、企业补充**等基金或资金支付的金额 | 多层次保障的补充支付 | **不含个人账户**；刷卡结算时自动完成，多数无需二次报销 |
| **个人账户支付** | 按政策规定用**个人账户**支付的医疗费用（**含目录范围内和目录范围外的费用**） | 花的是个人账户的钱，仍属个人负担 | **不等于**自付+自费（不同维度） |
| **个人现金支付** | 个人通过**现金、银行卡、微信、支付宝**等渠道支付的金额 | 真金白银自掏部分 | 预缴金退补后为实际现金支出 |
| **个人自付** | 本次费用中**由个人负担的属于医保目录范围内自付部分**的金额；含按病种、病组、床日等**打包付费且由患者定额付费**的费用。**该项为个税大病医疗专项附加扣除信息项** | 目录内个人负担 | 与"个人自费"互斥 |
| **个人自费** | 本次费用中**不属于医保目录范围**而全部由个人支付的费用 | 目录外全额自付 | 不含在个税扣除口径内 |
| **谈判药费**（地区增列） | 部分省份加列，标识国家谈判药品费用 | 谈判药专用标识 | 非全国必填 [KB-FIELD-062] |

**"个人自费"的完整构成** [KB-FIELD-063]（以嘉兴市口径为例，各地大同小异）：

```
个人自费 = 丙类项目费用
         + 超过项目医保支付价以上部分的超限价自费费用
         + 餐费、空调费、陪客躺椅费等非医疗费用
```

> **高频误读清单** [KB-FIELD-064]：
> 1. ❌「个人账户支付 = 个人自付 + 个人自费」→ 错。个人账户可支付**目录外**费用，与自付/自费是**不同维度**。
> 2. ❌「个人自费 = 自费药」→ 偏窄。还包含**超限价部分**和**非医疗费用**（餐费、空调费、陪客费等）。
> 3. ❌「全国统一票据有自付一/自付二」→ 错。全国统一票据只有「个人自付」「个人自费」；自付一/二为北京等地**结算单**用语。
> 4. ❌「其他支付包含个人账户」→ 错。"其他支付"指**大病保险、救助、公务员补助、大额补充、企业补充**等基金性支付。
> 5. ❌「医保统筹基金支付 = 医保报销总额」→ 偏窄。医保体系支付总额 = 统筹 + 其他支付。

## 3. 个人负担的细分全景 ★ [KB-PAY-040]

```
个人负担合计
├── 个人自付（目录范围内个人负担部分）
│   ├── ① 起付线以下部分
│   ├── ② 按比例自付部分 = 可报费用 × (1 − 报销比例)
│   ├── ③ 封顶线以上部分
│   ├── ④ 乙类等先行自付部分（= 自付二 / 分类自负）
│   └── ⑤ 目录范围内超限价部分
└── 个人自费（目录范围外全额）
    ├── ⑥ 丙类项目费用
    ├── ⑦ 超过医保支付价的超限价自费部分
    └── ⑧ 非医疗费用（餐费、空调费、陪客躺椅费等）
```

### 3.1 个人自付 vs 个人自费 ★ [KB-PAY-045]

| 对比项 | 个人自付 | 个人自费 |
| --- | --- | --- |
| 目录属性 | **目录内** | **目录外（丙类）** |
| 产生原因 | 起付线以下、封顶线以上、比例自付、乙类先行自付、超限价（目录内） | 项目未纳入目录、超医保支付价、非医疗费用 |
| 医保是否可能再报 | 通常不再报（大病保险/救助可再分担） | 医保**完全不报** |
| 医保支付额 | 部分支付 | 0 |
| 个人比例 | 部分 | 100% |
| 计入个税大病扣除 | **是** | **否** |
| 百万医疗险（社保内责任） | 可报 | 不报 |
| 百万医疗险（含社保外责任） | 可报 | 可报 |
| 惠民保 | 普遍保目录内自付；部分保目录外住院 | 仅含目录外责任产品可报（免赔高、比例有限） |
| 全国统一票据字段 | 有「个人自付」 | 有「个人自费」 |
| 结算单可能表述 | 自付一+自付二 / 个人自负+分类自负 | 自费 |

**个人自付（目录内）构成六项判定**：
1. 乙类先行自付（全国区间约 3%–30%，常见 10%）；
2. 起付线以下目录内费用（全额个人承担）；
3. 共付段个人比例：`(进入共付基数) × (1 − 统筹报销比例)`；
4. 封顶线以上经大额/大病接续后仍由个人承担的比例；
5. 超限价自付（床位费、材料等超过支付标准/限额部分）；
6. 打包付费定额（DRG/DIP、病种、床日付费规定患者定额支付部分）。

**个人自费判定**（满足任一即自费，医保支付额为 0）：不在《药品目录》内的药品；诊疗项目目录列为不予支付（丙类）的项目；超《医疗服务设施范围》支付标准的费用（特需/国际部床位差价、点名手术附加等）；法定不予支付情形对应的费用。典型：未进医保的进口靶向药/新特药、保健品、美容整形、近视矫正、保健按摩、非治疗性服务。

### 3.2 自付一（非全国统一票据字段）[KB-PAY-050]

**定义**：医保报销范围内、**报销比例之外由个人按比例负担**的部分。包含三种情形：① 起付线以下；② 封顶线以上；③ 报销比例内应个人承担的部分（`目录内可报金额 × (1 − 报销比例)`）。

**北京门诊示例** [EX-010 类]：

| 情形 | 计算 | 自付一 |
| --- | --- | --- |
| 年度首次门诊花费 1,000 元（医保内 800 元），未达起付线 1,800 元 | 800 元全部未报 | **800 元** |
| 达标后某次门诊医保范围内费用 500 元，报销比例 70% | 报销 350 元 | 500 × 30% = **150 元** |

**北京住院示例** [EX-011]（在职职工，年度首次住院，起付线 1,300 元）：住院 10,000 元、医保范围内 8,000 元 → 扣起付线 6,700 元 × 85% = 报 5,695 元；**自付一 = 1,300 + 6,700 × 15% = 2,305 元**。

### 3.3 自付二（非全国统一票据字段）[KB-PAY-055]

**定义**：医保报销范围内，属于"**有自付类**"的药品、检查治疗和材料，需**个人先行负担**的部分。典型来源：乙类药品/部分统筹项目，个人先行负担约 10%（比例以当地为准）。

示例 [EX-005 类]：乙类药品 200 元、自付比例 10% → **自付二 = 20 元**，剩余 180 元进入报销范围再按比例报销；某自付类检查 300 元、自付比例 8% → 自付二 = 24 元。

> **重要表述区别** [KB-PAY-056]（北京市医保局口径）：乙类药品**可报销部分**按比例报销后需自付的计入**自付一**；**不可报销部分**（先行自付部分）计入**自付二**。

**通行速记**：**自付二 = 乙类"先扣"的钱；自付一 = 目录内"打折后剩下的"钱**；总自付 = 自付一 + 自付二（当地分法成立时）。各地字段命名与归集口径有差异（个别地区含义相反或有第三栏），以参保地结算单说明为准。

### 3.4 分类自负与个人自负（上海口径）[KB-PAY-060]

| 概念 | 定义 | 对应北京表述 |
| --- | --- | --- |
| **分类自负** | 医保报销范围内，需个人**先行负担**的药品、诊疗项目、医用耗材的部分费用 | 自付二 |
| **个人自负** | 医保报销范围内，**除分类自负外**应由个人按比例负担的部分 | 自付一 |

**分类自负的两个典型来源** [KB-PAY-061]：① 乙类项目先行自负（乙类药 100 元先自负 10% → 10 元分类自负）；② 集采"价高药"差额（中选价/支付标准 5 元、价高药 30 元 → 25 元差额属分类自负）。

**上海个人账户抵充顺序** [KB-PAY-062]：本人历年结余资金（含家庭共济）**① 先抵充「个人自负」（门急诊自负段、住院起付线、共付段个人自负）→ ② 再抵充「分类自负」→ ③ 不足部分现金支付**。

### 3.5 超限价自付 [KB-PAY-065]

| 要点 | 内容 |
| --- | --- |
| **定义** | 实际价格**超过医保支付标准（限价）**的差额部分 |
| **产生场景** | ① 选择价格高于集采中选价的"价高药"；② 高值耗材超支付限额；③ 床位费超支付限额 |
| **归属** | 计入个人负担（部分地区归入个人自费，部分地区归入自付） |
| **是否可避免** | 是。可选择医保支付标准内的替代品，从而避免超限价自付 |

> **实务建议** [KB-PAY-066]：当用户问"同样的药为什么我比别人自付多"——解释**超限价自付**机制，并提示可与医生沟通是否有支付标准内的替代品种。

## 4. 广东省口径的简化公式 [KB-FIELD-090]

```
医疗总费用 = 医保统筹（基金）支付 + 个人自付 + 个人自费
```

- **医保统筹支付**：目录内按规定由统筹基金支付的费用。职工 = 基本支付 + **大额支付**；居民 = 基本支付 + **大病支付**。
- **个人自付**：目录范围内经医保报销后个人负担的费用（起付线以下、乙类先行自付、按比例自付、封顶线以上、目录内超限价），可先由个人账户支付，不足现金。
- **个人自费**：目录外药品、项目等全额自付。

> **两种口径的融合说明** [KB-FIELD-091]：广东口径把"其他支付"（大额/大病）归入"医保统筹支付"，是三段式；财政部票据口径把"其他支付"单列，是四段式。二者不矛盾，只是**颗粒度不同**。引用公式时应指明所用口径。

## 5. 商保视角对照表（建议与发票对照着看）

| 字段 | 钱是谁的 | 医保管了吗 | 商保（限社保内） | 商保（不限社保） |
| --- | --- | --- | --- | --- |
| 统筹基金支付 | 医保基金 | 已报 | 不重复赔 | 不重复赔 |
| 个人账户支付 | 本人账户 | 不管（自己的钱） | 计入个人负担（多数产品，行业实务观察、无统一规定） | 计入个人负担 |
| 个人自付 | 本人 | 管了一部分，剩这部分 | **主要赔付对象**（扣免赔额） | 赔 |
| 个人自费 | 本人 | 完全不管 | **不赔** | **主要赔付对象** |
| 其他支付（大病/大额/救助等） | 其他基金 | 已报 | 不重复赔 | 不重复赔 |
| 商业保险支付 | 保险公司 | — | （理赔后才有，不出现在发票上） | 同左 |

> **个人账户支付与商保免赔**：多数保司实务中把"个人账户支付"计入**个人实际负担**参与免赔额计算（它毕竟是本人实际支出），也有产品只认"个人现金支付"——**行业实务观察，没有统一规定**，务必以保单条款和保司客服口径为准。

## 6. 三个实战推论

1. **看自费栏判断产品价值**：总费用中自费占比越高，"不限社保"的商业医疗险越有用；自费为 0 时，限社保内产品与不限社保产品差距不大。
2. **免赔额的口径要确认**：免赔额从"个人负担（自付+自费）"里扣，还是从"现金支付"里扣，还是"医保统筹后剩余"——同一张发票在不同条款下算出的可赔金额不同。
3. **"经社保结算"影响赔付比例**：多数百万医疗险条款为"经社保结算 100%/未经社保 60%"（常见形态，以条款为准）。急诊未刷卡、异地未备案导致全自费的，除按未备案规则手工报销外，也直接影响商保赔付比例（见第 10、13 章）。

## 7. 费用分层算法（可执行）

**输入**：总费用 T、明细列表（每项金额 m_i、属性 甲/乙/丙、乙类自付率 b_i、限价 L_i）。

1. 自费 = Σ 丙类 m_i + Σ 超限价 (m_i − L_i)。
2. 政策范围内费用 P = T − 自费。
3. 乙类先行自付 = Σ 乙类 m_i × b_i。
4. 可报基数 K = P − 乙类先行自付。
5. 累计当年已计起付线：若 K 累计 ≤ 起付线 D，统筹 = 0；否则：共付基数 = (K 累计 − D) 的本次对应部分；统筹支付 = 共付基数 × 报销比例 r（医院级别/身份对应）。
6. 若统筹累计达封顶线 C，超出部分转大额医疗补助/大病保险（按第 09 章分段）。
7. 个人自付 = 乙类先行自付 + 起付线计入 + 共付基数×(1−r) + 封顶/超限个人部分。
8. 个账抵扣：自付+自费先由个账余额支付，余额不足计入现金。

**计算示例**（[假设示例]，数值为演示口径）：T=20000；丙类自费 2000；乙类先行自付 500；起付线 D=1000；r=85%。
- P=18000；K=18000−500−1000=16500。
- 统筹=16500×85%=14025；共付个人=2475。
- 个人自付=500+1000+2475=3975；个人自费=2000；现金=5975（个账为 0）。
- 校验：14025+5975=20000 ✓。
- 商保判定：若百万医疗免赔 10000，个人负担 5975 < 10000，本次医疗险不赔；住院津贴按天数另付（不凭发票）。

## 8. 发票费用项 → 报销类型 完整映射表 ★ [KB-PAY-100]

| 发票字段 | 费用性质 | 可能对应的报销类型 | 关键判定 |
| --- | --- | --- | --- |
| **医保统筹基金支付** | 目录内合规费用 | 基本医保统筹基金 | 已达起付线、在封顶线内 |
| **其他支付** | 目录内高额/困难/补充 | 大病保险 / 医疗救助 / 公务员补助 / 大额补充 / 企业补充 | 系统自动结算 |
| **个人账户支付** | 个人负担（可含目录外） | 医保个人账户（本人或家庭共济） | 历年/当年账户余额 |
| **个人现金支付** | 个人负担 | 现金/电子支付；**商保可赔付来源** | 扣减免赔额后按条款赔付 |
