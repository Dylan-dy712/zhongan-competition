# 05 医保结算单与读单方法

> 定位：读懂医保结算单上的每个字段、报销计算的完整过程、自动结算与手工报销两条路径。
> 边界：结算单字段各统筹区差异较大（北京"自付一/自付二"、上海"个人自负/分类自负"），以参保地结算单说明为准；文中数字均为虚构示例。

---

## 1. 结算单与发票的关系 [KB-STMT-001]

| 维度 | 医疗收费票据（发票） | 医保结算单 |
| --- | --- | --- |
| 出具方 | 医疗卫生机构 | 医保经办机构 / 医院医保办 |
| 法律性质 | 财政票据（法定收款凭证） | 结算凭据（非财政票据） |
| 信息颗粒度 | 汇总金额为主 | **完整报销计算过程** |
| 是否可替代 | **不可被结算单替代** | 不可替代发票用于财务报销 |
| 主要用途 | 费用凭证、理赔原件、个税扣除 | 读懂报销、核对参数、商保核赔 |

读账口诀："**票据看总额、结算单看分段**"。

## 2. 结算单核心字段全解 [KB-STMT-010]

**（1）项目等级类（部分省市，如北京）**

| 字段 | 定义 | 对应目录类别 |
| --- | --- | --- |
| **无自付** | 医保基金按比例**全额报销**的费用 | 甲类 |
| **有自付** | 个人负担一部分（多数为 10%，比例以当地为准），剩余部分医保按比例报销 | 乙类 |
| **全自付** | **完全自费**，医保不予报销 | 丙类 / 目录外 |

**（2）医保范围金额类**

| 字段 | 定义 | 计算关系 |
| --- | --- | --- |
| **本次医保范围内金额** | 本次费用中能够纳入医保支付范围的费用总额 | = 本次费用 − 个人自费 − 乙类先行自付 |
| **累计医保范围内金额** | 截至本次结算，本年度内医保范围内的累计金额 | 用于判断是否达到起付线 |
| **符合基本医疗保险规定支付范围金额** | 同"本次医保范围内金额"（各地表述不同） | 见式 [F3] |

**（3）限额与进度类（如北京）**

| 字段 | 定义 | 计算关系 |
| --- | --- | --- |
| **年度门诊大额基金累计支付** | 本年度内医保为参保人门诊已报销的累计总额 | 累加 |
| **年度门诊大额余额** | 本年度内医保还能为参保人支付的金额 | = 年度封顶线 − 年度门诊大额基金累计支付 |

**（4）个人负担类**

| 字段 | 定义 | 计算关系 |
| --- | --- | --- |
| **自付一** | 医保报销范围内，按报销政策应由个人**按比例负担**的部分；**包括起付线以下部分、封顶线以上部分** [KB-STMT-011] | 见第 08 章 |
| **自付二** | 医保报销范围内，**有自付类**的药品、检查治疗和材料中需个人**先行负担**的部分 [KB-STMT-012] | 见第 08 章 |
| **自费** | 不在医保范围内的检查或药品等，全额个人支付 | 同"个人自费" |
| **分类自负**（上海等地） | 医保报销范围内，需个人**先行负担**的药品、诊疗项目、医用耗材的部分费用 [KB-STMT-013] | 等同"自付二"概念 |
| **个人自负**（上海等地） | 医保报销范围内，**除分类自负外**应由个人按比例负担的部分 | 等同"自付一"概念 |
| **超限价自付** | 实际价格**超过医保支付标准（限价）**的差额部分 [KB-STMT-014] | 计入个人自费/个人负担 |
| **先行自付费用** | 乙类药品、医疗服务项目、医用耗材中由个人按比例**先行自理**的部分 | 计入"个人自付" |

> **术语对照表** [KB-STMT-015]：

| 概念 | 北京表述 | 上海表述 | 全国统一票据表述 |
| --- | --- | --- | --- |
| 比例自付 + 起付线以下 + 封顶线以上 | **自付一** | **个人自负** | 计入「个人自付」 |
| 乙类等先行自付部分 | **自付二** | **分类自负** | 计入「个人自付」 |
| 目录外全额 | **自费** | **自费** | 「个人自费」 |

## 3. 结算单读单方法（住院示例）[KB-STMT-020]

**示例场景**（虚构数字）：退休职工医保，三级医院住院，年度内首次住院，总费用 15,666 元。

| 步骤 | 计算 | 依据 |
| --- | --- | --- |
| ① 金额合计 | 15,666 元 | 票面 |
| ② 减个人自费 | −1,688.11 元 | 目录外 + 超限价 + 非医疗（餐费/空调费等） |
| ③ 减乙类先行自付 | −595.70 元 | 乙类药品/项目/耗材先行自理 |
| ④ **符合医保支付范围金额** | **= 15,666 − 1,688.11 − 595.70 = 13,382.19 元** | 式 [F3] |
| ⑤ 减住院起付标准 | −800 元（三级医院首次住院） | 参保地政策 |
| ⑥ 乘报销比例 | × 85%（退休职工本地三级机构） | 参保地政策 |
| ⑦ **医保统筹基金支付** | **= (13,382.19 − 800) × 85% = 10,694.86 元** | 式 [F4] |
| ⑧ 个人账户（家庭共济）支付 | 4,971.14 元 | 历年账户家庭共济 |
| ⑨ **个人现金支付** | **= 15,666 − 10,694.86 − 4,971.14 = 0 元** | 式 [F5] |
| ⑩ 预缴金处理 | 入院预缴 2,000 元**全额退还** | 结算差额 |

> **读单三问** [KB-STMT-021]：
> 1. **"符合范围金额"是多少？** —— 决定报销基数（= 总额 − 自费 − 先行自付）。
> 2. **起付线与报销比例是多少？** —— 决定基金支付额。
> 3. **个人负担由谁支付？** —— 分个人账户（含家庭共济）与现金两段。

## 4. 乙类先行自付的实例化 [KB-STMT-030]

| 项目 | 单价 | 先行自付比例 | 先行自付额 | 进入报销范围 |
| --- | --- | --- | --- | --- |
| 小儿豉翘清热颗粒（乙类药品） | 41.30 元 | 3% | **1.24 元** | 40.06 元 |
| 浅表器官彩超检查（一个部位） | 70.00 元 | 10% | **7.00 元** | 63.00 元 |

> **说明** [KB-STMT-031]：**先行自付比例因项目而异**，由目录管理与参保地政策确定，不是统一 10%。同一张票上可以有 3%、10%、20% 等不同比例。

## 5. 结算单中的"自动结算"机制 [KB-STMT-040]

| 机制 | 说明 |
| --- | --- |
| 大病保险自动结算 | 刷卡结算时相关基金项**自动结算，无需二次报销** |
| 医疗救助自动结算 | 同上（救助对象在系统内已标识） |
| 公务员医疗补助 | 同上 |
| 惠民保一站式结算 | 多地已试点医保与惠民保数据打通，出院同步结算、**无需申请自动获赔** [KB-STMT-041] |
| 商保创新药 | 部分地区探索医保、工伤与商保"一站式"结算 [KB-STMT-042] |

> **应答要点** [KB-STMT-043]：当用户问"还需要去申请报销吗"——先确认其所在地是否已开通**一站式结算**；已开通则无需二次申报，否则需自行向商保/大病保险申报。

## 6. 手工（零星）报销 [KB-STMT-050]

适用场景：未实现直接结算、异地未备案后补办、票据缺失补开、急诊未持卡、网络故障等。

| 环节 | 内容 |
| --- | --- |
| 提交材料 | 医疗收费票据**原件**、费用明细清单、病历/出院小结、诊断证明、身份与参保证件、银行卡；异地就诊证明；转诊的附转诊单 |
| 受理机构 | 参保地医保经办机构（窗口或当地医保 APP/政务网线上申报） |
| 执行政策 | **零星结算执行"参保地目录 + 参保地政策 + 就医地管理"** [KB-STMT-051] |
| 与直接结算差异 | 直接结算执行"**就医地目录 + 参保地政策 + 就医地管理**"；手工报销执行**参保地目录**，二者目录可能不同 |
| 时限 | 各地不同，常见为费用发生当年或次年内，逾期不受理风险高 |
| 与商保联动 | 报销后向医保经办索取**分割单**（发票原件被医保收走），凭分割单＋盖章复印件申请商保（见第 11 章） |

> 提示：商保对"未经社保结算"通常只按 60% 赔付，异地就医应优先备案并直接结算（见第 10、13 章）。
