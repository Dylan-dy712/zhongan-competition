# 01 医疗收费票据总论——性质、种类、式样与查验

> 定位：理解"医疗发票"的法律属性、种类全谱、全国统一式样、电子票据改革与查验真伪。
> 边界：各地医院出票习惯存在差异，本文描述**全国统一式样**；个别历史票据（2021 年前旧版）字段可能不同。

---

## 1. 一句话定义与四条基本性质

**医疗收费票据**（日常称"医疗发票""住院发票""门诊发票"）是医院、社区卫生服务中心等医疗卫生机构在收取医疗费用时开具的**财政票据**（非税收入类/结算类），由**省级财政部门统一监制**（票面监制章标示"××省/市财政厅（局）医疗收费票据监制章"），加盖"财政部门票据监制章"和"医疗机构的收费专用章/财务专用章"。

关键认知：它**不是税务发票**，而是财政部门监制的财政票据——这是它与超市小票、出租车票的根本区别，也是它能在医保、商保、单位报销、个税扣除中作为**法定凭证**的原因。[KB-INV-001]

| 性质 | 说明 |
| --- | --- |
| **法定性** | 依据财政票据管理规定制发，式样、联次、填列内容受统一规范约束 |
| **唯一性** | 每份票据有唯一的票据代码 + 票据号码，不可重复使用 |
| **证据性** | 是医保结算、商保理赔、单位报销、个税专项附加扣除、司法举证的**核心原始凭证** |
| **电子同等效力** | 医疗收费**电子**票据与纸质票据具有**同等法律效力**，可依法作为财务报销凭证 |

> **注意** [KB-INV-002]：医疗收费票据由**财政部门**（联合卫健、医保部门）规范管理，核验渠道是**财政电子票据查验平台**（pjcy.mof.gov.cn），而非增值税发票查验平台。这是高频错答点。
>
> **补充**：营利性医疗机构/社会办诊所、药店一般开具**税务部门监制的增值税普通发票**（"医疗服务"）。两类票据在医保/商保理赔中均被接受（商保是否认可取决于合同约定的机构范围，不取决于票据由财政还是税务监制），只是票面样式不同。

## 3. 票据种类全谱 [KB-INV-020]

| 序号 | 票据/凭证名称 | 出具方 | 核心功能 | 是否财政票据 |
| --- | --- | --- | --- | --- |
| 1 | **医疗门诊收费票据**（电子/机打） | 医疗卫生机构 | 门诊、急诊费用的法定收款凭证 | 是 |
| 2 | **医疗住院收费票据**（电子/机打） | 医疗卫生机构 | 住院费用的法定收款凭证（出院结清预交金"多退少补"后开具） | 是 |
| 3 | **医疗收费明细**（电子） | 医疗卫生机构 | 逐项列示收费项目与金额，票据附件（即"费用清单"） | 票据附件 |
| 4 | **医疗收费电子票据** | 医疗卫生机构 | 上述票据的电子形式 | 是 |
| 5 | **医保结算单** | 医保经办机构 / 医院医保办 | 载明医保报销计算明细 | **否** |
| 6 | **医疗费用总清单**（汇总清单） | 医疗卫生机构 | 住院全流程费用明细清单 | 否 |
| 7 | 门诊病历 / 费用清单 | 医疗卫生机构 | 病历与费用记录 | 否 |
| 8 | 预交金收据 | 医疗卫生机构 | 住院押金凭证（**非最终结算凭证**） | 视情况 |
| 9 | 定点零售药店购药票据 | 定点药店 | 购药费用凭证 | 是/视票种 |
| 10 | 长期护理保险费用结算单 | 长护险经办机构 | 长护险待遇结算 | 否 |

补充：**挂号费票据/挂号凭证**部分地区单独出具；多地医改后挂号费并入"一般诊疗费"（基层）或"医事服务费"（北京等），统一体现在门诊票据。**增值税普通发票**（药店购药、社会办医）为税务监制，样式与财政票据不同。

财综〔2019〕29 号启用的**全国统一式样共四种**：医疗门诊收费票据（电子）、医疗住院收费票据（电子）、医疗门诊收费票据（机打）、医疗住院收费票据（机打），同时启用全国统一的医疗收费明细（电子）式样。各地原自行印制旧式样票据陆续停用（在京中央医疗机构自 2021-01-01 全面换版）。

## 4. 票据联次 [KB-INV-030]

全国统一式样医疗收费票据通常为**三联**：

| 联次 | 名称 | 留存方 | 用途 |
| --- | --- | --- | --- |
| 第一联 | **收据联** | 交款人（患者） | 报销、理赔、个税扣除、留存的**原件** |
| 第二联 | **记账联** | 收款单位财务 | 单位记账与收入核算 |
| 第三联 | **存根联** | 开票单位 | 备查、核对、审计 |

> **实务提示** [KB-INV-031]：商保理赔通常要求提供**收据联原件**；若已在医保或单位报销，需提供**加盖留存单位公章的复印件 + 分割单**，或采用电子票据重复使用（部分地区支持电子票据一次出具、多方复用）。

## 5. 医疗收费电子票据改革 [KB-INV-040]

| 维度 | 内容 |
| --- | --- |
| **改革依据** | 财综〔2019〕29 号（2019 年起推行；2020 年底前全国基本完成电子票据改革推行） |
| **核心内容** | ① 全国统一票据**式样**；② 规范**填列**规则；③ 推行**电子票据**；④ 票据直接列示**大病医疗个税扣除**信息项 |
| **电子票据优势** | 不易遗失、可重复下载、便于异地报销、降低机构成本、支持在线查验与自动理赔 |
| **法律效力** | 与纸质票据**同等法律效力**（《财政票据管理办法》明确）；可作为财务报销凭证 |
| **查验方式** | 财政电子票据查验平台，凭票据代码、票据号码、校验码核验 |
| **关键字段关联** | 与个税大病扣除有关的信息项在"其他信息"栏直接列示 [KB-INV-041] |

**纸质 vs 电子票据对照**：

| 维度 | 纸质（机打）票据 | 电子票据 |
| --- | --- | --- |
| 载体 | 热敏/针打纸票 | PDF/OFD 文件，经医院公众号、自助机、邮箱或财政平台下载 |
| 法律效力 | 同等 | 同等 |
| 验真 | 监制章＋二维码/条码 | 平台在线验真＋电子签章（收款单位章＋财政监制章） |
| 补办 | 丢失需医院出具证明/存根联复印件盖章 | 可反复下载、重复打印（同一票号） |

> **重要性说明** [KB-INV-042]：该改革使发票同时承担"**医保凭证 + 商保凭证 + 个税凭证 + 财务凭证**"四种角色，是理解本知识库全部内容的制度起点。
>
> **现状**（2025 年以来）：全国三级医院基本全面上线电子票据，缴费后"秒开"；北京等地已开展医保结算后电子票据直接用于商业保险理赔的试点，保险公司可对接财政平台验真。

## 6. 票面结构分区 [KB-INV-060]

全国统一式样票据在版式上划分为四大功能区：

```
┌─────────────────────────────────────────────┐
│ ① 票头区：票据名称 / 票据代码 / 票据号码 / 校验码      │
├─────────────────────────────────────────────┤
│ ② 主体信息区：交款人 / 收款单位 / 开票日期 / 业务流水号 │
│   医疗机构类型 / 医保类型 / 就诊信息（门诊号·住院号等） │
├─────────────────────────────────────────────┤
│ ③ 收费项目区：按规范收费项目名称逐项列示金额           │
├─────────────────────────────────────────────┤
│ ④ "其他信息"区 ★：医保统筹基金支付 / 其他支付 /        │
│   个人账户支付 / 个人现金支付 / 个人自付 / 个人自费     │
│   （+ 地区增列项，如谈判药费）                        │
└─────────────────────────────────────────────┘
```

> **关键点** [KB-INV-061]：**"其他信息"栏是发票上医保与报销信息的集中区**，也是税务、商保理赔最常调取的部分。商保赔付**不会出现在发票上**（记录在保险公司《理赔决定通知书》，见第 04、11 章）。

**票据式样演进** [KB-INV-070]：

| 阶段 | 特征 | 主要问题 |
| --- | --- | --- |
| 老式票据（各省自定） | 各省自行设计，字段不统一，无个税扣除信息项 | 跨省报销困难、无法支撑个税扣除、易伪造 |
| 全国统一式样（现行） | 统一票样与填列规范，设"其他信息"栏 | 已解决统一性问题 |
| 电子票据（现行推进） | 统一式样电子化，在线查验、多方复用 | 使用习惯与系统对接问题 |

## 7. 票据查验与真伪识别 [KB-INV-080]

**四条核验路径**：

| 方法 | 操作 | 可发现的问题 |
| --- | --- | --- |
| ① 官方平台查验 | 财政电子票据查验平台 pjcy.mof.gov.cn，输入票据代码/号码/校验码（票面二维码扫码通常直达验真页） | 伪造、重复使用 |
| ② 字段逻辑自检 | 校验公式 [F1]、[F2] 是否成立 | 篡改金额、字段矛盾 |
| ③ 机构一致性核验 | 收款单位、医疗机构类型与就诊记录是否一致 | 张冠李戴、虚开 |
| ④ 明细一致性核验 | 发票收费项目金额与医疗收费明细是否相符 | 虚增费用、重复收费 |

> **校验规则** [KB-INV-081] / `[DR-001]`：若 `统筹 + 其他 + 个账 + 现金 ≠ 金额合计`，或 `个账 + 现金 ≠ 自付 + 自费`，则票据存在**逻辑异常**，需人工复核（详见第 03 章勾稽校验）。

**获取渠道**：收费窗口、门诊/住院自助机、医院公众号/APP、诊间/护士站二维码、短信/邮箱、当地财政电子票据平台、支付宝/微信医疗入口。

**防重复**：报销单位反馈入账状态；一票不得多报（票号理赔记录联网可查，重复索赔涉骗保，见第 15 章）。

## 8. 患者最容易忽略的 5 件事

1. **票据＋明细清单要一起拿**：只有发票没有费用明细清单，商保理赔大概率被退回补件。
2. **出院"预交金收据"不是发票**：住院押金凭证，出院结算后要换取正式的医疗住院收费票据。
3. **发票抬头就是患者本人**：以患者（被保险人）本人名义开具；名字打错要当场让医院冲正重开，**事后不可涂改**。
4. **医保结算后发票上会直接印出医保支付金额**：这就是"医保已报销多少"的官方记录，商保理赔要靠它证明剩余自担部分。
5. **原件只有一张**：报销型商业保险原则上要"发票原件"。原件若已交给医保（手工报销场景）或另一家保险公司，要走"分割单"流程（见第 11 章）。
