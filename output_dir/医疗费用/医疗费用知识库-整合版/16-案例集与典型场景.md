## A. 基础计算算例

### [EX-001] 读懂发票：从总额到个人现金支出

住院票面：金额合计 30,000；统筹支付 18,000；其他支付（大病保险）2,000；个账支付 1,500；现金支付 8,500；个人自付 7,000；个人自费 3,000。

1. 医保体系共支付 20,000（统筹 18,000 + 其他 2,000），占总额 **66.7%**；
2. 个人负担 10,000（目录内自付 7,000、目录外自费 3,000）；
3. 个人负担中 1,500 由个账支出、8,500 现金支出；
4. **校验**：18,000+2,000+1,500+8,500=30,000 ✓；1,500+8,500=7,000+3,000=10,000 ✓；
5. 若商业医疗险"不限社保、免赔 0、比例 100%"，理论上可再报 10,000（受保额与条款约束）。

### [EX-002] 乙类药品的报销拆解（双层折扣）

乙类药品 500 元，先行自付 10%，住院报销比例 85%：
```
先行自付 = 500 × 10% = 50 元
纳入报销范围 = 450 元；报销 = 450 × 85% = 382.50 元
个人承担 = 50 + 450 × 15% = 117.50 元
```
**结论**：该药实际个人负担比例 = 117.50 ÷ 500 = **23.5%**——既非 10% 也非 15%，而是**先行自付与比例自付的叠加**。

### [EX-003] 起付线的年度累计逻辑

某地职工门诊起付线 400 元，三级医院报销比例 50%：
- 首次门诊目录内 300 元 → 未达起付线，**全部自付**；
- 第二次 400 元 → 年度累计 700 元，超线 300 元 → **报销 300×50% = 150 元**；
- 此后当年目录内费用**直接按 50% 报销**。

### [EX-004] 目录外费用拉低实际报销比例

总费用 20,000，目录外自费 6,000、目录内 14,000；起付线 800、比例 80%：
```
可报基数 = 14,000 − 800 = 13,200；报销 = 13,200 × 80% = 10,560
政策范围内报销比例 = 80%；实际报销比例 = 10,560 ÷ 20,000 = 52.8%
```
**结论**：目录外占比越高实际报销比例越低——"为什么我报销比例这么低"的最常见原因。

### [EX-005] 自付一与自付二的分工

乙类药品 200 元（自付比例 10%）＋ 自付类检查 300 元（自付比例 8%），医保范围内合计 500 元，报销比例 70%：
```
① 药品先行自付（自付二）= 20 元；② 检查先行自付（自付二）= 24 元 → 自付二合计 44 元
③ 进入报销范围 = 456 元；④ 医保报销 = 456 × 70% = 319.20 元
⑤ 比例自付（自付一）= 456 × 30% = 136.80 元；⑥ 个人负担 = 44 + 136.80 = 180.80 元
```
**结论**：自付一（136.80）+ 自付二（44）= 个人自付（180.80）。

### [EX-006] 北京住院自付一计算 [地区数值·口径示例]

北京在职职工，年度首次住院，起付线 1,300 元，三级医院比例 85%。住院 10,000 元、医保范围内 8,000 元：
```
扣起付线 = 6,700；医保报销 = 6,700 × 85% = 5,695
自付一 = 1,300 + 6,700 × 15% = 2,305 元
```

### [EX-016] 发票逻辑校验发现异常

某发票：合计 12,000；统筹 8,000；其他 0；个账 1,000；现金 2,500；自付 2,000；自费 1,000。
```
[F1]：8,000+0+1,000+2,500 = 11,500 ≠ 12,000 ❌
[F2]：1,000+2,500 = 3,500 ≠ 2,000+1,000 = 3,000 ❌
```
**结论**：票据存在逻辑异常（差额 500 元），需向医疗机构或医保经办机构核实（不直接定性为欺诈 [DR-001]）。

### [EX-020] 个人自费不必然是"自费药"

某住院发票个人自费 1,688.11 元的构成拆解：
```
丙类（目录外）项目费用        约 1,200 元
超医保支付价的超限价自费       约 400 元
餐费、空调费、陪客躺椅费等     约 88.11 元
```
**结论**：个人自费 ≠ 只有自费药，还包含**超限价部分**和**非医疗费用**。

## B. 商保与惠民保算例

### [EX-007] 惠民保的免赔额与赔付比例

某惠民保医保目录内自付责任：免赔 1.5 万、比例 80%（健康人群）。年度目录内自付累计 5 万：
```
可赔费用 = 50,000 − 15,000 = 35,000；赔付 = 35,000 × 80% = 28,000 元
```

### [EX-008] 百万医疗险的理赔

住院总费用 50,000；医保统筹 28,000；个人自付+自费 22,000；百万医疗免赔 1 万、经社保 100%、保额 200 万：
```
商保可报 = (22,000 − 10,000) × 100% = 12,000；个人最终净支出 = 10,000 元
```

### [EX-009] 未使用社保身份的降比例赔付

同一笔费用（个人负担 22,000），以"有社保身份"投保但**未走医保结算**直接索赔：
```
商保可报 = (22,000 − 10,000) × 60% = 7,200 元，较走医保情形少赔 4,800 元
```
**结论**：**必须先走医保再索赔**。

### [EX-010] 商保目录外责任的差异

目录外自费药 15,000 元：
| 产品条款 | 结果 |
| --- | --- |
| "不限社保目录"的百万医疗险 | 该 15,000 元（扣免赔额后）可纳入赔付 |
| "限社保目录内"的医疗险 | 该 15,000 元**不予赔付** |

**必答点**：提示用户核对条款"社保目录内/不限社保"的表述。

### [EX-011] 集采"价高药"的超限价自付

某集采药品中选价（医保支付标准）5 元，非中选"价高药"30 元，参保人选择价高药：
```
按支付标准 5 元纳入医保报销范围；超出 25 元差额 = 分类自负/超限价自付，个人承担
```

## C. 个人账户与共济算例

### [EX-012] 门诊共济的家庭共济结算

退休职工住院，符合范围金额 13,382.19 元，起付线 800、比例 85%，历年账户家庭共济可用余额 4,971.14 元：
```
统筹支付 = (13,382.19 − 800) × 85% = 10,694.86
个人负担（含自费与先行自付）= 15,666 − 10,694.86 = 4,971.14
个账（家庭共济）支付 4,971.14；个人现金支付 = 0
```

### [EX-013] 个人账户历年资金抵充顺序（上海口径）

乙类药品 100 元，先行自负 10%（分类自负 10 元）；在职职工三级医院门诊自负 30%/医保报 70%；历年账户结余 30 元：
```
分类自负 = 10；个人自负 = (100−10) × 30% = 27；医保报销 = 63
抵充：① 先抵个人自负 27 → 剩 3；② 再抵分类自负 10 中的 3；③ 现金支付 7 元
```

## D. 异地、生育、工伤、个税算例

### [EX-014] 异地就医降比例的影响

本地三级住院比例 85%，政策范围内费用 10,000、起付线 800。未转诊自行跨省住院（降 20 个百分点至 65%）：
```
本地：报销 7,820 元；跨省未转诊：5,980 元；差额 1,840 元
```
**结论**：异地就医务必先备案、能转诊则办转诊。

### [EX-015] 生育津贴计算

单位上年度职工月平均工资 8,000 元：
```
顺产：8,000 ÷ 30 × 98 ≈ 26,133.33 元
难产/剖宫产（113 天）：≈ 30,133.33 元；双胞胎顺产（113 天）：≈ 30,133.33 元
```

### [EX-017] 个税大病医疗专项附加扣除

年度票据「个人自付」合计 43,000 元：
```
可扣除 = min(43,000 − 15,000, 80,000) = 28,000 元
```
仅「个人自付」计入，「个人自费」不计入。

### [EX-018] 个税扣除未达标情形

年度「个人自付」合计 12,000 < 15,000，**不可扣除**。

### [EX-021] 双通道购药的报销

谈判药品医院未配备，凭电子处方到双通道定点药店购买，药费 5,000 元：
```
按乙类政策：先行自付 10% = 500；纳入范围 4,500
按参保地比例 70% 报销 = 3,150；个人负担 = 500 + 4,500 × 30% = 1,850 元
（部分地区门诊双通道药品设单独起付标准，需合并计算）
```

### [EX-022] 工伤与医保的边界

职工工作时间因工作原因受伤住院 30,000 元：
```
① 工伤认定 → 成立；② 支付主体 = 工伤保险基金；③ 基本医保不予支付（社保法第30条第1项）
④ 适用工伤三目录；⑤ 不受甲乙类限制
```
**结论**：不能走基本医保，须走工伤保险流程。

糖尿病伴并发症患者（门诊慢特病 Ⅱ 类），某次门诊目录内费用 1,000 元：

## F. 全链条四层综合计算案例（演示各保障层如何分担）

> 数值全部为**假设口径**，用于演示计算顺序；非任何真实城市/产品标准。

**条件**：在职职工、三级医院住院治疗恶性肿瘤；总费用 300,000。
- 目录外（丙类）自费 50,000（进口靶向药 30,000 + 自费项目 20,000）；
- 政策范围内费用 250,000；乙类先行自付 15,000；起付线 1,500；统筹比例 85%；统筹未超封顶。

**第 1 层 基本医保**
- 共付基数 = 250,000 − 15,000 − 1,500 = 233,500
- 统筹支付 = 233,500 × 85% = **198,475**
- 共付段个人 = 35,025；个人自付 = 15,000 + 1,500 + 35,025 = **51,525**
- 个人自费 = **50,000**；医保后个人负担 = 101,525

**第 2 层 大病保险**（假设起付线 15,000；1.5–5 万段 60%；只对政策范围内自付）
- 可计自付 51,525；超起付 36,525 落在 1.5–5 万段
- 大病支付 = 36,525 × 60% = **21,915**；目录内自付剩余 = 29,610
- 个人负担 = 29,610 + 50,000 = 79,610

**第 3 层 惠民保**（假设目录内责任免赔 15,000、80%；目录外住院责任免赔 15,000、60%）
- 目录内 = (29,610 − 15,000) × 80% = 11,688；目录外 = (50,000 − 15,000) × 60% = 21,000
- 惠民保支付 = **32,688**；个人负担 = 46,922

**第 4 层 百万医疗险**（假设免赔 10,000、经社保 100%、含社保外、剩余费用均属责任）
- 惠民保已补偿 32,688 可抵扣免赔额（>10,000），免赔已用尽
- 百万医疗支付 = **46,922**；个人最终负担 ≈ **0**（理想情形）

**校验**：300,000 = 统筹 198,475 + 大病 21,915 + 惠民保 32,688 + 百万医疗 46,922 ✓
（若仅有医保、无任何商业补充，个人需承担 101,525——补充保障对大额费用的作用。）

## G. 十大典型报销场景手册

> 按"场景 → 发票上会看到什么 → 谁来报 → 易错点"组织，供快速对照。

### 场景一：门诊感冒开药（职工医保，个人账户充足）
- **发票上**：合计 396.40（虚构）＝ 统筹 180 ＋ 账户 116.40 ＋ 现金 100；自付 166.40＋自费 50。
- **谁来报**：门诊统筹报一部分（统筹 180）；个人账户支付是自己的钱。
- **易错点**：以为"医保卡刷卡＝报销"。给商保报门诊险时，可赔的是个人负担部分扣免赔额，不是全部 396.40。

### 场景二：住院手术（职工医保＋百万医疗险，本地参保）
- **发票上**：总 30,000＝统筹 18,000＋自付 7,000＋自费 5,000（虚构）。
- **谁来报**：医保直接结算 18,000 → 百万医疗险对个人负担 12,000 扣 1 万免赔 → 赔 2,000。
- **材料**：发票原件＋结算单＋清单＋出院小结。
- **易错点**：免赔额 1 万看起来"没用"，但若同年度再次住院，累计免赔已扣完，第二次可全额报剩余负担。

### 场景三：异地出差突发阑尾炎，没刷医保（有百万医疗险）
- **发票上**：全自费结算，无医保结算区；合计 12,000 全是个人现金支付。
- **谁来报**：① 医保：急诊抢救跨省**视同已备案**（医保发〔2022〕22 号），出院结算前找医院医保窗口补办直接结算；已自费的回参保地按规则手工报销（时限短）；② 商保：若最终未走医保，按"未经社保结算"降至 60%（常见）→ (12,000−10,000)×60% = 1,200（虚构演示）——**这就是先走医保的价值**。
- **易错点**：以为"没刷卡医保就不管了"。双通道都在，但时限短，行动要快。

### 场景四：退休父母随迁带娃（居民医保跨省长期备案）
- **发票上**：备案后直接结算，含统筹支付与个人负担；目录按就医地、政策按参保地。
- **谁来报**：就医地联网定点医院直接结算；居民医保无个人账户，个人负担全走现金。
- **易错点**："临时外出"备案只有 6 个月有效；长期随迁应选"跨省异地长期居住人员"备案。

### 场景五：车祸骨折（第三方责任）
- **发票上**：若用医保刷卡，事后医保核查第三方责任可追回；规范做法是先走事故责任渠道。
- **谁来报**：医保法定不报（社保法第 30 条）；由交强险/肇事方/商业三责险赔。自己的意外险（意外医疗＋住院津贴）可按条款报销/给付。
- **关键动作**：交警责任认定书＋全套发票清单病历原件。
- **易错点**：隐瞒第三方责任用医保结算——涉及基金追偿与法律责任；肇事逃逸无法确定第三人的，可申请医保**先行支付**。

### 场景六：体检＋自费疫苗
- **发票上**：健康体检/非免疫规划疫苗无医保结算区，全自费。
- **谁来报**：医保不报；多数百万医疗险不含；**单位补充医疗/团体险**常含体检与疫苗责任——找 HR 走团体理赔。多地允许职工医保**个人账户**支付自费疫苗。
- **易错点**：把体检发票混进住院理赔材料，会拖慢整案审核。

### 场景七：种植牙/正畸
- **发票上**：多为全自费（口腔种植专项治理是**限价**不是纳入医保）。
- **谁来报**：医保不报；普通医疗险按"矫形/美容/齿科"免责不报；专门的齿科保险或高端医疗险含齿科责任的按其限额报。
- **易错点**：以为"降价了就能报医保"——价格治理与医保支付是两回事。

### 场景八：大病住院＋惠民保（目录外新药大额费用）
- **发票上**：总 200,000（虚构）＝统筹 90,000＋自付 60,000＋自费 50,000（含目录外靶向药）。
- **谁来报**：基本医保 → 大病保险（自付超起付线部分分段报销，出院多为自动结算）→ 惠民保（自付/自费/特药责任分别扣免赔）→ 百万医疗险补位。
- **材料**：惠民保对"自付/自费"两栏分别计赔——**费用明细清单必须有**，否则无法区分目录内外。
- **易错点**：外购靶向药不在住院清单里，要单独凭处方＋药店发票申请（场景九）。

### 场景九：医院没有的药，医生让外购（双通道/特药）
- **发票上**：住院发票不含该药；药店开出**增值税发票**（抬头=患者姓名）。
- **谁来报**：① 医保：该药若在目录且当地开通**双通道**，凭定点医院处方到双通道药店购药按目录政策报销；② 商保：百万医疗"外购药责任"/特药险按清单报销，需处方＋发票原件。
- **易错点**：只留了药店小票没有正规发票，或发票抬头开成公司/店名——改名不可，当场重开。

### 场景十：无医保的自费患者（新市民/断缴期）
- **发票上**：全自费，无医保结算区。
- **谁来报**：商保按"未经社保结算"降比例（常见 60%）；惠民保多数同样区分"经医保结算"待遇；居民医保错过集中缴费期的等待期规则见当地文件。
- **易错点**：断缴不是"白缴"，续保后待遇恢复通常有等待期；补缴窗口各地不同，出险后先问参保地。

### 场景通用收尾动作（每次就医都做）
1. 结算当场对账（恒等式）；2. 三样单据拿齐并扫描；3. 先医保后商保的顺位规划；4. 给付型（重疾/津贴）并行申请；5. 理赔决定书归档。
