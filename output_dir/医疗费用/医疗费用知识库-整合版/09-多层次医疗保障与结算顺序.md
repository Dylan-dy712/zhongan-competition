# 09 多层次医疗保障体系与报销顺序

> 定位：基本医保之上还有谁——大病保险、大额补助、医疗救助、惠民保、税优健康险；以及"先报谁后报谁"的顺位铁律。
> 边界：各层参数（起付线、分段比例、限额）以参保地最新文件与产品条款为准；示例数值均已标注。

---

## 1. 多层次医疗保障体系总览 ★ [KB-PAY-005]

国家"三重保障"：**基本医疗保险（主体）→ 大病保险（减负）→ 医疗救助（托底）**；再加市场化/政策性补充层。

```
┌─────────────────────────────────────────────────────┐
│ 第 0 层：公共卫生服务（免疫、筛查、妇幼保健等）        │
│          医保基金不支付，由政府公共卫生经费承担         │
├─────────────────────────────────────────────────────┤
│ 第 1 层：基本医疗保险（职工医保 / 城乡居民医保）       │
│          保基本，目录内、按比例、有起付线与封顶线       │
├─────────────────────────────────────────────────────┤
│ 第 1.5 层：大病保险 / 职工大额医疗费用补助             │
│          对高额费用二次报销（发票"其他支付"栏）        │
├─────────────────────────────────────────────────────┤
│ 第 2 层：医疗救助（困难群众兜底，"其他支付"栏）        │
├─────────────────────────────────────────────────────┤
│ 第 3 层：商业健康保险                                │
│   3a 普惠型：惠民保（城市定制型，政府指导）            │
│   3b 商业型：百万医疗 / 中端 / 高端医疗、防癌医疗      │
│   3c 给付型：重疾险、住院津贴、手术津贴                │
│   3d 税优型：税优健康险                               │
├─────────────────────────────────────────────────────┤
│ 第 4 层：补充层（公务员医疗补助、企业补充、工会互助）  │
├─────────────────────────────────────────────────────┤
│ 第 5 层：社会互助与慈善（慈善基金、网络互助等）        │
└─────────────────────────────────────────────────────┘
```

## 2. 大病保险与职工大额补助（第 1.5 层）

### 2.1 定位与机制 [KB-PAY-020]

| 项目 | 城乡居民大病保险 | 职工大额医疗费用补助 |
| --- | --- | --- |
| 定位 | 对参保居民高额费用的**二次报销** | 对职工超基本统筹封顶线费用的补充（或对大额自付按比例补助） |
| 资金来源 | 从居民基本医保基金划拨，**个人不另行缴费** | 从职工医保基金划拨或单独筹资 |
| 参保方式 | 参加居民医保即**自动同步参加，无需申报**（国家医保局明确口径） | 随职工医保（名称各地不一："大额医疗费用补助""职工大病保险"等） |
| 触发条件 | 基本医保报销后，**个人负担的政策范围内（合规）费用累计超过大病起付线** | 超过基本医保年度最高支付限额，或个人大额负担达标（视当地规则） |
| 票据体现 | 发票"**其他支付**"栏 | 同左 |
| 结算方式 | **刷卡自动结算，多数无需二次报销**（个别地区需事后申请） | 同左 |

### 2.2 参数通行口径

- **起付线**：不高于当地上年度居民人均可支配收入的一定比例，**常见 1–2 万元量级**（多在 1.1 万–1.5 万），年度计一次。
- **分段比例**：费用越高比例越高，**分段递增，常见 60%–80%**（如 60%/65%/70%/75%）。
- **困难群众倾斜**（国家统一要求）：**起付线降低 50%、各段比例提高 5–10 个百分点、取消或提高封顶线**。

### 2.3 分段数值示例 [地区数值]

| 地区（口径） | 起付线 | 分段支付比例 | 封顶 |
| --- | --- | --- | --- |
| 安徽居民（皖医保发〔2024〕9 号） | 1.5 万 | 起付线–5 万 60%；5–10 万 65%；10 万以上更高分段 | 按文件 |
| 安徽芜湖/繁昌 | 1.5 万 | 0–5 万 60%；5–10 万 65%；10–20 万及以上递增 | 按文件 |
| 内蒙正镶白旗居民 | 1.4 万 | 1.4–10 万 60%；10 万以上 70% | 10 万 |
| 倾斜支付示例（荣成帮扶对象） | 9000 | 0.9–10 万：职工 75%/居民 65%；10 万以上分段提高 | 按文件 |

## 3. 医疗救助（第 2 层）[KB-PAY-025]

- 依据：国办发〔2021〕42 号《关于健全重特大疾病医疗保险和救助制度的意见》。
- **救助对象（分层）**：① 特困人员、孤儿；② 低保对象、返贫致贫人口；③ 低保边缘家庭成员、防止返贫监测对象；④ 因病致贫重病患者。
- **救助方式**：
  - **参保资助**：对困难群体参保个人缴费部分给予定额/全额资助；
  - **费用救助**：经基本医保、大病保险支付后，对政策范围内个人负担费用救助。
- **起付线**：低保对象、特困人员原则上取消（暂不具备条件地区不高于上年居民人均可支配收入 5%）；低保边缘家庭约 10%；因病致贫重病患者约 25%。年度累计、只计一次。
- **救助比例**：低保对象、特困人员合规费用**不低于 70%**（特困可到 100%）；其他对象略低；门诊慢特病与住院救助共用年度救助限额。
- **倾斜救助/再救助**：经三重保障后个人负担仍较重的，对超过一定阈值部分再救助。
- 原则：**先保险、后救助**。系统内已标识救助对象，刷卡**自动结算**。

### 救助数值示例 [地区数值]

| 对象（示例地区） | 救助起付线 | 救助比例 | 年度限额 | 再救助 |
| --- | --- | --- | --- | --- |
| 特困/低保/孤困/返贫（平原县） | 0 | 70% | 3 万 | 起付 5000、70%、2 万 |
| 低保边缘/监测对象（平原县） | 3000 | 50% | 1 万 | 起付 1 万、70%、2 万 |
| 特困（孤儿）（庆阳） | 0 | 100% | 5 万（重特大 8 万） | — |
| 低保/返贫（庆阳） | 0 | ≥70% | 同上 | — |

## 4. 其他政策性补充（第 4 层）

| 制度 | 覆盖 | 支付方式 |
| --- | --- | --- |
| 大额医疗费用补助（大额医保/大额统筹） | 参保职工（部分含居民） | 多在统筹封顶线以上接续，或对大额自付按比例补助。示例 [地区数值]：滨州职工经基本医保/公务员补助后个人负担政策范围内费用超 1.5 万部分按 90%、年限额 60 万 |
| 公务员医疗补助 | 公务员及参照管理人员 | 对起付线、自付、封顶以上按规定补助 |
| 企业补充医疗保险 | 企业职工 | 企业自主，对医保后自付补助，税前列支有比例限制 |

## 5. 惠民保（城市定制型商业医疗保险）★ [KB-COM-040]

### 5.1 基本属性

| 维度 | 内容 |
| --- | --- |
| **全称** | 城市定制型商业补充医疗保险（普惠型补充医疗保险），各地叫法"XX 惠保""XX 保" |
| **性质** | 介于**基本医保与纯商业保险之间**；**地方政府及相关部门指导**，商业保险公司承保，"一城一策" |
| **运营模式** | **共保模式**为主流（两家及以上保险机构共同承保运营） |
| **核心卖点** | **不限年龄、职业、户籍（限当地基本医保参保人）、无健康告知或极宽松、可带病投保、低保费、高保额** |
| **覆盖规模** | 覆盖全国超 30 个省份，累计参保超 2 亿人次 |
| **保费区间** | 多在 **59—300 元/年**（如 2026 年度北京普惠健康保 195 元、深圳惠民保 88 元）[地区数值] |
| **保障结构（典型三段）** | ① 医保目录内住院/门诊慢特病**个人自付**费用；② 医保**目录外住院自费**费用（部分产品含，免赔更高、比例更低、设正面清单）；③ **特定高额药品（特药）**费用，按特药目录赔付 |
| **免赔额** | 相对较高，**常见 1–3 万元**（各责任分别设置；部分与当地大病保险共用起付线、不重复计算） |
| **赔付比例** | 分段按比例，常见 60%–80%；**既往症相关费用除外或降低赔付比例**（须看特别约定） |
| **投保/生效** | 集中投保期，约定统一生效日；过期一般不补办 |

### 5.2 发展趋势（2026 年）[KB-COM-042]

| 趋势 | 表现 |
| --- | --- |
| 精细化运营 | 告别"一刀切"统一定价，分层定价、贴近真实风险 |
| 分层定价 | 基础版 150 元 + 升级版 300 元；按年龄分档；既往症人群单独设保费 |
| 健康人群与长期续保者让利 | 连续投保无理赔者降免赔（如 3 年降至 1 万）、提比例（如目录内升至 90%） |
| 既往症重新划界 | 下调既往症赔付比例（如 100%→30%）、提高既往症免赔额 |
| 扩大特药目录 | 特药清单扩容（如扩至 159 种）、病种覆盖扩展 |
| 一站式结算 | 多地医保与惠民保数据打通，出院同步结算、无需申请自动获赔 |
| 个账支付 | 多地开放医保个人账户支付本人及直系亲属保费 |
| 覆盖新市民 | 参保范围扩大至已参加基本医保的新市民 |
| 与商保创新药目录衔接 | 对商保创新药目录内药品提高报销比例 |

> **定位辨析** [KB-COM-041/043]：惠民保是"**补充品而非替代品**"，核心是**大病兜底**而非全面覆盖；不能替代基本医保，也不等同于高保障商业健康险。投保前重点关注：**免赔额、报销比例、是否限医保目录内、特药清单、既往症规则**。
>
> **与百万医疗险关系**：互补不替代——惠民保免赔高、保障窄但门槛低保费低、可带病投保；百万医疗保障宽、免赔 1 万、健康告知严。

## 6. 税优健康险 [KB-COM-045]

| 要点 | 内容 |
| --- | --- |
| **定义** | 享受**个人所得税税前扣除**优惠的商业健康保险 |
| **产品类型** | 可包含医疗保险、长期护理保险等 |
| **优惠形式** | 计算个税应纳税所得额时按规定扣除**保费** |
| **注意** | 需与"大病医疗专项附加扣除"区分——后者依据**医疗费用**（个人自付），前者依据**保费**；两者可并存，规则分别适用（见第 14 章个税节） |

## 7. 结算/报销顺序（总规则）★

标准顺序（多数地区"一站式、一窗口"联网结算）[KB-COM-061]：

| 顺位 | 渠道 | 规则 |
| --- | --- | --- |
| 1 | **基本医保统筹基金** | 目录内，扣乙类自付、起付线后按比例，封顶线内 |
| 2 | **大额补助/公务员补助等政策补充** | 承接封顶线以上或大额自付，按当地规则（部分地区与大病保险先后顺序不同） |
| 3 | **大病保险** | 个人合规负担超起付线后分段支付（多自动结算） |
| 4 | **医疗救助** | 困难群体，先保险后救助 |
| 5 | **惠民保** | 对目录内自付、目录外住院自费、特药按合同赔付（多地联网一站式或事后申请） |
| 6 | **商业医疗险（报销型）** | 对合同责任内剩余费用，扣除免赔额、已获补偿后按比例，适用损失补偿原则 |
| 任意 | **重疾险/住院津贴（给付型）** | 定额给付，与上述顺序无关，符合条款即赔，**无需排队** |

规则要点：
- 报销型各层**累计赔付额 ≤ 实际发生的责任内费用**（损失补偿原则）。
- 每一层只对"前序各层支付后剩余、且属于本层责任范围"的费用计算。
- 医保未直接结算（手工报销/未持卡）时，先到医保经办完成报销、取得结算单，再进入商业层。
- **"仅商保（未走医保）"模式常被降比例赔付（常见降至 60%），不推荐**。

**多渠道职责速记**：

| 渠道 | 触发 | 性质 |
| --- | --- | --- |
| 基本医保 | 目录内疾病治疗 | 报销 |
| 大病保险/大额补助 | 合规自付超起付线 / 封顶线以上 | 报销（分段） |
| 医疗救助 | 困难群体大额负担 | 托底报销 |
| 生育/工伤保险 | 生育/工伤 | 专项支付（见第 14 章） |
| 长护险 | 重度失能照护 | 服务给付（见第 14 章） |
| 惠民保 | 医保后自付/自费/特药 | 报销 |
| 商业医疗险 | 合同责任内费用 | 报销（补偿） |
| 重疾险/津贴 | 确诊/住院/手术 | 现金给付 |

> 全链条四层（医保→大病→惠民保→百万医疗）综合计算案例见第 16 章案例 F。
