# 15 电子票据验真、打印补打与丢失处理

> 定位：票据的"保全"实务——拿到、验真、补办、防丢、防重复报销。
> 法律基础：财政部修改后的《财政票据管理办法》——**财政电子票据与纸质票据具有同等法律效力**，可用于医保报销、商业保险理赔与单位报销。

---

## 1. 电子票据怎么拿

| 渠道 | 操作 |
| --- | --- |
| 医院公众号/小程序 | 缴费成功后自动推送"电子票据"消息，点开下载 PDF/OFD |
| 门诊/住院自助机 | 刷就诊卡/身份证/医保码 → "电子票据打印"→ 出纸质（同一票号）或扫码下载 |
| 诊间/护士站二维码 | 缴费单据上的二维码扫码取票 |
| 短信/邮箱 | 部分医院绑定后推送 |
| 当地财政电子票据平台 | 省财政厅票据查验/服务平台凭票号下载 |
| 支付宝/微信医疗入口 | 部分地区支持 |

- 电子票据文件一般为 **PDF 或 OFD** 格式，内含**电子签章**（收款单位章＋财政监制章），打印后效力等同。
- 住院电子票据在**出院结算完成后**才生成——住院中拿到的"预交金收据"不是票据（见第 03 章）。

## 2. 验真：三个渠道

1. **财政部全国财政电子票据查验平台**：pjcy.mof.gov.cn —— 输入**票据代码＋票据号码＋校验码**查验（票面上都印着）。
2. 各省财政厅票据查验平台/公众号。
3. 商保理赔 App 中的"票据验真"辅助功能（部分保险公司对接财政平台）。

> 医疗收费电子票据票面还有**二维码**，微信扫码通常直达验真页。
>
> **注意**：医疗收费票据是**财政票据**，验真走财政平台，**不是**增值税发票查验平台（高频错答点 [KB-INV-002]）。

## 3. 打印与补打

- **电子票据可以反复下载、反复打印**——打印件都对应同一票号，不产生"第二张票"。
- 机构报销若要"原件"，电子票据场景下通行做法是：**打印件 ＋ 验真截图 ＋（如需）承诺书**；具体以收件方要求为准。
- 纸质票据丢失后的"补打"不等同于重新开票：医院留存的是**存根联**，只能提供复印件加盖财务章或开具证明（见第 5 节）。

## 4. 防重复报销的合规底线

- 同一张票据向医保＋商保重复索赔、或利用电子票据可复制性向多家保司**隐瞒已赔付事实**重复全额索赔，属于保险欺诈（《保险法》与《刑法》保险诈骗条款规制；《社会保险法》第 88 条：骗保责令退回＋2—5 倍罚款），**票号理赔记录联网可查**。
- 合规路径是**分割单**：每报销一方向下家出具分割单＋盖章复印件（见第 11 章 3.3）。
- 个人扫描备份时，不要把票据扫描件交给非正规"代报案/代办理赔"渠道。

## 5. 纸质发票丢失怎么办（分级处理）

| 情形 | 处理路径 |
| --- | --- |
| **医保手工报销前丢失** | 携身份证到就诊医院**财务收费窗口**：多数医院可凭就诊记录提供票据存根联**复印件加盖财务专用章**，或开具《票据遗失证明》；参保地手工报销时一并提交并按当地要求签署承诺（各地口径不同，先电话咨询参保地医保经办） |
| **商保理赔前丢失** | 按保司要求提供：医院盖章的存根联复印件/遗失证明 ＋ 本人书面情况说明；由保司核定是否受理（部分保司受理、部分按条款从严）——**先报案说明情况再跑医院**，避免白跑 |
| **电子票据时代** | 优先走电子渠道：登录原获取渠道重新下载（票号不变），无需任何补办；部分地区支持电子票据一次出具、多方复用 [KB-INV-031] |
| **票据信息错误（姓名/金额）** | 由医院按**作废重开**流程处理（红冲原票、开具新票）；患者不可自行涂改 |

## 6. 票据保管建议（理赔材料保全）

1. **出院当天**全套扫描：发票、结算单、清单（见第 04 章核对清单）。
2. 纸质原件存放在单一固定位置（理赔专用文件袋），寄出前再扫描一次。
3. 手机端留存：医院公众号取票记录、电子票据文件、缴费记录截图——三重备份。
4. 时效提醒：商保索赔诉讼时效 **2 年**（《保险法》第 26 条），医保手工报销时限更短（各地以当年/次年规定为准）——**别把票据留到期末**。
