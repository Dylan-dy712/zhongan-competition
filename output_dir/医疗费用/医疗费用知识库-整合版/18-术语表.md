# 18 术语表（Glossary）

> 定位：160+ 术语定义，含英文参考与地区术语对照。以详版知识库术语体系为骨架，合并检索版与票据库的补充定义。

---

## 1. 票据与凭证类

| ID | 术语 | 英文参考 | 定义 |
| --- | --- | --- | --- |
| [GL-001] | 医疗收费票据 | Medical Charge Invoice / Receipt | 医疗卫生机构收费时开具的财政票据类凭证，即"医疗发票"，是医保/商保/单位报销、财务入账、个税扣除的法定凭证 |
| [GL-002] | 财政票据 | Fiscal Bill | 由财政部门管理的非税收入票据，医疗收费票据属其中一类 |
| [GL-003] | 票据代码 | Bill Code | 按财政票据编码规则编制，标识票据种类、年度、地区等 |
| [GL-004] | 票据号码 | Bill Number | 单份票据的唯一流水编号（财政票据系统生成，跨机构唯一） |
| [GL-005] | 校验码 | Verification Code | 电子票据用于官方平台查验真伪的校验字符串 |
| [GL-006] | 业务流水号 | Business Serial Number | 医疗卫生机构收费系统自动生成的院内流水号码 |
| [GL-007] | 医疗收费明细 | Medical Charge Detail | 逐项列示收费项目与金额的明细表，票据附件（费用清单） |
| [GL-008] | 医保结算单 | Medical Insurance Settlement Statement | 医保经办机构/医院医保办出具的报销明细凭据 |
| [GL-009] | 医疗费用总清单 | Total Medical Expense List | 住院全流程费用明细清单（汇总清单） |
| [GL-010] | 收据联 | Receipt Copy | 纸质票据联次之一，交予交款人留存（报销/理赔用原件） |
| [GL-011] | 记账联 | Bookkeeping Copy | 纸质票据联次之一，收款单位财务记账用 |
| [GL-012] | 存根联 | Stub Copy | 纸质票据联次之一，开票单位留存备查 |
| [GL-013] | 预交金收据 | Deposit Receipt | 住院押金凭证，非最终结算凭证 |
| [GL-014] | 交款人 | Payer | 支付医疗费用的一方，可为患者本人、家属或单位 |
| [GL-015] | 收款单位 | Payee Institution | 开具票据的医疗卫生机构 |
| [GL-016] | 医疗机构类型 | Institution Type | 按《医疗机构管理条例实施细则》确定的机构类别（影响报销比例） |
| [GL-017] | 分割单 | Expense Apportionment | 收走发票原件的单位（医保经办/保险公司）开具的已赔付凭证，供下一层报销 |

## 2. 目录与范围类

| ID | 术语 | 英文参考 | 定义 |
| --- | --- | --- | --- |
| [GL-020] | 医保三大目录 | Three Catalogs | 药品目录、诊疗项目（医疗服务项目）目录、医疗服务设施目录（医用耗材目录常并入表述） |
| [GL-021] | 基本医疗保险药品目录 | Basic Medical Insurance Drug Catalog | 国家统一制定的可报销药品清单，原则上每年调整一次（现行为 2025 版，2026-01-01 执行，3,253 种） |
| [GL-022] | 诊疗项目目录 | Diagnostic & Treatment Item Catalog | 可报销的医疗服务项目清单，含全额统筹/部分统筹/范围外三类 |
| [GL-023] | 医疗服务设施目录 | Medical Service Facility Catalog | 住院等环节的服务设施与环境范围，含床位费等支付限额 |
| [GL-024] | 医用耗材目录 | Medical Consumables Catalog | 可报销的医用耗材清单，以省级确定为主 |
| [GL-025] | 甲类药品 | Class A Drug | 临床必需、使用广泛、疗效确切、同类价格较低的药品，全额纳入报销、不先行自付 |
| [GL-026] | 乙类药品 | Class B Drug | 可供选择使用、疗效确切、同类价格略高的药品，个人先行自付一定比例后纳入报销 |
| [GL-027] | 丙类药品 | Class C / Non-catalog Drug | 未纳入医保目录、全额自费的药品（"丙类"为行业俗称，官方目录只有甲乙两档） |
| [GL-028] | 目录内 / 目录外 | In-catalog / Off-catalog | 是否纳入医保支付范围的判定结果 |
| [GL-029] | 限定支付范围 | Restricted Payment Scope | 药品目录中对适应症、人群、疗程、线数、机构等级等的支付限制 |
| [GL-030] | 全额统筹项目 | Fully Pooled Item | 全部纳入统筹支付、无需先行自付的诊疗项目 |
| [GL-031] | 部分统筹项目 | Partially Pooled Item | 需个人先行自付一定比例后再纳入统筹的诊疗项目 |
| [GL-032] | 范围外项目 | Out-of-scope Item | 医保不予支付、全额个人负担的诊疗项目 |
| [GL-033] | 准入法 | Positive List Approach | 明列"可报销"清单、清单外不报的目录管理方法 |
| [GL-034] | 排除法 | Negative List Approach | 明列"不予报销"情形、未排除者可报的目录管理方法 |
| [GL-035] | 商保创新药目录 | Commercial Health Insurance Innovative Drug Catalog | 2025 年首版，19 种创新药，医保不支付、供商保参考，与基本医保互补衔接 |
| [GL-036] | 双通道 | Dual-channel | 谈判药品通过定点医院与定点药店两个渠道供应并同步纳入医保支付 |
| [GL-037] | 医保待遇清单制度 | Benefit List System | 统一规范全国医保待遇范围的制度，含基本制度/基本政策/不予支付清单 |
| [GL-038] | 谈判药品 | Negotiated Drug | 经国家医保谈判纳入目录的药品，协议期内统一按乙类支付 |
| [GL-039] | 集中带量采购（集采） | Volume-based Procurement | 以量换价的采购方式，中选价为医保支付标准 |
| [GL-040] | 医保支付标准 | Payment Standard | 医保对药品/耗材的支付基准价，超出部分由参保人承担 |
| [GL-041] | 超限价自付 | Above-standard Co-payment | 实际价格超过医保支付标准的差额部分 |
| [GL-042] | 挂网价格 | Listed Price | 药品在省级集中采购平台的挂网价格 |

## 3. 支付与比例类

| ID | 术语 | 英文参考 | 定义 |
| --- | --- | --- | --- |
| [GL-050] | 医保统筹基金支付 | Pooled Fund Payment | 由基本医疗保险统筹基金支付的金额，即"医保报销"的统筹部分 |
| [GL-051] | 其他支付 | Other Payments | 由大病保险、医疗救助、公务员补助、大额补充、企业补充等基金支付的金额 |
| [GL-052] | 个人账户支付 | Personal Account Payment | 用医保个人账户资金支付的费用（可含目录内外），属个人负担 |
| [GL-053] | 个人现金支付 | Out-of-pocket Cash Payment | 通过现金/银行卡/微信/支付宝等支付的费用 |
| [GL-054] | 个人自付 | Patient Co-payment (In-catalog) | 目录范围内由个人负担的部分（起付线/先行自付/比例自付/封顶线上），为个税大病扣除信息项 |
| [GL-055] | 个人自费 | Self-payment (Off-catalog) | 目录范围外全额由个人负担的费用（含丙类、超限价、非医疗费用） |
| [GL-056] | 自付一 | Co-pay Tier 1 | 报销比例之外的个人负担（含起付线以下、封顶线以上、比例自付）——非全国统一字段 |
| [GL-057] | 自付二 | Co-pay Tier 2 | 乙类等"有自付类"项目的先行自付部分——非全国统一字段 |
| [GL-058] | 分类自负 | Classified Co-payment | 上海口径：医保报销范围内需个人先行负担的部分，等同"自付二" |
| [GL-059] | 个人自负 | Personal Co-payment | 上海口径：医保范围内除分类自负外个人按比例负担的部分，等同"自付一" |
| [GL-060] | 起付标准 / 起付线 | Deductible | 报销前需个人先行支付的目录内费用额度，也称"门槛费" |
| [GL-061] | 最高支付限额 / 封顶线 | Ceiling | 基本医保基金支付的年度上限 |
| [GL-062] | 报销比例（支付比例） | Reimbursement Rate | 起付线以上、封顶线以下，基金对政策范围内费用的支付比例 |
| [GL-063] | 自付比例 | Co-payment Rate | 与报销比例互补，个人在政策范围内承担的比例 |
| [GL-064] | 先行自付比例 | Pre-deductible Ratio | 乙类项目进入报销范围前个人先承担的比例（常见约 10%，区间 3%–30%） |
| [GL-065] | 政策范围内费用 | Policy-scope Expenses | 纳入医保报销范围的费用（= 总费用 − 全自费；甲类全额＋乙类扣除先行自付后部分＋合规项目设施） |
| [GL-066] | 政策范围内报销比例 | Policy-scope Reimbursement Rate | 纳入报销范围的费用中医保支付的占比 |
| [GL-067] | 实际报销比例 / 实际补偿比 | Actual Reimbursement Ratio | 医保支付额 ÷ 医疗总费用（含目录外费用），通常显著低于政策范围内比例 |
| [GL-068] | 符合范围金额 | Eligible Amount | 金额合计 − 个人自费 − 乙类先行自付后的可报基数 |

## 4. 保障层次与险种类

| ID | 术语 | 英文参考 | 定义 |
| --- | --- | --- | --- |
| [GL-070] | 基本医疗保险 | Basic Medical Insurance | 第一支柱，含职工医保与城乡居民医保 |
| [GL-071] | 职工基本医疗保险 | Employee Basic Medical Insurance | 面向用人单位职工与灵活就业人员，设个人账户 |
| [GL-072] | 城乡居民基本医疗保险 | Urban-rural Resident Basic Medical Insurance | 面向非就业居民、学生、儿童、农村居民，无个人账户 |
| [GL-073] | 大病保险 | Critical Illness Insurance (体系内) | 基本医保的拓展延伸，对参保人高额合规自付二次报销（居民） |
| [GL-074] | 大额医疗费用补助 | Large-amount Medical Subsidy | 职工医保中超过基本统筹封顶线或大额自付的补充保障 |
| [GL-075] | 医疗救助 | Medical Assistance | 对特困、低保等困难群众的托底保障（先保险、后救助） |
| [GL-076] | 公务员医疗补助 | Civil Servant Medical Subsidy | 公务员的补充医疗保障 |
| [GL-077] | 企业补充医疗保险 | Enterprise Supplementary Medical Insurance | 企业为职工建立的补充保障 |
| [GL-078] | 惠民保 | Inclusive Urban Customized Insurance | 城市定制型商业补充医疗保险，政府指导、商保承保，一城一策 |
| [GL-079] | 百万医疗险 | Million-yuan Medical Insurance | 高保额（100 万–600 万+）、高免赔（常见 1 万）的商业医疗险 |
| [GL-080] | 中端医疗险 | Mid-end Medical Insurance | 兼顾就医体验（特需/国际部）与费用的商业医疗险 |
| [GL-081] | 高端医疗险 | High-end Medical Insurance | 覆盖私立/国际部/全球医疗、含直付网络的商业医疗险 |
| [GL-082] | 防癌医疗险 | Cancer Medical Insurance | 仅覆盖恶性肿瘤相关治疗的商业医疗险 |
| [GL-083] | 门急诊医疗险 | Outpatient & Emergency Medical Insurance | 覆盖门急诊费用的商业医疗险 |
| [GL-084] | 意外医疗险 | Accident Medical Insurance | 覆盖意外伤害导致医疗费用的商业医疗险 |
| [GL-085] | 税优健康险 | Tax-advantaged Health Insurance | 享受个税税前扣除优惠的商业健康保险（按保费扣除） |
| [GL-086] | 费用补偿型保险 | Indemnity Insurance | 按实际费用报销的商业险，遵循损失补偿原则 |
| [GL-087] | 定额给付型保险 | Fixed-benefit Insurance | 按约定金额给付的商业险（重疾、津贴类），可叠加 |
| [GL-088] | 重大疾病保险 | Critical Illness Insurance (商业) | 确诊约定疾病即给付的商业险（现行行业规范 28 种重疾+扩展） |
| [GL-089] | 住院津贴 | Hospitalization Allowance | 按住院天数给付的商业险 |
| [GL-090] | 免赔额 | Deductible (Insurance) | 商业险中需被保险人自担的起始金额 |
| [GL-091] | 社保身份 | Social Insurance Status | 投保/理赔时是否以基本医保参保人身份，影响赔付比例 |
| [GL-092] | 损失补偿原则 | Principle of Indemnity | 补偿型保险赔付不超过实际损失的原则 |
| [GL-093] | 既往症 | Pre-existing Condition | 投保前已存在的疾病或症状，未告知不赔 |
| [GL-094] | 等待期 | Waiting Period | 保单生效后需经过的期间，期间内疾病出险不赔（意外除外） |
| [GL-095] | 一站式结算 | One-stop Settlement | 医保与商保/大病保险同步结算，无需事后申报 |

## 5. 制度与经办类

| ID | 术语 | 英文参考 | 定义 |
| --- | --- | --- | --- |
| [GL-100] | 门诊共济 | Outpatient Mutual-aid | 将职工医保普通门诊费用纳入统筹基金报销的制度（2021 年改革） |
| [GL-101] | 门诊统筹 | Outpatient Pooling | 门诊费用的统筹保障机制（居民医保为主） |
| [GL-102] | 门诊慢特病 | Outpatient Chronic & Special Disease | 门诊慢病与特病按住院比例报销的保障通道（Ⅰ/Ⅱ 类，需先认定） |
| [GL-103] | 家庭共济 | Family Mutual-aid | 个人账户资金可供近亲属使用的机制（仅钱共济、卡不共用） |
| [GL-104] | 医保钱包 | Medical Insurance Wallet | 全国统一医保信息平台中的虚拟额度载体，用于跨省共济 |
| [GL-105] | 当年账户 | Current-year Account | 医保年度起始时计入个人账户的资金 |
| [GL-106] | 历年账户（历年结余） | Accumulated Account Balance | 当年账户年度末结转形成的结余资金（家庭共济通常仅限历年资金） |
| [GL-107] | 医保年度 | Insurance Year | 部分地区非自然年度（如上海 7 月 1 日—次年 6 月 30 日） |
| [GL-108] | 定点医药机构 | Designated Medical Institution / Pharmacy | 与医保经办机构签订服务协议的机构 |
| [GL-109] | 异地就医备案 | Cross-region Filing | 异地就医前向参保地备案，方可享受直接结算 |
| [GL-110] | 就医地目录 | Host-city Catalog | 异地直接结算时按就医地目录确定可报范围 |
| [GL-111] | 参保地政策 | Home-city Policy | 异地直接结算时按参保地政策确定起付线、比例、限额 |
| [GL-112] | 零星（手工）报销 | Manual Reimbursement | 垫付后向参保地申报的报销方式（执行参保地目录） |
| [GL-113] | 联网定点医疗机构 | Networked Designated Institution | 支持跨省直接结算的定点机构 |
| [GL-114] | DRG | Diagnosis Related Groups | 按病组付费，住院打包付费方式 |
| [GL-115] | DIP | Big Data Diagnosis-Intervention Packet | 按病种分值付费，住院打包付费方式 |
| [GL-116] | 按床日付费 | Per-diem Payment | 按住院天数打包付费 |
| [GL-117] | 按人头付费 | Capitation | 按服务人数打包付费 |
| [GL-118] | 分级诊疗 | Tiered Diagnosis and Treatment | 按机构等级分工的诊疗制度，影响报销比例 |
| [GL-119] | 转诊单 | Referral Form | 三级转诊医院开具的异地转诊凭证 |
| [GL-120] | 承诺制备案 | Commitment-based Filing | 以个人承诺书先行办理、事后补材料的备案方式 |
| [GL-121] | 容缺受理 | Deficient-material Acceptance | 材料不全先行受理、限期补齐的经办方式 |
| [GL-122] | 生育保险 | Maternity Insurance | 覆盖生育医疗费用与生育津贴的社会保险（职工个人不缴费） |
| [GL-123] | 生育津贴 | Maternity Allowance | 对女职工产假期间收入损失的补偿（单位月均工资÷30×计发天数） |
| [GL-124] | 产前检查基本服务包 | Basic Antenatal Care Package | 推荐目录式的基础产检项目组合（部分地区全额保障） |
| [GL-125] | 长期护理保险 | Long-term Care Insurance | 覆盖长期失能人员护理费用的独立险种（全国统一 36 项服务目录） |
| [GL-126] | 特药 | Special Drug | 癌症/罕见病等高值门诊药品，需资格认定，按特药目录/双通道管理 |

## 6. 税务与监管类

| ID | 术语 | 英文参考 | 定义 |
| --- | --- | --- | --- |
| [GL-130] | 大病医疗专项附加扣除 | Serious Illness Medical Deduction | 个税专项附加扣除项，依"个人自付"口径，年度累计超 1.5 万部分在 8 万限额内据实扣除 |
| [GL-131] | 年度汇算清缴 | Annual Tax Settlement | 个人所得税年度汇总结算（次年 3/1—6/30），办理专项附加扣除的时点 |
| [GL-132] | 医疗保障基金使用监督管理条例 | Regulation on Supervision of Medical Security Fund Use | 国务院行政法规（令第 735 号），规范基金使用与法律责任 |
| [GL-133] | 欺诈骗保 | Insurance Fraud | 以虚假手段骗取医保基金的行为（退回+2—5 倍罚款，情节严重涉诈骗罪） |
| [GL-134] | 举报奖励 | Whistleblower Reward | 举报欺诈骗保行为的奖励机制 |

| [GL-148] | 一品两规 | One Drug Two Specifications | 医疗机构药品配备的数量限制，谈判药品可不受此限 |

| [GL-150] | 自费率指标 | Self-payment Rate Indicator | 医疗机构医保患者自费比例的考核指标（商保创新药不纳入） |
| [GL-151] | 补充保险 | Supplementary Insurance | 在基本保障之上的额外保险安排 |
| [GL-152] | 预缴金额 | Prepaid Amount | 住院入院时预交的押金 |
| [GL-153] | 补缴金额 | Supplementary Payment | 结算时需补交的金额 |
| [GL-154] | 退费金额 | Refund Amount | 结算时应退还的金额 |

## 8. 检索版知识库补充术语

| 术语 | 定义 |
| --- | --- |
| 医保统筹基金 | 由单位/财政等筹资形成、社会共济使用的基金，支付"医保报销"部分 |
| 费用补偿型/定额给付型 | 见 [GL-086]/[GL-087]；判定是否要发票、能否重复赔 |

| 乙类先行自付 | 乙类费用先由个人承担的比例部分（自付二/分类自负） |
| 双向享受待遇 | 异地备案后在参保地、备案地两地均可享受医保待遇 |
| 亲情账户 | 医保平台中帮家人（如老人小孩）展示医保码的代办功能，≠ 家庭共济账户 |
