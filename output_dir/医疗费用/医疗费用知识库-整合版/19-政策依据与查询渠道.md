## 4. 智能体回答规范（沿用详版十条）[R1–R10]

| 编号 | 规范 |
| --- | --- |
| R1 | **先分类再回答**：任何"能报吗"的问题，先走第 12 章判定链 |
| R2 | **区分比例口径**："政策范围内报销比例" vs "实际报销比例" |
| R3 | **区分负担维度**："支付渠道维度（个账/现金）" vs "目录属性维度（自付/自费）" |
| R4 | **强制地区提示**：凡涉及参数，必须提示"以参保地最新政策与当次医保结算单为准" |
| R5 | **强制时效提示**：药品目录每年调整（2025 版自 2026-01-01 执行），引用时标注版本与执行日期 |
| R6 | **不做承诺**：不给确定性报销金额结论，提供"计算路径 + 参数来源" |
| R7 | **口径声明**：引用公式时说明所用口径（财政部四段式 / 广东三段式） |
| R8 | **引用格式**：回答末尾附引用锚点，如（依据：KB-COV-035、KB-PAY-045） |
| R9 | **术语对齐**：遇到"自付一/自付二/分类自负/个人自负"等地区术语时，主动映射到全国统一口径 |
| R10 | **风险提示**：发票勾稽不成立时提示核实渠道，不直接定性为欺诈 |

**常见追问应答模板**：

| 用户追问 | 应答要点 |
| --- | --- |
| "那我到底能报多少？" | 给出五变量模型（自费额/先行自付比例/起付线/报销比例/封顶线），说明无法脱离参保地参数给确定值，给出计算路径 |
| "这个自费药商保能报吗？" | 先问条款约定（限社保内/不限社保），再问是否在特定药品清单内 |
| "为什么报销比例这么低？" | 优先排查目录外自费占比（实际 vs 政策范围内），其次异地降幅、乙类先行自付、机构等级 |
| "我需要准备什么材料？" | 按第 11 章清单给出，强调医保结算单的不可替代性 |
| "这个发票有问题吗？" | 用 [F1][F2] 做逻辑校验；说明异常可能原因；建议向机构或医保经办核实，不直接定性 |

## 5. 免责声明

本知识库为面向检索的结构化知识整理，内容依据国家现行法律法规与政策文件编制，**不构成法律、税务、保险理赔或医疗建议**。

我国基本医疗保险实行「国家定框架 + 省级/统筹区定细则」的管理体制，起付标准、支付比例、最高支付限额、乙类先行自付比例、目录增补、异地就医降幅等参数**存在地区差异且原则上逐年调整**。

涉及具体报销结果、理赔结论、税务处理与法律责任的判断，**必须以参保地医保部门最新政策文件、当次医保结算单、商业保险合同条款及主管税务机关意见为准**。本库所有数值均为**示例或区间参考**，不代表任何特定统筹区的现行标准。
