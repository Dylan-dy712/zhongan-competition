## 1. 使用前的边界声明

1. **地方差异**：医保为**地市级统筹**。起付线、报销比例、封顶线、乙类先行自付比例、大病保险分段、救助比例与限额、目录细化、备案规则均**各地不同且逐年调整**，一律以**参保地医保局最新政策**为准。本库给出全国统一规则 + 典型数值区间 + 示例城市数值（均已标注）。
2. **不推算个人负担**：本库解释规则与票面字段含义；用户实际负担必须依据其真实**结算单/理赔决定书**核算，缺少证据时不可推算。
3. **非投保/理赔建议**：商业保险一律以**保险合同条款 + 保单特别约定**为准；本库产品描述为行业通行形态。
4. **金额单位**默认人民币元。"年度"医保口径各地不同（如上海为当年 7/1—次年 6/30），商业险指保单年度。

## 2. 事实分级（检索时按此采信）

- **[统一规则]**：全国性法律法规/部门规章明文，长期有效（票据字段与勾稽、三大目录分类、法定不支付情形、理赔原则、产品分类）。
- **[地区数值]**：来自具体城市官方文件，仅代表该地该年度，其他地区不可套用（上海、安徽、南宁、湖南、昆明、北京、庆阳、滨州、深圳、武威、芜湖、漯河、福建等示例均已标注）。
- **[假设示例]**：`[EX-nnn]` 等案例数字为演示算法而假设，非真实标准，不得作为事实引用。
- **[规则推演]**：场景判定表中医疗事故、食物中毒、动物致害等，是把"第三人负担"规则结合《民法典》《食品安全法》的适用，结论随责任认定而变。
- **[经验区间]**：产品参数区间（如小额住院保额、特药险保额）为行业常见范围，具体以条款为准。

## 3. 核心结论与公式速查

**三层核心结论**：
1. **模型层**：一张医疗发票可分解为**两个正交维度**——"资金维度（谁出钱：统筹/其他/个账/现金）"与"目录属性维度（医保管不管：统筹/其他/自付/自费）"。二者的个人负担金额**必然相等**。[KB-PAY-002]
2. **范围层**：医保"能报什么"由**目录**决定，目录外一律不报；目录内还要叠加**限定支付范围**与**法定不予支付情形**两道校验。[KB-COV-003]
3. **金额层**：报销后自付金额由五个变量共同决定——`目录外自费额、乙类先行自付比例、起付标准、报销比例、年度最高支付限额`，**无法脱离参保地参数给出确定结论**。[KB-RATE-030]

**核心公式**：
```
[F1] 金额合计 = 医保统筹基金支付 + 其他支付 + 个人账户支付 + 个人现金支付
[F2] 个人负担 = 个人账户支付 + 个人现金支付 = 个人自付 + 个人自费
[F3] 符合基本医保支付范围金额 = 金额合计 − 个人自费 − 乙类先行自付
[F4] 医保统筹基金支付 = (符合范围金额 − 起付标准) × 报销比例（封顶线内）
[F5] 个人现金支付 = 金额合计 − 医保统筹基金支付 − 其他支付 − 个人账户支付
[F6] 政策范围内报销比例 = 医保支付额 ÷ 符合范围金额
[F7] 实际报销比例（实际补偿比） = 医保支付额 ÷ 金额合计
[F8] 商保赔付额 = (合理费用 − 医保已报 − 其他支付 − 免赔额) × 赔付比例
```
个税大病扣除：`min(年度目录内个人自付累计 − 15000, 80000)`，据实扣除。

## 4. 口径差异与归一说明（三源冲突点处理）

整合中发现以下口径差异，按"更准确/更完整"的表述归一，并在此留痕：

| 争议点 | 各源表述 | 本库归一口径 |
| --- | --- | --- |
| 法定不予支付情形 | 详版/kb：六类（待遇清单口径）；票知库：法定四类 | 《社会保险法》第 30 条**法定四类**；国家医保待遇清单制度扩展为**六类**（+体育健身/养生保健/健康体检、+国家规定其他）。两者并存不矛盾，见第 12 章 |
| 起付线计算 | 详版：按自然年度累计；kb：住院按次、多次递减；票知：各地不同 | **门诊统筹多按年度累计；住院多按次计算**（每次住院承担），部分统筹区年内多次住院递减或按年累计。见第 7 章统一说明 [KB-LINE-010] |
| 乙类先行自付比例 | 5%–30% / 10%–30% / 常见 10% 且 3%、8%、20% 并存 | **全国无统一比例，常见约 10%，区间约 3%–30%**；个别地市极低（如深圳市内乙类约 1%）；湖北已全省统一 10% |
| 未走社保商保赔付比例 | 60% / 60%–80% | 常见降至 **60%**，部分产品/特定情形 80%，以条款为准 |
| 惠民保免赔额 | 1–2 万 / 1–3 万 | 常见 **1–3 万元**，多在 1–2 万；部分与当地大病起付线共用不重复计算 |
| 大病保险起付线 | 1.1–1.5 万 / 1–2 万量级 | 常见 **1–2 万元量级**，多与上年度居民人均可支配收入挂钩 |
| 发票口径切分 | 财政部四段式（其他支付单列）/ 广东三段式（并入统筹） | 两种口径并存不矛盾，颗粒度不同，引用时须声明口径 [KB-FIELD-091] |
| 门诊慢特病跨省直接结算病种 | kb：10 种（2024 年底起）；详版：以最新公布为准 | 采用 kb 明细：**10 种**（病种清单见第 13 章），以国家医保局最新公布为准 |

## 7. 维护建议

- 数值类内容（比例、起付线、目录版本、产品形态）随政策与市场变动，建议**每年复审一次**：每年 12 月药品目录发布后更新第 06 章；惠民保产品年度迭代后更新第 09 章；各地门诊共济参数调整后更新第 07 章。
- 一致性校验：定期用公式 [F1][F2] 校验示例数据；用第 12 章判定链校验判定类条目。
- 各文内虚构示例仅用于演示口径，禁止当作真实报销数据传播。
